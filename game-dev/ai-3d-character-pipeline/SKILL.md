# AI 3D 角色生产线

## 何时调

- "用 AI 做一个 3D 角色 / 游戏主角"
- "T-pose 四视图怎么出"
- "生成的模型怎么绑骨蒙皮 / 为什么会变形"
- "Mixamo 动作怎么接到自己的角色上"
- "角色要拿东西 / 碰到道具，怎么才不像穿模"

## 不适用

- 场景/关卡搭建（走 `ai-3d-scene-pipeline`）
- 骨骼动画的**美术表现**（表演、镜头）——这里只管资产与绑定
- 已有角色只缺动作库 → 直接看第 6 节

## 零、核心链路

> T-pose 四视图 → Tripo Smart Mesh P2.0 → 白模检查 → 贴图 → Auto-Rig Pro 绑骨蒙皮 →
> Mixamo 动作 → 重定向 →（可选）IK 手部/道具接触精调

每一步的产物都是**下一步的输入**，中间任何一步跳过都会在后面加倍还回来。

## 一、步骤 1：T-pose 四视图

用图像模型出标准 **T-pose**（正视 / 背视 / 左视 / 右视）。

硬要求：
- **四个视角服装、比例、发型、配色高度一致**——不一致会被 Tripo 融合成"四不像"。
- 必须是 T-pose（双臂水平张开），因为骨骼绑定要靠这个姿态定位关节。
- 视角顺序在提示词里写死："正面、背面、左侧面、右侧面"。

可复用提示词见 `references/prompts.md` §T-pose 四视图。

## 二、步骤 2：Tripo 生成（Smart Mesh P2.0）

用 Tripo 的**「多视图生成 3D」**，按顺序上传四视图。

参数选择（角色专用，作者实测）：
- 拓扑 = **四边形（quad）** → 便于绑骨与动画
- 精度 = **最高**
- 模型 = **Smart Mesh P2.0**（面数可控、拓扑规整，专为游戏/交互内容设计）

不要用静态资产那套高精度模型出角色：面数高、拓扑乱，蒙皮直接崩。

## 三、步骤 3：白模检查（贴图之前）

**先看白模**再决定贴图：

- 网格整齐无误 → 直接点 **Texture** 生成贴图。
- 局部网格形状不合理 → 用 **Edit Mesh** 局部重绘再重新生成。

跳过这步的代价：贴图会把错误拓扑放大成"贴歪 + 后续绑骨失败"，返工成本翻倍。

## 四、步骤 4：Auto-Rig Pro 自动绑骨 + 蒙皮

要求：骨骼位置与人物关节**精准对齐**。绑完必须做**动作测试**：
抬手、弯腿、转身，检查变形 / 拉扯 / 穿模。

可复用提示词见 `references/prompts.md` §自动绑骨、蒙皮与动作测试。

没有 Auto-Rig Pro 时：要么手工在 Blender 里摆骨骼（成本高），要么先用 Mixamo 的
"自动绑骨"（Mixamo 上传模型自动加骨架 + 动作）跳过 Blender 环节——但拓扑脏的角色在
Mixamo 上更容易失败。

## 五、步骤 5：Mixamo 动作获取

1. 去 <https://www.mixamo.com/> 按关键词搜动作（行走 / 跳跃 / 挥手 / 坐下…），下载 `.fbx`。
2. 交给 AI 检查**动作数据是否匹配角色的真实骨骼结构**，并在 Blender 或引擎里完成接入与**重定向**。
   骨骼命名/骨长不匹配时，角色会"滑步"或"关节穿帮"。

## 六、步骤 6：复杂交互精调（进阶，可选）

通用动作库处理不了"人与道具发生物理接触"（如提水壶、握剑、拉门把手）。

解法（作者做法）：
1. 在 Mixamo 里挑一个**姿势最接近**的基础动作。
2. 在 Blender 里用 Auto-Rig Pro 的**手臂 IK 控制器**做局部修正，配合手指握持姿态与道具空间位置修正补全动作。

硬性验收：手掌与道具把手**接触稳定**，提起过程自然流畅，不出现穿模 / 握持脱离 / 道具悬空。

可复用提示词见 `references/prompts.md` §复杂交互与 IK 手部精调。

## 七、验收判据

- [ ] 四视图一致（同服装、同比例、同配色）
- [ ] 生成模型为四边面拓扑、白模无明显错误面
- [ ] 绑骨后骨骼与关节对齐，抬手/弯腿/转身无拉扯、无穿模
- [ ] Mixamo 动作重定向后无滑步、无穿帮
- [ ] （若涉及道具）接触稳定，无悬空/脱离

## 八、常见坑

| 坑 | 后果 | 防 |
|---|---|---|
| 四视图不一致 | 生成的角色"四不像" | 一致性优先，必要时逐视图单独生成再拼 |
| 用静态高精度模型出角色 | 拓扑乱，蒙皮崩 | 角色一律 Smart Mesh P2.0 + 四边面 |
| 直接贴图不看白模 | 错误被固化 | 白模 → Texture / Edit Mesh 分支 |
| 绑完不测动作 | 变形留到引擎里才炸 | 抬手/弯腿/转身三项必测 |
| 动作不重定向 | 滑步、穿帮 | 对骨骼结构做匹配检查 |
| 复杂动作硬套 Mixamo | 穿模/悬空 | 基础动作 + IK 局部精调 |
