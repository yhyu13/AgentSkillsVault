# 替换方案表

不删除，要替换。填完这张表才算方案成立。

## 一、定位空档

| 项 | 你的答案 |
|---|---|
| 不该做的动作 |  |
| 它占用的具体时间 |  |
| 触发点（什么前置动作或位置引出它） |  |
| 不做之后空出来的位置（手 / 眼 / 时间） |  |

## 二、设计替换动作

替换动作必须同时满足三条，缺一条都不成立：

- [ ] 上手阻力明显更低（不需要准备、不需要启动成本）
- [ ] 能和原触发点绑定（在同一个时间、同一个位置、同一个前置动作之后就能做）
- [ ] 自带过程乐趣（不是又一个要逼自己完成的任务）

| 项 | 你的答案 |
|---|---|
| 替换动作 |  |
| 它和原触发点怎么绑定 |  |
| 它的过程乐趣是什么 |  |
| 需要动环境吗（手机放哪、东西摆哪） |  |

## 三、先改触发点，再放替换

1. 改环境：把原动作的触发物移出原位。
2. 放替换：在原位放上替换动作需要的东西。
3. **两个都改才算成立**，只改一个会失败。

## 四、兜底

| 情况 | 降级动作 |
|---|---|
| 替换动作做不起来 |  |
| 空档被第三个动作填了 |  |
| 连续一周失效 |  |

## 五、两周后回看

- 新动作是否自己长住了（不需要每天决定）。
- 如果它也需要每天逼自己，说明它不够「低阻力」，换一个更便宜的。
- 如果空档被别的东西填了，说明环境没改干净，回到第三节。
