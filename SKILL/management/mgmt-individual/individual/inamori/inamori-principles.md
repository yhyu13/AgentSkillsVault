# 稻盛和夫 · 六项精进与经营十二条

> 六项精进是个人修行的地基，经营十二条是企业经营的梁柱——心性修到什么程度，经营就能走到什么高度。

## 核心理念

稻盛和夫要解决的根本问题是：**一个普通人，凭什么能做出不普通的经营成果？**

他的回答是：靠心性。不是靠天赋、不是靠资源、不是靠运气，而是靠"提高心性，拓展经营"——心性和经营之间不是因果关系，而是同一枚硬币的两面。心性提高了，经营自然拓展；经营遇到瓶颈，根源一定在心性上。

这个命题有三个支撑判断：第一，稻盛和夫本人27岁创办京瓷时既无资金也无技术更无经验，唯一有的是"无论如何必须成功"的强烈愿望和拼命工作的态度——京瓷后来成为世界500强；第二，52岁创办KDDI（第二电电），同样从零进入完全陌生的通信行业，再次成为世界500强——两次成功证明不是偶然；第三，78岁出山重建日航，仅用一年时间从破产到重新上市、利润创历史新高——用的是同一套哲学，证明方法论可迁移。

六项精进源于稻盛和夫1978年在京瓷提出的年度口号："胸中怀有渗透到潜意识的强烈愿望，以燃烧的激情去实现自己设定的目标"。后来他将其提炼为六条，并明确说这六条"既是搞好企业经营的最基本条件，也是度过美好人生的最基本条件"——它同时适用于经营和人生。

经营十二条则是稻盛和夫将京瓷和KDDI两次创业的成功经验系统化提炼的结果。2010年重建日航时，他再次用这十二条指导经营，一年内扭亏为盈。六项精进和经营十二条的关系：六项精进=个人修行层面，经营十二条=组织经营层面，两者是同一哲学的两层表达。

## 关键模块

### 模块1：六项精进（个人修行层面）

- 定义：稻盛和夫提炼的六条个人修行准则，既是搞好企业经营的最基本条件，也是度过美好人生的最基本条件；六条不是并列关系，而是有先后逻辑——努力是前提，谦虚是防线，反省是机制，感谢是根基，利他是方向，去烦恼是保障
- 输入：个人的日常行为+内心状态+工作态度
- 输出：持续提高的心性水平+自然拓展的经营成果
- 关键动作：
  - 付出不亚于任何人的努力：拼命工作是一切的前提；自然界所有生物都在拼命生存，只有人类想偷懒；稻盛和夫说"努力中蕴含快乐"——当你真正全身心投入工作，工作本身就会带来喜悦；这不是苦行，而是发现工作意义的过程
  - 要谦虚，不要骄傲：惟谦受福——成功后最容易骄傲，骄傲是衰败的入口；谦虚不是自卑，而是清醒地认识到一切成就离不开他人的帮助和时代的机遇；谦虚是福气的入口
  - 要每天反省：每天回顾自己是否有自私自利的行为；反省不是自责，而是净化心灵——就像每天洗澡清洁身体一样，心灵也需要日日清洗；稻盛和夫每天临睡前反省当天的言行
  - 活着，就要感谢：感谢是幸福的起点；对困难也感谢——困难是成长的机会；感谢改变心态——从"为什么是我"转向"感谢让我经历"；感谢不是对结果的满意，而是对过程的态度
  - 积善行，思利他：行善积德，利他行为产生善果；因果报应不是迷信，而是长期行为的统计规律——持续利他的人会积累信任和善意，这些在关键时刻会转化为帮助和机会
  - 不要有感性的烦恼：不因情绪烦恼，理性面对，乐观向前；感性的烦恼消耗能量但不解决问题；稻盛和夫说"已经发生的事无法改变，为它烦恼是浪费生命"
- 常见误区：把六项精进当作道德说教——它们是实践准则不是道德评判，核心是"这样做有效"而非"这样做高尚"；把努力等同于加班——努力是全身心投入的状态，不是时间长度；把感谢等同于满意——感谢是对过程的态度，不是对结果的妥协；把利他等同于牺牲——利他是行为方向，利他最终利己

### 模块2：经营十二条（企业经营层面）

- 定义：稻盛和夫将京瓷和KDDI两次创业的成功经验系统化提炼的十二条经营原则，每一条都是实践的结晶而非理论的推演；2010年重建日航时再次验证了十二条的有效性
- 输入：经营者的心性+企业面临的现实+员工的共识
- 输出：可持续的经营成果+全员共有的经营哲学
- 关键动作：
  - 明确事业的目的和意义：大义名分——事业的目的必须光明正大，上升到信念高度；不是为了赚钱，而是为了社会、为了他人；京瓷的目的是"追求全体员工物质和精神两方面的幸福"，日航的目的是"为了留住日航的员工，为了对日本经济做出贡献"
  - 设立具体目标：目标必须具体可量化，不能是"努力提高销售额"而必须是"月度销售额达到X亿"；年度目标分解为月度目标，月度分解为每日目标；目标必须全员共有——每个员工都清楚今天的目标是什么
  - 胸中怀有强烈的愿望：愿望必须渗透到潜意识——日思夜想、吃饭想、走路想、睡觉也想；当愿望进入潜意识，你会在不知不觉中做出导向目标的行为；稻盛和夫说"心不唤物物不至"——内心不渴望的东西不会来到身边
  - 付出不亚于任何人的努力：与六项精进第1条重合，是经营的基础；不亚于任何人=不是一般努力，而是比任何竞争者都更努力；稻盛和夫说"只要你全力以赴，神都会出手相助"
  - 销售最大化，经费最小化：利润不需要追逐，是结果——销售做到最大、经费压到最小，利润自然产生；不需要复杂的利润计算，只需要持续追问"销售额还能不能再提高一点？经费还能不能再减少一点？"；单位时间附加值=（销售额-经费）÷总时间，这是阿米巴经营的核心指标
  - 定价即经营：价格由市场决定，定价者即经营者；价格定错了，一切全错——再怎么努力也无法弥补定价失误；定价必须找到客户愿意接受的最高价格，同时确保在这个价格下还能产生利润；定价不是财务问题，是经营者的核心判断
  - 坚强的意志：经营需要不屈不挠的意志，如岩石般坚定；一旦设定目标就必须达成，不因困难退缩，不因反对动摇；坚强的意志不是固执，而是基于大义名分的坚定
  - 燃烧的斗魂：经营者需要战斗精神，像斗士一样保护员工和企业；企业面临危机时，经营者必须第一个站出来战斗；斗魂不是攻击性，而是守护的力量
  - 拿出勇气做事：正确的事要有勇气去做，不可怯懦；经营中经常面临艰难决策——裁员、退出、改革——没有勇气就无法做出正确选择；勇气不是没有恐惧，而是明知恐惧仍然行动
  - 不断从事创造性的工作：明天胜过今天，每天创新；不要满足于现状，永远寻找更好的方法；用未来进行时定义能力——不因现有能力否定课题，相信能力会随挑战而增长；稻盛和夫说"每天哪怕只进步一点点，一年就是365点进步"
  - 以关怀坦诚之心待人：利他之心在经营中的体现；买卖是相互的——不能只考虑自己赚钱，要让对方也获益；坦诚=不欺骗、不隐瞒、不敷衍；关怀不是软弱，而是赢得人心的力量
  - 始终抱有乐观向上的心态：乐观面对一切，困境中更要开朗；悲观的人看不到机会，乐观的人能在危机中发现转机；乐观不是盲目，而是基于"只要方向正确、全力以赴就一定能成功"的信念
- 常见误区：把十二条当作管理工具——它们是经营哲学不是操作手册，核心是改变经营者的心性而非提供具体方法；把"利润是结果"理解为不需要关注利润——恰恰相反，需要极度关注销售和经费，只是不把利润本身当目标；把"强烈的愿望"等同于空想——愿望必须配合行动，没有行动的愿望只是幻想；把"定价即经营"理解为价格越高越好——定价是找到客户愿意接受的最高价且能产生利润的平衡点

### 模块3：领导人的资质

- 定义：稻盛和夫认为领导人不是靠权力驱动下属，而是靠人格魅力和使命感感召团队；领导人的资质不是天生的，而是通过持续修行获得的
- 输入：领导人的心性水平+使命感+自律程度
- 输出：团队的信任+组织的凝聚力+大义名分的传递
- 关键动作：
  - 领导人必须具备5项资质：使命感（为什么做）、责任感（对结果负责）、公正（不偏私）、勇气（敢于做正确的事）、自律（以身作则）
  - 领导人不可将天赋才能据为私有：才能是上天暂时寄存在你这里的，必须用于群体而非个人；稻盛和夫说"才能是公器"——把才能当作私有财产的人，才能会枯竭
  - 站得住高位，待得了低层：领导人既能站在高处指引方向，也能沉到一线与员工并肩工作；稻盛和夫重建日航时亲自走访一线，与空乘和地勤面对面交流
  - 以身作则传递大义名分：领导人必须第一个践行自己倡导的价值观；如果领导人说"要努力"自己却不努力，没有人会跟随
- 常见误区：把领导人资质等同于领导技巧——技巧是表层的，资质是深层的；把"才能是公器"理解为自我牺牲——公器意味着才能的使用方向是为群体创造价值，不是否定个人；把"站得住高位"理解为集权——高位是指视野和担当，不是权力集中

### 模块4：盛和塾教育体系

- 定义：稻盛和夫1983年创办的经营学习组织，义务传授经营哲学近40年；盛和塾不是商学院，而是"实践道场"——学习、实践、分享三位一体
- 输入：塾生的经营困惑+稻盛和夫的哲学指导+塾生间的实践经验
- 输出：塾生经营能力的提升+经营哲学的实践验证+塾生间的互助网络
- 关键动作：
  - 学习：研读稻盛和夫的著作和演讲，理解经营哲学的核心
  - 实践：将哲学应用到自己的企业经营中，用结果验证
  - 分享：在塾长例会上分享实践经验和成果，互相启发
  - 全球9000+塾生，覆盖日本、中国、美国等多国
  - 稻盛和夫亲自出席塾长例会，逐一点评塾生的经营问题——近40年从未间断
- 常见误区：把盛和塾当作商学院——盛和塾教的是心性不是技巧；把塾生的成功完全归因于稻盛哲学——塾生的成功有多重因素，稻盛哲学是其中之一；认为盛和塾模式可复制——稻盛和夫的个人魅力和近40年的义务投入是不可复制的核心要素

### 模块5：用未来进行时定义能力

- 定义：不要因为现有能力不足就否定课题，而要预见未来能力的提升来定义当下的行动边界；能力会随挑战而增长，用"未来进行时"来设定目标
- 输入：当前能力评估+目标课题+成长意愿
- 输出：超越现有能力限制的目标设定+能力随挑战增长的实际结果
- 关键动作：
  - 不因现有能力否定课题：如果因为"现在做不到"就不做，永远不会有突破；稻盛和夫在京瓷早期接到IBM的严苛订单时，现有技术完全达不到要求，但他没有拒绝，而是说"现在做不到，但到时候一定做得到"
  - 预见未来能力提升：相信人在面对挑战时会激发出潜在能力；能力不是静态的存量，而是动态的增量
  - 外行优势：稻盛和夫说"技术开发必须由外行来做"——外行没有思维定式，只有纯粹的愿望；纯粹的愿望进入潜意识，驱动人日思夜想地寻找解决方案；半专家有太多"不可能"的先入之见，反而束缚创造力
  - 技术开发必须由外行来做：京瓷的很多技术突破都是"外行"完成的——他们不知道什么不可能，所以做到了可能
- 常见误区：把"用未来进行时定义能力"等同于盲目乐观——乐观必须配合拼命努力，没有行动的乐观是妄想；把"外行优势"理解为不需要专业知识——外行优势是思维不受限，不是无知即力量；忽视能力增长的时间维度——能力确实会增长，但不是瞬间增长，需要合理的成长周期

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 判断是否接受挑战性课题 | 如果现有能力不足但方向正确→接受，用未来进行时定义能力；如果方向本身错误→拒绝，能力再强也不做 | 用未来进行时定义能力 |
| 面对经营困境 | 如果困境中情绪低落→先调整心态（乐观向上），再分析问题（理性面对），最后全力行动（付出不亚于任何人的努力） | 经营十二条第12条+第4条 |
| 设定经营目标 | 如果目标不可量化→重新设定，必须具体到数字；如果目标只有经营者知道→必须全员共有 | 经营十二条第2条 |
| 定价决策 | 如果定价只考虑成本→方向错误，定价必须从市场出发；如果定价后利润不确定→重新定价，定价即经营 | 经营十二条第6条 |
| 成功后心态调整 | 如果成功后开始骄傲→立即反省，惟谦受福；如果开始归功于自己→记住才能是公器 | 六项精进第2条+领导人资质 |
| 日常行为校准 | 如果今天没有反省→临睡前补上日日反省；如果对他人缺乏感谢→练习对困难也感谢 | 六项精进第3条+第4条 |
| 判断是否需要勇气 | 如果知道正确但不敢做→必须拿出勇气，怯懦是经营的大敌；如果不确定是否正确→先确认大义名分 | 经营十二条第9条+第1条 |
| 面对创新停滞 | 如果满足于现状→每天追问"明天怎么比今天更好"；如果用现有能力否定新课题→切换到未来进行时 | 经营十二条第10条 |
| 利润出现问题时 | 如果直接追利润→方向错误，应追问"销售额还能提高吗？经费还能减少吗？" | 经营十二条第5条 |
| 选择团队成员 | 如果只看能力→不够，还要看心性；如果有能力但自私→不选，利他是方向 | 六项精进第5条+领导人资质 |

|-----------|------|------|
| 德鲁克卓有成效 | 对比-西方效率vs东方心性 | 德鲁克问"如何做对的事"（效果逻辑），稻盛问"心性到了什么程度"（心性逻辑）；德鲁克从行为入手，稻盛从心性入手；两者都认为管理可以学会，但路径不同——德鲁克靠结构化实践，稻盛靠持续修行 |
| 华为干部管理 | 对比-流程选拔vs心性修炼 | 华为通过流程和制度选拔干部（ATI/ATB/ATC），稻盛通过心性修炼培养领导人；华为是"制度出干部"，稻盛是"心性出领袖"；华为的干部标准可量化，稻盛的领导人资质偏主观 |
| Netflix Candor | 对比-坦诚反馈vs反省净化 | Netflix的坦诚是向外的——给别人直接反馈；稻盛的反省是向内的——审视自己的自私和不足；Netflix靠外部反馈纠正行为，稻盛靠内部反省净化心性；方向相反但目的相同：消除盲区 |
| 阿里管理三板斧 | 并行-管理者教育 | 阿里三板斧（定战略/造土壤/拿结果）和稻盛经营十二条都是管理者教育体系；阿里偏技能训练（怎么做），稻盛偏心性修炼（怎么想）；两者都强调领导人的使命感 |
| 胖东来员工尊严 | 并行-关怀之心 | 胖东来的"用真品换真心"和稻盛的"以关怀坦诚之心待人"都强调利他；胖东来把关怀制度化（委屈奖/不开心假），稻盛把关怀哲学化（利他是行为方向）；胖东来是关怀的制度化，稻盛是关怀的心性化 |
| 阿米巴经营 | 下游-哲学的制度化 | 阿米巴经营是稻盛哲学的制度化实现——"销售最大化、经费最小化"通过阿米巴核算落地，"全员共有"通过阿米巴自主经营实现；没有稻盛哲学的阿米巴只是核算工具，有哲学的阿米巴才是经营体系 |
| 利他哲学 | 上游-心性基础 | 利他哲学是稻盛一切方法论的心性基础——六项精进第5条"积善行思利他"、经营十二条第11条"以关怀坦诚之心待人"、领导人"才能是公器"，都源于利他哲学；利他不是道德要求，而是"利他最终利己"的实践智慧 |

## 适用场景

### 最适合

- 中小企业创始人/经营者的自我修炼——六项精进和经营十二条最初就是为经营者设计的
- 企业从0到1阶段——强烈的愿望+拼命努力+用未来进行时定义能力，是创业期的核心方法论
- 企业危机重建——日航重建证明稻盛哲学在危机场景的有效性
- 领导人培养——领导人5项资质+以身作则+才能是公器，是领导人教育的完整框架
- 个人职业发展——六项精进同时是"度过美好人生的最基本条件"

### 不适合

- 高度成熟的规模化企业日常运营——十二条偏宏观，日常运营需要更具体的流程和工具
- 需要严格数据驱动的决策场景——稻盛哲学强调心性和直觉，与纯数据驱动有张力
- 快节奏互联网产品迭代——"每天反省"和"日日复盘"的节奏可能跟不上互联网的周级迭代
- 多元化集团管控——稻盛哲学基于统一价值观，多元化集团的价值观差异可能削弱其效果
- 需要快速淘汰低绩效者的场景——稻盛强调关怀和利他，与"残酷筛选"逻辑冲突

## 实施检查清单

- [ ] 是否每天践行"付出不亚于任何人的努力"——不是偶尔拼命，而是持续的全力以赴
- [ ] 成功后是否保持谦虚——警惕骄傲，惟谦受福
- [ ] 是否建立了每日反省的习惯——临睡前回顾当天的言行，识别自私自利的行为
- [ ] 是否对困难也保持感谢——从"为什么是我"转向"感谢让我经历"
- [ ] 经营目的是否上升到"大义名分"——不是为了赚钱，而是为了谁、为了什么
- [ ] 经营目标是否具体可量化且全员共有——每个员工都清楚今天的目标
- [ ] 是否有渗透到潜意识的强烈愿望——日思夜想、吃饭走路都在想
- [ ] 是否持续追问"销售额还能提高吗？经费还能减少吗？"——利润是结果不是目标
- [ ] 定价是否从市场出发而非仅从成本出发——定价即经营
- [ ] 面对正确但艰难的事是否有勇气去做——不可怯懦
- [ ] 是否每天追问"明天怎么比今天更好"——不断从事创造性的工作
- [ ] 领导人是否以身作则——说到的必须做到，才能是公器不是私产

## 诚实边界

1. **六项精进缺乏操作化工具**：六条准则都是方向性指引，没有具体的执行工具。比如"每天反省"——反省什么、怎么反省、反省后怎么改？稻盛和夫本人有极强的自律能力，但普通人缺乏结构化的反省框架，六项精进容易沦为口号。

2. **经营十二条过于宏观**：十二条是经营哲学不是操作手册。比如"定价即经营"——定价的具体方法、定价的策略框架、定价的动态调整机制，十二条都没有提供。经营者需要额外的工具来落地。

3. **领导人资质理想化**：5项资质（使命感/责任感/公正/勇气/自律）是理想画像，现实中很少有领导人同时具备全部5项。稻盛和夫本人是极少数接近理想的人，但用理想化标准要求所有领导人，可能导致自我否定而非自我提升。

4. **盛和塾模式不可复制**：盛和塾的成功高度依赖稻盛和夫个人的魅力、近40年的义务投入、以及日本企业文化的土壤。稻盛和夫去世后，盛和塾能否持续有效是未知数。其他组织试图复制盛和塾模式，缺乏核心人物时效果存疑。

5. **外行优势的适用边界**："技术开发必须由外行来做"在特定条件下成立——外行的纯粹愿望驱动突破。但在需要深厚专业积累的领域（如半导体制造、药物研发），外行优势的适用性有限。稻盛和夫的案例多来自材料科学和精密制造，跨领域推广需要谨慎。

6. **努力至上的过劳风险**："付出不亚于任何人的努力"如果被极端解读，可能导致过劳文化。稻盛和夫本人每周工作80-100小时，但这不意味着所有人都应该如此。日本企业的过劳死问题与"拼命工作"的文化有直接关联，六项精进需要与健康管理平衡。

7. **因果报应的不可证性**："积善行思利他"背后的因果报应逻辑——利他行为产生善果——在短期和个体层面不可证。现实中利他者吃亏、自私者得利的案例比比皆是。稻盛和夫的因果观是长周期的统计信念，但长周期对个体而言可能意味着一生都看不到回报。
