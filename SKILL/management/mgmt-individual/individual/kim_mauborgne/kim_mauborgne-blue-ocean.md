# W·钱·金+勒妮·莫博涅 · 蓝海战略+价值创新

> 不要在红海中竞争，要创造蓝海——价值创新同时追求差异化和低成本，打破竞争与取舍的对立

## 核心理念

金和莫博涅要解决的核心问题是：**为什么有些企业能够跳出竞争的泥潭，创造无人竞争的市场空间？竞争真的是战略的唯一逻辑吗？**

2005年《蓝海战略》出版之前，战略领域被波特的竞争逻辑主导——战略就是在给定的行业结构中选择最佳竞争定位，差异化与低成本是互斥的取舍。金和莫博涅通过对百年产业史的系统研究，提出了一个根本性的挑战：最成功的战略不是在红海中找到最佳位置，而是跳出红海创造蓝海——通过价值创新（Value Innovation）同时追求差异化和低成本，打破竞争与取舍的对立。

蓝海战略的核心数据：金和莫博涅研究了30个行业的108家企业，发现：86%的业务拓展属于红海（在现有市场中竞争），只贡献了62%的总收入和39%的总利润；14%的业务拓展属于蓝海（创造新市场空间），贡献了38%的总收入和61%的总利润。蓝海业务的利润贡献远超其数量占比——创造新市场比在旧市场中竞争更赚钱。

核心公式：**蓝海 = 价值创新 = 差异化 + 低成本（同时而非取舍）**

## 关键模块

### 模块1：红海vs蓝海

- 定义：红海是已知的市场空间，企业在其中竞争；蓝海是未知的市场空间，企业通过价值创新创造
- 输入：行业竞争格局 + 价值创新机会
- 输出：跳出红海进入蓝海的战略选择
- 关键动作：
  - **竞争vs非竞争**：红海逻辑——行业边界已经确定且被接受，竞争规则已经形成，企业在相同的规则下争夺相同的客户，结果是零和博弈——一个企业赢意味着另一个企业输。蓝海逻辑——行业边界可以被重新定义，竞争规则可以被改写，企业通过创造新的需求而非争夺现有需求来实现增长，结果是正和博弈——市场被做大，多个参与者可以同时获利
  - **为什么竞争是红海陷阱**：金和莫博涅的核心论点：大多数企业陷入"竞争思维"——把竞争当作战略的默认选项，把"比对手做得更好"当作战略目标。竞争思维导致三个陷阱：①红海陷阱——在饱和市场中竞争，利润被压缩，增长见顶；②benchmarking陷阱——对标竞争对手意味着你在模仿而非创新，最终所有企业趋同；③取舍陷阱——波特说差异化与低成本不可兼得，企业被迫选择其一。金和莫博涅说：竞争思维是"在给定的棋盘上选位置"，蓝海思维是"换一个棋盘"
  - **价值创新=同时追求差异化和低成本**：蓝海战略最核心的命题——差异化与低成本不是取舍关系，而是可以同时实现。价值创新（Value Innovation）的逻辑：①剔除和减少行业过度竞争的元素——降低成本；②增加和创造行业从未提供的元素——创造差异化；③两者同时进行——成本降低不是因为"偷工减料"，而是因为剔除了客户不重视的元素；差异化不是因为"堆砌功能"，而是因为创造了客户真正重视的新价值。太阳马戏团的经典案例：剔除动物表演和明星演员（大幅降本），增加艺术性和故事性（创造差异化），同时实现低成本和高差异化——从一个衰退的马戏行业跳入了一个全新的娱乐蓝海
- 常见误区：认为蓝海=蓝海市场——蓝海不是"找到"一个已有的蓝海市场，而是"创造"一个不存在的市场空间；认为价值创新=低价——价值创新是同时追求差异化和低成本，不是单纯降价；认为蓝海不需要竞争——蓝海不是没有竞争，而是竞争不再是战略的核心逻辑

### 模块2：战略布局图

- 定义：战略布局图是可视化行业竞争格局的工具——通过价值曲线展示企业在各竞争元素上的投入水平
- 输入：行业竞争元素 + 各企业在各元素上的投入水平
- 输出：行业竞争格局的可视化 + 蓝海机会的识别
- 关键动作：
  - **价值曲线**：价值曲线是战略布局图的核心——横轴是行业的竞争元素（如酒店的位置/房间大小/餐饮/设施/价格），纵轴是企业在各元素上的投入水平（高/中/低）。将各元素上的投入水平连成线，就是一条价值曲线。价值曲线的三个洞察：①同一行业的企业价值曲线高度趋同——说明大家在同一红海中竞争；②蓝海创造者的价值曲线与红海企业截然不同——说明他们重新定义了竞争元素；③蓝海创造者的价值曲线在某些元素上很低（剔除/减少）、在某些元素上很高（增加/创造）——同时实现了低成本和差异化
  - **为什么画图比写报告有效**：金和莫博涅发现，战略布局图比任何文字报告都更能揭示竞争格局——因为：①可视化让模式一目了然——红海企业的趋同曲线和蓝海企业的差异化曲线对比鲜明；②可视化让团队对齐——所有人看着同一张图讨论，比看50页PPT更高效；③可视化让取舍显性——哪些元素可以剔除/减少，哪些需要增加/创造，在图上一目了然
  - **如何识别蓝海机会**：用战略布局图识别蓝海机会的三个步骤：①画出当前行业的价值曲线——识别竞争元素和各企业的投入水平；②画出非客户的替代品价值曲线——看非客户在用什么替代方案满足需求；③设计新的价值曲线——在替代品和现有产品之间找到"第三条路"——剔除/减少现有产品的元素，增加/创造替代品的元素
- 常见误区：只画自己的价值曲线——必须同时画出竞争对手和替代品的价值曲线，否则无法看到蓝海机会；竞争元素太多——应该聚焦5-10个核心竞争元素，而非列出所有元素；画完就结束——战略布局图是讨论工具，画完必须讨论"我们应该剔除/减少/增加/创造什么"

### 模块3：四步动作框架

- 定义：四步动作框架是蓝海战略的核心工具——通过剔除/减少/增加/创造四个动作重新定义价值曲线
- 输入：当前行业的价值曲线 + 非客户分析
- 输出：新的价值曲线设计
- 关键动作：
  - **剔除（Eliminate）**：哪些行业理所当然的竞争元素可以被完全剔除？剔除的目的是消除那些客户不再重视但行业仍在大量投入的元素——这些元素是成本的来源但不是价值的来源。太阳马戏团剔除了动物表演——动物表演是传统马戏的标配，但客户（成人）不再重视，且成本高昂
  - **减少（Reduce）**：哪些竞争元素可以被减少到远低于行业标准？减少的目的是降低过度投入——行业在某些元素上投入过多，远超客户的需求。经济型酒店减少了餐饮和设施——客户只需要一张好床和干净卫生间，不需要餐厅和游泳池
  - **增加（Raise）**：哪些竞争元素应该被增加到远高于行业标准？增加的目的是在客户真正重视的元素上超越对手。经济型酒店增加了床品质量——客户最重视的是睡好觉，好床比游泳池更有价值
  - **创造（Create）**：哪些行业从未提供的元素应该被创造？创造的目的是提供全新的价值——这些元素是行业从未想到的，但客户会为此买单。太阳马戏团创造了艺术性和故事性——传统马戏从未把"艺术"和"故事"当作竞争元素，但成人观众为此买单
  - **为什么做减法和做加法一样重要**：金和莫博涅的核心洞察：大多数企业只关注"增加"和"创造"，忽略了"剔除"和"减少"——结果是成本不断攀升，差异化越来越贵。蓝海战略的关键是同时做减法和加法——剔除/减少释放了资源，增加/创造用释放的资源投入新价值。做减法不是"偷工减料"，而是"把资源从客户不重视的地方转移到客户重视的地方"
- 常见误区：只做加法不做减法——只增加和创造，不剔除和减少，结果成本失控；把剔除等同于降质——剔除的是客户不重视的元素，不是降低客户重视的元素的质量；四步动作没有系统性——四个动作必须同时设计，不能分开考虑

### 模块4：六条路径

- 定义：六条路径是发现蓝海的六种视角——从六个不同的维度重新审视市场边界
- 输入：行业假设 + 非客户分析
- 输出：蓝海机会的发现
- 关键动作：
  - **路径1：跨替代产业**——不要只看同行业竞争者，要看替代品。客户在选择时不是在同行业产品中选择，而是在所有能完成同一任务的替代品中选择。电影院不仅要和其他电影院竞争，还要和餐厅、Netflix、游戏竞争——这些替代品定义了更大的市场空间
  - **路径2：跨战略集团**——不要只看自己所在的战略集团（高端/中端/低端），要看其他战略集团。高端酒店和高端酒店竞争是红海，但高端酒店和经济型酒店之间有蓝海——如精品酒店既不是高端也不是经济型，而是创造了新的战略集团
  - **路径3：跨买方链**——不要只看购买者，要看使用者/影响者/决策者。购买者可能不是使用者——药品的购买者是医院/保险公司，使用者是患者，影响者是医生。重新定义"为谁创造价值"可以发现蓝海
  - **路径4：跨互补产品/服务**——不要只看核心产品，要看互补产品和服务。客户的需求不是孤立的产品，而是产品+互补品的完整体验。电影院+餐饮+停车=完整的晚间娱乐体验，重新定义产品边界可以发现蓝海
  - **路径5：跨功能-情感导向**——不要只看功能或只看情感，要看两者之间的转换。行业往往被锁定在功能导向或情感导向——功能导向的行业可以加入情感元素（如Swatch把手表从计时工具变成时尚配饰），情感导向的行业可以加入功能元素（如The Body Shop把化妆品从情感驱动变成功能+伦理驱动）
  - **路径6：跨时间**——不要只看当前趋势，要看趋势如何重塑市场。参与正在发生的趋势而非预测未来——如绿色消费趋势正在重塑汽车、能源、食品行业，参与趋势可以发现蓝海
  - **为什么6条路径发现蓝海**：六条路径的共同逻辑是"打破行业假设"——每个行业都有一套默认假设（"我们的竞争者是谁""我们的客户是谁""我们的产品边界是什么"），这些假设定义了红海的边界。六条路径每一条都挑战一个核心假设，打开一个蓝海方向
- 常见误区：只走一条路径——六条路径应该都被审视，不同路径可能发现不同的蓝海；把六条路径当作线性流程——六条路径是六种视角，不是六个步骤；忽略路径5（功能-情感）——很多蓝海来自功能与情感的转换，这条路径经常被忽视

### 模块5：蓝海转型5步

- 定义：蓝海转型5步是从理论到实践的路径——从启动到落地的系统化流程
- 输入：蓝海战略理论 + 组织现状
- 输出：蓝海转型的实施路径
- 关键动作：
  - **第1步：启动**——选择蓝海转型的起点。关键决策：①选择哪个业务线/产品线启动——不要试图在整个组织同时启动，选择一个有蓝海潜力的业务线；②组建蓝海团队——跨功能团队，包含一线员工而非只有管理层；③获得高层支持——蓝海转型需要资源投入，没有高层支持无法推进
  - **第2步：现状**——理解当前的竞争格局。关键动作：①画出当前行业的战略布局图；②识别红海竞争的元素；③理解非客户为什么不选择现有产品；④识别"非客户"的三层——即将成为客户的"浅层非客户"、拒绝成为客户的"拒绝型非客户"、从未考虑过的"未探索非客户"
  - **第3步：蓝海想象**——设计新的价值曲线。关键动作：①用六条路径发现蓝海方向；②用四步动作框架设计新价值曲线；③画出新的战略布局图——对比红海和蓝海的价值曲线；④验证蓝海概念——与客户和非客户测试新价值曲线的吸引力
  - **第4步：落地**——将蓝海概念转化为行动。关键动作：①识别落地的关键障碍——组织惯性、资源约束、利益冲突；②设计试点——在小范围内测试蓝海概念；③快速迭代——根据试点结果调整价值曲线；④规模化——在试点成功后扩大范围
  - **第5步：迭代**——蓝海不是一劳永逸的。关键动作：①监测蓝海是否被模仿——如果模仿者涌入，蓝海会变成红海；②持续探索新的蓝海——在当前蓝海被填满之前找到下一个蓝海；③更新战略布局图——定期重新评估竞争格局和价值曲线
- 常见误区：跳过"现状"直接设计——不理解当前红海就无法设计有效的蓝海；只做设计不做落地——蓝海战略的失败大多不是因为设计不好而是因为落地不力；认为蓝海是永久的——蓝海最终会被模仿和填满，需要持续创新

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 判断是否在红海 | 如果行业价值曲线高度趋同→红海，需要寻找蓝海 | 战略布局图 |
| 判断是否有蓝海机会 | 如果非客户数量远超现有客户→蓝海机会大 | 非客户分析 |
| 判断价值创新是否有效 | 如果新价值曲线同时实现了低成本和高差异化→有效；如果只实现了一个→不是真正的蓝海 | 价值创新 |
| 判断是否应该剔除某元素 | 如果客户不再重视且行业仍在大量投入→应该剔除 | 四步动作框架 |
| 判断是否应该创造新元素 | 如果行业从未提供但客户会为此买单→应该创造 | 四步动作框架 |
| 判断蓝海是否被模仿 | 如果竞争者开始复制你的价值曲线→蓝海正在变红，需要寻找下一个蓝海 | 蓝海转型5步 |
| 判断非客户类型 | 如果是"差点就买"的非客户→浅层非客户；如果是"坚决不买"的非客户→拒绝型非客户 | 非客户三层 |
| 判断功能-情感路径 | 如果行业被锁定在功能导向→加入情感元素；如果被锁定在情感导向→加入功能元素 | 路径5 |
| 判断蓝海转型是否成功 | 如果新价值曲线吸引了大量非客户→成功；如果只是抢了现有客户→不是蓝海 | 蓝海转型5步 |
| 判断是否需要蓝海战略 | 如果行业增长停滞且竞争激烈→需要蓝海战略；如果行业仍在快速增长→红海策略可能仍然有效 | 红海vs蓝海 |

| 关联方法论 | 关系 | 接口 |
|-----------|------|------|
| 波特竞争战略 | 对比-竞争vs非竞争 | 波特假设竞争是给定的，战略是在竞争框架内选择最佳定位；蓝海认为竞争本身可以被超越——通过价值创新开辟无人竞争的新市场；波特是"在红海中找到最佳位置"，蓝海是"跳出红海创造蓝海"——两者是战略思考的根本对立 |
| 克里斯坦森颠覆式创新 | 互补-颠覆+蓝海 | 颠覆式创新从低端或新市场切入，逐步向上蚕食；蓝海战略通过价值创新创造新市场空间；颠覆式创新是"供给端"逻辑（新技术创造新市场），蓝海是"需求端"逻辑（新价值曲线创造新市场）——两者从不同角度解释同一现象 |
| 柯林斯刺猬理念 | 互补-聚焦+价值创新 | 柯林斯刺猬理念（三个圆的交集：你热爱什么/你擅长什么/你的经济引擎是什么）提供了内在驱动力框架，蓝海提供了外部市场空间框架；刺猬理念回答"我们为什么能持续"，蓝海回答"我们去哪里竞争"——两者结合：用刺猬理念找到内在聚焦，用蓝海战略找到外部空间 |
| 科特勒STP | 对比-细分vs重新定义 | 科特勒STP在现有市场中细分（Segmentation→Targeting→Positioning），蓝海战略重新定义市场边界；STP假设市场边界是给定的，蓝海假设市场边界可以被创造——STP是"在给定市场中找到最佳位置"，蓝海是"重新定义市场" |
| 华为DSTE | 互补-战略管理+蓝海发现 | 华为DSTE提供了战略管理的系统流程（五看三定/BEM解码），蓝海战略提供了"看行业"和"定战略"的具体方法；DSTE告诉你"战略管理流程是什么"，蓝海告诉你"如何在战略管理中发现蓝海机会" |
| 里斯+特劳特定位 | 互补-心智定位+价值创新 | 里斯+特劳特定位解决"如何在消费者心智中占据一个位置"，蓝海战略解决"如何创造一个值得占据的新位置"；定位是"心智侧"，蓝海是"价值侧"——先有蓝海的价值创新，再用定位占据心智 |

## 适用场景

### 最适合

- 行业增长停滞——红海竞争激烈，需要寻找新增长空间
- 产品同质化严重——行业价值曲线趋同，差异化困难
- 价格战频发——竞争逻辑主导，利润被压缩
- 非客户远超现有客户——大量潜在需求未被满足
- 新产品/新业务线规划——从零开始设计价值曲线

### 不适合

- 行业仍在快速增长——红海策略可能仍然有效，不需要冒险创造蓝海
- 高度监管行业——市场边界由法规决定，重新定义空间有限
- 资源极度匮乏的创业公司——蓝海转型需要资源投入，早期创业公司可能无力承担
- 需要快速见效的场景——蓝海转型是中长期战略，不适合短期业绩压力

## 实施检查清单

- [ ] 是否画出了当前行业的战略布局图——识别竞争元素和价值曲线
- [ ] 是否识别了非客户——浅层/拒绝型/未探索三层非客户
- [ ] 是否用四步动作框架设计了新价值曲线——剔除/减少/增加/创造
- [ ] 是否同时做了减法和加法——而非只做加法
- [ ] 是否用六条路径审视了市场边界——而非只看同行业竞争者
- [ ] 新价值曲线是否同时实现了低成本和差异化——而非只实现了一个
- [ ] 是否与客户和非客户验证了蓝海概念——而非只在内部讨论
- [ ] 是否设计了试点——而非试图一次性全面转型
- [ ] 是否监测了蓝海被模仿的信号——竞争者是否开始复制你的价值曲线
- [ ] 是否在当前蓝海被填满之前探索下一个蓝海——蓝海不是永久的

## 诚实边界

1. **蓝海的"永久性"问题**：金和莫博涅承认蓝海最终会被模仿和填满——太阳马戏团的成功引来了大量模仿者，蓝海变成了红海。但蓝海战略没有给出"蓝海能持续多久"的系统性回答。如果蓝海只能维持2-3年，那蓝海战略的投入产出比可能不如在红海中深耕。

2. **价值创新的"同时性"假设**：蓝海战略的核心命题是差异化与低成本可以"同时"实现，但现实中很多价值创新是"先差异化后低成本"或"先低成本后差异化"——同时实现两者对组织能力的要求极高。太阳马戏团花了多年才同时实现艺术性和低成本，而非一步到位。

3. **六条路径的"发现"vs"创造"**：六条路径暗示蓝海可以被"发现"——就像地图上的未探索区域。但蓝海更多是"创造"出来的——太阳马戏团不是"发现"了成人娱乐市场，而是"创造"了一种新的娱乐形式。六条路径更像是"灵感来源"而非"发现工具"。

4. **蓝海战略对执行的低估**：金和莫博涅在《蓝海战略》中花了大量篇幅讲"如何发现蓝海"，但对"如何执行蓝海"的讨论相对薄弱。2017年的《蓝海转型》补充了5步法，但执行仍然是蓝海战略的薄弱环节——很多企业发现了蓝海但无法落地。

5. **案例的幸存者偏差**：蓝海战略的案例（太阳马戏团/Swatch/Cirque du Soleil/Yellow Tail葡萄酒）都是成功案例，但金和莫博涅没有系统性地分析"发现了蓝海但失败了"的案例。失败案例可能揭示蓝海战略的隐性前提条件——如市场规模是否足够大、客户是否愿意接受新价值曲线、组织是否有能力执行。

6. **对竞争的过度否定**：蓝海战略把"竞争"当作负面词汇，但竞争有其积极面——竞争推动效率提升、创新加速、客户选择增加。完全否定竞争可能导致企业忽视竞争者的威胁——蓝海不是没有竞争，而是竞争暂时不激烈。

7. **公开资料与原始研究的差异**：《蓝海战略》基于INSEAD的学术研究，但面向大众的写作风格使得很多研究细节被简化。中文译本对"Value Innovation""Eliminate-Reduce-Raise-Create"等概念的翻译存在多个版本。本文件基于多个版本交叉比对，但无法保证完全还原金和莫博涅英文原意。
