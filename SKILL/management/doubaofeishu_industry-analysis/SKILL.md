# 行业分析报告（doubaofeishu_industry-analysis）

一份报告的成败在动笔前就定了：**有没有一条能被证伪的判断主线**。这套方法的顺序是
「定锚 → 取证分级 → 定判断 → 分批写 → 自检 → 交付」，不是「先写再润色」。

## 何时用 / 何时不用

- 用：行业深度研究、赛道机会研判、产业链与利润池拆解、竞争格局与集中度分析、投资/立项前的行业底稿。
- 不用：把已有文章转成笔记（`analysis-to-vault`）；估值建模（`dcf-valuation`、`comparable-analysis`）；单点事实核查（`truth-seeking-research`）。

## 五条质量标准（优先级从高到低）

1. **数据真实可溯源**：每个数字能追到来源，并说清是一手披露、具名机构、行业数据还是本研究测算。不用印象、常识、模糊出处补数。
2. **判断贯穿一条主线**：报告要有一个可验证、可推翻的核心判断；五大板块各自认领一个子命题去印证或限定它，而不是资料汇编。
3. **信息详实、有量化**：定义与边界、规模与增速、产业链与利润池、竞争格局与集中度、政策与驱动、盈利质量与现金流、关键风险与落地路径。
4. **事实支撑判断**：读者要看到判断如何由事实推出，不是只看到事实清单。
5. **克制专业**：区分确定事实、机构估算、媒体观点、作者推断；估算写"据估算"，推断写"可能意味着"。

## 核心方法

### 先有判断，再写正文

取证结束后、动笔前，先落一张**判断主线底稿**；证据推翻判断时，先改这张表，再动正文。

```text
一句话主线：可验证、可推翻的核心判断
七格表：
  1 决策问题      2 市场共识     3 非共识判断
  4 核心数据 3-5 个  5 因果链     6 利润池迁移
  7 验证/证伪信号 ≥5 个
三情景：基准 / 乐观 / 悲观（先想好结果，再写推导）
各板块子命题：每个板块认领什么命题去印证主线
```

### 五大板块（固定结构）

每个板块开头一句"亮明判断"的主题句，结尾必须有「回扣主线」小节：

1. 行业定义与规模
2. 行业结构与竞争格局
3. 核心驱动与制约
4. 趋势研判与结构性机会
5. 商业化路径与盈利质量

外加：执行摘要、风险提示、结语、参考文献。

### 三级数据分级

| 级别 | 定义 | 使用规则 |
|---|---|---|
| 一级 | 一手披露 / 官方统计 / 监管数据 | 可直接陈述，作为核心数据 |
| 二级 | 具名机构研报 / 行业协会 / 权威媒体 | 须显名归因，可作展示数据 |
| 三级 | 自媒体 / 社交内容 / 聚合页 | 仅作线索，不入展示 |

### 全表格化

规模趋势、产业链全景、各环节毛利率、市场份额、三情景对比等并列信息，一律用表格；**不出折线图、柱状图、饼图**。

## 工作流程（六步）

```text
1 定锚     基准年 + 预测窗口（当年 +5）；确认任务类型与行业结构类型；训练数据可能过期，规模/政策/融资/技术以检索为准
2 取证     只走两条通道：公开搜索（事实/政策/事件）+ 金融数据（规模/增速/份额/财务）；
           覆盖度停机：核心维度各 ≥2 条、累计 ≥18 条；边查边记来源台账（通道/级别/基期/源值）
3 定判断   判断主线底稿（见上）
4 写正文   分 6 批写入独立分片：摘要 → 定义规模 → 结构竞争 → 驱动制约 → 趋势机会 → 商业化风险参考文献；
           每批写完单批校验；批 3 后做阶段校验；引用按首次出现顺序编号，同源复用
5 自检     主线贯穿 / 数据前后一致 / 通道与级别达标 / 每个数字句末标引用并对照台账核验
6 交付     拼接 + 整篇校验；默认可交互网页报告；用户明确要求时转飞书云文档
```

## 硬约束（违反任一条即返工）

- 无来源数字不入正文；数字必核对。
- 市场数字两维红线：取数通道必须是金融数据，出处必须一级或二级。
- 只能走两条取数通道，不得引入第三条隐藏数据源。
- 结论强度不超出证据档位：估算、推断各自带限定语。
- 缺数据如实暴露，绝不编造。
- 时效红线：趋势预测以当年为基准，正文标注数据基期。
- 五大板块每章末尾有「回扣主线」。
- 写正文前必须先想清楚判断主线。
- 只用授权检索工具与用户文件，只取合法公开内容。
- 不出任何配图，并列信息一律表格。
- 正文分 6 批写入独立分片，拼接后整篇校验。
- 不暴露内部机制：不出现 skill 名称、检索轮次、工程术语标签。

## 交付形态

- **默认**：可交互网页报告（单文件 HTML，表格化，引用可点）。
- **按需**：飞书云文档——写作规范见参考原文第二节（结论先行、证据导向、结构化、克制组件），含分析报告/技术方案/进展总结三套模板与新建/更新/图片/评论的操作要点。
- 结尾必须带免责声明：AI 辅助生成、条件性分析、不构成专业意见，关键结论回原始来源核验。
