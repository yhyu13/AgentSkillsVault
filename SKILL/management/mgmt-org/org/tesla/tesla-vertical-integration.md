# Tesla · 垂直整合

> 白痴指数高的部件自己造，制造方式本身就是创新——把供应链从外部采购清单变成内部能力清单，用自研+自产+自建工厂把成本压到物理极限

## 核心理念

Tesla垂直整合解决的核心问题是：**当供应链的每一层都在加价，你如何把成本从行业惯例的6500万美元压到原材料成本的物理极限？**

传统制造业的逻辑是分工外包——你做发动机、我做车身、他做电池，大家各赚各的利润，最后整车厂组装。这条路径的隐含假设是：专业供应商比你更高效，外包比自研更经济。但Musk用白痴指数戳破了这个假设：如果一枚火箭的原材料成本只占总价的2%，剩下98%全是供应链溢价、认证加价和行业惯性，那"专业供应商更高效"就是个假象——他们不是更高效，而是更会加价。

垂直整合的本质不是"什么都自己造"的教条，而是白痴指数驱动的理性决策：指数高的部件自己造，指数低的部件外采。SpaceX火箭白痴指数约50，所以自研发动机、自造箭体、自建发射场，成本降90%。Tesla电池白痴指数极高，所以自研4680电池、自建Gigafactory、自研FSD芯片和Dojo超算。而白痴指数接近1的通用件（螺丝、线束），Tesla照样外采。

更深一层，Musk把工厂本身当作产品来设计——"工厂即产品"。传统汽车公司把工厂当作成本中心，Musk把工厂当作创新主体：一体压铸把171个零件减至2个，4680电池把电芯直接集成到车身结构，Gigafactory用规模化把电池成本从600美元/kWh压至100以下。制造方式不是对设计的被动执行，而是主动创造竞争优势的源头。

核心命题：**Apple用外包+极致管控控制供应链，华为用流程化打通供应链，Tesla用垂直整合把供应链内部化——三种范式，三种逻辑，三种对"谁该拥有制造能力"的回答。**
