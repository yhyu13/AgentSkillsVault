# Tesla · 五步工作法（The Algorithm）

> 五步严格有序——质疑→删除→简化→加速→自动化，顺序不可颠倒，自动化永远在最后。

## 核心理念

五步工作法解决的核心问题是：**如何用最少的步骤和资源，把一件事情做到物理极限？**

马斯克不叫它"方法论"，而叫它"算法"（The Algorithm）——这不是建议，而是全公司强制执行的指令。五步的顺序绝对不能颠倒，因为每一步都是下一步的前提：不先质疑需求，你可能优化了一个不该存在的东西；不先删除冗余，简化就没有对象；不先简化，加速只是在加速浪费；不先手动跑通，自动化只会把错误固化。

这个算法的底层逻辑来自第一性原理——如果一条需求、一个零件、一道工序经不起"它是否真的必须存在"的追问，那它就不该存在。五步法本质上是第一性原理在执行层面的展开：从"该不该做"到"该怎么做"的严格递进。

## 框架结构

```
五步工作法 = 质疑→删除→简化→加速→自动化（严格有序）
│
├── Step 1 质疑需求
│   └── 所有需求都可能是错的 → 每个需求必须绑定具体人名
│       → 无人认领的需求=无人负责的需求=可以删除的需求
│
├── Step 2 极力删除
│   └── 删到不能再删 → 如果没有把删掉的加回来10%→删得不够狠
│       → 一体压铸：171个零件减至2个
│
├── Step 3 简化优化
│   └── 只对"必须存在"的东西优化 → 绝不优化不该存在的东西
│       → 警告：优化一个该删的东西=浪费+固化错误
│
├── Step 4 加速周期
│   └── 提高循环速度和生产速度 → 但只加速"该做的事"
│       → 不是更快地做错事，而是更快地做对的事
│
├── Step 5 自动化
│   └── 放在最后一步 → 千万不要自动化一个本该被删除的流程
│       → Model 3工厂教训：过早自动化=错误固化
