# 阿里巴巴 · 361绩效双轨制

> 业绩决定你能不能留下来，价值观决定你能不能往上走——双轨绑定、强制分布、末位淘汰三位一体

## 核心理念

361绩效双轨制解决的核心问题是：**如何在规模化组织中同时驱动业绩产出和文化传承？**

传统绩效管理只看业绩数字，忽略"怎么做到的"。阿里的解法是把价值观从软性要求变成硬性考核——业绩和价值观各占半壁江山，两条轨道独立评分、交叉定档，任何一条轨道塌方都会拉低总评。这套体系的底层逻辑是：业绩好但价值观差的人是"野狗"，必须清除；价值观好但业绩差的人是"小白兔"，也要淘汰；只有两条轨道都过关的人才是"阿里人"。

三个关键设计选择：
1. **双轨绑定**：业绩和价值观不是"主+辅"，而是等权重的两条独立轨道
2. **强制分布**：361硬性比例防止主管打好人牌，确保组织始终保持新陈代谢
3. **末位淘汰**：10%不仅是数字，更是组织活力的底线——"做了三年管理没开除过人，不称职"

## 框架结构

```
361绩效双轨制
│
├── 双轨考核层
│   ├── 业绩轨道（硬性产出）
│   │   ├── 普通员工：70%权重
│   │   └── 管理者：40%权重（+30%团队+30%价值观）
│   ├── 价值观轨道（行为准则）
│   │   ├── 普通员工：30%权重
│   │   └── 管理者：30%权重
│   └── 双轨交叉定档（九宫格）
│
├── 361分布层
│   ├── 30% 杰出（3.75+）
│   ├── 60% 符合期望（3.5）
│   └── 10% 需改进（3.25-）
│
├── 价值观考核层
│   ├── A级：超越期望（价值观标杆）
│   ├── B级：符合期望（行为达标）
│   └── C级：不符期望（价值观红线）
│
├── 业绩工具层
│   ├── OKR（目标对齐）
│   ├── KPI（结果量化）
│   └── 管理决定（主观判断兜底）
│
└── 结果应用层
    ├── 30%杰出 → 丰厚年终奖+优先晋升
    ├── 60%符合 → 正常年终奖+常规调薪
    └── 10%末位 → 无年终奖+无加薪+淘汰预警
```

## 关键模块

### 模块1：双轨考核——业绩与价值观绑定

- 定义：绩效由业绩分和价值观分两条独立轨道构成，不同角色权重不同
- 输入：业务目标完成情况 + 六脉神剑行为表现
- 输出：双维评分，交叉落入九宫格定位
- 关键动作：
  - 普通员工：业绩70% + 价值观30%，业绩权重占主导但价值观有一票否决权
  - 管理者：业绩40% + 团队管理30% + 价值观30%，管理者需同时为团队产出和文化传承负责
  - 九宫格交叉定档：业绩高+价值观高=明星；业绩高+价值观低=野狗（清除）；业绩低+价值观高=小白兔（培养或淘汰）；业绩低+价值观低=狗（立即清除）
- 常见误区：以为价值观考核是走过场——实际上价值观C级直接触发淘汰流程，与业绩末位等效

### 模块2：361强制分布——从271到361

- 定义：绩效结果按3:6:1强制分布，源自GE活力曲线的本土化改造
- 输入：全员绩效评分
- 输出：三档分布结果及对应奖惩
- 关键动作：
  - 原始版本271：20%杰出/70%符合/10%淘汰，直接借鉴韦尔奇GE活力曲线
  - 演进为361：30%杰出/60%符合/10%淘汰，扩大激励面、缩小中间层
  - 从271到361的调整逻辑：20%杰出面太窄，中间70%太厚导致"大锅饭"；扩大到30%让更多人获得激励，压缩中间层到60%减少混日子空间
  - 10%末位比例不变——这是组织新陈代谢的底线，无论271还是361都坚守
- 常见误区：以为361是放松了淘汰——10%末位比例从未变过，变的是激励面的扩大

### 模块3：价值观考核——六脉神剑的硬性量化

- 定义：将阿里的价值观（六脉神剑）从文化口号变成可打分的考核项
- 输入：员工日常行为表现、360度反馈、关键事件记录
- 输出：价值观A/B/C三级评分
- 关键动作：
  - A级：价值观超越期望，成为团队标杆，可弥补业绩小幅不足
  - B级：价值观符合期望，行为达标，无加分无减分
  - C级：价值观不符期望，触碰红线，即使业绩优秀也必须淘汰
  - 价值观考核不是主观印象——每条价值观都有行为锚定描述，从"客户第一"到"拥抱变化"都有具体的行为标准
  - 价值观一票否决：业绩3.75但价值观C = 淘汰，不存在"业绩好就容忍价值观问题"
- 常见误区：把价值观考核等同于"人缘好不好"——实际考核的是行为是否符合六脉神剑的具体标准，不是同事评价

### 模块4：业绩考核工具——OKR+KPI+管理决定三合一

- 定义：业绩评分不是单一工具产出，而是三种工具的综合判断
- 输入：OKR完成度 + KPI达成率 + 管理者主观判断
- 输出：业绩轨道最终评分
- 关键动作：
  - OKR对齐方向：确保个人目标与组织方向一致，但OKR完成率不等于绩效分数
  - KPI量化结果：可衡量的硬性指标，是业绩评分的基础锚点
  - 管理决定兜底：当OKR和KPI无法完全反映贡献时（如跨部门协作、隐性付出），管理者有权做主观调整
  - 三者不是简单加权，而是互为校验——OKR看方向、KPI看结果、管理决定看过程
- 常见误区：以为OKR完成率=绩效分数——阿里与字节不同，OKR在阿里是业绩工具之一而非沟通工具，且与绩效强绑定

### 模块5：末位淘汰——10%的组织新陈代谢

- 定义：每轮考核强制10%落入末位，承受无年终奖、无加薪、淘汰预警的后果
- 输入：361分布结果
- 输出：末位人员的改进计划或淘汰决定
- 关键动作：
  - 10%末位：无年终奖、无加薪、进入绩效改进观察期
  - 连续两次末位：直接淘汰，无例外
  - 管理者淘汰责任："做了三年管理没开除过人，不称职"——管理者有义务识别和清除低绩效者，不淘汰等于失职
  - 淘汰不是目的，活力才是——10%的压力传导让整个组织保持紧张感，避免"温水煮青蛙"
- 常见误区：以为末位淘汰是裁员手段——实际是组织活力机制，核心目的不是省钱而是保持竞争压力

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 业绩好但价值观差 | 如果价值观评C，则无论业绩多高都必须淘汰——"野狗"比"小白兔"危害更大 | 阿里双轨九宫格 |
| 价值观好但业绩差 | 如果连续两次业绩末位，则即使价值观A也要淘汰——"小白兔"不能占坑 | 361末位淘汰 |
| 管理者不愿淘汰人 | 如果管理者三年未淘汰过任何人，则该管理者不称职——不淘汰=纵容低绩效 | 阿里管理者淘汰责任 |
| OKR与KPI冲突 | 如果OKR完成但KPI未达标，则以KPI为主——结果导向是底线 | 业绩工具三合一 |
| 361分布执行 | 如果团队整体偏强，仍必须强制10%末位——分布是硬约束非弹性调整 | 361强制分布 |
| 价值观评分争议 | 如果行为符合六脉神剑描述则评B以上，如果触碰红线则直接C——行为锚定而非主观印象 | 价值观考核A/B/C |

## 适用场景

### 最适合

- 中大型企业（200人以上），需要同时驱动业绩和文化传承
- 业务可量化且文化价值观有明确行为定义的组织
- 管理者有意愿和能力执行末位淘汰（这是硬前提）
- 处于高速扩张期，需要组织保持紧张感和新陈代谢
- 价值观已沉淀为可描述的行为标准（如六脉神剑）

### 不适合

- 10人以下初创团队（强制分布在小样本上无意义）
- 创意型/探索型工作为主的团队（价值观考核难以量化创意行为）
- 管理者不敢淘汰人的组织（361会沦为"30%轮流转"的形式主义）
- 价值观尚未明确行为锚定的组织（价值观考核变成主观印象分）
- 人才市场极度紧缺时（10%淘汰可能赶走优秀人才）

## 实施检查清单

- [ ] 是否定义了业绩和价值观的双轨权重（普通员工vs管理者不同权重）
- [ ] 是否建立了价值观行为锚定描述（六脉神剑或等效，每条有具体行为标准）
- [ ] 是否建立了361强制分布的执行机制（硬性比例，不可弹性调整）
- [ ] 是否建立了末位淘汰的配套流程（改进期、二次评估、淘汰执行）
- [ ] 是否建立了管理者淘汰责任机制（不淘汰=失职）
- [ ] 是否建立了双轨交叉九宫格定档规则（野狗/小白兔/明星/狗的处置方案）
- [ ] 是否建立了价值观一票否决的执行标准（什么行为触发C级）
- [ ] 是否培训了管理者价值观考核的面谈技能（避免变成人缘评分）
- [ ] 是否建立了绩效校准机制（跨部门拉齐361分布标准）

## 诚实边界

1. **强制分布的残酷性**：10%末位淘汰意味着即使全员优秀也必须有人"被末位"，在团队整体偏强时会造成不必要的优秀人才流失
2. **价值观考核的主观性**：尽管有行为锚定描述，价值观评分仍不可避免地包含主观判断，可能被用于排除异己
3. **双轨绑定的副作用**：价值观与绩效强绑定可能导致员工"表演价值观"而非真正内化，行为合规≠文化认同
4. **从271到361的妥协**：扩大激励面到30%虽然减少了中间层的"大锅饭"，但也意味着杰出标准的稀释——30%的"杰出"是否还够杰出？
5. **文化前提不可忽视**：361有效运行需要"拥抱变化"和"客户第一"的文化土壤，在"以和谐为本"的组织中会变形为轮流坐庄
6. **公开资料局限**：阿里361的具体操作细则（如校准会议流程、价值观C级的申诉机制、管理者淘汰责任的量化标准）未完全公开，本文基于公开资料推断
