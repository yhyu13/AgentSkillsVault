# 阿里巴巴 · 六脉神剑价值观体系

> 用6+3条价值观嵌入硬考核，让文化成为组织操作系统——不是墙上标语，而是绩效生死线

## 核心理念

阿里巴巴六脉神剑价值观体系解决的核心问题是：**如何让价值观从口号变成行为约束？**

大多数企业的价值观停留在墙上的标语，阿里的做法截然不同——把价值观写进绩效考核，占50%权重，价值观打C则绩效直接不及格。这种"硬绑定"让价值观不再是软性倡导，而是决定升迁去留的硬标准。配合政委体系的文化守护和人才九宫格的分类处置，阿里构建了一套完整的文化驱动型组织操作系统。

从2001年的独孤九剑到2019年的新六脉神剑，阿里的价值观体系经历了四次迭代，每一次都反映了组织规模和战略阶段的变化。但内核始终不变：**文化不是装饰，是生产力。**

核心公式：**文化 × 制度 = 执行力**（价值观考核绑定行为，政委体系守护文化）

## 关键模块

### 模块1：独孤九剑（2001）

- 定义：阿里第一个价值观体系，9条生存法则，诞生于互联网寒冬
- 输入：创业团队在B2B业务中积累的协作经验和生存智慧
- 输出：早期阿里的行为共识和团队凝聚力
- 关键动作：
  - 9条：群策群力 / 教学相长 / 质量 / 简易 / 激情 / 开放 / 创新 / 专注 / 服务与尊重
  - 核心逻辑：创业期需要的是"怎么活下来"的行为准则，而非宏大叙事
  - "独孤"取自金庸武侠，寓意以九剑破万法——简单直接
- 常见误区：把独孤九剑当作六脉神剑的缩写版——两者语境完全不同，独孤九剑是生存期的应急共识，六脉神剑是成长期的制度设计

### 模块2：六脉神剑（2004）

- 定义：阿里最经典的价值观体系，6条行为准则，从9条精简而来，沿用15年
- 输入：独孤九剑的实践经验+组织规模化后的共识需求
- 输出：全员统一的行为标准和考核依据
- 关键动作：
  - 客户第一：不是口号，是决策优先级——客户利益与短期利润冲突时选客户
  - 团队合作：共享共赢，个人英雄主义不被鼓励
  - 拥抱变化：互联网行业唯一不变的是变化，抗拒变化=出局
  - 诚信：底线红线，触碰即出局，无商量余地
  - 激情：不是喊口号，是对事情发自内心的投入和执着
  - 敬业：把分内事做到极致，不是加班文化，是职业态度
- 常见误区：把6条当作并列关系——实际上有层级：诚信是底线（触碰即死），客户第一是北极星（决策优先级），其余4条是行为方式

### 模块3：九阳真经（2008）

- 定义：管理者专属的3条额外价值观，对六脉神剑的领导力补充
- 输入：管理者在带团队过程中暴露的"有业绩无格局"问题
- 输出：管理者的价值观考核标准（6+3=9条）
- 关键动作：
  - 胸怀：容得下不同意见，扛得住委屈，功劳归团队责任归自己
  - 眼光：看得见趋势，抓得住机会，能提前布局而非事后补救
  - 超越伯乐：培养出比自己更强的人，不是招比自己弱的人来确保安全
- 常见误区：把九阳真经当作六脉神剑的替代——它是补充而非替代，管理者考9条（6+3），普通员工考6条

### 模块4：新六脉神剑（2019）

- 定义：阿里20周年升级版价值观，从行为准则升级为战略表达
- 输入：组织从电商走向数字经济体的战略转型+价值观稀释的内部信号
- 输出：面向未来的价值观体系，更强调长期主义和生态思维
- 关键动作：
  - "客户第一，员工第二，股东第三"正式写入价值观——不是排序，是利益冲突时的优先级
  - 原有6条的表述升级——从"做什么"升级为"为什么做"
  - 新增对"因为信任所以简单"的强调——回应组织规模扩大后信任成本上升的问题
  - 对"拥抱变化"的重新诠释——从被动适应变为主动创造变化
- 常见误区：以为新六脉神剑推翻了旧版——内核完全一致，是表达升级而非方向转向

### 模块5：价值观考核机制

- 定义：将价值观嵌入绩效考核的硬约束机制，是阿里文化驱动的核心引擎
- 输入：员工日常行为表现+360度反馈
- 输出：1-5分的价值观评分+人才分类结果
- 关键动作：
  - 1-5分制：每条价值观配5个行为指南，共30项可观测指标
  - 价值观占绩效50%——与业绩各半，不是点缀而是半壁江山
  - 价值观打C（不符合）→绩效直接不及格，无论业绩多好
  - 价值观考核不是主观印象——30项行为指标让评分有据可依
  - 政委（HRBP）参与价值观评分，防止业务主管"只看业绩不看价值观"
- 常见误区：以为价值观考核是走过场——阿里的价值观考核是真刀真枪，C就是不及格，连续C就是淘汰

### 模块6：人才五分类

- 定义：基于业绩×价值观二维矩阵的五类人才分类及处置策略
- 输入：业绩评分+价值观评分
- 输出：分类结果+对应的培养/淘汰决策
- 关键动作：
  - 明星（业绩好+价值观好）：重奖重用，给舞台给资源
  - 老黄牛（业绩中+价值观好）：给机会给时间，帮助提升业绩
  - 小白兔（业绩差+价值观好）：给机会不改就开——"心要仁慈，刀要快"
  - 野狗（业绩好+价值观差）：必须开——业绩再好，价值观不过关就是毒瘤
  - 狗（业绩差+价值观差）：直接淘汰，无需犹豫
  - "心要仁慈，刀要快"：对小白兔要给机会（仁慈），给完机会不改就果断淘汰（刀快）；对野狗没有犹豫空间，价值观红线不可触碰
- 常见误区：以为"心要仁慈"意味着可以容忍低绩效——仁慈是给机会，不是无限等待；刀快是果断，不是残忍

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 业绩好但价值观不达标 | 野狗必开，业绩不能抵消价值观缺陷 | 人才五分类 |
| 价值观好但业绩持续不达标 | 给1-2次机会，不改则开，"心要仁慈刀要快" | 人才五分类 |
| 客户利益与短期利润冲突 | 客户第一，利润是客户满意的副产品 | 六脉神剑第1条 |
| 管理者只出业绩不培养人 | 检查"超越伯乐"——管理者必须培养出比自己更强的人 | 九阳真经第3条 |
| 组织规模扩大导致价值观稀释 | 价值观考核权重不能降，政委体系必须跟进 | 文化驱动逻辑 |
| 价值观考核流于形式 | 检查30项行为指标是否可观测——不可观测的指标等于没有考核 | 考核机制 |
| 招聘时价值观与能力冲突 | 价值观一票否决——能力可以培养，价值观很难改变 | 招聘原则 |
| 价值观需要升级 | 内核不变，表达升级——方向不变，语言与时俱进 | 新六脉神剑 |

## 适用场景

### 最适合

- 组织从创业期进入成长期，需要用价值观统一快速扩张的团队
- 业务高度依赖人的判断力而非流程执行——销售/运营/产品等"人效"型业务
- 需要在短时间内建立强文化认同的新组织或新团队
- 创始人希望将个人理念制度化，减少对个人魅力的依赖
- 行业变化快，需要"拥抱变化"作为组织基因

### 不适合

- 研发驱动型组织——代码质量靠流程和标准而非价值观驱动
- 强合规行业——金融/制药/航空，流程管控比价值观更重要
- 小团队（<50人）——人治效率更高，价值观考核增加管理成本
- 价值观考核无法做到行为指标可观测的组织——不可观测的考核比没有考核更糟
- 缺乏政委/HRBP体系支撑的组织——没有独立于业务线的文化守护者，价值观考核会被业务主管架空

## 实施检查清单

- [ ] 价值观是否不超过6-9条，且每条都有5个可观测的行为指南？
- [ ] 价值观考核是否占绩效≥30%（阿里是50%）？
- [ ] 价值观C是否有明确的淘汰机制？
- [ ] 是否有独立于业务线的文化守护者（政委/HRBP）参与价值观评分？
- [ ] 人才分类是否基于业绩×价值观二维矩阵？
- [ ] 野狗（业绩好+价值观差）是否有明确的淘汰规则？
- [ ] 小白兔（业绩差+价值观好）是否有"给机会→不改则开"的处置流程？
- [ ] 管理者是否有额外的价值观要求（如九阳真经）？
- [ ] 价值观体系是否有定期升级机制（不是推翻，是表达升级）？
- [ ] 价值观考核的30项行为指标是否全员可见且可讨论？

## 诚实边界

1. **考核的刚性代价**：价值观占绩效50%的硬绑定，意味着价值观评分的主观性直接影响员工切身利益。虽然30项行为指标试图客观化，但"激情""胸怀"等维度的评分仍不可避免地受主管主观判断影响。这是硬考核模式的内生矛盾。

2. **文化同质化风险**：价值观考核的强约束可能导致"价值观正确但缺乏多样性"的团队——人们为了拿高分而表演价值观行为，而非真正内化。阿里内部也有"价值观被用来整人"的批评声音。

3. **"心要仁慈刀要快"的执行困境**：理论上小白兔给机会不改就开，实际上很多管理者因为人情、团队稳定等因素迟迟不动刀。价值观考核的刚性设计恰恰说明人性天然倾向于"刀慢"。

4. **新六脉神剑的验证不足**：2019年升级后的新版本，公开资料尚缺乏充分的实践验证——升级是否真正解决了旧版的问题（如价值观稀释），还是只是换了表达？

5. **与华为基本法的规模差异**：阿里6+3条操作系统级的精简设计，优势是可执行性强，劣势是覆盖面窄——很多组织治理问题（如权力制衡、利益分配机制）在6+3条里找不到答案，需要靠其他制度补充。

6. **文化驱动的路径依赖**：阿里的文化驱动模式高度依赖创始人的个人魅力和早期铁军文化的沉淀。换一个没有马云式人物的组织，同样的价值观体系可能无法复制同样的效果。
