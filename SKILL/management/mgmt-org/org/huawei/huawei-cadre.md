# 华为 · 干部管理

> 从实战中选拔、在流动中培养、以战功论英雄的干部全生命周期管理体系

## 核心理念

干部管理解决的核心问题：如何确保组织的关键岗位始终由"打过仗、打过胜仗"的人占据？

很多企业的干部管理是"HR的事"——招聘、培训、考核、晋升，一套标准流程走完。华为的解法完全不同：干部管理不是HR流程，而是业务指挥系统的一部分。干部从业务中来（猛将必发于卒伍），在业务中成长（之字形成长），由业务结果评价（战功考核），向业务需要的地方流动（听从组织安排）。

核心思想可以概括为三点：
1. **将军是打出来的**：干部不是培养出来的，是在实战中选拔出来的；培训给的是方法，战场给的是能力
2. **流动即培养**：岗位轮换不是惩罚，而是培养；跨部门/跨区域/跨职能的"之字形"路径是干部成长的正途
3. **干部管理独立于HR**：2019年总干部部从HR体系拆分，干部的任免、整训、考核由专职机构负责，与员工管理分轨运行

## 关键模块

### 模块1：使命责任——干部的起点

- 定义：干部首先要有使命感，知道"为什么当干部"
- 输入：华为核心价值观（以客户为中心、以奋斗者为本）
- 输出：干部行为准则和责任边界
- 关键动作：
  - 明确干部的使命是"带领团队打胜仗"，不是"管人"
  - 干部必须践行核心价值观，言行不一者一票否决
  - 干部要承担"传帮带"责任，培养接班人
- 常见误区：把干部使命理解为"权力"而非"责任"；干部只顾自己不顾团队

### 模块2：标准——什么样的人能当干部

- 定义：干部选拔的标准体系，核心是"干部四力"
- 输入：岗位要求、业务挑战、组织发展阶段
- 输出：干部任职资格标准和选拔条件
- 关键动作：
  - 用干部四力（理解力+执行力+决断力+人际连接力）评估干部潜力
  - 不同层级干部对四力的侧重不同：基层重执行力，中层重理解力+人际连接力，高层重决断力
  - "猛将必发于卒伍"：必须有基层实战经历，不从外部空降
- 常见误区：用学历/资历/关系代替四力评估；从外部空降干部跳过基层历练

### 模块3：任用程序——怎么选干部

- 定义：干部选拔的流程机制，确保"选对人"
- 输入：干部标准、候选人池、业务需求
- 输出：干部任命决定
- 关键动作：
  - 三权分立：业务部门提名→HR审核资格→上级任命
  - 选拔而非任命：从打胜仗的人中选，不是从听话的人中选
  - 候选人必须有成功的业务经历（战功）
- 常见误区：领导一个人说了算；选拔标准模糊导致"谁关系好谁上"

### 模块4：能力发展——怎么培养干部

- 定义：干部能力提升的路径和方法
- 输入：干部能力差距、岗位要求
- 输出：培养计划（以实战锻炼为主，培训为辅）
- 关键动作：
  - 之字形成长：岗位轮换是干部培养的核心手段
    - 跨部门流动：理解不同业务逻辑
    - 跨区域流动：理解不同市场环境
    - 跨职能流动：理解不同专业视角
  - 培训给方法，战场给能力：721法则（70%实战+20%辅导+10%培训）
  - 关键岗位必须有后备，后备必须在实战中锻炼
- 常见误区：把培训当培养；轮岗变成"镀金"而非"历练"

### 模块5：评价激励——怎么考核干部

- 定义：干部绩效评价和激励机制
- 输入：PBC绩效结果、团队业绩、干部四力表现
- 输出：干部绩效等级、激励方案、发展建议
- 关键动作：
  - 干部评价看三件事：业务结果（打赢了没有）+团队建设（梯队建了没有）+价值观践行（以身作则没有）
  - 战功考核：以业务结果为硬指标，不以态度/过程为评价依据
  - 激励拉开差距：给火车头加满油，不让雷锋吃亏
- 常见误区：干部评价只看业务结果不看团队建设；激励搞平均主义

### 模块6：梯队建设——干部的可持续供给

- 定义：确保关键岗位始终有合格接班人的机制
- 输入：组织架构、关键岗位清单、现任干部年龄/任期
- 输出：后备干部名单、培养计划、继任时间表
- 关键动作：
  - 每个关键岗位至少有1-2名后备
  - 后备不是"指定"的，而是在实战中"冒出来"的
  - 后备培养以实战锻炼为主（项目历练、代职锻炼）
  - 定期审视后备池，淘汰不合格者，补充新冒出者
- 常见误区：后备变成"太子党"；后备长期不轮岗变成"备而不用"

### 模块7：监察——干部的约束机制

- 定义：对干部行为和决策的监督与纠偏
- 输入：审计结果、员工投诉、业务异常
- 输出：调查结论、处理决定、制度改进建议
- 关键动作：
  - 经济责任审计：干部离任必审
  - 民主生活会：干部自我批评+互相批评
  - 蓝军机制：专门挑毛病的反向思考团队
  - 一票否决：腐败、重大决策失误、价值观严重偏离
- 常见误区：监察变成政治斗争工具；只查不纠

### 模块8：总干部部——干部管理的组织保障

- 定义：2019年从HR体系拆分出的专职干部管理机构
- 输入：业务需求、干部池、组织战略
- 输出：干部任免决定、整训方案、考核结果
- 关键动作：
  - 干部任免：由总干部部主导，非业务部门自行决定
  - 队伍整训：定期组织干部集中学习和整训
  - 战功考核：以业务结果为核心评价干部
  - 与HR分轨：员工管理归HR，干部管理归总干部部
- 常见误区：总干部部变成"第二个HR"；干部任免仍由业务一把手说了算

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 干部选拔 | 如果候选人没有基层打胜仗的经历，则不考虑提拔 | "猛将必发于卒伍" |
| 外部空降干部 | 如果是成熟业务岗位，优先内部选拔；如果是全新业务领域，可考虑外部引进 | 华为干部选拔实践 |
| 干部轮岗 | 如果干部在同一岗位超过3年且业绩平稳，则应启动轮岗 | 之字形成长原则 |
| 干部淘汰 | 如果干部连续两年绩效C及以下，则应免职或降级 | 华为干部淘汰机制 |
| 后备干部选拔 | 如果后备只在培训中表现好但实战中没有突出业绩，则不应列入后备 | "将军是打出来的" |
| 干部四力评估 | 如果基层干部执行力弱，则不适合提拔；如果高层干部决断力弱，则不适合继续留任 | 干部四力模型 |
| 跨部门调动 | 如果干部拒绝组织安排的轮岗，则视为不服从组织，影响晋升 | 华为干部流动纪律 |

## 适用场景

### 最适合

- 规模化企业（500人以上），有足够多的岗位支撑轮岗
- 业务复杂度高、需要跨领域视野的行业
- 强调执行力+结果导向的组织文化
- 关键岗位风险高（干部不胜任代价大）的企业
- 愿意在干部培养上做长期投入的组织

### 不适合

- 小型企业（岗位少，轮岗空间有限）
- 专业性极强的岗位（如首席科学家，轮岗反而损失专业深度）
- 不愿接受"组织安排"流动的文化（干部会抵触轮岗）
- 没有足够业务规模支撑"打胜仗"选拔的组织

## 实施检查清单

- [ ] 是否建立了"从实战中选拔"的机制（非领导指定）
- [ ] 是否建立了干部轮岗制度（轮岗周期、轮岗路径、轮岗保障）
- [ ] 是否建立了关键岗位后备制度（每个关键岗位1-2名后备）
- [ ] 是否建立了干部绩效评价体系（业务结果+团队建设+价值观）
- [ ] 是否建立了干部淘汰/降级机制（连续低绩效如何处理）
- [ ] 是否建立了干部监察机制（审计+民主生活会+蓝军）
- [ ] 是否有专职机构负责干部管理（非HR兼职）
- [ ] 是否建立了干部"服从组织安排"的流动纪律

## 诚实边界

1. **"打出来"的局限**：从实战中选拔意味着必须有仗可打，新业务/新领域初期可能没有足够的"战场"来选拔干部
2. **轮岗的代价**：干部轮岗有学习曲线，短期内业务可能波动；优秀干部被轮走对原部门是损失
3. **总干部部的权力风险**：专职机构如果缺乏制衡，可能形成新的权力中心
4. **文化前提**：干部管理有效运行需要"服从组织安排"的文化，在强调个人自由选择的文化中难以推行
5. **规模前提**：之字形成长需要足够多的岗位和业务场景，小组织无法提供
6. **公开资料局限**：干部七步曲的完整操作细则（如任免流程细节、后备池管理方法）未公开，本文基于公开资料推断
