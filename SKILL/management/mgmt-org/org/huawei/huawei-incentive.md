# 华为 · 科学分钱（激励机制）

> 用价值链闭环驱动"以奋斗者为本"的三层激励体系

## 核心理念

科学分钱解决的核心问题：如何让分配机制成为价值创造的加速器而非刹车片？

很多企业的激励是"分蛋糕"思维——年终算利润，按职级分钱，结果大锅饭、养懒人。华为的解法是"做蛋糕→量蛋糕→分蛋糕"的闭环：先定义什么是价值创造（做蛋糕），再建立价值评价体系（量蛋糕），最后按贡献分配（分蛋糕）。分配不是终点，而是下一轮价值创造的起点。

核心思想可以概括为三点：
1. **价值链闭环**：价值创造→价值评价→价值分配，三者缺一不可；没有评价的分配是撒钱，没有分配的评价是空谈
2. **三层激励锁定**：短期（工资+奖金）锁定当下，中期（TUP）锁定3-5年，长期（虚拟受限股）锁定长期，形成递进式绑定
3. **拉开差距**：给火车头加满油，不让雷锋吃亏；同层级收入差距可达3-5倍

## 关键模块

### 模块1：价值创造——做蛋糕

- 定义：定义什么行为和结果算"创造了价值"
- 输入：战略目标、业务计划、客户需求
- 输出：价值创造的衡量标准（哪些算、哪些不算）
- 关键动作：
  - 以客户为中心：只有为客户创造价值的活动才算价值创造
  - 以结果为导向：过程努力不等于价值创造，拿到结果才算
  - 多打粮食：利润、收入、回款是硬指标，能力建设是软指标
- 常见误区：把"忙"等同于"创造价值"；把内部汇报/流程工作算作价值创造

### 模块2：价值评价——量蛋糕

- 定义：建立衡量价值贡献大小的评价体系
- 输入：PBC绩效结果、业务贡献、能力成长
- 输出：绩效等级、贡献排序、激励资格
- 关键动作：
  - PBC绩效评价是价值评价的核心工具
  - 区分"奋斗者"和"普通贡献者"：不是所有人都享受同等激励
  - 评价维度：业务结果（硬）+团队贡献（软）+价值观践行（底线）
- 常见误区：评价标准模糊导致"谁声音大谁分得多"；只看短期结果不看长期贡献

### 模块3：价值分配——分蛋糕

- 定义：按价值评价结果进行差异化分配
- 输入：绩效等级、职级、司龄、激励资格
- 输出：工资调整、奖金额度、TUP授予、虚拟股配售
- 关键动作：
  - 三条分配原则：
    - 以奋斗者为本：激励向奋斗者倾斜，非平均分配
    - 拉开差距：同层级收入差距3-5倍，拒绝大锅饭
    - 给火车头加满油：最优秀的人获得最大激励
  - 分配顺序：先分给奋斗者，再考虑其他人
- 常见误区：搞平均主义"雨露均沾"；怕差距大影响和谐

### 模块4：短期激励——工资+奖金

- 定义：当期兑现的激励，锁定当下的执行力
- 输入：岗位价值、个人绩效、市场薪酬水平
- 输出：月度工资+年度/季度奖金
- 关键动作：
  - 工资：基于岗位价值和市场水平，保障基本生活
  - 奖金：基于绩效结果，拉开差距
  - 奖金包机制：部门奖金包=部门业绩×分配系数，个人奖金=包内按绩效分配
  - 奖金是"挣出来的"不是"发下来的"
- 常见误区：奖金搞职级制（高职级自动高奖金）；奖金与绩效弱关联

### 模块5：中期激励——TUP（时间单位计划）

- 定义：5年递进解锁的分红权激励，锁定3-5年中期留存
- 输入：个人绩效、职级、授予资格
- 输出：TUP份额及年度分红收益
- 关键动作：
  - 授予：根据绩效和职级授予TUP份额，无需出资购买
  - 5年递进解锁机制：

| 年度 | 分红比例 | 说明 |
|------|---------|------|
| 第1年 | 0% | 等待期，无分红 |
| 第2年 | 1/3 | 开始享受1/3分红权 |
| 第3年 | 2/3 | 享受2/3分红权 |
| 第4年 | 100% | 享受全额分红权 |
| 第5年 | 100%+结算 | 享受全额分红+增值结算后清零 |

  - 结算清零：第5年结束后TUP份额清零，需重新授予
  - 无需出资：与虚拟股不同，TUP不需要员工掏钱买
- 常见误区：把TUP等同于期权（TUP无行权价）；以为TUP可以长期持有（5年必清零）

### 模块6：长期激励——虚拟受限股

- 定义：华为独有的长期股权激励，只有分红权和增值权，无表决权和转让权
- 输入：个人绩效、职级、司龄、配售资格
- 输出：虚拟股份额及年度分红收益
- 关键动作：
  - 四大约束：
    - 无表决权：不参与公司治理决策
    - 不可转让：不能在二级市场交易
    - 离职回购：离开公司时由公司按净资产回购
    - 只有分红权+增值权：享受年度分红和股价增值
  - 配售机制：根据绩效和职级配售，需要员工出资购买
  - 分红数据（2024年）：每股分红1.41元，股价7.85元，收益率约18%
  - 动态进退：每年根据绩效调整持股，绩效差则减少配售甚至回购
- 常见误区：把虚拟股等同于真实股权（无所有权）；以为离职可以带走股份（必须回购）

### 模块7：三层激励的协同逻辑

- 定义：短期/中期/长期三层激励如何协同运作
- 输入：员工职业生命周期、绩效轨迹
- 输出：不同阶段的激励组合方案
- 关键动作：
  - 入职1-3年：以工资+奖金为主，辅以少量TUP（锁定中期）
  - 入职3-5年：工资+奖金+TUP递进解锁，开始配售虚拟股（锁定长期）
  - 入职5年以上：三层激励全面覆盖，虚拟股成为收入重要组成部分
  - 核心逻辑：短期激励保执行，中期激励保留存，长期激励保忠诚
- 常见误区：只做短期激励（员工随时可走）；只做长期激励（短期缺乏动力）

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 奖金分配 | 如果同层级奖金差距不到2倍，则分配过于平均，需拉开 | "给火车头加满油" |
| TUP授予 | 如果员工绩效连续两年A，则应授予TUP；如果绩效C及以下，则不授予 | 华为TUP授予实践 |
| 虚拟股配售 | 如果员工司龄<3年，则不配售虚拟股（用TUP过渡） | 华为股权激励实践 |
| 离职回购 | 如果员工主动离职，则按净资产回购虚拟股，不享受当年分红 | 虚拟受限股规则 |
| 绩效差的处理 | 如果干部绩效连续两年C，则减少/取消TUP和虚拟股配售 | 价值链闭环原则 |
| 新业务激励 | 如果是新业务（短期无利润），则提高TUP比例降低奖金比例 | 华为新业务激励实践 |
| 激励预算不足 | 如果总包有限，则优先保"火车头"（A级）的激励，压缩C/D级 | "以奋斗者为本" |

## 与其他方法论的关系

| 关联方法论 | 关系 | 接口 |
|-----------|------|------|
| PBC | 上游 | PBC绩效等级是价值评价的核心输入，决定奖金/TUP/虚拟股分配 |
| 干部管理 | 上游 | 干部绩效评价结果输入激励分配；干部享受更高比例的TUP和虚拟股 |
| BEM | 间接上游 | BEM→PBC→绩效评价→激励分配 |
| 熵减 | 理论基础 | 激励拉开差距+末位淘汰是熵减在分配领域的实践 |
| 华为基本法 | 上游 | 基本法第17-19条定义了知识资本化和价值分配原则 |
| DSTE | 间接上游 | 战略→组织→绩效→激励，激励是战略落地的最后一环 |

## 适用场景

### 最适合

- 规模化企业（500人以上），有足够利润支撑三层激励
- 高增长行业（利润增长可覆盖股权激励成本）
- 需要长期绑定核心人才的企业
- 业务结果可量化、可评价的组织
- 愿意在分配上拉开差距的文化

### 不适合

- 利润微薄或亏损的企业（无法支撑TUP和虚拟股分红）
- 不愿意公开薪酬差距的组织（"给火车头加满油"会引发内部矛盾）
- 员工流动性极高的行业（TUP和虚拟股的锁定效应无法发挥）
- 非营利组织或体制内单位（分配机制受外部约束）
- 没有清晰绩效评价体系的企业（价值评价缺失则价值分配无依据）

## 实施检查清单

- [ ] 是否建立了价值创造→价值评价→价值分配的闭环体系
- [ ] 是否定义了"奋斗者"的识别标准（非全员平等激励）
- [ ] 是否建立了短期激励（工资+奖金）的绩效挂钩机制
- [ ] 是否设计了中期激励（TUP或等效工具）的递进解锁机制
- [ ] 是否设计了长期激励（虚拟股或等效工具）的约束条件
- [ ] 是否建立了三层激励的协同逻辑（不同阶段不同组合）
- [ ] 是否建立了激励的动态调整机制（绩效差则减少激励）
- [ ] 是否建立了离职回购机制（防止股权外流）
- [ ] 是否在分配上敢于拉开差距（同层级3-5倍差距）
- [ ] 是否建立了激励预算的管理机制（总包控制+结构优化）

## 诚实边界

1. **利润前提**：三层激励的运转依赖持续盈利，如果利润下滑（如2022年华为净利润大幅波动），分红和虚拟股收益会受影响
2. **虚拟股的法律风险**：虚拟受限股在中国法律框架下存在争议，非上市公司股权激励的法律保障较弱
3. **锁定效应的双面性**：TUP和虚拟股锁定员工的同时，也降低了员工的流动性选择权，可能造成"金手铐"效应
4. **18%收益率的不可持续性**：2024年18%的分红收益率建立在华为特殊的高利润基础上，普通企业无法复制
5. **拉开差距的代价**：收入差距3-5倍在强调公平的文化中可能引发严重内部矛盾
6. **公开资料局限**：华为激励的完整方案（如TUP授予算法、虚拟股回购定价公式、奖金包计算模型）未公开，本文基于公开资料推断
