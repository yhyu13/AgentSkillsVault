# 胖东来 · 员工自治+轮值

> 用轮值打破权力固化，用委员会替代个人权威，用满意度投票决定管理者的去留——把"谁来管"的答案从"老板指定"变成"员工说了算"。

## 核心理念

员工自治+轮值要解决的根本问题是：**组织权力如何避免固化与腐败。**

任何组织都面临同一个陷阱——权力一旦集中在少数人手中，就会自然产生三个后果：信息向上过滤（只报喜不报忧）、决策脱离一线（坐在办公室想当然）、管理者对上负责而非对下负责（讨好上级而非服务员工）。传统企业的解决方案是"换人"——换CEO、换总监、换店长，但换人只是换了一个独裁者，权力结构本身没有改变。

胖东来的做法是从结构层面拆解权力：把一个人的权力拆成一群人的权力（决策委员会），把固定岗位的权力拆成流动的权力（三级轮值），把"上级任命"的合法性来源拆成"下级投票"的合法性来源（满意度罢免）。三者叠加，形成一套"权力无法停留"的治理系统——没有人能长期占据权力，没有人能独自做出重大决策，没有人能在员工不满意的情况下继续留任。

核心思想概括为三点：
1. **集体决策替代个人拍板**：8名核心业务主管组成决策委员会，重大经营事项集体讨论、集体表决，任何个人无法单独拍板
2. **轮值流动替代权力固化**：三级轮值覆盖从门店到集团的全层级，权力是流动的，岗位是共享的，没有人"拥有"某个管理位置
3. **自下而上的合法性**：管理层竞聘上岗、年度匿名评议、满意度低于80%即罢免——管理者的权力来自被管理者的认可，而非上级的授权

## 框架结构

```
员工自治+轮值 = 权力无法停留的治理系统
│
├── 决策层：决策委员会
│   ├── 8名核心业务主管
│   ├── 日常经营集体决策
│   └── 于东来2026年退居顾问，不再参与日常经营
│
├── 执行层：三级轮值
│   ├── 店长级：按天轮值
│   ├── 业态总经理级：按月轮值
│   └── 集团总经理级：按季度轮值
│
├── 制度层：员工自定规则
│   └── 管理制度由员工讨论制定，而非管理层自上而下颁布
│
├── 准入层：竞聘上岗
│   └── 管理岗位通过公开竞聘产生，而非上级任命
│
└── 退出层：满意度罢免
    ├── 年度匿名评议，满意度<80%即罢免
    └── 每月文化考试<80分即停岗
```

## 关键模块

### 模块1：决策委员会

- 定义：由8名核心业务主管组成的集体决策机构，替代创始人个人决策
- 输入：重大经营事项、战略方向、资源分配方案
- 输出：集体表决后的经营决策
- 关键动作：
  - 8名核心业务主管构成委员会，覆盖主要业务板块
  - 日常经营事项由委员会集体讨论、集体表决，不设"一票否决"
  - 于东来2026年正式退居顾问角色，日常经营完全交给决策委员会
  - 创始人从"决策者"变为"文化守护者"——保留价值观层面的影响力，退出经营层面的操作权
- 常见误区：把决策委员会等同于"民主投票"——委员会不是一人一票的简单多数决，而是基于专业判断的集体审议，讨论质量比投票结果更重要

### 模块2：三级轮值

- 定义：从门店到集团的三个管理层级均实行轮值制，权力按时间周期流转
- 输入：轮值周期规则、候选人资格标准、轮值交接流程
- 输出：管理权力的定期流转与更替
- 关键动作：
  - 店长级按天轮值：每天换一人主持门店运营，确保每位店长都熟悉全流程
  - 业态总经理级按月轮值：每月换一人统筹业态经营，兼顾决策连续性与视角多样性
  - 集团总经理级按季度轮值：每季度换一人负责集团层面经营，周期足够长以推动战略落地，又足够短以防止权力固化
  - 轮值不是"值班"——轮值者在任期内拥有该岗位的完整决策权，而非仅执行既定方案
- 常见误区：认为轮值会导致决策不连续——轮值的本质是"视角轮换"而非"方向摇摆"，决策委员会提供方向稳定性，轮值提供执行视角的多样性

### 模块3：员工自定管理制度

- 定义：企业的管理制度由员工讨论制定，而非管理层自上而下颁布
- 输入：一线运营痛点、员工诉求、行业最佳实践
- 输出：员工参与制定的运营规范和管理规则
- 关键动作：
  - 制度起草过程向全体员工开放，一线员工可以直接提出制度建议
  - 制度通过前需经员工讨论和反馈，而非管理层闭门制定后直接下发
  - 员工自定规则的底层逻辑：只有被管理者参与制定的规则，才会被真正遵守——外部强加的制度永远在执行层面打折扣
- 常见误区：把"员工自定"理解为"员工想怎样就怎样"——员工自定的是管理制度（考勤、排班、服务标准等），而非企业战略和价值观——战略和价值观是于东来定下的文化基石

### 模块4：竞聘上岗

- 定义：管理岗位通过公开竞聘产生，而非上级直接任命
- 输入：岗位需求、候选人资质、竞聘评审标准
- 输出：通过竞争选拔产生的管理者
- 关键动作：
  - 管理岗位空缺时公开发布，符合条件的员工均可报名
  - 竞聘过程公开透明，包含述职、答辩、评议等环节
  - 竞聘上岗的本质是"能力导向"替代"关系导向"——管理者不是因为跟上级关系好而上位，而是因为在一群人面前证明了自己能干
- 常见误区：认为竞聘只是走形式——如果竞聘评审标准模糊、评委全是上级，那竞聘就是披着民主外衣的任命。竞聘的有效性取决于评审标准的客观性和评审人的多元性

### 模块5：满意度罢免

- 定义：年度匿名评议中满意度低于80%的管理者即被罢免，每月文化考试低于80分即停岗
- 输入：员工匿名评议数据、文化考试成绩
- 输出：不合格管理者的免职决定
- 关键动作：
  - 年度匿名评议覆盖所有管理者，评议结果直接决定去留
  - 80%满意度是硬线——低于这个数字，不论资历、不论业绩，直接罢免
  - 每月文化考试低于80分停岗——文化认同不是软要求，而是硬门槛
  - 罢免机制的本质：管理者的合法性来自被管理者的认可，而非上级的庇护
- 常见误区：认为满意度罢免会导致管理者"讨好员工"——80%的门槛设计恰恰防止了这一点：管理者需要的是"多数人认可"，而非"所有人满意"，80%的阈值留出了20%的容错空间，避免陷入"讨好型管理"

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 是否设立决策委员会 | 如果组织依赖创始人个人决策且创始人有退出计划→必须建立委员会实现权力过渡 | 于东来2026年退居顾问 |
| 轮值周期设计 | 如果岗位决策频次高→短周期轮值（天）；如果决策影响范围大→长周期轮值（季度） | 三级轮值实践 |
| 管理者选拔方式 | 如果要打破"关系导向"→竞聘上岗；如果要确保"能力导向"→竞聘评审标准必须客观 | 竞聘上岗机制 |
| 满意度罢免阈值 | 如果设50%→管理者只需讨好一半人；如果设95%→几乎无人能留任；80%是"多数认可"与"容错空间"的平衡点 | 80%满意度硬线 |
| 文化考试停岗线 | 如果文化认同是组织的核心竞争力→必须设硬门槛；80分与80%满意度形成双80规则 | 每月文化考试 |
| 制度制定权归属 | 如果制度执行效果取决于一线员工配合度→让一线员工参与制定 | 员工自定管理制度 |
| 创始人退出节奏 | 如果文化根基已稳固→创始人可退居顾问；如果文化尚未内化→创始人退出会导致制度崩塌 | 于东来退居顾问 |

## 与其他方法论的关系

| 关联方法论 | 关系 | 接口 |
|-----------|------|------|
| 华为轮值CEO | 对比参照 | 华为轮值CEO是高层轮值（3位轮值），胖东来三级轮值覆盖全层级——华为解决的是"谁来掌舵"，胖东来解决的是"权力不能停留" |
| Netflix知情船长 | 对比参照 | Netflix指定最知情的人做决策（个体决策），胖东来用轮值+委员会集体决策——Netflix追求决策速度，胖东来追求权力制衡 |
| Amazon单线程领导 | 对比参照 | Amazon用100%专职消除跨团队依赖，胖东来用轮值消除权力固化——Amazon的敌人是"依赖"，胖东来的敌人是"固化" |
| 胖东来极致利润共享 | 上游支撑 | 利润共享让员工成为利益共同体，自治+轮值让员工成为权力共同体——没有利益共享，自治就是空壳 |
| 胖东来极致透明经营 | 并行支撑 | 透明经营让信息对称，自治+轮值让权力对称——信息对称是权力对称的前提 |

### 胖东来 vs 华为：全层轮值 vs 高层轮值

| 维度 | 胖东来员工自治+轮值 | 华为轮值CEO |
|------|-------------------|-----------|
| 轮值范围 | 全层级——店长/业态总经理/集团总经理三级轮值 | 仅高层——3位轮值CEO |
| 轮值目的 | 消除权力固化——权力不能停留在任何人手中 | 培养接班人——轮值是历练，不是制衡 |
| 决策机制 | 委员会集体决策 | 轮值CEO个人决策（EMT集体议事） |
| 退出机制 | 满意度<80%即罢免 | 无公开的满意度罢免机制 |
| 权力来源 | 自下而上——员工评议决定去留 | 自上而下——董事会任命轮值CEO |
| 适用逻辑 | 劳动密集型——一线服务质量决定客户体验 | 技术密集型——战略判断力决定企业方向 |

### 胖东来 vs Netflix：集体轮值 vs 知情船长

| 维度 | 胖东来员工自治+轮值 | Netflix知情船长 |
|------|-------------------|---------------|
| 决策模式 | 集体决策——委员会讨论表决 | 个体决策——指定最知情的人拍板 |
| 权力分配 | 轮值流动——权力按周期流转 | 固定授权——船长在特定领域拥有决策权 |
| 制衡机制 | 委员会制衡+满意度罢免 | 依赖坦诚文化+360度反馈 |
| 假设前提 | 权力需要被分散和流动 | 最知情的人做最快最好的决策 |
| 速度取舍 | 慢——集体讨论耗时，但防止单点失误 | 快——个体决策高效，但依赖判断力 |
| 适用场景 | 权力腐败风险高的组织 | 人才密度高、判断力强的组织 |

### 胖东来 vs Amazon：轮值消固化 vs 专职消依赖

| 维度 | 胖东来员工自治+轮值 | Amazon单线程领导 |
|------|-------------------|----------------|
| 核心敌人 | 权力固化——一个人长期占据岗位导致思维僵化 | 跨团队依赖——一个人兼顾多项目导致优先级冲突 |
| 解决手段 | 轮值——让权力流动起来 | 专职——让一个人100%投入一件事 |
| 权力逻辑 | 权力共享——轮值者共同拥有岗位经验 | 权力集中——单线程领导对该项目拥有完整决策权 |
| 组织假设 | 管理能力是可培养的——轮值让更多人获得锻炼 | 专注才能卓越——分散注意力是最大的浪费 |
| 副作用 | 短期决策连续性可能受损 | 长期可能形成信息孤岛 |

## 适用场景

### 最适合

- 创始人计划退出、需要制度化权力过渡的企业
- 一线服务质量决定客户体验的劳动密集型组织
- 权力腐败风险高、管理层级不多的中小型组织
- 已建立强文化认同、员工价值观高度一致的组织
- 追求"权力制衡"而非"决策效率"的治理场景

### 不适合

- 需要快速战略决策的技术密集型企业——集体决策拖慢节奏
- 管理层级超过5层的大型集团——轮值在多层级的传递损耗过大
- 文化尚未建立的新创企业——没有文化共识，自治会变成无序
- 高度依赖个体判断力的创意/投资类组织——轮值稀释了顶尖判断力的价值
- 竞争环境剧烈变化、需要快速应变的行业——轮值交接期可能错失窗口

## 实施检查清单

- [ ] 是否建立了集体决策机构（决策委员会）并明确其权责范围
- [ ] 是否设计了三级轮值制度并明确各层级的轮值周期
- [ ] 轮值者在任期内是否拥有完整决策权（而非仅值班权）
- [ ] 管理岗位是否通过公开竞聘产生（而非上级任命）
- [ ] 是否建立了年度匿名评议机制并设定满意度罢免硬线
- [ ] 满意度罢免阈值是否设在80%（平衡"多数认可"与"容错空间"）
- [ ] 是否建立了文化考试机制并设定停岗硬线（80分）
- [ ] 管理制度是否由员工参与制定（而非管理层闭门制定）
- [ ] 创始人是否已规划退出路径并明确顾问角色边界
- [ ] 决策委员会与轮值机制之间是否有清晰的权责划分（方向vs执行）

## 诚实边界

1. **创始人退出的不可逆风险**：于东来2026年退居顾问，这套自治系统能否在他完全退出后持续运转，目前没有验证。决策委员会的8名主管都是于东来培养的，他们的决策模式深受其影响。当这一代人退休后，下一代是否还能维持集体决策的质量，存疑。

2. **集体决策的效率代价**：8人委员会的集体决策天然比个人决策慢。在需要快速反应的经营场景中（如供应链危机、公关事件），委员会可能成为瓶颈。胖东来目前没有公开的"紧急决策例外机制"。

3. **轮值的连续性损耗**：店长按天轮值意味着每天换一个负责人，这对门店运营的连续性是挑战。虽然决策委员会提供方向稳定性，但一线执行层面，频繁的负责人更替可能导致标准执行的不一致。

4. **满意度罢免的讨好风险**：80%满意度硬线在理论上留出了20%容错空间，但在实践中，管理者可能倾向于"不做错事"而非"做对的事"——因为得罪人的决策会直接拉低满意度。创新性决策往往伴随争议，罢免机制可能抑制管理者的冒险意愿。

5. **文化考试的标准化困境**：每月文化考试低于80分停岗，前提是考试内容能准确衡量"文化认同"。但文化认同本质上是主观的、情境化的，标准化考试容易沦为"背诵标准答案"，而非真正内化价值观。

6. **与华为轮值CEO对比的局限**：华为轮值CEO是在3位高管之间轮值，且轮值CEO拥有完整的经营决策权，本质上是一种"轮流执政"。胖东来的三级轮值覆盖更广，但轮值者的权力受决策委员会制约，更接近"轮流执行"而非"轮流执政"。两者虽然都叫"轮值"，权力结构差异很大。

7. **规模边界**：胖东来目前仅16家店、约1.2万员工，这套自治系统在这个规模下可行。当组织规模扩大到数万人、跨区域运营时，8人委员会的信息处理能力和三级轮值的协调成本都会成为瓶颈。
