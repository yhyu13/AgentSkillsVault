# 丰田 · TPS精益生产

> 只在需要的时候，生产需要的东西，生产需要的数量——彻底消除浪费

## 核心理念

TPS（Toyota Production System）的核心命题是：如何用最少的资源满足客户需求？答案不是加快速度，而是消除一切不创造价值的活动。两大支柱——JIT（准时化）和自働化（带人字旁的自动化）——构成系统的骨架：JIT确保不生产多余的东西，自働化确保不合格的东西不流入下一环节。浪费不是成本，是犯罪。

## 框架结构

```
TPS精益生产系统
├── 基础：彻底消除浪费
│     └── 七大浪费
│           ├── 制造过剩（最严重的浪费）
│           ├── 停工待料（等待）
│           ├── 搬运
│           ├── 加工过剩
│           ├── 库存
│           ├── 动作浪费
│           └── 次品（返工）
├── 支柱1：JIT准时化生产
│     ├── 只在需要的时候
│     ├── 生产需要的数量
│     └── 工具：看板、均衡化、连续流
├── 支柱2：自働化（Jidoka）
│     ├── 异常时自动停止
│     ├── 人机分离
│     └── 工具：安灯、防错（Poka-yoke）
└── 地基：5S + 标准化作业
```

## 关键模块

### 模块1：JIT准时化生产

- 定义：后工序在需要的时候，到前工序取走需要的量；前工序只补充被取走的量
- 输入：客户订单（最终拉动源）
- 输出：零库存的连续流
- 关键动作：建立连续流（消除工序间等待）；实施看板拉动（可视化信号卡控制生产指令）；均衡化排程（品种和数量均衡分配）
- 常见误区：把JIT理解为"零库存"目标而强行压库存，不改变流程只压供应商

### 模块2：自働化（Jidoka）

- 定义：当异常发生时，设备或人自动停止生产线，不让缺陷流入下一工序
- 输入：设备异常、质量缺陷、操作偏差
- 输出：被隔离的缺陷+立即触发的改善
- 关键动作：安装防错装置（Poka-yoke）；安灯系统（Andon）让任何人可以停线；人机分离——设备自动运转时人可以离开去做其他工作
- 常见误区：只关注自动化程度，忽略"异常即停"的机制设计

### 模块3：七大浪费

- 定义：一切消耗资源但不创造客户价值的活动
- 输入：当前流程的全面观察
- 输出：浪费清单及消除优先级
- 关键动作：现场走查识别浪费；制造过剩是万恶之源（它掩盖其他浪费）；库存是"水面"，浪费是"礁石"——降低库存让问题暴露
- 常见误区：只关注动作层面的浪费，忽视制造过剩和库存这两大系统性浪费

### 模块4：标准化作业

- 定义：当前已知的最佳工作方法，作为改善的起点而非终点
- 输入：工作分解、节拍时间、作业顺序
- 输出：标准作业单（三要素：节拍时间、作业顺序、标准在制品量）
- 关键动作：记录当前最佳实践；定期审查更新；标准是改善的基线
- 常见误区：把标准化当作僵化的规定，不允许偏离；或标准化后不再更新

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 发现库存堆积 | 库存是掩盖问题的水面，降低库存暴露根因 | 大野耐一 |
| 不确定是否该继续生产 | 如果没有被下游取走，就不生产 | JIT原则 |
| 设备出现异常 | 立即停止，解决问题后再继续 | 自働化原则 |
| 发现缺陷品 | 不让缺陷流入下一工序，就地解决 | 自働化原则 |
| 选择改善优先级 | 先消除制造过剩的浪费，它是其他浪费的根源 | 七大浪费排序 |
| 想增加库存"以防万一" | 增加库存=增加掩盖问题的水面 | 库存-礁石隐喻 |

## 适用场景

### 最适合

- 重复性生产/服务流程
- 需要缩短交期、降低库存的制造场景
- 流程中存在大量等待、搬运、库存的场景
- 希望建立"问题即改善机会"文化的组织

### 不适合

- 高度定制化的一次性项目（如建筑、大型工程）
- 创意性工作（设计、研发早期阶段）
- 需求极度不稳定的场景（JIT的前提是相对可预测的需求）

## 实施检查清单

- [ ] 是否识别了流程中的七大浪费并排序
- [ ] 是否建立了连续流（而非批量排队）
- [ ] 是否实施了拉动式生产（看板或其他信号机制）
- [ ] 异常时是否能自动/手动停线
- [ ] 是否有防错装置防止缺陷流入下一工序
- [ ] 是否有标准化作业文件且定期更新
- [ ] 5S是否到位（TPS运行的基础环境）
- [ ] 是否在降低库存而非增加库存（库存=掩盖问题）

## 诚实边界

1. JIT对供应链稳定性要求极高，任何环节断裂都会导致全线停工
2. "零库存"是方向而非目标，实际需要根据供应链风险保留安全库存
3. TPS在丰田的成功依赖数十年积累的组织文化，工具可以复制，系统难以复制
4. 七大浪费框架主要针对制造业，服务业需要重新定义"浪费"
5. 自働化要求员工有停线的权力，这在等级森严的组织中难以实现
