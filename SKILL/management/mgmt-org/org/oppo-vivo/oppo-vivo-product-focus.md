# OPPO/vivo · 产品聚焦

> 单款打爆而非机海战术，聚焦旗舰+中端两个价位段——少做才能做好，做好才能打爆

## 核心理念

OPPO/vivo的产品策略是"少就是多"在产品层面的具体实践。与三星、华为等品牌的多机型覆盖策略不同，OPPO/vivo选择在每个价位段只做1-2款产品，但做到该价位段的极致。OPPO的Find系列和Reno系列、vivo的X系列和S系列，每个系列每年只出1-2代，但每一代都集中全公司最优质的资源打磨。这种策略的逻辑是：产品数量越少，每款产品获得的资源越多；资源越集中，产品力越强；产品力越强，单款销量越大；单款销量越大，供应链成本越低；供应链成本越低，产品性价比越高——形成正循环。机海战术的问题在于：每款产品分到的资源都不够，每款产品都做不到极致，每款产品都没有足够的销量支撑供应链优化，最终陷入"多而不精"的恶性循环。

核心命题：**产品聚焦的本质不是少做产品，而是用"少"换"精"——少做才能做好，做好才能打爆，打爆才能建立品牌心智。**

## 关键模块

### 模块1：旗舰价位段聚焦——OPPO Find / vivo X Pro

- 定义：在旗舰价位段（4000-6000元）只做1-2款产品，集中全部资源打造该价位段的标杆
- 输入：旗舰市场的用户需求和竞争格局
- 输出：旗舰价位段的品牌标杆和利润贡献
- 关键动作：
  - OPPO Find系列：每年1代，集中影像/设计/性能全部顶级资源
  - vivo X Pro系列：每年1代，影像长板做到行业最强
  - 不做旗舰机海——不做Pro+/Ultra+/折叠屏等衍生型号稀释资源
  - 旗舰定价不追高——旗舰价位段坚守4000-6000元，不追8000元以上超高端
- 常见误区：以为旗舰聚焦就是做最贵的手机——旗舰聚焦是在旗舰价位段做到最好，不是做最贵的手机

### 模块2：中端价位段聚焦——OPPO Reno / vivo S系列

- 定义：在中端价位段（2000-3500元）只做1-2款产品，用旗舰级体验降维打击中端市场
- 输入：中端市场的主力消费需求
- 输出：中端价位段的销量担当和规模效应
- 关键动作：
  - OPPO Reno系列：每年1-2代，设计+影像为核心卖点
  - vivo S系列：每年1-2代，自拍+外观为核心卖点
  - 旗舰技术下放——将旗舰的影像算法、快充技术下放到中端
  - 中端不做多款——不做Lite/SE/Y等衍生型号，聚焦1-2款做到极致
- 常见误区：以为中端聚焦就是做便宜的旗舰——中端聚焦是在中端价位段做到最好，不是旗舰的缩水版

### 模块3：资源集中——每款产品都是全公司最重要的产品

- 定义：每款产品都获得全公司最优质的资源，不存在"二等公民"产品
- 输入：有限的研发、供应链、营销资源
- 输出：每款产品都做到该价位段的极致
- 关键动作：
  - 研发资源集中——不做多款产品分散研发团队，每款产品都是精锐团队
  - 供应链资源集中——单款海量采购获得最优供应链价格和优先级
  - 营销资源集中——每款产品的营销预算不分散，集中打透
  - 管理层关注集中——每款产品都是CEO级关注，不存在被忽视的产品
- 常见误区：以为资源集中就是人海战术——资源集中是精锐团队+充足预算+管理层关注，不是堆人

### 模块4：供应链优势——单款海量的成本壁垒

- 定义：单款产品的海量销量带来供应链议价权和成本优势，形成竞品无法复制的成本壁垒
- 输入：单款产品的销量规模
- 输出：远低于行业平均的BOM成本和供应链优先级
- 关键动作：
  - 单款海量采购——同价位段只做1款，采购量远超竞品的多款合计
  - 供应商深度绑定——与核心供应商建立长期合作，获得优先供应和技术支持
  - 成本优势让利——供应链成本优势部分让利给用户，增强产品竞争力
  - 不做多款分散采购——多款产品分散采购量，每款都拿不到最优价格
- 常见误区：以为供应链优势就是压价——供应链优势来自规模和长期合作，不是压榨供应商

### 模块5：迭代节奏——不追新不追快，每代做到极致

- 定义：产品迭代不追求频率，追求每代都是该价位段的标杆，宁可慢不可烂
- 输入：市场对新品频率的期待
- 输出：每代产品都有实质性的体验升级
- 关键动作：
  - 每年1代旗舰——不追半年更新，每代间隔足够打磨
  - 每代有实质升级——不做挤牙膏式更新，每代都有用户可感知的升级
  - 不追首发——不追求首发新芯片/新技术，追求首发即成熟
  - 长周期打磨——旗舰产品打磨周期18-24个月，不赶工期
- 常见误区：以为迭代慢是落后——迭代慢的前提是每代都做到极致，快迭代但每代平庸才是落后

## 适用场景

### 最适合

- 消费电子等需要品牌心智的品类
- 资源有限、无法支撑多产品线的企业
- 追求品牌溢价而非低价竞争的品牌
- 供应链规模效应显著的品类
- 需要渠道简单化运营的品牌（少款好推）

### 不适合

- 需要覆盖所有细分市场的全品类品牌
- 技术迭代极快、需要快速试错的品类
- 低价竞争为主的品类（聚焦打爆需要利润空间支撑）
- B2B业务（客户需求差异大，单款难以覆盖）
- 早期创业公司（还没有找到产品市场匹配点）

## 实施检查清单

- [ ] 每个价位段是否不超过2款产品？
- [ ] 旗舰产品是否集中了最优质的研发资源？
- [ ] 中端产品是否有旗舰技术下放？
- [ ] 是否不做低价位段的产品（1000元以下）？
- [ ] 每款产品是否都有1-2个做到行业最强的长板？
- [ ] 供应链是否因单款海量获得成本优势？
- [ ] 产品迭代节奏是否足够打磨（旗舰18-24个月）？
- [ ] 是否不做多款衍生型号（Lite/SE/Y）稀释资源？
- [ ] 营销资源是否集中打透1-2款而非分散到多款？
- [ ] 每代产品是否有用户可感知的实质性升级？

## 诚实边界

1. 产品聚焦在旗舰价位段的市场份额有限——4000-6000元价位段只占中国手机市场约20%，聚焦意味着放弃80%的市场
2. 聚焦策略在5G换机潮期间暴露了短板——当所有价位段都在爆发时，OPPO/vivo因不做低价位段而错失了换机红利
3. 单款打爆的风险集中——一旦某代产品失败，没有其他产品可以弥补，风险高度集中
4. 产品聚焦在IoT品类执行不一致——OPPO/vivo的IoT产品线远比手机分散，聚焦纪律在IoT品类有所松懈
5. 聚焦旗舰+中端的策略在海外市场需要调整——印度、东南亚等市场的核心价位段是1000-2000元，OPPO/vivo需要做低价位段产品
6. "不做多款衍生型号"的纪律在市场竞争加剧时有松动——OPPO的A系列和vivo的Y系列实际上已经覆盖了低价位段
