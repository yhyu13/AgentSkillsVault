# OPPO/vivo · 代理商体系

> 省级代理+地市代理+县级代理，三级分销但利益共享——代理商是伙伴不是工具，利益共同体而非雇佣关系

## 核心理念

OPPO/vivo的代理商体系是中国消费电子行业最独特的分销结构。表面上看它是传统的三级分销——省代→市代→县代，但本质完全不同：传统三级分销是层层加价、层层压货的剥削链条，OPPO/vivo的三级分销是利益共享、风险共担的共同体。关键区别在于：代理商不是品牌的附庸，而是品牌的合伙人。省级代理不仅是分销商，更是区域市场的经营者——他们参与区域市场策略制定、承担区域库存风险、分享区域增长红利。地市代理和县级代理同样不是简单的搬箱子角色，而是各自区域的渠道管理者和用户服务者。这种模式的底层逻辑是：品牌方的能力有边界，但代理商的本地化能力没有边界——品牌方提供产品和品牌，代理商提供人脉和地缘，两者结合才能覆盖中国广袤的下沉市场。

核心命题：**三级分销的效率取决于利益分配的公平性——不是品牌方赚多少代理商赚多少，而是谁贡献谁获益，谁承担风险谁分享利润。**

## 关键模块

### 模块1：省级代理——区域市场的经营者

- 定义：省级代理是一省范围内的总经销商，不仅是分销角色，更是区域市场的经营者和策略参与者
- 输入：品牌方的产品、品牌和区域策略框架
- 输出：全省范围内的渠道覆盖、销售达成和市场秩序维护
- 关键动作：
  - 参与区域市场策略制定——不是被动执行，而是主动参与
  - 承担省级库存风险——省代是区域库存的第一责任人
  - 管理地市代理——省代负责地市代理的招募、培训和管理
  - 区域价格秩序维护——防止窜货和乱价，维护全省价格体系
- 常见误区：以为省代只是大分销商——省代是区域合伙人，有经营权而不仅是分销权

### 模块2：地市代理——城市渠道的管理者

- 定义：地市代理是一个地级市范围内的经销商，是连接省级代理和县级代理的中间层
- 输入：省级代理的渠道策略和品牌方的产品支持
- 输出：地级市范围内的渠道覆盖和销售达成
- 关键动作：
  - 执行省级策略在地市的落地——将省代策略转化为地市行动
  - 管理县级代理——地市代负责县代的日常管理和支持
  - 地市核心门店运营——地市代直接运营部分核心门店
  - 本地化促销执行——根据地市消费特征调整促销节奏
- 常见误区：以为地市代是多余的中间层——地市代的价值在于本地化运营，省代无法直接管理所有县代

### 模块3：县级代理——最后一公里的触达者

- 定义：县级代理是一个县范围内的经销商，是渠道下沉到乡镇的最后一环
- 输入：地市代理的渠道支持和品牌方的产品供应
- 输出：县域和乡镇市场的终端覆盖和用户触达
- 关键动作：
  - 乡镇门店开发——县代是乡镇门店开发的第一责任人
  - 终端导购管理——县代直接管理乡镇门店的导购人员
  - 本地用户服务——县代承担县域范围内的售后服务
  - 本地口碑经营——县代是品牌在县域的口碑代言人
- 常见误区：以为县代是最底层的搬箱子——县代是品牌在县域的代言人，其本地人脉和口碑是品牌无法替代的资产

### 模块4：利益分配——谁贡献谁获益的分配逻辑

- 定义：三级分销的利益分配不是层层截留，而是按贡献分配——谁承担风险、谁贡献资源、谁创造价值，谁就分享利润
- 输入：各级代理商的投入和贡献
- 输出：公平的利益分配结果和持续的合作动力
- 关键动作：
  - 省代利润来自区域规模——全省销售规模越大，省代利润越高
  - 市代利润来自城市运营——地市覆盖越深，市代利润越高
  - 县代利润来自终端服务——终端销售越好，县代利润越高
  - 返利不扣罚——完成目标给返利，没完成不扣罚，正向激励为主
- 常见误区：以为三级分销就是层层加价——OPPO/vivo的三级分销利润来自品牌方让利，不是终端消费者加价

### 模块5：风险共担——品牌方承担更多风险的信任机制

- 定义：品牌方主动承担更多风险（库存风险、降价风险、滞销风险），让代理商安心经营
- 输入：市场波动和经营风险
- 输出：代理商的安全感和长期合作意愿
- 关键动作：
  - 不压货——品牌方不向代理商强行压库存，库存按需调配
  - 价格保护——产品降价时补差价给代理商，不让代理商承担降价损失
  - 滞销退换——滞销产品品牌方协助调货或退换，不让代理商独自承担
  - 新品试销——新品先小范围试销，验证后再大规模铺货，降低代理商风险
- 常见误区：以为风险共担是品牌方做慈善——品牌方承担更多风险是为了换取代理商的长期忠诚和深度绑定，是投资不是慈善

## 适用场景

### 最适合

- 需要覆盖广袤下沉市场的消费品类
- 产品需要本地化服务和体验的行业
- 品牌方能力有边界、需要借助本地化力量的业务
- 追求长期渠道壁垒而非短期渠道效率的品牌
- 消费者决策依赖线下信任关系的品类

### 不适合

- 纯线上品类（不需要线下渠道）
- 产品高度标准化、不需要本地化服务的品类
- 追求极致渠道效率的品牌（三级分销效率低于直营）
- 品牌方对渠道有强管控需求的业务（伙伴体系管控力弱于直营）
- 利润空间薄、无法支撑三级分销的品类

## 实施检查清单

- [ ] 省级代理是否参与区域市场策略制定（而非仅被动执行）？
- [ ] 地市代理是否有本地化运营空间（而非仅搬箱子）？
- [ ] 县级代理是否覆盖到乡镇（而非仅停留在县城）？
- [ ] 利益分配是否按贡献分配（谁承担风险谁分享利润）？
- [ ] 返利机制是否以正向激励为主（不扣罚）？
- [ ] 是否有不压货承诺（库存风险品牌方承担）？
- [ ] 是否有价格保护机制（降价补差价）？
- [ ] 滞销产品是否有退换机制？
- [ ] 代理商选择是否以"本分"为首要标准？
- [ ] 代理商退出时是否好聚好散（结清所有款项）？

## 诚实边界

1. 三级分销的渠道效率低于直营和扁平分销，多一层分销就多一层信息损耗和利益截留
2. 代理商体系的管控力弱于直营体系——品牌方对终端门店的控制力需要通过代理商传导，传导过程有衰减
3. 代理商的能力参差不齐，部分县代和乡镇经销商的经营能力有限，品牌赋能的效果有天花板
4. 三级分销的窜货风险始终存在，尽管利益分配可以缓解但无法根除
5. 代理商体系的改革阻力大——当品牌方需要调整渠道策略时，各级代理商的既得利益是最大的阻力
6. 伙伴关系的维护成本高——品牌方需要持续投入人力和资源维护代理商关系，这不是一次性投入
