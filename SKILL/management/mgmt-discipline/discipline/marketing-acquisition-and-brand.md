# 营销 · 获客与品牌

> 营销的终极命题：让对的人在对的场景想到你、选择你、传播你——从心智占领到行为转化，从品牌建设到增长引擎

## 核心理念

营销学科解决的核心问题是：**如何让产品被目标用户知道、选择并传播？**

横跨组织实践与个人理论，营销方法论呈现三条主线：第一条是**品牌心智线**——里斯+特劳特的定位理论占据心智位置，夏普的品牌增长双法则提升心智可用性，高汀的紫牛+部落用卓越和归属感占领心智；第二条是**增长获客线**——埃利斯的增长黑客用AARRR+实验驱动用户增长，字节跳动的增长方法论用算法+数据飞轮实现规模化获客，小米的参与感用粉丝共创实现低成本冷启动；第三条是**流程体系线**——华为MTL用六模块流程将"营"体系化，科特勒的STP+4P提供营销战略的经典框架，伯杰的STEPPS揭示传播的心理机制。

三条主线的根本张力在于：品牌心智线追求"长期心智资产"，增长获客线追求"短期行为转化"，流程体系线追求"可复制的系统化"。三者不是替代关系而是互补关系——没有品牌心智的增长是"漏水桶"，没有增长的品牌是"空中楼阁"，没有流程体系的品牌和增长是"不可复制"。

## 关键模块

### 模块1：品牌心智建设

- 定义：在消费者心智中建立品牌认知和偏好，是营销的长期资产
- 输入：品类心智地图 + 竞品心智位置 + 品牌资源
- 输出：品牌在心智中的位置定义 + 独特性资产清单 + 心智可用性提升策略
- 关键动作：
  - 定位：在心智中占据一个词——里斯+特劳特的核心洞察是心智容量有限、先入为主优势巨大；定位是减法不是加法
  - 心智可用性：在购买场景中被想到——夏普将品牌资产重新定义为心智可用性，品牌增长=心智可用性↑+物理可用性↑
  - 独特性资产建设：颜色/形状/声音/语言/人物——夏普认为差异化是幻觉，独特性才是真实；独特性资产提升心智可用性
  - 紫牛：产品本身值得谈论——高汀认为卓越即营销，无聊的产品注定隐形
- 常见误区：把定位等同于产品定位——定位是心智定位不是产品定位；追求差异化而非独特性——夏普数据表明同品类消费者几乎无法区分功能差异；定位贪多——同时占据多个位置等于没有位置

### 模块2：增长获客引擎

- 定义：系统化地获取新用户并推动行为转化的机制
- 输入：PMF验证结果 + 用户行为数据 + 增长基础设施
- 输出：可量化的获客渠道 + 转化漏斗优化 + 增长飞轮
- 关键动作：
  - AARRR漏斗：获取→激活→留存→变现→推荐——埃利斯的核心增长路径；修复留存比增加获客更有效
  - 数据飞轮：用户行为→算法优化→体验提升→更多用户——字节跳动的增长惯性机制；需要最小规模才能启动
  - 参与感飞轮：参与→共创→归属→传播→新用户——小米的粉丝经济闭环；冷启动成本降60%+
  - 增长实验循环：假设→优先级→实验→分析→迭代——埃利斯的增长引擎；速度>完美
- 常见误区：只关注获客层——真正的增长瓶颈往往在激活或留存层；认为有数据就有飞轮——飞轮需要最小规模才能自转；PMF未达成就做增长——最常见的致命错误

### 模块3：传播与口碑机制

- 定义：让用户自发传播产品/品牌的心理和运营机制
- 输入：产品特性 + 传播目标 + 目标受众心理特征
- 输出：传播策略 + 口碑运营体系
- 关键动作：
  - STEPPS六原则：社交货币/诱因/情绪/公共性/实用价值/故事——伯杰揭示传播的心理机制；触发1-2个原则就足以产生显著传播效果
  - 部落建设：发现共享兴趣群体→连接→赋能→引领→运动——高汀的5阶段；1000个真粉丝>100万冷漠关注者
  - 许可营销：获得消费者许可后再沟通——高汀的逆向营销哲学；许可=信任，打断=偷窃
  - 三三法则：做粉丝/做自媒体/做参与感 × 论坛/微博/同城会——小米的参与感运营框架
- 常见误区：只关注线上传播——60%口碑传播在线下；认为增长黑客完全替代传统营销——品牌建设仍需传统营销；把部落等同于粉丝群——部落是双向连接，粉丝群是单向

### 模块4：营销流程体系

- 定义：将营销活动结构化、流程化、可追踪的体系
- 输入：市场洞察 + 战略规划 + 组织能力
- 输出：标准化的营销流程 + 可量化的营销指标
- 关键动作：
  - MTL六模块：MI(市场洞察)→MM(市场管理)→J(联合创新)→SCE(销售赋能)→DG(需求激发)→MQA(质量保证)——华为的B2B营销流程
  - STP+4P：细分→目标→定位 × 产品/价格/渠道/推广——科特勒的经典营销战略框架
  - 三类市场策略：H1防守/H2进攻/H3培育——华为MTL的市场管理策略
  - 线索质量管控：从线索到商机的全链路追踪——MTL的MQA模块确保线索质量
- 常见误区：流程过重变形式主义——MTL的六模块在C端场景过重；STP过度细分——夏普数据表明同品类购买者特征几乎相同；只考核线索数量不考核质量——导致销售抱怨线索无用

### 模块5：营销范式选择

- 定义：根据产品阶段、市场类型、预算约束选择合适的营销范式
- 输入：产品阶段 + 市场类型 + 预算约束 + 组织能力
- 输出：营销范式组合策略
- 关键动作：
  - 传统营销 vs 增长黑客：传统营销适合品牌建设和B2B大客户；增长黑客适合用户增长和B2C消费互联网
  - 信念驱动 vs 数据驱动：高汀的信念驱动适合不可量化的品牌忠诚；字节的数据驱动适合可量化的用户增长
  - 心智定位 vs 心智可用性：里斯追求"占据一个词"（窄而深）；夏普追求"多场景被想到"（广而浅）
  - B2B流程 vs B2C实验：华为MTL的流程管理适合B2B长决策链；埃利斯的实验驱动适合B2C短决策链
- 常见误区：认为增长黑客完全替代传统营销——两者互补不互斥；在B2B场景生搬硬套增长黑客——B2B决策链长，A/B测试统计意义不足；追求单一范式——不同阶段需要不同范式组合

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 品牌定位 | 如果品牌没有在心智中占据明确位置→品牌不存在，找到心智空位 | 里斯+特劳特定位 |
| 增长瓶颈 | 如果留存率低→先修留存再扩获客，漏水桶不能靠多倒水解决 | 埃利斯AARRR |
| 传播力评估 | 如果产品/内容没有触发任何STEPPS原则→传播力弱 | 伯杰STEPPS |
| 增长范式选择 | 如果产品边际成本趋近于零→优先用增长黑客 | 埃利斯范式对比 |
| 品牌资产定义 | 如果品牌资产=消费者情感→重新定义为心智可用性 | 夏普双法则 |
| 目标市场选择 | 如果目标市场是"所有人"→不成立，找到最小可行受众 | 高汀最小受众 |
| 营销预算分配 | 如果H1市场贡献70%收入但只分配30%预算→重新校准 | 华为MTL-MM |
| 广告投放策略 | 如果追求"精准投放"→扩大触达面，广告效果=触达×频率 | 夏普广告真实作用 |
| 忠诚度计划ROI | 如果考虑投入忠诚度计划→先评估ROI，可能对增长贡献为零 | 夏普对传统营销挑战 |
| 线索质量 | 如果线索到商机转化率<10%→线索捕获标准需收紧 | 华为MTL-MQA |

## 适用场景

### 最适合

- B2B复杂解决方案的营销体系化——MTL+定位+SPIN组合
- C端互联网产品的用户增长——增长黑客+数据飞轮+AARRR
- 新品牌上市的心智建设——定位+紫牛+STEPPS
- 快消品品牌的增长诊断——夏普双法则+独特性资产
- 创业公司冷启动——参与感+最小可行受众+许可营销

### 不适合

- 垄断市场——没有竞争就不需要营销
- 纯平台/流量型业务——线索获取靠算法而非营销流程
- 强监管行业——实验和传播策略可能违反合规要求
- 数据基础设施缺失——增长黑客和数据飞轮无法运行

## 实施检查清单

- [ ] 品牌是否在心智中占据了明确位置——消费者用什么词描述你的品牌
- [ ] 是否测量了心智可用性和物理可用性——而非仅看知名度
- [ ] 增长策略是否聚焦渗透率——而非购买频率
- [ ] PMF是否已验证——40%非常失望测试
- [ ] 是否建立了AARRR漏斗基线数据——各层转化率
- [ ] 传播内容是否触发了至少1-2个STEPPS原则
- [ ] 广告投放是否追求广触达+适度频率——而非精准投放
- [ ] 是否建立了独特性资产清单——颜色/形状/声音/语言/人物
- [ ] 是否根据市场地位选择了正确策略——H1防守/H2进攻/H3培育
- [ ] 营销与销售之间是否有线索交接的SLA

## 诚实边界

1. **B2C偏向性**：增长黑客、数据飞轮、参与感等方法论天然偏向C端消费互联网。B2B营销的决策链长、样本量小、A/B测试统计意义不足，很多C端方法难以直接应用。
2. **品牌心智vs增长行为的张力**：定位和品牌建设追求长期心智资产，增长黑客追求短期行为转化。两者在预算分配上天然冲突——品牌投入难以短期量化，增长投入可以精确计算ROI。组织容易偏向可量化的增长而忽视不可量化的品牌。
3. **夏普vs里斯的根本分歧**：夏普追求"广而浅"的心智可用性（多场景被想到），里斯追求"窄而深"的心智定位（占据一个词）。两者对"心智"的理解根本不同，实践中需要根据品类和阶段选择。
4. **数据飞轮的冷启动困境**：字节的数据飞轮需要最小规模才能自转，冷启动阶段仍需人工运营和内容供给。很多创业公司模仿字节增长方法论但无法跨越冷启动门槛。
5. **参与感的规模天花板**：小米的参与感在百万级用户时效果显著，但数亿用户后社区声音的代表性下降，沉默的大多数不参与投票。
6. **方法论的文化依赖**：定位理论基于美国消费市场，参与感基于中国科技爱好者社区，增长黑客基于硅谷互联网文化。跨文化应用需要适配。
7. **快消品结论的泛化风险**：夏普的实证数据主要来自快消品，其结论（如"差异化是幻觉""忠诚度计划无效"）不能无条件推广到所有品类。
