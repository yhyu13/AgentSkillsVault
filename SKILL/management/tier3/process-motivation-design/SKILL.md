# 过程动力设计 · 让长期计划真的发生

一句话：**你要改的不是「更想要那个结果」，是「过程里更舒服」。**

## 何时调

- 用户描述的是「反复开始又放弃」，不是「不知道方法」。
- 用户已经知道该做什么，但做不动、拖延、做一周摆烂一周。
- 用户在做计划/习惯/学习方案，问「这样能不能长期跑」。
- 用户在评价别人的自律方案，想找出为什么不可持续。

## 何时不用

- 用户缺的是「怎么做」的方法知识 → 那是领域 skill，不是这个。
- 用户要的是情绪支持或鼓励 → 本 skill 会让他更难受。
- 持续两周以上的情绪低落、失眠、无法工作 → 建议专业帮助，不要用本 skill 硬解。
- 「人和这件事是否根本不适合」（相性）→ 先把过程动力做好再判断，本 skill 不处理。

## 零、三条地基（不认这三条，后面全错）

**1. 活动是抽象概念，现实里只有一个个行动。**
活动只是一个名字，用来指代那串行动组成的整体。真正被执行的，永远是下一个具体动作。
→ 推论：任何「坚持不下去」的诊断必须在**具体行动**这一层做，不能停在「这件事我不喜欢」这种整块判断上。把「我要学好英语」拆到「今晚打开第 3 课听 12 分钟」，问题往往自己就变了形状。

**2. 续航只能靠过程动力，不能靠结果动力。**
过程动力的线索是**近端、可感知、可重复**的，所以确定；结果动力全靠你对结果的想象，而想象会疲劳、会偏差、会中断。
→ 怎么防：方案里只要有一条是靠「想想目标」来维持的，直接判它不成立。不是不够努力，是机制不成立。

**3. 好的模式是一句不等式：过程里促进动力多，阻碍动力少。**
不是「动力更强」，是「动力更密」。
→ 怎么防：写方案必须写**频率**（每小时出现几次），不写强度（这件事有多爽）。写不出频率的方案就是空话。

## 一、诊断：三个问题定位

按顺序问，第一个命中就停：

| 问题 | 命中信号 | 判定 | 去向 |
|---|---|---|---|
| Q1 你能开始吗？ | 一想到就不想动；拖延超过 3 天；打开文件就烦 | 阻碍过高 | `process-friction-cut` skill |
| Q2 开始后能维持 20 分钟吗？ | 能开始，但很快无聊、频繁切窗口刷手机 | 促进不足 | `process-reward-boost` skill |
| Q3 你的问题是「做不到」还是「停不下」？ | 明知不该做还在做，禁令总被违背 | 禁令违背 | `action-substitution` skill |

补充判据：

- **做完很累但不难受，只是没乐趣** → 促进不足（密度不够），不是阻碍问题。这两者的解法完全不同，别混。
- **一上手就烦躁、畏难、想逃** → 阻碍。此时加乐趣是无效投入，乐趣会被情绪抵消。
- **两种症状同时出现** → 先减阻碍。见下一节。

## 二、优先级：先减阻碍，再加促进

**结论**：阻碍没清掉之前，加促进的投入基本被吃掉。

为什么（两条性质）：

1. **暴露作用**：只有把痛苦拿掉，你才看得清这件事到底有多少乐趣。带着畏难去体验，你测到的是畏难，不是乐趣。
2. **非线性**：就算阻碍全清掉了，乐趣不足，问题仍然会回来 —— 甚至痛苦会重新长出来。

→ 怎么防：写成两个独立阶段，先跑「减阻碍」，跑通了再进「加促进」。别同时上，你会不知道是哪一条起了作用。

**例外**：如果阻碍本身很低、纯粹是无聊，跳过第一节直接加促进。

## 三、一个反直觉的口径

用户最容易搞错的一件事：以为要「更喜欢这件事」。

实际上要的是**密度**：一天里促进动力出现很多次，每次可以很弱。
游戏的例子就是极端版 —— 促进动力密集到每一步都有反馈，阻碍动力压到几乎没有。

→ 怎么防：任何「加乐趣」的动作，验收口径是「这个动作在 20 分钟内能出现几次」，不是「做完有多爽」。

## 四、路由

- 增促进动力（觉察 → 记录 → 乐趣规律）→ `process-reward-boost` skill
- 减阻碍动力（情绪 / 难度 / 能力三条路）→ `process-friction-cut` skill
- 禁令总被违背（用替换代替删除）→ `action-substitution` skill

出处与原文引用见 `references/source-notes.md`。

## 五、验收：一个方案算通过要同时满足

1. 有一个**可观察的动作**，不是感受（「打开第 3 课」而不是「更有动力」）。
2. 有**频率口径**（每次/每天几次）。
3. 有一条**失败兜底**：做不到时降级到什么。
4. 没有任何一条写成「我要更自律」「我要下定决心」。

少任何一条，方案都会在第二周失效。

## 六、红线

- ❌ 承诺「练出意志力」——这是本理论明确反对的方向。
- ❌ 用「想想你为什么要做这件事」当主要手段——那是结果动力，机制上不成立。
- ❌ 把相性问题（人和事不匹配）当动力问题处理，会让人白耗几个月。
- ❌ 在情绪明显异常时继续做动力优化。
