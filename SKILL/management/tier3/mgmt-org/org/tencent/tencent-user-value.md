# 腾讯 · 用户价值为本

> 一切以用户价值为依归——瑞雪文化是制度化约束，用户体验是红线，用户价值优先于商业短期收益。

## 核心理念

用户价值为本解决的核心问题是：**当商业利益与用户体验冲突时，组织如何确保不因短期诱惑伤害用户长期信任？**

腾讯的答案是：把"一切以用户价值为依归"从口号变成制度。瑞雪文化不是道德说教，而是一套行为约束——什么能做什么不能做，有明确的红线和惩戒机制。用户体验红线不是建议，而是硬约束——触碰红线的功能不上线，触碰红线的人要追责。

这套方法论的核心张力在于：用户价值与商业价值的长期一致性 vs 短期冲突。长期来看，用户价值与商业价值是一致的——好的用户体验带来用户增长，用户增长带来商业价值。但短期来看，两者经常冲突——广告多了用户体验差但收入高，功能多了体验臃肿但留存高。腾讯的解法是：短期冲突时用户价值优先，因为长期信任比短期收益更值钱。

## 关键模块

### 模块1：价值锚定——一切以用户价值为依归

- 定义：用户价值是腾讯一切决策的第一性原理，是核心价值观的第一条
- 输入：用户需求+用户反馈+用户行为数据
- 输出：决策判断标准+价值排序规则+行为约束
- 关键动作：
  - 核心价值观第一条：腾讯的愿景是"用户为本，科技向善"，"用户为本"排在第一位
  - 决策判断标准：当多个方案冲突时，用"哪个对用户价值更大"作为判断标准
  - 价值排序规则：用户价值>商业价值>技术偏好>管理层偏好
  - 长期信任投资：用户信任是最大的商业资产，短期伤害用户体验换取商业收益是透支信任
- 常见误区：用户价值等于用户满意——有时候用户不满意但长期价值更高（如取消不合理功能）；用户价值等于免费——免费不等于用户价值，付费也可以创造用户价值

### 模块2：瑞雪文化——制度化行为约束

- 定义：瑞雪文化是一套制度化的行为约束，明确什么能做什么不能做，有红线有惩戒
- 输入：用户体验问题+行业乱象+组织文化
- 输出：行为红线+惩戒机制+文化实践
- 关键动作：
  - 瑞雪行动：腾讯内部发起的整治行动，针对弹窗骚扰/诱导下载/强制关注等伤害用户体验的行为
  - 行为红线清单：明确列出禁止的行为，不是模糊的"要善待用户"而是具体的"不能做X"
  - 全员参与：瑞雪不是某个部门的事，每个员工都有权举报伤害用户体验的行为
  - 定期审视：瑞雪红线随产品形态演进，定期更新禁止行为清单
- 常见误区：瑞雪文化等于道德说教——瑞雪是制度化约束不是道德呼吁；瑞雪文化等于不作为——瑞雪约束的是伤害用户体验的行为，不约束正常的产品创新

### 模块3：用户体验红线

- 定义：用户体验是不可触碰的底线，触碰红线的功能不上线，触碰红线的人要追责
- 输入：产品方案+用户体验评估+红线标准
- 输出：功能取舍+方案调整+追责机制
- 关键动作：
  - 功能红线：任何新增功能必须通过用户体验评估，评估不通过的功能不上线
  - 广告红线：朋友圈广告的克制是典型案例——广告位/频次/形式有明确标准，不能无限制加广告
  - 隐私红线：用户数据保护是不可触碰的底线，任何泄露/滥用用户数据的行为零容忍
  - 欺诈红线：欺骗/误导用户的行为零容忍——虚假促销/隐藏条款/诱导消费都是红线
  - 红线追责：触碰体验红线的人要追责，不是"下次注意"而是"这次担责"
- 常见误区：体验红线等于不创新——红线约束的是伤害体验的创新，不是所有创新；体验红线等于用户体验至上——红线是底线不是上限，底线之上还有优化空间

### 模块4：用户投诉直达机制

- 定义：用户投诉直达产品团队，不经过层层过滤，确保用户声音不被衰减
- 输入：用户投诉（客服/社区/社交媒体/内部渠道）
- 输出：产品改进+用户满意度提升+信任积累
- 关键动作：
  - 客服直达：用户投诉通过客服系统直达产品团队，不经过中间管理层过滤
  - 社区监控：产品团队主动监控社交媒体和社区的用户反馈
  - 高管直通车：重大用户投诉可以直接到达高管层
  - 投诉响应时效：不同级别的投诉有不同的响应时效要求
  - 投诉闭环：每个投诉必须有处理结果和反馈，不能石沉大海
- 常见误区：投诉直达等于用户说了算——用户投诉是输入不是指令，产品团队需要判断投诉背后的真实需求；投诉直达等于没有过滤——过滤的是噪音不是信号

### 模块5：文化考核与激励

- 定义：用户价值践行纳入绩效考核，文化不是口号而是考核项
- 输入：员工行为+用户体验指标+文化评估
- 输出：绩效评分+晋升依据+文化强化
- 关键动作：
  - 用户价值纳入绩效：员工绩效评估中包含用户价值践行维度
  - 用户体验指标考核：产品团队的KPI包含用户体验指标（NPS/满意度/投诉率）
  - 文化红线一票否决：触碰文化红线的行为一票否决，不管业务成绩多好
  - 正向激励：用户价值践行的优秀案例公开表彰和奖励
- 常见误区：文化考核等于形式主义——如果考核流于形式，文化就会变成口号；文化考核等于不看重业绩——文化是底线约束，业绩是上限追求，两者不矛盾

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 商业与体验冲突 | 如果短期商业收益<长期信任损失→用户体验优先；如果短期商业收益>长期信任损失→需要高管审批 | 价值锚定 |
| 功能是否触碰红线 | 如果功能伤害用户体验→不上线；如果功能改善用户体验但有争议→灰度验证 | 体验红线 |
| 广告加载量 | 如果广告影响核心功能使用→减少广告；如果广告不影响核心功能→可以适度增加 | 广告红线 |
| 用户投诉处理 | 如果投诉涉及体验红线→立即处理；如果投诉是功能建议→纳入需求池 | 投诉直达 |
| 文化与业绩冲突 | 如果触碰文化红线→一票否决；如果在红线内→可以权衡 | 文化考核 |
| 隐私与便利冲突 | 如果涉及用户数据泄露风险→隐私优先；如果不涉及泄露→可以权衡 | 隐私红线 |

## 与其他方法论的关系

| 关联方法论 | 关系 | 接口 |
|-----------|------|------|

| 腾讯产品驱动 | 上游理念 | 用户价值是产品驱动的价值锚——产品驱动的"驱动"就是用户价值 |
| 腾讯赛马机制 | 上游理念 | 用户价值是赛马的裁判标准——谁更贴近用户价值谁赢 |
| 腾讯生态化战略 | 上游理念 | 用户价值是生态化的目的——生态化的目的是为用户提供更丰富的服务 |
| 腾讯投资赋能战略 | 上游理念 | 用户价值是投资赋能的筛选标准——投资的公司必须为用户创造价值 |
| Apple用户体验 | 对比 | Apple用户体验是设计驱动的极致体验（Jony Ive的美学标准），腾讯用户价值是需求驱动的克制体验（不伤害就是底线）；Apple追求极致，腾讯追求不伤害 |
| 华为以客户为中心 | 对比 | 华为以客户为中心是B2B逻辑（客户=企业客户），腾讯用户价值是C端逻辑（用户=消费者）；华为关注客户商业成功，腾讯关注用户体验 |
| 胖东来顾客服务 | 对比 | 胖东来顾客服务是极致服务（超预期），腾讯用户价值是克制体验（不伤害）；胖东来追求惊喜，腾讯追求不失望 |
| Netflix人才密度 | 对比 | Netflix人才密度是"对人才好"（顶级人才+顶级回报），腾讯用户价值是"对用户好"（用户体验优先）；Netflix是人才优先，腾讯是用户优先 |
| Google不作恶 | 对比 | Google不作恶是道德底线（不主动作恶），腾讯用户价值是体验底线（不伤害用户体验）；Google是道德约束，腾讯是体验约束 |

## 适用场景

### 最适合

- C端互联网产品，用户体验是核心竞争力
- 用户有选择权的市场，用户可以轻易离开
- 品牌信任是重要资产的业务
- 需要长期用户关系的订阅制/生态型产品

### 不适合

- 垄断市场（用户没有选择权，用户体验不是竞争力）
- B2B企业级产品（客户需求>用户体验）
- 短期变现型业务（用户生命周期短，不值得长期信任投资）
- 强监管行业（合规约束>用户体验）

- [ ] 是否有明确的用户体验红线清单（什么不能做）？
- [ ] 红线触碰是否有追责机制？
- [ ] 是否有瑞雪文化或类似的行为约束制度？
- [ ] 用户投诉是否直达产品团队（不经过层层过滤）？
- [ ] 用户体验指标是否纳入产品团队KPI？
- [ ] 文化红线是否有一票否决机制？
- [ ] 广告/商业化是否有克制标准？
- [ ] 用户数据保护是否有零容忍机制？
- [ ] 价值排序是否明确（用户价值>商业价值>技术偏好）？

## 诚实边界

1. 用户价值优先在商业压力下经常妥协：朋友圈广告从克制到密集的演变、微信支付从免费到收费的调整，都说明"用户价值优先"在商业压力下不是铁律。当公司面临收入压力时，用户体验往往让位于商业收益。

2. 瑞雪文化的执行力度在衰减：瑞雪行动在发起初期效果显著，但随着组织规模扩大和业务复杂度增加，瑞雪文化的约束力在减弱。部分产品团队对红线的理解和执行存在差异。

3. "不伤害"不等于"做好"：腾讯的用户价值方法论更侧重"不伤害用户体验"（底线思维），而非"创造极致用户体验"（上限追求）。与Apple相比，腾讯的用户体验上限不够高。

4. 用户价值定义的模糊性：什么是"用户价值"在不同产品、不同场景下定义不同。社交产品的用户价值是连接效率，游戏产品的用户价值是娱乐体验，广告产品的用户价值几乎无法定义——这种模糊性导致"用户价值优先"在执行中存在大量灰色地带。

5. C端用户价值与B端客户价值的冲突：腾讯云等B端业务中，"用户价值"与"客户价值"经常冲突——客户要的功能可能伤害终端用户体验。腾讯在B端业务中尚未建立清晰的价值排序规则。

6. 文化考核容易形式化：如果文化考核变成填表打分，"用户价值为本"就会从制度退化为口号。文化考核的有效性取决于高层的以身作则和红线的刚性执行。
