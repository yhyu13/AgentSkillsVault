# 丰田 · 造物先造人

> 产品是人做的——不培养人，就无法做出好产品

## 核心理念

"造物先造人"解决的问题是：为什么引进了最好的工具和方法，组织仍然无法持续改善？答案——工具和方法靠人执行，人不成长，工具就是空壳。丰田的人才观是：产品是人做的，人的品质决定产品的品质。所以培养人不是成本，是投资；不是HR部门的事，是每个管理者的事。核心实践：现地现物（亲临现场才能真正理解）、OJT（在岗培训，边做边学）、多能工（一人多岗，打破部门墙）、从内部提拔（领导者必须从一线成长）。

## 框架结构

```
造物先造人体系
├── 理念：人的品质=产品的品质
├── 核心实践
│     ├── 现地现物（Genchi Genbutsu）
│     │     └── 亲临现场，用五官感受真实
│     ├── OJT在岗培训
│     │     └── 边做边学，师傅带徒弟
│     ├── 多能工培养
│     │     └── 一人多岗，技能矩阵
│     └── 内部提拔
│           └── 领导者从一线成长
├── 支撑机制
│     ├── 工作轮换
│     ├── 作业分解（培训用标准）
│     └── 反思（Hansei）
└── 目标：能解决问题的人
```

## 关键模块

### 模块1：现地现物（Genchi Genbutsu）

- 定义：亲临现场，用自己的眼睛看、耳朵听、手触摸，获取一手信息
- 输入：问题、决策需求
- 输出：基于现场事实的理解和判断
- 关键动作：管理者定期走现场；决策前先去现场确认；不依赖报告和二手数据；与一线员工对话了解真实情况
- 常见误区：走现场变成"视察"，只看不问；或走马观花，没有深入理解

### 模块2：OJT在岗培训

- 定义：在实际工作中学习，师傅带徒弟，边做边教
- 输入：新员工或需要提升技能的员工
- 输出：能独立完成工作且理解原理的员工
- 关键动作：作业分解——把工作拆成可教学的步骤；四步培训法——准备→示范→实操→跟进；培训不是一次性的，是持续的过程
- 常见误区：OJT变成"跟着看"，没有结构化教学；师傅忙于生产没有时间教

### 模块3：多能工培养

- 定义：一个员工掌握多个岗位的技能，打破"一人一岗"的僵化
- 输入：技能矩阵（当前技能状态）
- 输出：多岗位胜任的员工
- 关键动作：绘制技能矩阵（谁会什么、熟练度如何）；制定多能工培训计划；定期轮岗学习新技能；多能工是应对需求波动的柔性力量
- 常见误区：多能工=打杂，没有系统培养；技能矩阵不更新

### 模块4：内部提拔

- 定义：领导者从一线成长，不空降外部管理者
- 输入：一线表现优秀的员工
- 输出：深谙工作、贯彻哲学的领导者
- 关键动作：领导者必须经历一线磨练；晋升基于对哲学的理解和践行，不仅看业绩；导师制——资深管理者带新人
- 常见误区：内部提拔变成论资排辈；空降管理者破坏文化连续性

### 模块5：反思（Hansei）

- 定义：定期诚实地面对自己的不足，是改善的前提
- 输入：项目结果、个人表现
- 输出：对不足的清醒认识+改善决心
- 关键动作：项目结束后必做反思会；不是追责，是学习；反思包括"什么做得好"和"什么需要改善"；反思后必须有行动
- 常见误区：反思变成自我批评大会；反思后没有行动

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 需要做决策但信息不足 | 先去现场看，再回来决策 | 现地现物 |
| 新员工培训 | OJT+作业分解，边做边教 | OJT原则 |
| 需求波动导致人力不足 | 培养多能工，柔性调配 | 多能工原则 |
| 需要新管理者 | 从内部一线提拔，不空降 | 内部提拔原则 |
| 项目结束 | 必须做反思（Hansei） | 反思原则 |
| 员工只会一个岗位 | 制定多能工培训计划 | 技能矩阵 |

## 适用场景

### 最适合

- 需要长期培养人才的组织
- 技能传承至关重要的行业
- 希望建立持续改善文化的企业
- 管理层需要深度理解一线业务的场景

### 不适合

- 人员流动率极高的组织（培养成本无法回收）
- 需要快速引入外部专业知识的场景
- 短期项目制组织（没有时间培养）
- 高度专业化的岗位（多能工意义有限）

## 实施检查清单

- [ ] 管理者是否定期走现场（现地现物）
- [ ] 是否有结构化的OJT培训体系
- [ ] 是否有技能矩阵并定期更新
- [ ] 是否有多能工培训计划
- [ ] 领导者是否从内部一线提拔
- [ ] 项目结束后是否做反思（Hansei）
- [ ] 作业是否有分解文档用于培训
- [ ] 培训是否持续而非一次性

## 诚实边界

1. 内部提拔可能导致近亲繁殖，缺乏外部视角和创新
2. OJT依赖师傅的能力和意愿——师傅不好，徒弟学歪
3. 多能工培养有成本——培训期间生产效率会下降
4. 现地现物在远程办公时代需要重新定义"现场"
5. 内部提拔速度慢，无法快速填补关键岗位空缺
