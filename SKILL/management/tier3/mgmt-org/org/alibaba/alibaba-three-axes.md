# 阿里巴巴 · 管理三板斧（九板斧）

> 把最简单的事情做到极致——用分层递进的三组"基本功"覆盖管理者从一线到高层的全生命周期能力图谱

## 核心理念

三板斧解决的核心问题：**如何让不同层级的管理者各司其职、各练其功，而不是所有人都学一样的"领导力"？**

传统企业做管理培训的套路是：不管你是刚升上来的Team Leader还是VP级别的高管，统统塞进同一个"领导力训练营"，讲沟通、讲激励、讲战略。结果是什么？新人听不懂战略（离自己太远），老手觉得基础课浪费时间（自己早就会了），最后谁都没真正学到东西。

阿里的解法是彻底分层：管理者被比喻成一个人的"腿、腰、头"三个部位，每个部位需要的能力完全不同，训练的内容也完全不同。腿部要稳（拿结果、带团队），腰部要通（懂战略、搭班子），头部要远（定方向、造土壤）。三层九招，每层三招，层层递进。

这套体系的雏形可以追溯到2000-2001年阿里创业早期。当时马云带着团队在湖畔公寓打拼，发现一个问题：业务跑得很快，但管理者的成长速度跟不上。很多人技术强、销售强，但一当管理者就手忙脚乱——不知道怎么定目标、不知道怎么管人、不知道怎么处理冲突。于是开始摸索一套"管理者必修课"。到2010年左右，经过近十年的迭代沉淀，正式形成了今天看到的"腿部+腰部+头部"三层九板斧的完整框架。

核心思想可以概括为三点：

1. **聚焦+落地**：不追求花哨的管理理论，而是把最基础的几件事反复练、练到极致。就像武术中的基本功——马步、冲拳、踢腿，看起来简单，但把这三样练到极致的人，实战中往往比学了一百种花招的人更厉害
2. **荣誉归团队，责任归自己**：这是贯穿所有层级的核心价值观。团队出了成绩，功劳是大家的；团队出了问题，责任是管理者的。这个原则倒逼管理者从"个人贡献者" mindset 转向"成就他人" mindset
3. **从独善其身到成就他人**：这是每个管理者必须完成的身份转型。P序列（专业线）的优秀标准是自己能干；M序列（管理线）的优秀标准是团队能干。这两套评价体系完全不同，很多新晋管理者卡在这个转型上

## 关键模块

### 模块1：腿部三板斧（Manager）——执行层的生存技能

腿部是一个人站立和行走的根基。对应组织中的一线管理者（通常是M1-M2级别，直接带团队的Team Leader或经理）。这个层级的管理者面临的最大挑战是：**从"自己干"变成"带着别人干"**。

#### ① 拿结果

- 定义：不是自己冲锋陷阵去拿结果，而是通过设定目标、拆解任务、跟踪进度、解决障碍，让整个团队拿到结果
- 输入：上级下达的业务目标 + 团队现有资源 + 时间节点
- 输出：可衡量的业务结果（不是"努力了"，是"做到了"）
- 关键动作：
  - 目标拆解：把一个大目标拆成每个人每天能执行的 actionable items
  - 过程跟踪：不是等到deadline才看结果，而是建立日/周/月的检查节奏
  - 障碍清除：团队成员遇到困难时，管理者的首要职责是帮他们搬石头，而不是指责他们搬不动
  - 结果复盘：拿到结果后要回溯——哪些做得好可以复制，哪些做得差需要改进
- 常见误区：以为"拿结果"就是自己拼命干——Manager的价值在于让5个人产出6个人的效果，而不是自己产出2个人的效果；只盯结果不看过程——过程失控的结果往往是运气而非能力

#### ② 建团队

- 定义：打造一支有凝聚力、战斗力、自我进化能力的队伍
- 输入：现有团队成员 + 业务目标 + 组织文化
- 输出：一支"离开你也能打仗"的团队
- 关键动作：
  - 团队氛围建设：营造"说真话、敢担当、互相信任"的团队文化——如果团队成员不敢在你面前说真话，你的信息来源就被切断了
  - 能力培养：识别每个人的短板和长板，通过辅导、授权、反馈帮助他们成长
  - 冲突处理：团队内部有矛盾不可怕，可怕的是矛盾被掩盖。管理者要主动暴露和解决冲突
  - 团队仪式感：周会、复盘会、庆功会——这些"形式主义"其实是团队凝聚力的粘合剂
- 常见误区：把"建团队"理解为"搞好关系"——好的团队不是一团和气，而是敢于直面问题；替团队成员干活来"带团队"——这是在培养依赖，不是在建团队

#### ③ Hire & Fire

- 定义：管理者最重要的两个决策权：决定谁进来，决定谁离开
- 输入：岗位需求 + 候选人池 + 现有团队成员表现
- 输出：合适的人加入 + 不合适的人离开
- 关键动作：
  - Hire：招聘不只是HR的事，管理者必须亲自参与面试——因为只有你最清楚团队需要什么样的人。关键不是找"最强"的人，而是找"最匹配"的人
  - Fire：这是最痛苦但最必要的管理动作。一个长期表现不合格但不被处理的成员，对团队的伤害远大于空缺本身——他在消耗资源、拉低标准、传递"平庸可以被容忍"的信号
  - "小恶即大善"：及时处理不合适的人，对他本人也是负责任的——拖得越久，他的市场竞争力越弱
  - Hire的标准：宁可空缺也不将就——一个错误招聘的成本是工资的3-5倍（含隐形成本）
- 常见误区：把Hire完全交给HR——HR筛选简历，管理者判断 fit；不敢Fire——拖延只会让问题恶化；Fire时不给对方尊严——即使是被辞退，也要让对方体面地离开

### 模块2：腰部三板斧（Director）——中坚层的承上启下

腰部连接着头和腿，负责传递力量、协调动作。对应组织中的中层管理者（M3-M4级别，总监/高级总监）。这个层级的管理者面临的最大挑战是：**既要理解上面的战略意图，又要能把战略翻译成下面能执行的具体动作**。

#### ① 懂战略

- 定义：不是"制定战略"（那是头部的事），而是"真正理解战略"——知道公司为什么要做这件事、这件事的优先级是什么、资源和时间边界在哪里
- 输入：公司/事业部层面的战略方向 + 业务数据 + 市场环境
- 输出：对本部门战略定位的清晰认知 + 能够向团队准确传达的战略意图
- 关键动作：
  - 战略解码：把抽象的战略语言翻译成具体的业务语言——"我们要成为行业第一"→"这意味着我们的市场份额要从X%提升到Y%，需要在Q4之前完成Z个关键客户"
  - 优先级判断：资源永远不够，所以必须知道什么该做什么不该做。"懂战略"的本质是懂得取舍
  - 信息上传：把一线的真实情况反馈给决策层——腰部是组织的"神经中枢"，信息的准确传递至关重要
  - 战略对齐：确保自己的团队目标与公司战略方向一致，避免"各自为战"
- 常见误区：以为"懂战略"就是参加高层会议——真正的懂是把战略内化成自己的判断框架；把战略当成口号挂在墙上——战略必须体现在每天的决策中

#### ② 搭班子

- 定义：构建和管理自己的管理团队（下属的Manager们）
- 输入：业务目标 + 现有管理者团队 + 人才池
- 输出：一个互补、协同、有战斗力的管理团队
- 关键动作：
  - 班子结构设计：不是找一群和自己一样的人，而是找一群能力互补的人——有人擅长执行，有人擅长创新，有人擅长稳定
  - 管理者培养：你的下属也是管理者，他们也需要成长。Director的重要职责之一是帮助下面的Manager完成从"独善其身"到"成就他人"的转型
  - 冲突协调：管理者之间的冲突比员工之间的冲突更复杂——涉及权力边界、资源分配、功劳归属。Director必须是公正的仲裁者
  - 班子迭代：没有一劳永逸的班子。业务变化了，班子也要跟着变。该换人的时候不能犹豫
- 常见误区：把"搭班子"理解成"找熟人"——班子的核心标准是能力匹配而非关系亲近；班子成员之间有冲突就回避——健康的冲突是创新的源泉

#### ③ 做导演

- 定义：不是自己做演员（那是腿部的事），也不是只做编剧（那是头部的事），而是像电影导演一样——设定场景、调度资源、把控节奏、确保最终呈现的效果
- 输入：战略目标 + 团队资源 + 时间节点
- 输出：各部门/各角色协同运转、高效达成目标的状态
- 关键动作：
  - 资源调配：在有限的资源下，决定什么项目优先、什么项目暂缓、什么项目砍掉
  - 跨部门协同：中层管理者的大量精力花在"推墙"上——打破部门壁垒，让信息、资源、人员流动起来
  - 节奏把控：什么时候冲刺、什么时候休整、什么时候复盘——这决定了团队的可持续战斗力
  - 异常处理：当计划赶不上变化时，Director必须快速做出调整决策并推动执行
- 常见误区：以为"做导演"就是发号施令——导演是在现场解决问题的，不是坐在监视器后面喊"action"；事必躬亲——那是演员的工作，导演的工作是让别人演好

### 模块3：头部三板斧（VP）——决策层的顶层设计

头部决定方向、感知环境、做出终极判断。对应组织中的高层管理者（VP及以上级别）。这个层级的管理者面临的最大挑战是：**在高度不确定的环境中，为整个组织指明方向、创造土壤、做出最关键的用人决策**。

#### ① 定战略

- 定义：确定组织未来3-5年的方向、路径和取舍
- 输入：市场趋势 + 竞争格局 + 自身能力 + 组织愿景
- 输出：清晰的战略方向 + 关键战役 + 资源分配优先级
- 关键动作：
  - 方向选择："做什么"和"不做什么"同样重要。定战略最难的不是找到机会，而是放弃诱惑
  - 战略叙事：战略不只是PPT上的文字，而是一个能让全员理解和认同的故事——人们不会为自己不理解的东西拼命
  - 战略校准：市场在变，战略也要定期审视和调整。僵化的战略比没有战略更危险
  - 战略落地机制：战略如果不能分解成具体行动，就是空谈。VP必须确保战略有对应的组织保障、资源配置和考核机制
- 常见误区：把"定战略"等同于"做规划"——规划是术，战略是道；追求完美的战略——在不确定环境中，"大致正确"优于"精确错误"

#### ② 造土壤

- 定义：设计和维护组织的文化土壤——让正确的行为自然生长，让错误的行为自然枯萎
- 输入：组织现状 + 愿景价值观 + 行业特性
- 输出：一套能够自我运行的组织文化和制度环境
- 关键动作：
  - 文化设计：不是写几句口号贴在墙上，而是设计一套"行为-反馈-强化"机制——什么样的行为会被奖励？什么样的行为会被惩罚？
  - 制度配套：文化靠制度落地。如果文化说"客户第一"但考核指标只看营收，那文化就是假的
  - 榜样示范：高层的一言一行都在塑造文化。VP说的不重要，做的才重要
  - 土壤改良：土壤不是一次造好就不变的。随着组织规模扩大、业务复杂度提升，文化土壤需要持续改良
- 常见误区：以为"造土壤"就是搞团建活动——团建是表面功夫，真正的土壤在日常的每一次决策中体现；用文化绑架人——文化应该让人感到力量，而不是束缚

#### ③ 断事用人

- 定义：在关键时刻做出艰难决策，并为关键岗位选对人
- 输入：组织面临的重大抉择 + 关键岗位需求 + 人才库
- 输出：重大事项的明确决策 + 关键岗位的合适人选
- 关键动作：
  - 果断决策：VP级别的决策往往信息不全、时间紧迫、各方利益冲突。犹豫不决本身就是一种决策——而且通常是最差的决策
  - 用人决断：关键岗位的任命是最重要的投资决策。用错一个人，损失的不只是他的工资，还有他做出的错误决策和他带偏的团队方向
  - 为决策担责：断事之后就要为结果负责。"荣誉归团队，责任归自己"在这里体现得最充分
  - 容错与纠错：果断不代表不犯错。关键是要快速发现错误、承认错误、纠正错误
- 常见误区：试图讨好所有人——VP的决策必然有人不满，这是职位属性决定的；用人唯亲——短期省心，长期致命

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 新晋管理者培训 | 如果是从IC转Manager，优先训练腿部三板斧（拿结果/建团队/Hire&Fire） | 分层培养原则 |
| 中层管理者瓶颈 | 如果管理者能带好团队但不能跨部门协同，重点补腰部三板斧（懂战略/搭班子/做导演） | 承上启下定位 |
| 高层管理者选拔 | 如果候选人战略视野窄或用人犹豫不决，不适合VP岗位 | 头部三板斧要求 |
| 管理者转型诊断 | 如果管理者还在用"自己干"的方式拿结果，说明没完成从独善其身到成就他人的转型 | 核心转型标志 |
| 招聘决策 | 如果候选人是"最强"但不是"最匹配"，不录用——匹配度 > 绝对能力 | Hire & Fire原则 |
| 团队问题归因 | 如果团队业绩不好，首先问"我作为管理者哪里没做好"，而不是"团队成员不行" | 责任归自己原则 |
| 战略传达 | 如果一线员工说不清公司战略在做什么，说明腰部管理者的"懂战略"和"做导演"失效 | 战略解码链条 |
| 文化建设 | 如果高层行为与宣称的文化不一致，文化建设注定失败 | 造土壤的示范效应 |

| 华为干部管理 | 对照参照 | 华为用"干部九条"+训战结合+之字形成长的模式，强调从实战中选拔和在流动中培养；阿里用三板斧分层培养的模式，强调不同层级练不同的基本功。华为重"战场验证"，阿里重"分层训练"。两者都强调干部的责任意识，但华为的干部四力（理解力/执行力/决断力/人际连接力）与阿里的三层九招在能力维度上有交叉映射 |
| Netflix Keeper Test | 下游参照 | Netflix Keeper Test回答"这个人是否值得留住"，阿里Hire&Fire回答"这个人是否应该留下"。一个是留人决策，一个是用人决策，两者构成人才管理的闭环 |
| P/M双通道体系 | 并行支撑 | P序列（专业线）和M序列（管理线）的双通道设计是三板斧运行的制度前提——只有当管理通道和专业通道真正分离时，管理者才能专注于"成就他人"而非"证明自己更强" |
| 字节OKR体系 | 间接关联 | 阿里三板斧中的"拿结果"模块需要目标管理工具支撑，OKR是一种可选工具。字节用OKR驱动目标对齐，阿里三板斧驱动管理者能力建设，两者在不同层面运作 |

## 适用场景

### 最适合

- 快速成长型企业，大量IC（个人贡献者）被提拔为管理者，急需系统化的管理能力训练
- 多层级组织（至少3层以上管理架构），不同层级的管理者面临截然不同的挑战
- 强调"实干"文化的组织——三板斧不讲虚的理论，全是实操性的基本功
- 需要统一管理语言的大型企业——三板斧提供了一套跨部门、跨业务线的共同话语体系
- 正在进行管理者梯队建设的组织——从腿部到腰部到头部的递进逻辑天然适配梯队培养

### 不适合

- 扁平化组织（管理层级少于2层）——腰部和头部的三板斧没有用武之地
- 创业初期团队（10人以下）——此时更需要的是创始人个人魅力和业务直觉，而非系统化管理方法
- 强调"理论深度"的学术型组织——三板斧 deliberately 不追求理论完备性，追求的是实用性和可操作性
- 权力高度集中的组织——三板斧要求各级管理者有真正的决策权和责任承担，如果实际权力集中在顶层，三板斧会沦为形式

## 实施检查清单

- [ ] 是否建立了清晰的P/M双通道体系（专业线与管理线真正分离）
- [ ] 是否对不同层级管理者设计了差异化的训练内容（非一刀切的领导力培训）
- [ ] 腿部三板斧是否包含：目标拆解与结果跟踪、团队建设与辅导、招聘决策与人员优化
- [ ] 腰部三板斧是否包含：战略理解与解码、管理团队搭建与培养、跨部门协同与资源调配
- [ ] 头部三板斧是否包含：战略方向确定与取舍、组织文化与制度建设、重大决策与关键用人
- [ ] 是否建立了"荣誉归团队，责任归自己"的文化考核机制
- [ ] 是否有明确的"从独善其身到成就他人"的转型评估标准
- [ ] 训练方式是否以实战演练为主（非纯课堂讲授）
- [ ] 是否建立了分层级的认证或评估机制（每层三板斧掌握程度的检验）

## 诚实边界

1. **"聚焦+落地"的双刃剑**：三板斧刻意简化管理理论，只保留最核心的几个动作。这种简化的好处是易学易用，坏处是可能遗漏某些重要的管理维度（如变革管理、危机公关、外部关系等）。三板斧是"必备项"而非"全部项"。

2. **分层的刚性成本**：严格按层级划分训练内容，可能导致管理者视野受限——腿部管理者不了解战略，腰部管理者不了解执行细节。在实际操作中需要适度"跨界"。

3. **文化强依赖**："荣誉归团队，责任归自己"听起来很美，但在KPI导向、竞争激烈的实际环境中，很多管理者会本能地把功劳往自己身上揽、把锅往外甩。三板斧的有效性高度依赖于组织文化是否真正支持这套价值观。

4. **与华为对比的语境差异**：说"阿里重分层训练、华为重战场验证"是简化。阿里也有实战锻炼（轮岗、挂职），华为也有分层培训（青训营、高研班）。差异是侧重点和哲学底色不同，而非非此即彼。

5. **与Amazon Bar Raiser对比的范围差异**：Amazon Bar Raiser是一个精细化的招聘质量控制工具，阿里Hire&Fire是管理者的一项通用能力要求。两者不在同一粒度上——如果把Bar Raiser缩小到"管理者在招聘中的职责"，则与阿里Hire&Fire模块可比；如果把阿里三板斧放大到"整个人才管理体系"，则远超Bar Raiser的范畴。

6. **公开资料局限**：三板斧的具体训练课程设计、评估标准、认证流程等操作细节未完全公开，本文基于公开资料和行业解读重构，部分推断可能与阿里内部实际存在偏差。

7. **时代适应性**：三板斧成型于2010年左右的阿里高速增长期，其假设前提（业务快速扩张、大量管理岗位涌现、组织文化强势）在今天的环境下可能需要调整。远程办公、AI辅助、零工经济等新变量对管理者能力提出了新的要求。
