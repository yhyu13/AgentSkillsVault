# 3 页 Boss 海报(单文件 HTML)

"Boss 海报"= 站在会议室最后排也能读懂的那种。3 页,一页一件事,左右滑动翻页,能自动播。

## 页面结构(写死,不要自创)

```
P1  结论 + Hero 数字        —— 90% 的面积留给一个数字
P2  三步机制               —— 1 / 2 / 3 三个动作，各一行
P3  试一下 + 带走           —— 一个可拖的滑块(现场演示) + 一句判断
```

每页必备元素,缺一个就会被 G4 机检拦下:

| 元素 | 属性/约定 | 为什么 |
|------|-----------|--------|
| 页容器 | `<section class="page" data-page="1">` | 机检靠它数页 |
| Hero 数字 | `<div class="hero" data-hero>` | 机检靠它查字号 |
| 背景动效 | `<canvas class="bg" data-motion>` | 机检靠它查帧差 |
| 进度点 | 3 个 dot,当前页高亮 | 读者知道还有多少 |

## 交互契约

```js
// 1. 左右滑动(手机) + 方向键(桌面) + 滚轮(触控板)
let i = 0, auto = true, timer;
function go(n){ i = (n + 3) % 3; track.style.transform = `translateX(${-i*100}%)`; paintDots(); }
// pointerdown/up 记 dx,|dx|>60 就翻页
// 2. 自动播放:6s 一页,循环;任何手势立刻暂停 3s 再恢复
// 3. 空格键 = 暂停/继续;暂停时进度条停住
```

- **自动播放默认开**,第一页停 8s(让人读完),后续 6s
- 用户一碰就**暂停 3 秒**再继续,不要硬抢控制权
- 右下角一个 `⏸/▶` 按钮,状态可读(`aria-pressed`)
- `prefers-reduced-motion: reduce` → 关掉背景动效与自动播放

## 视觉(反 AI 味的具体做法)

| 项 | 值 | 不要 |
|----|----|------|
| Hero 字号 | `clamp(64px, 14vw, 200px)`,字重 800,`font-variant-numeric: tabular-nums` | 60px 以下 |
| 正文 | `clamp(15px, 2.2vw, 20px)`,行高 1.5,一行不超过 22 个汉字 | 14px 灰字满屏 |
| 配色 | 1 主色 + 1 强调色 + 1 底色,三色封顶 | 渐变堆叠、玻璃拟态、紫蓝光晕 |
| 留白 | 每页留白 ≥ 30%,Hero 周围留白 ≥ 15% | 四边贴边 |
| 字体 | 系统栈(`-apple-system, "Segoe UI", "Microsoft YaHei"`),不引 CDN | 外链字体 |

**不要**用:毛玻璃卡片、`box-shadow` 大光晕、渐变文字、emoji 当图标、居中三卡片并排。

## 背景动效(必须动,但不许抢戏)

三选一,都在 canvas 里画,`requestAnimationFrame` 驱动:

1. **流动点阵**:网格点按 `sin(x*0.01 + t)` 上下浮动 ±6px,透明度 0.06–0.12
2. **慢速噪声**:两个正弦叠加的色块缓慢漂移,周期 ≥ 20s
3. **扫描线**:一条 2px 竖线 24s 走完一屏,透明度 0.08

硬约束:
- 背景亮度对比 ≤ 8%,不许出现比正文更亮的东西
- 帧率无关:所有位置都是 `f(t)` 的纯函数(`t = performance.now()/1000`),不用增量累加
- 掉到 30fps 以下自动降级(少画点/降分辨率)
