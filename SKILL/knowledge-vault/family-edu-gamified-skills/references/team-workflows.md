# 团队编排接口与交接规范

本文只整理原团队的协作关系，不新增学科、游戏机制或奖励规则。专业方法以各角色文档及对应成员回传为准。

## 信息流向

家长输入 → 顾周全整理与中转 → 对应专业成员 → 完整原文回传顾周全 → 下一位成员或统一发布。

禁止成员直接互传，禁止用总规划师代写替代成员产出。正式协作须先建立团队，再调度相应成员，收到专业回传后继续；不创建另一个团长角色。

## 每日任务交接

1. 总规划师提供年级、教材进度、学校作业、课外任务、可用时间与当日情绪。
2. 温故知负责预习/复习内容；游亦学负责作业包装。两者可以并行，不互相设计对方的专业部分。
3. 总规划师保留两份完整原文，核对学习目标、任务量和时间冲突。
4. 把整合稿完整交励其心，获得话术、情绪支持与奖励建议。
5. 总规划师统一发布；记录实际执行回传，不能把计划当成果。

## 日间与睡前交接

- 习恒之提供复习—作业—预习的节奏、习惯打卡和专注方案；实际作业时间与游亦学方案由总规划师对齐。
- 拓之远与苗向阳轮流提供拓展/兴趣活动，不强行同时叠加。
- 情绪异常时先暂停任务，由励其心处理；调整任务量由总规划师协调。
- 睡前由习恒之和励其心提供习惯反馈与成就结算建议；总规划师只汇总真实数据。

## 周复盘交接

- 习恒之回传习惯记录与趋势。
- 温故知回传学习效果、卡点及需要的单元综合挑战。
- 苗向阳回传兴趣线索与活动偏好。
- 三份完整产出先回总规划师，再按需要中转给其他成员。
- 周颁奖典礼与奖励建议由励其心提供，总规划师不另写一套规则。

## 通用交接字段

| 字段 | 说明 |
|---|---|
| 本次目标 | 要解决的一个明确问题 |
| 已知资料 | 区分家长原话、既有记录和专业成员建议 |
| 缺失资料 | 不知道就留空，不补造 |
| 时间/情绪约束 | 先确认可用时间和当前状态 |
| 上游完整原文 | 后续成员需要的完整专业产出 |
| 本次专业职责 | 只处理该成员负责的领域 |
| 待其他成员确认 | 只提出问题，不代替对方回答 |
| 回传内容 | 完整方案、依据、边界、需确认项 |

## 原团队默认值与缺口

| 项目 | 原定义已有内容 | 归档处理 |
|---|---|---|
| 习惯计划 | 21天，分1—7、8—14、15—21天 | 保留为计划框架，不承诺必然形成习惯 |
| 习惯补签 | 每周限1张 | 与作业连击补签分别记录 |
| 作业连击 | 每周2次补签 | 不与习惯补签次数合并 |
| 专注副本 | 每次25分钟，集3颗专注宝石解锁自由玩耍 | 原团队默认值，个体适配须明确 |
| 统一等级/完整积分表 | 源定义只提及，未列完整表 | 待团队确认，不补造数值 |
| 奖励兑换 | 提到智慧值、称号、家庭特权 | 完整兑换表由对应成员确认 |

以上是规则来源对照，不代表所有规则适用于每个孩子。调整建议由相关专业成员提出，经总规划师中转统一，不能由归档者静默修改。
