# 用刻意练习变强

目标是比同区内的其他人更快变强。只求变强或只求赢，都不是讲者给出的目标。

方法来自 BV1pGsL62E7y 的英语原声。讲者自述、观察、转述和估计不能混成实验结论。原片时间与口径见 [references/method.md](references/method.md)。

## 先写清今天练什么

每次只选一到两件具体的事。目标要具体到能够观察，例如“处理某个反复失误”，而不是“少犯错”或“多反击”。

训练时想的是这件事，不是这一局的胜负。讲者估计，做得正确时会很难受，而且几乎一定会输掉一些对局。短期变差不等于方法错了。

## 用六个部分检查

讲者转述 Ericsson 1993 的刻意练习，并把它分成六个部分：

1. 有可参考的做法。新游戏可能还没有稳定的最佳做法。
2. 有分步计划。
3. 难度略高于当前能力。
4. 练习时全程投入注意力。
5. 有高质量反馈。
6. 有可靠的指导者。当前阶段可能很难找到。

缺一项，就先补这一项，不把普通对局的时长当成刻意练习。

## 选择信息和对手

不要把大约 20 支队伍在 Deadlock Night Shift 的封闭互打当成全部最佳做法。ABL 和 Deathy 是讲者认为可以大致信任的参考，但仍要保持开放，接受自己原本会排斥的阵容、想法和原则。

找会惩罚失误、略强于自己的对手。对手强到让人完全退出时，就降低难度。连续不败不是训练质量高的证据。讲者自述，队伍曾三周训练赛不败，随后半决赛被打崩。

训练赛和排位都保留。训练赛练团队配合，排位练个人局势判断。

## 让练习留得住

把同一个新动作或新想法分散到一周，不要压进一天。讲者转述，分散练习比一天练 10 小时更可能被记住。当下觉得准备得差，不代表学得差。

每天用一到两小时处理那一到两件事。讲者估计，多数人每天大约只能承受 4 小时刻意练习。其余时间可以放松、只求赢或单纯玩，避免耗竭。

## 用反馈修正，不让反馈替你决定

讲者转述一项未点名的大型统计研究：大多数反馈让人进步，但其中三分之一让人更差。因此要互相指导，也要指导自己，并向可信的人寻求反馈。

反馈要解释错误为什么发生。没有反馈，刻意练习会退回天真练习。它的目的不是永远由别人下指令，而是让自己逐渐发现自己的错误。

## 睡眠是前提

睡眠不足时，其他训练都会直接白费。训练前保持休息和较低压力。讲者把睡眠对记忆和表现的影响放在其他建议之上。

## 输出一张训练卡

用 [templates/session-card.md](templates/session-card.md)。每张卡只写：

- 今天的一到两件具体事情。
- 对手为什么略强，以及什么情况下该降低难度。
- 谁提供反馈，反馈解释了哪个错误。
- 这次练习分到一周中的哪几天。
- 今天的刻意练习是否超过讲者估计的约 4 小时。
- 睡眠是否已满足。

没有观察证据时写“未知”，不补一个看起来完整的计划。

## 检查与边界

```bash
python scripts/check_plan.py <session-card.md>
```

检查器确认六个部分、两个练习量、反馈口径和睡眠都在。退出码 0 只表示卡片结构完整。退出码 1 会指出缺的部分。它不算完成，也不能证明训练已经有效。

研究数字保持“讲者转述”或“讲者估计”。不把一次讲座的数字改写成普遍规律，也不把游戏建议扩展成医疗、教育或职业成功保证。

## 卡片失败时怎么改

检查器指出缺字段，就只补那一项。没有观察证据时写“未知”，不要为了让卡片看起来完整而编造对手、反馈或睡眠状态。

如果卡片把短期掉分写成方法失败，就改回讲者的判断：正确练习时可能难受，也可能输掉一些对局。如果它把封闭圈子写成唯一答案，就补上 ABL、Deathy 只是可大致信任的参考，并保留对其他想法开放。

如果它把“三分之一反馈让人更差”写成已经证实的规律，就改回“讲者转述一项未点名研究”。研究作者没有出现在逐字稿里，不能补作者。

```bash
python scripts/check_plan.py examples/complete-card.md
```

```bash
python scripts/check_plan.py examples/bad-card.md
```

第一张完整卡应返回 0。第二张把反馈写成“已证实一定有效”，应返回 1。两次结果相同，就先修检查器，不继续生成计划。

## 什么时候停止

用户要的是总结视频、导出 PPT 或制作口播时，不用这份方法卡。逐字稿没有支持的数字、对手强度或睡眠状态，保持未知。把游戏训练建议扩展到治疗、教育成绩或职业成功，就停止并说明这超出了讲座范围。
