# UGC 与内容审核初筛

## 定位

初筛的价值 = **命中位置 + 判断理由**，缺一样初筛无价值。AI 只做初筛分级，最终裁定永远由审核员做。

## 规避表达覆盖清单

谐音、缩写、拆字、同形/形近字替换、间隔符、混合大小写、表情符号替换关键字。

## 分级

`通过 / 待定 / 违规` 三档建议 + 命中位置（原文引用）+ 理由（命中哪条规则）。拿不准一律上抛，不放行。

## 高危内容（跳过分级，立即上抛）

自伤自杀、违法行为、人身威胁、涉未成年人安全。上抛时保留原文与上下文证据，不做改写转述。

## 输出格式

```
item_id,excerpt,rule_hit,verdict,confidence,reason
```

`confidence` 分 `high / medium / low`；`low` 与全部 `违规` 建议默认进人工队列。
