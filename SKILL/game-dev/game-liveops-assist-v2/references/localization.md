# 内容本地化

## 输入三件套（缺一先要，不要开翻）

1. 术语表
2. 角色设定
3. 长度限制（UI 框宽度/字数上限）

## 术语表格式

```
source,term_zh,term_en,note
```

一行一术语，随版本更新；翻译时术语表优先级高于行文流畅。

## 长度限制处理

- 有硬限制时给"截断安全"改写：保关键词、舍修饰语，而不是硬截断
- 可能超限的条目在交付中显式标出，交人工决定改文案还是改 UI，不默默截断

## 文化表达

初稿中**显式标出需人工判断的表达**（梗、谐音、敏感意象、宗教/历史指涉），不自己默默抹平或替换。

## 回译抽检

- 人工复核后做抽样回译，比例取"≥5% 且 ≥20 条"的较大者
- 回译检查术语一致性与语义偏移，是校验手段，不是二次创作
- 发现偏移的术语回流进术语表，下版本生效
