# 买量素材与版本数据对比

## 批量版本纪律

- 变量明确：开场 3 秒钩子 / 节奏 / 卖点组合；**一次只变一个主变量**，否则数据无法归因
- 实机画面：操控引擎录制，不用无关素材拼凑
- 每个版本配套音乐、字幕、多语言文案，版本间除主变量外保持一致

## 数据口径

统一统计窗口与归因方式后再对比；跨渠道数据先对齐口径，不直接比原始值。

## 输出格式（表头固定）

```
version,hook,spend,ctr,install,cpi,day1_ret,verdict
```

## 结论

用数据决定加码方向，不凭"最好看"选；落选素材归档并注明失败变量，供下一轮排除，不删除（失败变量也是资产）。
