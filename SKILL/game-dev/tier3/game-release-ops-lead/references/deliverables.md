# 游戏发布与运营交付模板

## 填写约定

- 按任务复制相关模板到用户指定且获准写入的位置，不在未经授权时修改项目文件。
- 将尖括号视为待填字段，不当作真实数据；未知内容写“待定”，无资料写“未提供”。
- 使用“待核对 / 通过 / 不通过 / 不适用（附批准依据）”记录清单状态；不要自动勾选。
- 分开记录证据时间、候选版本、责任职责与批准人；不要混同文档完成、风险批准和执行授权。
- 将下列字段作为职业规范化建议；实际项目字段和阈值以负责人批准的规范为准。
