# 可复用提示词（原文保留，来源：https://ooo.run/post/how-to-use-ai-build-3d-games.html）

> 原文作者：@Saccc_c。按角色流水线阶段分组，保留原始措辞。

## 一、T-pose 四视图（步骤 1）

**何时用**：拿到角色设定，准备喂给 Tripo 多视图生成。

要点写进提示词：标准 T-pose、正视/背视/左视/右视、四个视角的服装与比例必须一致。

（原文未给逐字提示词，锚点："使用 Image 2.5 生成小王子的标准 T-pose 四视图（正视、背视、左视、右视），务必确保各个视角下的人物服装、比例等细节高度统一。"）

## 二、自动绑骨、蒙皮与动作测试（步骤 4）

**何时用**：Tripo 角色已出、已贴图，准备在 Blender 里绑骨。

> 使用 Auto-Rig Pro 为人物完成绑骨和蒙皮，确保骨骼位置与人物关节精准对齐。完成后测试抬手、弯腿、转身等基础动作，检查并修正明显的变形、拉扯和穿模问题。

## 三、复杂交互与 IK 手部精调（步骤 6）

**何时用**：角色要和道具发生物理接触（提水壶 / 握剑 / 拉把手），Mixamo 通用动作不够用。

> 请参考提供的 Mixamo 基础动作，保留其中适用的部分，并使用 Auto-Rig Pro 的手臂 IK 控制器调整手臂姿势，配合手指握持姿态和水壶空间位置的细节修正，补全「提水壶」的完整动作。确保手掌与水壶把手接触稳定、提起过程自然流畅，避免出现穿模、握持脱离或水壶悬空等问题。

## 四、通用提示词骨架（自己套用）

给编码模型（Opus 级）做角色任务时，按这个骨架写，命中率比一句话高：

```
[对象] + [当前资产状态：来自哪一步、什么格式、拓扑类型] +
[要做的事：绑骨/蒙皮/重定向/精调] +
[可用的具体工具：Auto-Rig Pro 的哪个控制器、Mixamo 哪个动作文件] +
[验收项：哪些现象算失败（拉扯、穿模、滑步、悬空）] +
[要产出什么：骨骼好的 .blend/.fbx + 测试截图]
```

「验收项」和「失败现象」这两段最容易漏，而它们正是返工的来源。
