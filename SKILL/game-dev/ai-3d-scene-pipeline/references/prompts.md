# 可复用提示词（原文保留，来源：https://ooo.run/post/how-to-use-ai-build-3d-games.html）

> 原文作者：@Saccc_c。下面按流水线阶段分组，保留原始措辞，仅补了一行"何时用"。

## 一、多视角场景图（步骤 1）

**何时用**：已经有一张满意的主场景图，需要补角度。

> 基于上传的场景参考图，帮我生成一张该场景的全面貌参考图片，包括整体环境的多视角视图以及局部细节的展示。

补充用法：
- 俯视图 → 明确平面布局
- 斜侧视图 → 补高度、造型、前后层次
- 一次性综合图（多视角 + 局部细节）→ 提示词里显式列出"俯视 / 正视 / 3/4 侧视 / 细节特写"

## 二、资产拆解与标注（步骤 2）

**何时用**：拿到参考图、准备生成资产之前。技术栈写清楚，AI 才知道按什么工具分流。

> 我现在要进行游戏开发，我的技术栈是 Tripo + Blender + Unity。请你根据上述生成的场景参考图，帮我深入分析哪些资产适合用 Tripo 生成，哪些资产适合用 Blender 直接进行搭建。并将需要用 Tripo 生成的资产在图片中标注出来，方便我确认。

## 三、场景复刻 + 多机位盲审迭代（步骤 3）

**何时用**：Tripo 资产导出后、交给编码模型组装场景时。把参考图和资产一起给。

> 根据上传的场景内外景多视角参考图以及生成好的 Tripo 3D 资产，请你对照参考图进行完美级的复刻，要求实现和参考图一致的惊艳质感与细节还原。
>
> 在实现完成后，请派一个独立的审查 Agent 进行多机位的场景盲审。如果发现有和参考图存在差异的地方，就不断地进行迭代完善。

**为什么要原样保留"派一个独立的审查 Agent"**：这是作者整套流程里唯一的**验收闸**，
删掉它，"复刻"就退化成模型自说自话。
