# 可直接复制的模板 (aigc-image-control)

四段模板：A 海报风格迁移、B 图生提示词、C 角色资产、E 二维转 3D。
所有 `[方括号]` 是一次性填写位；所有 `【】` 是**变量**——保留括号、替换内容，括号里已经放了能直接跑的值。

---

## A. 海报风格迁移 prompt 骨架

```
输出：一张 [9:16] 竖版 [展览] 海报，印刷级完稿。
参考图角色：我上传的图片只作**风格与设计系统参考**，不是编辑目标。
新主题：[主题一句话，含希望传达的情绪]。

锁定（必须保留）：
- 画幅与栅格：竖版，[上 1/3 留白] 的剧场式分区，边距约为画宽的 [7%]；
- 字体层级：主标题占画面上方 [38%]，[无衬线粗体 + 大字距]，副标题小两档；
- 主视觉机制：[单主体居中偏下，顶边与主标题下沿轻微重叠]；
- 配色关系：[高饱和主色压在低明度背景上，强调色只占 5% 面积]；
- 影像处理：[丝网印质感 + 轻微半色调网点]；
- 信息密度：[低密度，留白占 60%]。

替换（必须换掉）：
参考图中的人物、产品、道具、场景、Logo、文案、品牌标识、主题符号全部替换为新主题元素；
保留空间语法，不复制具体构图坐标，不复刻任何独特插画。

新主题内容：
核心信息 [一句话]；主视觉 [主体 + 动作]；场景 [环境]；道具 [2–5 件，每件都要有叙事理由]；
视觉隐喻 [一个符号]；情绪 [形容词]；文案层级 [主标题 / 副标题 / 日期地点]。

精确文案（逐字渲染，不许多字少字，不许出现其他文字）：
主标题：「[中文标题]」
副标题：「[副标题]」
底部：「[日期 · 地点]」

禁止：参考图中的 Logo、真人身份、品牌字体名、水印；乱码字符；多余的英文单词；
风格迁移成"只有配色像"的退化结果——版式、字级、主视觉占比必须可辨认为同一视觉系统。
```

批量（走 D 时把它变成变量槽）：

```
保留上面全部锁定项，只替换下列变量，生成 [春夏秋冬] 四张，[9:16]：
季节 = 【春】；主视觉 = 【嫩芽与风铃】；主标题 = 【春生】；
季节 = 【夏】；主视觉 = 【浪与冰饮】；主标题 = 【夏长】；
→ 先只生成【春】一张样稿，等我确认版式后再扩展其余三张。
```

## C. 角色资产

### C1. 多角度设定表（建议每角度单出一张）

```
为参考图中的人物制作专业角色设定图，仅生成【正面】一个视角。
必须是同一个人：脸型、五官比例、眼距、眉形、鼻型、嘴唇、年龄、肤色、发际线、身体比例完全一致。
构图：全身入画，人物居中，头顶留白约 8%。
服装：黑色基础款短袖。表情：中性。光线：柔和均匀正面光。背景：浅灰纯色。
不要添加文字、不要美化、不要改变长相、不要加道具。
要求：可直接作为后续所有生成的同一角色参考。
```

### C2. 合成（多图时给每张图分配职责）

```
请制作一张 [9:16] 竖版商业海报。
图 1 为人物参考：保持脸部、发型、姿势、身材、服装不变。
图 2 为排版参考：只参考人物位置、画面比例、视觉层级和留白关系；不复制其中人物、Logo 与品牌元素。
图 3 为风格参考：只参考配色、光线、材质与整体氛围；不参考其中人物与排版。
将图 1 放入图 2 的结构，套用图 3 的视觉风格。
优先级：人物一致性 > 排版 > 风格。
禁止：把图 2/图 3 里的人物带进来；改动脸型与眼距；修改发型；添加参考图之外的文字。
```

### C3. 虚构角色 → 真人肖像

```
以我上传的图片作为虚构角色的外貌参考，将角色重新诠释为现实中存在的年轻成年女性，
生成一张未经重度修饰的专业真人肖像照片。

保留身份特征：修长的黑色直发、轻薄齐刘海、灰蓝色眼睛、柔和安静的表情、
紫色水滴形耳坠、黑色圆领短袖；正面直视镜头、居中构图。

真实化：脸型与五官比例按真实成年女性的人类生理范围重新自然化：
眼睛可比常人略大，但必须落在可信范围内；不要夸张动漫眼。

皮肤：真实相机拍摄的质感，不是插画、游戏角色或 3D 渲染。
可见细小毛孔、轻微肤色不均、局部泛红、细微绒毛、真实唇纹；
不使用磨皮、美颜滤镜、无瑕肤色、塑料皮肤。

布光：柔和主光从左前方约 45° 照下、略高于眼睛，鼻侧与面颊出现轻微明暗过渡；
右侧只有较弱的补光，不使用完全均匀的正面美容光。中性灰背景，真实景深，轻微自然颗粒。

禁止：动漫、插画、半写实绘画、3D 渲染、游戏建模、CGI 皮肤、蜡像、陶瓷/塑料皮肤、
空气感磨皮、美颜滤镜、过度锐化、假毛孔贴图、严重痘疤、娃娃脸、巨大眼睛、尖锐下巴、
完全对称的五官、假睫毛、塑料头发、连续条带状发光。
```

## E. 二维场景 → 3D

```
以我上传的场景图为空间与氛围参考，生成一个可探索的 3D 环境。
保留：透视线索、地平线高度、主要体块的遮挡关系、材质语言、光线方向与色温。
我理解的边界：原图不可见区域由你推断补全，这是概念空间，不是精确重建。
请避免：明显穿模、漂浮物体、闪烁的纹理、被拉伸的招牌文字。
如果某个区域没有足够信息，请给出合理但简洁的体块，不要堆砌细节。
```

交付时必须写：**这是概念探索空间，不可用于测量或作为精确资产**，并列出实际走查中发现的崩坏点。
