## 二、按"使用场景"重新选型(平台中立建议)

### 场景 A:快速验证灵感 / 量产短视频
- **首选**:TapNow 类"一画布"工作台 / 一键文生视频
- **理由**:出片快、批量任务排队、适合"灵感→落地"高频迭代

### 场景 B:品牌片 / 高级感广告
- **首选**:Sora / 高级 DiT 模型 + 图生视频
- **理由**:画面质感最高、时空一致性最好、影视感强

### 场景 C:角色一致 / 剧情短片
- **首选**:Runway Gen-2 / Kling / Seedance 多模型混合
- **理由**:角色参考能力强、可分镜控制

### 场景 D:艺术实验 / 风格化
- **首选**:Pika Labs / Seedance / 自定义 LoRA
- **理由**:风格自由度最高,但出图较慢

### 场景 E:产品开箱 / 电商主图视频
- **首选**:任何支持图生视频 + 高分辨率输出的平台
- **理由**:需要精准控制产品外观,出片速度优先于剧情

## 三、按"能力维度"选型矩阵(2026 年视角)

| 能力维度 | 强项平台 | 弱项平台 |
|----------|----------|----------|
| **时空一致性(人物不变形)** | Sora / Kling 2 / Seedance 2 | Pika 早期版 |
| **风格自由度** | Pika / 自定义 LoRA | 限定模板平台 |
| **出片速度** | TapNow / Seedance | Sora(慢但精) |

| **原生 4K 输出** | Sora / 部分专业平台 | 多数平台仍 1080p |

## 四、按"提示词可控性"选型

| 控制粒度 | 推荐工具 | 理由 |
|----------|----------|------|
| **关键词级**(基础) | 任何 T2V 平台 | 主体 + 动作 + 环境 三要素 |
| **镜头级**(中等) | Runway / TapNow | 支持"慢推""手持晃动"等镜头词 |
| **分镜级**(高级) | TapNow 分镜模式 / Sora | 支持单帧精细控制 |
| **资产级**(专家) | 自托管 + LoRA 微调 | 完全自定义风格,学习曲线最陡 |

## 五、按"成本"选型

| 预算档 | 推荐方案 | 月成本估算 |
|--------|----------|-----------|
| **免费** | Pika 免费版 / Sora 限流版 / 国内平台试用 | 0 元 |
| **入门(< 100 元/月)** | 单平台月度订阅 | 50-100 元 |

## 六、模型迭代风险

- AI 视频模型迭代周期 **6-12 个月**一次大版本
- 选平台时优先看:**平台的中长期路线 + 多模型切换能力 + 数据导出可移植性**
- **不建议**把全部作品绑定单一平台,优先选择支持"模型可切换 + 资产可导出"的工作台

## 八、不可绕过的"五条死线"选型 checklist

```
[ ]  是否一画布? 一画布 ≠ 跳转 = 流程摩擦
[ ]  模型可切换? 一键切换 Sora / Kling / Seedance?
[ ]  提示词辅助? 新手友好(关键词补全/模板库)?
[ ]  商用授权? 输出能否商用?水印?分辨率?
[ ]  协作版本管理? 团队项目是否可用?
```

> 五条都勾选才能上"专业创作者"使用;缺 1-2 条可作"个人玩具"。
