# 按风格分类的提示词库模板

按风格分类的提示词模板,每条 = **风格定位 + 万能公式展开 + 关键质感词 + 失败预警**。新创作时基于模板微调。

---

## 1. 治愈系 (Healing / Cozy)

### 适用
- 生活方式 / Vlog / 情感文案可视化 / 小红书图文延伸

### 模板(基于万能公式展开)
```
主体:一位 <年龄> <性别>,穿着 <柔软材质 + 浅色系> 服饰,表情 <平静/微笑>
动作:<低强度连续动作,如缓步、翻书、泡茶、轻抚宠物>
环境:<春日/午后/雨后/窗边> <光:柔光/丁达尔效应/侧逆光>,背景 <绿植/旧书/木质家具>
情绪:温暖、宁静、有呼吸感
镜头:慢推 / 中景跟拍 / 固定机位浅景深
风格:<日系清新 / 新海诚式 / 宫崎骏水彩>
规格:4K 1080p,电影感,无水印
```

### 关键质感词
- "丁达尔效应"、"柔和逆光"、"浅景深"、"暖色调"、"胶片颗粒"、"治愈系"
- 节奏词:"缓慢呼吸般移动"、"如时间凝固"、"细腻光斑"

### 失败预警
- 主体动作过大 → 变成剧情片,失去治愈感
- 镜头过抖 → 失去"呼吸感"
- 颜色饱和度过高 → 失去治愈系标志的"低饱和奶咖"

## 2. 国风唯美 (Chinese Aesthetics)

### 适用
- 古装短剧 / 文化宣传 / 敦煌风 / 国风 MV / 二十四节气

### 模板
```
主体:<性别>,穿着 <汉服/唐服/旗袍/敦煌飘带>,<发型/头饰>
动作:<古典动作,如抚琴、舞剑、回眸、撑伞>
环境:<场景:青绿山水 / 樱花 / 红叶 / 黄昏古寺 / 月下竹林>
情绪:东方意境、留白、禅意
镜头:"慢速推进 + 浅景深" / "固定机位 + 烟雾前景遮挡"
特殊效果:"留白构图"、"对称构图"、"工笔重彩"
风格:<工笔重彩 / 敦煌壁画 / 新中式水墨>
规格:4K 21:9 电影画幅
```

### 关键质感词
- "留白"、"烟雨"、"古寺"、"黄昏"、"汉服"、"敦煌飞天"、"红叶"、"晨雾"
- 镜头词:"慢推"、"固定机位"、"浅景深"、"烟雾前景"

### 失败预警
- 西式五官 → 失东方韵味
- 现代服饰混搭 → 失古风
- 高饱和度 → 失水墨淡彩的留白感

## 3. 赛博朋克 (Cyberpunk)

### 适用
- 科技产品 / 未来概念 / 潮玩广告 / 游戏宣传

### 模板
```
主体:<性别/角色>,<改装义体 / 发光纹路 / 霓虹妆容>
动作:<激烈动态,如奔跑、挥刀、Hack 操作、回头>
环境:<场景:霓虹小巷 / 立体交通 / 雨夜都市 / 全息广告>
情绪:紧张、躁动、对抗、未来感
镜头:"广角 + 仰拍 / 俯拍"、"快速推拉"、"手持晃动感"
特殊效果:"霓虹光晕"、"全息投影"、"雨夜反射"、"故障感"
风格:"赛博朋克 2077 风"、"银翼杀手风"、"国产赛博"
规格:4K 21:9,高对比度
```

### 关键质感词
- "霓虹光晕"、"义体改装"、"全息广告"、"雨夜反射"、"失真感"、"噪点"
- 镜头词:"广角仰拍"、"快速推拉"、"手持晃动"

### 失败预警
- 主体不够赛博(普通装扮)→ 出戏
- 场景不够都市感(空旷)→ 失赛博氛围
- 色调偏暖 → 失赛博的冷蓝紫调

## 4. 剧情片 / 微电影 (Cinematic Drama)

### 适用
- 短剧分镜 / 情绪片 / 品牌故事 / 广告叙事

### 模板
```
主体:<性别>,<角色定位:母亲 / 战士 / 少年 / 老人>
动作:<戏剧动作 > 含情绪, 比如「外强中干的转身」、「颤抖的双手」>
环境:<场景 > 带时间, 比如「雨夜便利店」、「黄昏天台」、「午夜医院走廊」>
情绪:具体情绪词,如「孤独」「压抑中的挣扎」「释然」
镜头:"固定机位 + 长焦 / 中景"、"慢推 + 浅景深"
特殊效果:"侧逆光剪影"、"丁达尔效应"、"老电影划痕"
风格:"王家卫式 / 是枝裕和 / 诺兰式"
规格:4K 21:9,高动态范围
```

### 关键质感词
- "情绪基调"必给,如「释然」「压抑中的挣扎」「孤独中的希望」
- 声音暗示:加「脚步声回响」「远处钟声」可显著提升情绪

### 失败预警
- 没有情绪词 → 像空壳动作片
- 镜头太稳 → 失戏剧张力,加手持晃动或快速推拉

## 5. 产品 / 商业广告

### 适用
- 开箱动效 / 产品宣传 / 卖点视频 / 电商主图视频

### 模板
```
主体:产品本身,占画面 <60-70%>,光圈 <f/1.4> 突棚质感
动作:<简洁动作,如旋转、悬浮、绽放、散落>
环境:<极简背景:纯色 / 渐变 / 浅景深虚化>
情绪:高端、精致、礼物感
镜头:"微距 + 慢推"、"360 度环绕"、"定机位慢推"
特殊效果:"金属反光"、"丝绸光泽"、"光斑散景"、"烟雾背景"
风格:"苹果广告 / 戴森路特插画风 / 国家地理摄影"
```

### 关键质感词
- 材质描述必给:"金属反光"、"丝绸光泽"、"磨砂表面"、"水晶折射"
- 背景干净是底线

### 失败预警
- 产品占比过小 → 失焦点
- 背景杂乱 → 失高端感
- 镜头太快 → 看不清产品

## 6. 科普 / 知识可视化

### 适用
- 科普动画 / 教学视频 / 数据可视化 / 抽象概念具象化

### 模板
```
主体:<抽象概念的具象化身,如「细胞」/「分子」/「数据流」>
动作:<可视化动作,如「分裂」「合成」「流动」「旋转」>
环境:<场景化背景,如「显微镜下」「血管内部」「芯片内部」>
情绪:好奇、探索、沉浸
镜头:"中景 + 慢推"、"微距特写"、"环绕运镜"
特殊效果:"荧光染色"、"光路轨迹"、"数据流"
风格:"3D 渲染 / 国家地理 / 苹果 keynote"
```

### 关键质感词
- "显微"、"荧光"、"3D 渲染"、"光路"、"数据流"

### 失败预警
- 抽象概念没有具象化身 → 观众没有锚
- 颜色过于真实 → 失科普的趣味性

## 7. 复古 / 胶片 (Retro / Film Grain)

### 适用
- 复古 Vlog / 情怀短片 / 老电影修复风 / 80s 80s 风格

### 模板
```
主体:<服饰:复古衬衫/中山装/港风/工装>
动作:<自然动作,不要过于戏剧化>
环境:<年代感场景,如「旧式录像厅」「街机厅」「港式茶餐厅」>
情绪:怀旧、温暖、忧郁
镜头:"手持晃动 + 中景"、"固定机位 + 长焦"
特殊效果:"胶片颗粒"、"老电影划痕"、"褪色色调"、"CRT 显示器"
规格:4K + 后期加胶片 LUT
```

### 关键质感词
- "胶片颗粒"、"老电影划痕"、"褪色"、"4:3 画幅"、"CRT 显示器"

### 失败预警
- 数码感过强(锐利) → 失胶片感
- 颜色过艳 → 失褪色

---

## 通用:在任一模板基础上加这 5 个开关

```
情绪增强:加"孤独感"、"希望之光"、"压抑中的挣扎"等情绪基调
镜头增强:加"慢推"、"广角仰拍"、"手持晃动"、"焦外虚化"
声音暗示:加"脚步声回响空旷走廊"、"风铃轻响"、"远处钟声" (虽不能直接生成声音,但可触发观众联想)
时间锚点:加"黄昏时刻"、"暴雨前的寂静"、"午夜三点"
风格微调:加"宫崎骏笔下的梦境"、"王家卫式迷幻"、"新海诚的夜空"
```

> 📌 **心法**:同一段提示词,加 1 个质感词几乎看不出来,加 5 个质感词叠加就能明显提升电影感 — 但超过 10 个就开始"过载",模型会挑重点忽略细节。**5-7 个质感词是甜蜜点**。
