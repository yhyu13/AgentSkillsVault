# AI 生图可控工作流 (aigc-image-control)

**一句话**：找对参考 → 拆清规则 → 锁定不变量 → 替换内容变量 → 检查结果。

**它解决的问题**：AI 生图最大的失败不是"画得不好看"，而是**不受控**——同一套视觉说不出为什么对、换一个主题就漂移、换个发型像换了个人、海报里文字全是乱码、批量出图风格各走各的。

**它不解决的问题**：模型本身的能力上限、平台账号与配额、版权授权。本 skill 只负责"把可控的部分控制住"。

## 适用 / 不适用

| 适用 | 不适用 |
|------|--------|
| 拿到一张参考海报，要出同视觉系统的新海报 | AI 视频（文生/图生视频、镜头运动）：用 `aigc-video-creation` |
| 想把参考图反推成可复用的提示词（中英双版） | 网站 / App 视觉方向与界面稿：用 `taste-imagegen-web` / `taste-imagegen-mobile` |
| 人物或品牌 IP 要在多张图里保持同一张脸 | 用代码画图、画插画、做等距图解：用 `canvas-design` / `anatomy` |
| 系列内容（四季、星座、节气、十二生肖）批量出图 | 找现成免授权素材图：用 `unsplash-asset-images` / `aura-asset-images` |
| 二维场景图 → 可探索 3D 世界 | 高精度三维资产建模：用 `blender-game-assets-v2` |

## 五种玩法，先选路再动手

| # | 玩法 | 输入 | 输出 | 主要风险 |
|---|------|------|------|----------|
| A | 参考图 → 同系列新海报 | 1 张参考海报 + 新主题 | 新海报 + 保留/替换清单 + 最终 prompt | 丢了版式只剩配色 |
| B | 参考图 → 可复用提示词 | 1 张以上参考图 | 画面拆解 + 中/英 prompt + 负向 + 参数 + 可编辑变量 | 把推断当事实（瞎报镜头/模型/作者） |
| C | 角色 / IP 资产一致性 | 人物图或品牌形象 | 角色资产目录 + 多角度设定表 + 生成用的职责分配 prompt | 换装换发型就换脸；多图互相污染 |
| D | 系列批量（四季/生肖/节气） | 一套风格母版 | 统一视觉的 N 张图 | 越往后越飘；单张跑偏没抽检 |
| E | 二维 → 3D 可探索场景 | 一张带透视的场景图 | 3D 场景 + 可探索链接 | 把"AI 补全"当成精确重建交付 |

默认路由：

```
用户给了参考图 + 新主题，要成品？  → A（内部走 B 的分析纪律）
用户只要提示词 / 要复用到别的工具？ → B
用户提到"同一个人 / 同一个 IP / 多张图"？ → C
用户提到"一套 / 系列 / N 张"？      → D（A 或 C 的批量化包装）
用户提到 3D / 可探索 / 场景漫游？   → E
```

## 全局纪律（五种玩法都适用，违反其中任何一条都会翻车）

1. **观察与推断必须分开写。** 看得见的是观察；镜头焦距、光圈、渲染器、艺术家、seed、原始 prompt 一律是推断，必须标 `推测`。不要假装知道"原图的提示词"。
2. **不指名道姓。** 不猜艺术家、不猜模型、不猜品牌字体。风格描述写视觉行为（"标题占画面上方 38%"），不写"像某某的作品"。
3. **不复制身份证。** 参考图里的人、Logo、文案、独特角色设计、品牌元素属于"必换"清单，风格语法才是"硬锁"。风格本身不受版权保护，但构图 + 可识别元素的组合可以构成侵权。
4. **变量必须内嵌当前值。** 可编辑提示词用 `【】` 包住变量，括号里放一个现在就能用的值（`一位【穿深红色长外套的年轻女性】站在【雨夜的城市街道】上`），不要输出"变量 1/变量 2"的空壳，也不要另附一张变量清单代替正文。
5. **先出样稿再批量。** 任何"系列 / N 张 / 整套"的请求，先出 1 张；用户确认版式与风格后才扩展。批量时每张都要跑验收清单（见下），不能默认"母版对了后面都对"。
6. **文字不靠模型。** 短标题可以赌；密集文案、精确中文排版一律走双层：生成留白图 → 用 HTML / 矢量 / 文档工具叠字。**没有检查过图就不要声称文字准确。**
7. **失败要归因，不要重写整个 prompt。** 单点问题（一个词、一处位置）就用一次定点修改 + 重复不变量；只有大方向错了才重写。

## A. 参考图 → 同系列新海报

### 抽取顺序（照着这个顺序看，不要从配色开始）

1. 海报原型与传播目的（演出 / 展览 / 招聘 / 产品发布 / 电影 / 招聘 / 促销）
2. 画布、栅格、边距、分区、阅读路径
3. 字体层级与文字行为（行数、断行位置、大小比例、字重对比）
4. 主视觉机制（主体占比、裁切方式、与文字的重叠关系、图层叠放）
5. 色彩关系与对比分布（不是色值，是关系：谁压谁、对比集中在哪）
6. 图形装置、装饰密度、重复节奏
7. 影像处理、材质、光线、质感与后期
8. 信息密度、负空间占比、整体节奏

测量用**相对值**："主标题占画面左上 38%"，不用"大标题在顶部"。

### 三层锁定：这是整个玩法的核心

| 层 | 内容 | 处理方式 |
|----|------|----------|
| **硬锁 (Hard lock)** | 画幅比例、栅格家族、边距节奏、标题占地、主视觉与画布比、主重叠行为、配色关系、字体类别、影像处理方式、密度分布 | 必须保留。这是"同一视觉系统"的判据 |
| **软锁 (Soft lock)** | 装饰数量、次级模块、纹理强度、光向、局部旋转小标、强调形状 | 可保留可微调，随新主题适配 |
| **必换 (Must replace)** | 参考图里的人物、产品、道具、场景、Logo、文案、品牌标识、受版权保护的角色、主题符号 | 必须换掉。保留空间语法，不保留具体内容 |

**优先级**：人物/主视觉一致性 > 版式 > 风格。冲突时按这个顺序放弃后面的。

### prompt 装配顺序

`输出意图 → 参考图的角色（只作设计系统参考） → 新主题 → 锁定版式 → 字体行为 → 新主视觉 → 环境/道具 → 色彩 → 材质/光线 → 精确文案（逐字引号） → 约束与禁止项`

必写的三句：
- "输入图仅作**风格与设计系统**参考，不是编辑目标。"
- "保留：[硬锁清单]。"
- "替换：[必换清单]；禁止出现参考图中的 Logo、人物、文案、品牌元素。"

同时把可替换处做成内嵌变量（见全局纪律 4），这样一张母版能直接跑 D 的批量。

### 参考图筛选（不可省的一步）

硬要求：画面有明确的画布、字体层级、主视觉、信息模块、设计过的阅读顺序。**普通照片不是海报**，不要硬套。多张参考时指定**一张主控**（版式 + 字体 + 主视觉 + 色彩由它决定），其余只作补充参考，不静默平均互相矛盾的部分。

## B. 参考图 → 可复用提示词

### 分析顺序

1. **主体与动作**：身份类别、数量、姿态、表情、互动、服装、道具
2. **构图**：朝向、裁切、主体位置、对称性、前中后景、负空间、视点
3. **环境**：地点、背景元素、天气、时间线索、氛围
4. **光线**：方向、软硬、对比、主光/补光/轮廓光、实用光源、阴影性格
5. **色彩**：主色板、强调色、饱和度、色温、明度范围
6. **表面与细节**：材质、纹理、景深、颗粒、辉光、运动、反射
7. **视觉语言**：摄影 / 电影 / 编辑 / 商业 / 绘画 / 矢量 / 赛璐璐 / 黏土 / CGI / 拼贴
8. **拍摄或渲染线索**：景别、透视、焦距区间、渲染方式、后期——全部标 `推测`
9. **文字与版式**：只转录清晰可读的字；不可读写 `[unreadable text]`，或描述为"版式块"

用空间化短语："主体在画面右下三分之一处"、"来自画面左侧的柔和逆光"。用具体视觉属性替代空洞形容词（"8K 大师作品"这类词直接删）。

### 输出契约（六段，缺一不可）

1. `画面拆解` — 主体/构图/光线/色彩/媒介风格/关键质感，重要推断标 `推测`
2. `中文 Prompt` — 一段可直接复制的成品
3. `English Prompt` — 独立优化，不是中文的逐字翻译
4. `Negative Prompt` — 只写本题相关的缺陷项；模型不吃负向词就整段省略
5. `建议参数` — 先画幅比例，再给少量起点建议，全部标为"建议"而非"还原"
6. `可编辑变量` — 一段完整提示词，`【】` 内嵌当前值

### 模型差异（只写有依据的部分）

| 模型 | 处理 |
|------|------|
| Midjourney | 自然语言在前，只补有用的比例/stylize/chaos/图片权重；不声称原值 |
| SD / SDXL / FLUX | 正负向分开；给尺寸/比例，guidance/steps 作起点建议 |
| DALL·E / 通用 | 连贯自然语言 + 明确构图与约束，不加命令语法 |

### 特殊类型的分析重心

- **海报 / 平面**：视觉 prompt 与精确文案分开；保留层级、栅格、间距、字体类别、文字位置
- **UI 截图**：按信息架构、布局、组件样式、密度、色板 token、交互状态描述，不当摄影场景
- **产品图**：几何、材质、机位、接地阴影、反射、背景、商业布光
- **人像**：姿态、视线、裁切、表情、发型、服装、背景分离、皮肤受光；**不推断身份**
- **高度风格化**：先写线质、形状语言、明暗方式、纹理、色板、构图，再用类型标签

## C. 角色 / IP 资产一致性

### 不要存"一张人物图"，要存一套资产

```
角色名称/
├── 角色设定与固定描述      ← 唯一事实源，先写这个
├── 标准正脸与多角度参考
├── 全身与身体比例
├── 表情库
├── 动作库
├── 发型库
├── 服装库
├── 海报成品
├── 网页素材
└── 禁止变化项              ← 这张脸"什么绝对不能变"的清单
```

### 第一步：多角度角色设定表（一张图只做一件事）

一份能用的设定表 prompt 必须包含：

- 同一个人：脸型、五官比例、眼距、眉形、鼻型、嘴唇、年龄、肤色、发际线、身体比例**完全一致**
- 视角：正面、左侧 45°、右侧 45°、侧面、全身
- 黑色基础服装 + 中性表情 + 柔和均匀光线 + 浅灰纯背景
- 所有视图**同一比例**、不带文字、不美化、不改变长相

> 模型的软肋：一张图里塞五个角度，最常见的失败是"五个人"。稳妥做法是**每个角度单独出一张**，或先出正脸定稿再逐角度生成；设定表里真正要的是一致性，不是排版好看。

### 第二步：多图时给每张图分配职责

参考图越多，AI 越喜欢把人物、动作、服装、风格混着抄。必须逐张写职责：

```
图 1 = 人物身份参考，只看脸部与身体特征。
图 2 = 动作参考，只看姿态与机位，不参考其中的人物长相。
图 3 = 服装参考，只看款式与材质。
```

先拿到"人物 / 动作 / 服装 / 机位都正确"的基础素材，再处理海报风格与排版。

### 第三步：合成时写死优先级

```
请制作一张 9:16 竖版商业海报。
图 1 为人物参考：保持脸部、发型、姿势、身材、服装不变。
图 2 为排版参考：只参考人物位置、画面比例、视觉层级和留白关系，不复制其中人物、Logo、品牌元素。
图 3 为风格参考：只参考配色、光线、材质与氛围，不参考其中人物与排版。
将图 1 放入图 2 的结构，套用图 3 的视觉风格。
优先级：人物一致性 > 排版 > 风格。
```

### 常见失败与处理

| 现象 | 常见原因 | 处理 |
|------|----------|------|
| 换发型就换了个人 | 没锁身份特征 | 用多角度设定表 + 列禁止变化项 |
| 人物像参考图里的模特 | 没区分图片职责 | 明确写"动作图不参考长相" |
| 服装对了脸变了 | 一次控制太多变量 | 先定人物/动作/服装，再做排版与风格 |
| 海报把参考品牌抄了 | 没限定排版参考范围 | 明确禁止复制 Logo、文案、品牌元素 |
| 多图信息混在一起 | 缺优先级 | 写死"人物一致性 > 排版 > 风格" |

### 虚构角色 → 真人肖像（换脸向的提示词骨架）

要点排序：身份辨识特征（发型/刘海/瞳色/耳饰/衣领/机位构图）→ 人类生理可信（眼距、脸型比例、唇峰下颌）→ 皮肤微观（毛孔、肤色不均、毛细血管、绒毛、唇纹）→ 真实布光（约 45° 侧上方主光，略高于眼睛，少量补光，不做正面平光）→ 中性灰背景、真实景深、轻微颗粒。

禁止项（要显式写出来）：动漫、插画、半写实、3D 渲染、游戏建模、CGI 皮肤、蜡像、陶瓷/塑料皮肤、空气感磨皮、美颜滤镜、过度锐化、无瑕肤色、假毛孔贴图、塑料头发、完全对称的五官、假睫毛。

> 长提示词不必一次全用。**先锁身份与真人化方向**，再按失败结果补皮肤、头发、布光和负向限制。

## D. 系列批量（四季 / 生肖 / 节气 / 一套配图）

1. 上传一张或几张风格统一的母版
2. 说明系列里必须统一的部分（对应 A 的硬锁）
3. 列出每张要变的主题变量（季节、主体、文案、日期）
4. **先出一张样稿**，确认版式与风格
5. 确认后批量扩展，每张都过验收清单
6. 抽检一致性：把 N 张拼成一张对比图看，漂移在拼图里一眼就能看出来

## E. 二维场景 → 可探索 3D

可用工具（Marble 一类）能从透视线索推断空间关系并生成可探索场景，但：

- 它**不是**精确三维重建。原图不可见的区域由 AI 推断补全——背面、侧面、遮蔽处、文字招牌都会即兴创作。
- 验收要看：透视是否自洽、地平线是否稳定、遮挡关系是否合理、走进去有没有穿模与漂浮物、文字是否报废。
- 交付时明确标注这是**概念探索空间**，不是可用于测量的模型。需要精确几何就走真正建模（`blender-game-assets-v2`）。

## 参考图去哪找

| 需求 | 平台 |
|------|------|
| AI 生图案例与提示词参考 | 即梦、Midjourney 灵感栏目 |
| 平面与视觉设计 | 站酷、Dribbble、Behance |
| 游戏、概念设计、三维场景 | ArtStation |

**渐进式搜索**：在 Pinterest / 花瓣输入一个大方向，先点开接近目标的图，再顺着平台推荐逐步收窄；不要一开始就要求自己想出精准关键词。

**版权红线**：参考图用于学习设计规律与找方向。正式商用前确认素材授权、肖像权、商标与版权边界；不直接复制他人品牌元素或作品。

## 验收清单（每张图都跑，不要跳）

```
□ 主题相关性：主体讲的是新主题，不是参考图的主题
□ 构图与层级：阅读顺序与硬锁一致
□ 硬锁保真：画幅/栅格/标题占地/主视觉比/配色关系是否还在
□ 文字准确性：逐字核对；没看图不许说"文字正确"
□ 参考污染：检查是否残留参考图的人物、Logo、文案、品牌符号
□ 伪影：乱码字符、多余物体、畸形手部、错误反射、重复纹理
□ 版权：没有复制可识别品牌元素或真人身份
```

打分方式：硬锁逐项打勾；**只有"氛围像但版式/字级/主视觉机制丢了"的结果一律判不合格**，不要用"挺好看的"放过它。

## 我对这套工作流的批评（用它之前先读这段）

这套方法来自两个 v0.1.0 的上游 skill 加一份观众配套说明。它值得用，但有七个真实缺陷：

1. **"精确排版"是靠描述的，不是靠坐标的。** 硬锁写成"标题占上方 38%"，模型并不会真的按 38% 画。真正需要精确版式时，正确做法是**生成无字底图 + HTML/矢量排版**，本 skill 已把这条写成硬规则，上游没有。
2. **多角度设定表是这套流程里最容易失败的一步。** 上游要求"一张图包含正面/左右 45°/侧面/全身且比例统一"，但当前模型在一张图里画五个角度时，一致性恰恰最差。取舍：改成"每角度单张 + 正脸先定稿"，一致性优先于排版美观。
3. **长提示词堆叠会互相打架。** 真人肖像那段几十行约束塞给 Midjourney 会被截断或权重稀释；正负向混写进 SD 的正向栏会起反作用。取舍：分阶段加约束，按失败归因补条目。
4. **没有复现机制。** 全篇没有任何 seed / 参数留存约定。同样的 prompt 明天出的是另一张图。可用做法是把"能复现的最小集合"（prompt 全文 + 模型 + 参数 + 参考图版本号）一起归档，本 skill 要求把它写进角色资产目录。
5. **上游依赖"能看图的运行时"，但没说看不图时怎么办。** 纯文本/无视觉通道时，模型会**假装分析过**参考图。Fail closed：没有视觉通道就明说，只做变量模板（玩法 B 的第 6 段 / A 的 prompt 装配），不编造"我观察到"。
6. **没有量化验收。** 上游给了 fidelity rubric 的方向，但没有可复算的评分。本 skill 的验收清单是打勾制——能被反驳，比"感觉挺像"强。
7. **合规护栏太薄。** "不要复制品牌元素"只是一句提醒。真正要盯的是：真人肖像授权、参考图商用授权、把可识别角色做衍生。这三条不过，前六条做得再好也不能用。

另外两个来自本仓库的取舍：**合并成一个 skill，不装两个**（观察/推断分离、变量内嵌、验收清单是三套玩法共用的，写两遍必然漂成两套说法）；**不软依赖上游仓库**（上游没有脚本、没有 eval、没有测试，vault 的缺陷审计标准会把"无法验证的 payload"判为低质；方法留下，依赖去掉）。

## 输出契约

不管走哪个玩法，最后必须给到：

1. **成品或可直接使用的 prompt**（不要只给分析）
2. **保留了什么 / 替换了什么**（硬锁清单 / 必换清单各一段）
3. **验收结果**（清单逐项，或 fidelity 打分）
4. **变量说明**（哪些位置可换，换了会怎样）
5. 走 3D 时额外给：这是概念空间而非精确模型的声明 + 已知崩坏点

模板见 `references/prompt-templates.md`；蒸馏来源、保留/丢弃的逐条证据见 `references/source-notes.md`。
