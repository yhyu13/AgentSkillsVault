# 中文平台载体式教程风格 (style-cn-platform-tutorial)

一份**风格预设**而非完整写作流程:为"以某个 AI 工具/产品为载体,从零基础 → 实操 → 审美 → 时代宣告"的中文长文提供 10 个可复用的语音指纹。风格来自 2026 年一篇以 TapNow 为载体的 AI 视频生成全攻略长文。

继承 `content-craft` 的"准确 / 有用 / 易读 / 活人感"基线 — 这个 skill 只管**语音**,不管事实、结构和发布流程。

## 适用场景 vs 不适用

| 适用 | 不适用 |
|------|--------|
| 中文 AI/工具/SaaS 的"全攻略"教程 | 英文 long-form |
| 中文工具/产品的 "零基础→高阶"体系课 | 短帖 / 推文 / LinkedIn(用 `blog-to-*` / `long-blog-to-viral-social-posts`) |
| 中文公司产品 deep-dive(以官方文档为载体) | 知乎专业回答(用 `tech-design-to-zhihu`) |
| 平台横评 + 单平台主推 | 学术论文 / 行业研究报告 |
| 需要"既要教程也要审美"的中立推广文 | 纯营销文案 / 产品 PR 通稿 |
| 想写"创作平权""人人都是 X"使命感文 | 争议复盘 / 八卦叙事(用 `style-cn-tech-deep-dive`) |

## 风格指纹速览(详细定义见 references/voice-fingerprint.md)

| # | 指纹 | 一句话定义 |
|---|------|----------|
| 1 | **平台锚定式开场** | "在 X 工具/平台中,XXX 凭借 N 大特点,成为 Y 的首选" |
| 2 | **"从 X 到 Y"承诺式提纲** | "✅从零入门 → ✅精通实操 → ✅提升审美 → ✅打造 Z" 四阶段承诺 |
| 3 | **emoji 钩子标** | `✅ ❌ 🎯 💡 🔍 ✨ 🌟 📌 💡 🚀 📊 📝` 等作为段首/条目标记 |
| 4 | **三形态对照表** | 把同一领域划成 3 种"工作模式"放表里对比 |
| 5 | **万能公式 + 低效 vs 高效对比** | 抽出可复用的公式骨架,再用"❌ 低效"vs "✅ 高效"演示 |
| 6 | **N 个技巧表** | "9 个提升 X 的方法",标题"X:一个 Y" |
| 7 | **"X vs Y"对比表** | 把传统方式和新方式对照,加 ✨结论 |
| 9 | **三步走机制表** | 把流程切成 ①/②/③ 三步,固定句式 |
| 8 | **"五条/N 条"红线表** | 把坑点压缩成 N 条,用表呈现 |
| 10 | **"创作平权时代"使命感收尾诗** | 三行短句金句(每行 12-20 字)宣告时代 + 邀请读者开始 |

## 工作流

```
1. 确认题材命中"适用场景"列(以某工具/平台为载体,做全方位拆解)。
2. 读 references/voice-fingerprint.md,挑出本篇要用的指纹(不必 10 个全用,通常 6-8 个)。
3. 读 references/structural-patterns.md,套用对应的节级模板。
4. 用 references/templates.md 的句式填充开头/小节标题/收尾。
5. 用 references/examples.md 对照 2026.md 原文,确认风格没漂移。
6. 走 content-craft 的"源头锚定"铁律(数字 + quote 必须可回溯)。
```

## 不写什么(反向边界)

- **不写争议/八卦叙事**:不写"被曝""偷传"等争议语;本风格是中性教程 + 升格,不是争议复盘(那种用 `style-cn-tech-deep-dive`)
- **不堆无关 emoji**:每个 emoji 必须标记真正的"看,这里是关键",不是装饰
- **不写"看似客观实则纯推广"**:本风格自带平台锚定(以某工具为载体),但必须保持横向对比和"五条/N 条死线"中立性
- **不堆段落形容词**:本风格以表格 + 公式 + 短句为主,不写长段抒情
- **不写"我们都是创作者"等空喊口号**:使命感收尾诗必须有具体动词(点燃 / 讲述 / 创造)

## 已知局限

- **不是"中文教程唯一正确风格"**:还有少数派、极客时间、网易云课堂等多套主流教程风格,本 skill 只覆盖 2026.md 这一脉"平台载体式 + 审美升格 + 时代宣告"
- **不替代事实核查**:指纹负责让文字"像人写的",不保证"写得对";事实核验归 `content-craft` 的源头锚定
- **不适合纯学术/工程**:本文带强使命感和 emoji,工程类 / 学术类强 pinp 教程请另寻风格
- **平台绑定的"软广"风险**:本风格自带"以 X 平台为载体"的预设立场 — 写中性教程时请把"五条死线 / 横向对比"做足,避免被读成"软文"
