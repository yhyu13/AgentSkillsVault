# 句式库 (Templates)

可直接套用的句式。每条 = **使用场景 + 模板 + 注意事项 + 原文示例**。

---

## 一、开场钩子变体(指纹 1)

### 变体 A · "而在 X 中,XX 凭借 Y" 平台锚定
- 模板:`而在 <具体年份/领域> 的 <N 个工具> 中,**XX** 凭借 "<X 大特点>", 成为 <用户群> 的 <定位>。`
- 触发:几乎所有平台载体式教程
- 示例:`而在 2026 年众多 AI 视频工具中,TapNow 凭借"一张画布搞定全流程"的极致体验,成为新手入门、创作者量产、专业创作的首选平台`

### 变体 B · "本篇文章将以 XX 为核心" 承诺式
- 模板:`本篇文章将以 **XX 为核心实操载体**, 全方位拆解 <领域>, 从 <维度 1>, <维度 2>, <维度 3>, <维度 4>, 再到 <维度 5>——`
- 触发:平台教程的承诺段
- 示例:`本篇文章将以 TapNow 为核心实操载体,全方位拆解AI视频生成,从核心技术原理、底层运行逻辑、工具深度测评、全功能精细化操作、提示词高阶技巧、常见避坑指南,再到 AI 视频时代的深度审美思考`

### 变体 C · "在 X 时代,XX 早已摆脱旧标签"
- 模板:`在 <时代背景>, <领域> 早已摆脱 <旧标签>, 迈入 <新阶段>。从 <旧方式>, 到 <新方式>, <领域> 正在 <大动作 3>。`
- 触发:现状/背景段
- 示例:`在短视频称霸内容市场、品牌与个人创作者对视频内容需求爆发式增长的当下,AI视频生成技术早已摆脱早期"画质粗糙、内容生硬"的标签,迈入高质量、高可控、全流程自动化、可商用落地的成熟阶段`

**禁忌**:
- 不要 `在这个 AI 飞速发展的时代...`
- 不要 `今天我们来聊聊...`
- 不要 `作为一名 XX,从我自己的观察来看...`

## 三、提纲/承诺式变体(指纹 2)

### 模板
```markdown
👉 手把手带你:

✅ 从零入门 → ✅ 精通实操 → ✅ 提升审美 → ✅ 打造 <终极目标>
```

### 阶段命名常用词
- 入门阶段:从零入门 / 零基础起步 / 快速上手
- 实操阶段:精通实操 / 深度操作 / 高级技巧
- 审美阶段:提升审美 / 培养品味 / 拓展视野
- 终极阶段:打造 X / 创作出 X / 做出 X

|------|-------|

| 劣势 / 负面 / 不推荐 | ❌ |
| 目标 / 场景 / 适合 | 🎯 |
| 关键点 / 重点 | 📌 |

- 2500-3500 字文章:15-25 个 emoji

- 重点段(机制表、收尾)可以用 2-3 个

## 四、三形态对照表(指纹 4)

### 模板(三种模式各一段)
```markdown
#### （N） <模式名>:<一句话定位>

- ✅ **优势**:<优势 1, 具体细节>
- ❌ **劣势**:<劣势 1, 具体细节>
- 🎯 **适用场景**:
    - <场景 1>
    - <场景 2>
    - <场景 3>

<平台受益:**
- <提升 X>
- <提升 Y>

> 🛠️ <实操建议>:<一句话>

🚀 **案例示范**:

> <quote/derived quote,10-30 字>

> 🌟 **秘诀**:<一句话核心心法>
```

### 模式命名常用词
- 模式 A(基础):文生视频 / 入门版 / 标准版 / 零基础版
- 模式 B(进阶):图生视频 / 进阶版 / 增强版
- 模式 C(最推荐):图+文混合 / 高级版 / 专业版 / 最推荐版

### 三形态顺序的逻辑
- "从最简单到最复杂" → 入门 / 标准 / 高级
- "从最有缺陷到最强" → 标准 / 增强 / 旗舰
- "从最广泛到最精细" → 通用 / 专用 / 定制

## 五、万能公式 + 低效 vs 高效(指纹 5)

### 公式骨架模板
```cobol
【要素 1】 + 【要素 2】 + 【要素 3】 + 【要素 4】 + 【要素 5】 + 【要素 6】 + 【要素 7】
```

### 公式项数量建议
- 5-7 个为佳(过少失"万能"感,过多记不住)
- 9 个勉强,11 个以上放弃

### 对比演示模板
```markdown
> ❌ 低效提示:"<简单到不行的常见错误>"
>
> ✅ 高效提示:"<加满公式要素的标准答案>"
```

### 低效示例选择规则
- 用领域内"最常见/最易写"的简单句子
- 不能"刻意编一个不像样的句子" — 必须是真实常见的

### 高效示例选择规则
- 加满公式所有要素(展示公式的力量)
- 不要堆砌无关要素(避免被读成"展示越多越好")

### 关键点解析
- 逐项对应公式要素
- 每项 1 行,讲"为什么这个要素重要"
- 末尾 "> 效果:" → 断言效果

## 六、"N 个技巧"表(指纹 6)

### 模板
```markdown

|------|------|------|
| 1. <动词> "<对象>" | <示例词条 1> / <示例词条 2> / <示例词条 3> | <效果断言> |
| 2. <动词> "<对象>" | <示例词条> | <效果断言> |
| ... | ... | ... |
| N. <动词> "<对象>" | <示例词条> | <效果断言> |

> 📌 **进阶建议**:
> - <建议 1:具体可操作>
```

### 技巧命名常用动词

### 技巧数选择
- 7-9 个为佳
- 5 个勉强,11 个以上读者会跳读

## 七、"X vs Y"对比表(指纹 7)

### 模板
```markdown
> ✨ **对比 <方式>**:
>
> | 维度 | <旧方式> | <新方式> |
> |------|----------|----------|
> | <维度 1> | <旧值> | <新值> |
> | <维度 2> | <旧值> | <新值> |
> | <维度 3> | <旧值> | <新值> |
> | <维度 4> | <旧值> | <新值> |
>
> > 💡 **结论**:<一句话核心断言>
```

### 维度命名建议
- 简短:"成本""时间""技能要求""可复用性""稳定性""质量"
- 不要超过 6 个维度(读者读起来累)

## 九、翻车避坑表(指纹 9)

### 模板
```markdown
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| <症状 1> | <原因 1> | <具体可操作> |
| <症状 2> | <原因 2> | <具体可操作> |
| ... | ... | ... |
| <症状 N> | <原因 N> | <具体可操作> |

> ✅ **终极提醒**:<一句话心法>
```

### 问题列选择规则
- 用"读者先遇症状描述的"表述
- 必须是真实常见的翻车(不要虚构场景)

### 解决方案列规则
- 必须给"具体可操作动作"
- 不要"注意细节""仔细检查"这种无信息量的话

## 十、"创作平权时代"收尾诗(指纹 10)

### 模板
```markdown
我们正站在一个前所未有的 <X> 时代:
- 不需要 <门槛 1>
- 不需要 <门槛 2>
- 不需要 <门槛 3>
- 只需要 <核心条件>

而 **<X 工具>**, 正是这个时代最 <锋利> 的 <创作武器>。

> 从今天开始,不再等待 "<借口>"
>
> 用 <N 1>, <动词 1> 一个 <对象 1>;
>
> 用 <N 2>, <动词 2> 一段 <对象 2>;
>
> 用 <N 3>, <动词 3> 一场 <对象 3>。
```

### 三行诗的常见句式
- `用一句提示词,点燃一个故事;`
- `用一个分镜,讲述一段人生;`
- `用一分钟,创造一场感动。`

### 三行诗的要素
- **动词各不相同**:点燃 / 讲述 / 创造(不是重复动词)
- **对象有重量**:故事 / 人生 / 感动(不是"内容""视频"这种空泛词)
- **量词押节奏**:一句 / 一个 / 一分钟 / 一段 / 一场

### 邀请段
```markdown
---

📌 **作者注**:<一句话署名 + 出处>
📅 发布时间:<YYYY 年 M 月 D 日>
🔖 标签:#标签 1 #标签 2 ... #标签 N

---

✅ **如果你喜欢这篇文章,欢迎点赞、收藏、转发,让更多人看见 <领域> 的无限可能!**
```

## 十一、过渡句(节与节之间)

### 顺承过渡
- `> 💡 **结论**:<一句话总结>`
- `接下来,我们进入 <下一节主题>。`
- `<前节总结>, <后节引子>。`

### 引出下一个工具/平台
- `了解了 <A>, 我们再看看 <B>。`

### 中段过渡
- `本篇文章的三步走机制:`(引出三步走)
- `> ✨ **对比传统制作**:`(引出对比表)

## 十二、口语化但不滑头的口吻

### 可用
- "撕掉"(形容去除)
- "搭车"(形容附带)
- "扎心"(形容数字很残酷)
- "搭把手"(形容协助)
- "铺路"(形容准备)

### ⚠️ 慎用
- 段子手梗("一整个""破防了""yyds")— 配不上"教程 + 升格"风格
- 过度感叹号 — 3 个以上一段就显得用力过猛

### 不用
- "在这个大模型时代"
- "作为 AI 时代的 XX"
- "让我们一起..."

## 十三、原文金句(可直接迁移的中心论点)

写新文时如果一时想不出金句,可以参考 2026.md 的金句结构:

> **技术决定你能做什么,审美决定你做成什么样。**

迁移公式:`<X> 决定 <能力 1>, <Y> 决定 <能力 2>。`

示例衍生:
- 工具决定你能跑多快,流程决定你能跑多远。
- 模型决定你能生成什么,提示词决定你生成什么样。

## 十四、平台绑定中的"软广"风险规避

本风格自带"以 X 工具为载体"的软绑定 — 写中性教程时务必:

1. **横向对比段必做**:用 X vs Y 对比表 + "五条/N 条死线"展示中立性
2. **不要全篇只夸 X**:必须有 1-2 个"X 也有弱点"的提示
3. **结尾邀请不要"假大空"**:点赞/收藏/转发是真邀请,不要写成"立即购买"

> 违规示例:全篇只夸 X,无任何对比或局限提示 → 沦为软文
> 合规示例:本篇以 X 为载体,同时给 Y/Z 客观评分 + "五条死线"判据
