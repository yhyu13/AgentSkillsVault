# 第 1 课的演示数字

这些数字只描述 MegaDev 第 1 课那一次采样和那一次 harness。换模型、换采样参数、换工具目录，数字就变。排查别的系统时，把这些格子留空，写“未采样”或“未计数”。

| 观察 | 那一次的值 | 不要写成 |
|---|---|---|
| “只要代码”的第一候选 | certainly，约 66% | 所有模型都会先说客套话 |
| 后两个候选 | sure 与三个反引号，各约 14% | 代码标记永远是 14% |
| 随机数 | 8 约 20%，7 约 18%，9 约 16% | 模型的随机等于这个分布 |
| 偶数判断 | `isEven(7)` 被写成 true | 模型总是算错奇偶 |
| 一句 hi | 工具搜索开着时约 21,000 token | 短消息通常是这个长度 |
| 循环上限 | 那份演示代码是 40 步 | 智能体都应该跑 40 步 |

讲师说步数大概比“回合”更合适，但在那个例子里差别不大。不要把这句话改成“步数永远比回合准确”。
