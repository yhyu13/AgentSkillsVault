# 用验证建立信任

来源：BV1hEaN67EkV，英文对谈 3048 秒。讲者是 Cursor 工程师 Lauren Tan，上传者 TsingWong。公开流 480p。数字都是讲者自述：加入约五个月，某月 1000 个 PR，当月 12 日时接近 800 个。这些不是代码质量统计。

她把信任放在验证，不放在把每一步写细：

- Agent 要能按用户真正使用的方式运行：跑代码、看 CPU trace、堆快照或打开模拟器。验证不保证写得好，只让它先写得对。
- 她从自己观察到的失败做 Skill。Agent 自信下结论，却没有读受影响的代码，这次信任就断了。对应的 Skill 是：停止猜测，先搜索并读代码。
- 验证材料要能维护。功能地图写清怎么到达、快捷键和选择用的 DOM 属性，并有一份负责更新它的 Skill。
- 评测像 Agent 的单元测试。改一份 Skill 后重跑。她的做法是协调者先写评分标准，再开多个子代理；目录名不要让被测代理知道自己在被评，因为知道后行为会变。
- Cursor 里可以跨模型评。没有统一框架，评测的严格程度由人定。维护 Skill 需要观察和判断，不容易。

PStack 是她按自己工程习惯做的插件，名字拿 Y Combinator 的 Gary Tan 的 GStack 开玩笑。她说两人没有亲戚关系。
