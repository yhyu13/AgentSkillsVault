## Was Distilly macht

Distilly macht aus Quellmaterial (Nachrichten, Dokumente, Interviews, öffentliche Quellen) und deiner Beschreibung ein quellenbasiertes Person Profile und verpackt es als Agent Skill.

- Drei Personentypen: **colleague** (Kollegen, Mentoren), **relationship** (Partner, Familie, Freunde) und **celebrity** (öffentliche Personen, fiktive Figuren).
- Läuft in acht Agent-Hosts: Claude Code, Hermes Agent, OpenClaw, Codex, DeepSeek Harness, Pi coding agent, Grok Build und OpenCode.
- Quellen: Lark, DingTalk, Slack, WeChat, öffentliche X-Posts, PDF, E-Mail, Markdown.

## Installation

Sende in einem unterstützten Agent-Host:

> Installiere Distilly von `https://github.com/titanwings/distilly` und prüfe, ob dieser Host es findet.

Oder klone es selbst in das Skills-Verzeichnis deines Hosts:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## Nutzung

Sage deinem Agenten: *„Erstelle mit Distilly ein Person Profile für `<Person>`.“* Für dein eigenes Profil: *„Richte mit Distilly mein Profil ein.“*
