## Что делает Distilly

Distilly превращает исходные материалы (сообщения, документы, интервью, открытые источники) и ваше описание в Person Profile, основанный на источниках, и упаковывает его как Agent Skill.

- Три типа людей: **colleague** (коллеги, наставники), **relationship** (партнёры, семья, друзья) и **celebrity** (публичные персоны, вымышленные персонажи).
- Работает в восьми агентных хостах: Claude Code, Hermes Agent, OpenClaw, Codex, DeepSeek Harness, Pi coding agent, Grok Build и OpenCode.
- Источники: Lark, DingTalk, Slack, WeChat, публичные посты X, PDF, почта, Markdown.

## Установка

В любом поддерживаемом агентном хосте отправьте:

> Установи Distilly из `https://github.com/titanwings/distilly` и проверь, что этот хост его видит.

Или клонируйте сами в каталог Skills вашего хоста:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## Использование

Скажите агенту: *«Создай с помощью Distilly Person Profile для `<человек>`.»* Для собственного профиля: *«Настрой мой профиль с помощью Distilly.»*
