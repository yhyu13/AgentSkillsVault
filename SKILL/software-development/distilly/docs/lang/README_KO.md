## Distilly가 하는 일

Distilly는 원자료(메시지, 문서, 인터뷰, 공개 자료)와 사용자의 설명을 근거 기반 Person Profile로 만들고, 이를 Agent Skill로 패키징합니다.

- 세 가지 인물 유형: **colleague**(동료, 멘토), **relationship**(연인, 가족, 친구), **celebrity**(공인, 가상 인물).
- 8개 에이전트 호스트에서 동작합니다: Claude Code, Hermes Agent, OpenClaw, Codex, DeepSeek Harness, Pi coding agent, Grok Build, OpenCode.
- 데이터 소스: Lark, DingTalk, Slack, WeChat, 공개 X 게시물, PDF, 이메일, Markdown.

## 설치

지원되는 에이전트 호스트에서 다음을 보내세요:

> `https://github.com/titanwings/distilly`에서 Distilly를 설치하고 이 호스트가 인식하는지 확인해 줘.

또는 호스트의 Skills 디렉터리에 직접 클론하세요:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## 사용법

에이전트에게 이렇게 말하세요: *"Distilly로 `<인물>`의 Person Profile을 만들어 줘."* 내 프로필은: *"Distilly로 내 프로필을 설정해 줘."*
