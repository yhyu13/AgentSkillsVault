## Qué hace Distilly

Distilly convierte material de origen (mensajes, documentos, entrevistas, fuentes públicas) y tu descripción en un Person Profile basado en fuentes, y lo empaqueta como Agent Skill.

- Tres tipos de persona: **colleague** (compañeros, mentores), **relationship** (pareja, familia, amigos) y **celebrity** (figuras públicas, personajes de ficción).
- Funciona en ocho hosts de agentes: Claude Code, Hermes Agent, OpenClaw, Codex, DeepSeek Harness, Pi coding agent, Grok Build y OpenCode.
- Fuentes: Lark, DingTalk, Slack, WeChat, publicaciones públicas de X, PDF, correo, Markdown.

## Instalación

En cualquier host de agentes compatible, envía:

> Instala Distilly desde `https://github.com/titanwings/distilly` y comprueba que este host lo detecta.

O clónalo tú mismo en el directorio de Skills de tu host:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## Uso

Dile a tu agente: *«Usa Distilly para crear un Person Profile de `<persona>`.»* Para tu propio perfil: *«Usa Distilly para configurar mi perfil.»*
