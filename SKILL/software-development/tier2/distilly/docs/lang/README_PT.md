## O que o Distilly faz

O Distilly transforma material de origem (mensagens, documentos, entrevistas, fontes públicas) e a sua descrição em um Person Profile baseado em fontes, e o empacota como Agent Skill.

- Três tipos de pessoa: **colleague** (colegas, mentores), **relationship** (parceiros, família, amigos) e **celebrity** (figuras públicas, personagens de ficção).
- Funciona em oito hosts de agentes: Claude Code, Hermes Agent, OpenClaw, Codex, DeepSeek Harness, Pi coding agent, Grok Build e OpenCode.
- Fontes: Lark, DingTalk, Slack, WeChat, posts públicos do X, PDF, e-mail, Markdown.

## Instalação

Em qualquer host de agentes compatível, envie:

> Instale o Distilly a partir de `https://github.com/titanwings/distilly` e verifique se este host o encontra.

Ou clone você mesmo no diretório de Skills do seu host:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## Uso

Diga ao seu agente: *"Use o Distilly para criar um Person Profile de `<pessoa>`."* Para o seu próprio perfil: *"Use o Distilly para configurar meu perfil."*
