# 质检门 G1–G5

五个门，每个门只给三种结论：**通过** / **需修复**（写明改什么） / **无法验证**（写明缺什么）。不许含糊成"基本没问题"。

## G1 结构（AST 是否还在）

- 每页都能对回 `ast_outline.md` 的某条状态变化。
- 页面顺序构成一条推进线，不出现"讲完又回到讲什么"。
- 标题是人话，不是"XX 概述 / 关于 XX 的思考"这类 AI 总结腔。
- 判定口径：随便抽 3 页，如果其中任一一页说不出"听众此刻被推动到哪里"，G1 不通过。

## G2 内容人感

- 页面上的字是"给人念的"，不是"给模型看的"：有具体名词、具体数字、具体场景。
- 不使用"赋能 / 抓手 / 闭环生态"这类空转词作为主要动词。
- 复杂概念有类比或例子，而不是堆术语。
- 检查方法：把每页正文朗读一遍，卡壳的地方就是要改的地方。

## G3 页面可用

- HTML 主文件本地双击能开，无控制台致命报错。
- 无文字溢出容器、无重叠、无 `undefined`、无 `[必填]`、无空 `src=""`。
- 所有资源为相对路径，无盘符、无 `file:///` 硬编码。
- 长页有分页或滚动策略，不靠缩小字号硬塞。

## G4 演讲与视频

- presenter 入口能打开，当前页/下一页可用，逐字稿在页面里能读到。
- `video_slots.json` 每个 slot 有 mp4、poster 或明确降级说明。
- 计时器行为说明清楚（从哪开始计、如何重置）。

## G5 交付可复制

- `DELIVERY.md` 列出：主入口、备选入口、资源目录、presenter 入口、视频、部署命令、PDF 命令、已知限制。
- 把 `deck/` 整个目录拷到另一个路径，主文件仍能打开（验证没有绝对路径）。
- 用 `python scripts/validate_pack.py --deck deck --stage delivery` 复跑一次，退出码 0。

## 机器能查 vs 只能人查

| 项 | 谁查 |
|---|---|
| 文件齐备、JSON 可解析、断链、占位符、绝对路径 | `scripts/validate_pack.py` |
| 状态变化是否成立、文案是否人话、视觉是否溢出 | 主理人 + 截图目视 |

机器过了但人查不过，仍然不交付。反过来，人觉得好但脚本报警，先修脚本报的项，因为那些是分发时会真的坏掉的地方。
