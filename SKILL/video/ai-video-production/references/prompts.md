# 提示词模板（来源：余弦博客 2026-09-27 整理 + 评论区补充）

## 一句话就能跑（概念短片）

```
给我做一个抽代但不局限于抽代的宣传片 几分钟 视频要丰富 不要那么抽象 主要是展示抽代的美 视觉表现要丰富有冲击力 你懂我意思不
```

```
Make a dynamic 15-second motion graphics video that shows what an incredible
motion designer you are, like it's your showreel for a résumé. go all out.
```

极简版（effort 拉满）：

```
make an extremely visually impressive video, go all out
```

## 产品宣传片（结构可直接抄）

```
Make a dynamic 15-second motion graphics video that shows what an incredible
motion designer you are, like it's your showreel for a résumé. go all out.

Make it a video to introduce http://typingmind.com

Use actual product screenshot/logo/assets
Must have music and motion must match the music

Do it like a real professional production video, not like a demo or prototype.
```

## 换个受众重新讲

```
make the same message much more interesting to a social media audience
that loves anime and quick clips and compressed learning
```

## 让它当导演（接视频模型出镜头）

```
make a high-end netflix style documentary about superintelligence for normies
```

## 改片时的镜头语言（关键）

```
slow every zoom to 0.7x
hard cut here
push in on the button
```

中文同样有效：「这里硬切」「推近到按钮」「缓动再慢一点」「这一幕多停一会儿再转场」。

## 不只是视频：画 App Icon

```
帮我为 http://BaoCut.app 重新设计一个 App Icon，简单一点，彩色的，体现视频编辑、AI Agent
可以直接用 js 绘制 canvas
```

要点：让它用 JS 画 Canvas，不要写 SVG；然后像甲方一样挑方案逐轮改，几轮定稿。

## 自用起手式（推荐模板）

```
给我做一个 <主题> 的 <时长> 视频，给 <谁> 看。
视觉要丰富、有冲击力，像专业团队做的正式作品，别做成 demo 或者网页录屏。
要有配乐，动作跟音乐卡点。
素材用 <真实截图 / logo / 官网链接 / 文档>，别编界面也别编事实。
参考风格：<参考片链接>
先给我 3 个分镜方向，每个场景一张静帧，我选完你再做动画。
```

短片：删掉最后一行，直接放它去做。
