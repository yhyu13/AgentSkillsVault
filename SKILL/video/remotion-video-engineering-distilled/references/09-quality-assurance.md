# 独立质量验收

> 专业整理：渲染质量验收工程师。依据 Remotion `4.0.532` 本地资料。本次未运行渲染、媒体探测或上游源码复核；本页是验收方法，不是成片合格证明。

**核心方法：冻结输入与环境，按同一帧号取证，区分解码像素、编码包字节和文件字节的一致性。**

## 1. 适用与不适用

- 适用：合成与模板改造、渲染故障定位、修复前后对照、视频交付检查。
- 不适用：仅凭文档证明具体成片合格、线上稳定性或授权合规；预览正常不能替代导出验收。
- 输入：合成 ID、props、fps、durationInFrames、素材/字幕清单、编码目标、验收容差、环境记录及待验产物。
- 输出：判定、命令与日志、帧号及同步证据、缺陷复现步骤、未覆盖面。没有产物时只设计实验，不填造结果。

## 2. 七步验收流程

1. **冻结条件**：记录依赖锁定、OS、浏览器、GL、FFmpeg、字体及资源哈希；固定随机种子与时钟，冻结外部输入。排查帧外时钟、并发竞态、网络变化和字体回退。
2. **约定门槛**：令 N＝durationInFrames，预期帧号为 0…N−1；预先确定 codec、像素格式、色彩/位深、alpha、CRF/码率、体积预算，以及时长、同步和字幕容差。
3. **建立基线**：纯色、单帧、无媒体的最小合成先跑两次，再逐项加入动画、素材和字幕。修复复验先重现旧问题，每轮只改变一个因素。
4. **双渲染比对**：同环境、同输入、同参数和同并发得到 A/B；固定解码条件与像素格式，比较帧序列并定位差异帧。跨编码输出不宜直接逐像素判等。
5. **核对时间与同步**：检查解码帧数、帧率、时间戳、首尾帧及字幕出入点。恒定帧率下使用 **N / fps ≈ 时长秒 T**；原资料 `duration / fps == durationInFrames` 写反。浮点容差需约定，时长达标不能替代帧数检查。
6. **检查画面与编码**：核对首尾帧、转场、字幕关键帧、字体完成加载、delayRender/continueRender 配对；查看文字溢出、重叠、色带及透明通道。结合编码设置、日志和探测结果检查交付参数与体积。分片另做整片/合并片对照，专查边界丢帧、重帧及音画接缝。
7. **归档与复验**：保存命令、参数、退出码、日志、探测 JSON、哈希、差异帧及同步证据。修复后重复原实验并检查原缺陷是否消失；“一次运行没报错”不能证明修复。

## 3. 一致性的三个层级

| 层级 | 方法 | 不能据此推断 |
|---|---|---|
| 解码像素 | 比较逐帧哈希及帧序 | 不代表时间戳、音频或编码字节正确 |
| 编码包字节 | 视频流不解码复制后计算哈希 | 不代表容器字节、全部元数据和时间轴一致 |
| 文件字节 | 比较整个文件哈希 | 文件不同不等于画面不同 |

**AAC priming 独立取证**：结合预期事件帧、解码音频采样、时间戳和已知起音点素材检查偏移；不能只看 start_time 或音轨总长。资料提及的 `aac-priming.ts` 缺完整路径，其补偿机制本次未能确认；“1 帧”不得泛化为通用标准。视频哈希相同不能证明音画同步正确。

## 4. 复验命令骨架

以下命令用于说明取证方式，假定本机有相应版本的 FFmpeg/ffprobe 且 A/B 已存在；**本次未执行**。

```bash
ffmpeg -v error -i A.mp4 -map 0:v:0 -an -f framemd5 -
ffmpeg -v error -i A.mp4 -map 0:v:0 -c copy -f hash -
ffprobe -v error -count_frames -show_streams -show_format -of json A.mp4
```

B 同样执行；保存完整 stdout/stderr 与退出码。记录 FFmpeg 版本、哈希算法和解码参数，不能跨算法/环境直接比较摘要。

## 5. 判定规则

- **通过**：约定范围内证据齐全且全部达标，无阻断缺陷；结论必须标明已验证范围。
- **不通过**：已有证据证明违反门槛，例如少帧、字幕时段错误或编码不兼容。
- **证据不足**：只有成功日志、单次渲染、缺关键产物，或测试被跳过。跳过不算通过；文档审核通过不等于成片通过。

## 6. 故障分诊与检查清单

以下是候选环节，不是已确认根因。

| 报错/现象 | 候选环节 | 验证动作 |
|---|---|---|
| target closed | 浏览器/帧捕获 | 最小合成对照，查退出、资源及沙箱日志 |
| 帧齐但编码失败 | 编码/封装 | 保留中间帧，仅改变 codec 或像素格式复验 |
| 字体未加载、文字跳动 | 资源就绪 | 核对字体文件与加载前后帧，排查回退 |
| undecodable | 媒体解码 | 同管线替换已知可解码素材，核对支持情况 |
| out of memory | 浏览器或编码 | 分别对照并发与素材尺寸，记录内存及完成帧号 |
| timeout、delayRender 未完成 | 帧等待 | 对齐帧号、等待句柄及异步资源完成记录 |

最小清单：环境固定 → A/B 可复现 → 帧数/时长 → 首尾/转场 → 音画/字幕 → 字体/等待结束 → 编码/体积 → 分片边界。

**假设示例，非本次观察**：30fps、N＝90 应有 90 帧、约 3 秒；若仅 89 帧则不通过，即使容器时长仍为 3 秒。两次都少一帧也不能放行。

## 7. 文档与技能的验收边界

对技能资料本身，独立核对领域覆盖、来源可追溯、参数矛盾、公式、示例有效性、相对引用、可移植性、是否包含占位内容及是否夸大“已验证”。结构校验通过只证明资料包的结构，不证明视频工程命令已运行或项目已适配。
