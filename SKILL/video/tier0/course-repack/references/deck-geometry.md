# 版面几何

所有坐标写在一个 `layout.json` 里，单位是**设计像素**：画布 1920×1080。
视频按 1280×720 输出（等比 0.667），PPTX 是 13.333×7.5 英寸。三者靠两条换算绑定：

```
1 in = 144 px        1 px = 0.5 pt
1920 px = 13.333 in = 960 pt
```

## 为什么不用「目测字号」

同一句话在 HTML 里用 CSS 字号、在 PPT 里用磅值，两条渲染路径的行高和字宽都不一样。
实测差异在 4% 左右，长行上就是「视频里刚好，PPT 里出框」。

规矩只有一条：**一个字号只写一次**。`layout.json` 给框和基准字号，`fit_text.py` 用真实
字体文件量出结果，写回 `content.json` 的 `sizes`，视频渲染器和 PPTX 生成器都读这个值。

颜色和字体同理，事实源是 `design.json`：PPTX 直接读，视频在渲染时把 `colors`/`fonts`
注入 `templates/scene/template.html` 的 `:root`。只改一处，两边一起变。

## 八种页型

| 页型 | 底色 | 用途 | 关键约束 |
|---|---|---|---|
| `cover` | 深 | 每集开场：模块名 + 主张 + 支撑句 | 主标题最多两行，作者署名放页脚 |
| `chapter` | 深 | 模块边界，左侧大号数字 | 数字用 Arial，字号 ≥ 130 px，占一列宽 |
| `hero` | 深 | 一个数字/一个大判断 | `hero.value` 要在一行内放下：`fit_text.py` 给的行数必须是 1，否则先改文案或降字号 |
| `steps` | 浅 | 2–6 步的方法 | 两行是上限（`rows2` 卡片高度）；超过 6 步拆页，不要缩小 |
| `conclusion` | 浅 | 有对照的结论 | 数字与支撑句二选一占主位，不要都放 |
| `try` | 浅 | 一个可执行动作/反问 | 单独一页，不加第二个动作 |
| `review` | 浅 | 逐条对照或回看 | 每行一条，行高固定，不用自动换行 |
| `takeaway` | 深 | 每集收束 | 一段话，不分条，不加标签 |

深色页用于「停下来想一下」的位置：开场、转场、大数字、收尾。浅色页用于信息密度高的页。
一集里深浅交替出现，观众才有呼吸节奏。

## 框与地板

- 内容列宽 1318 px，左边距 108 px，右边留给图形元素或留白。
- 正文字号地板 36 px（=18 pt）。低于地板不是「小一号」，是这页该拆。
- `hero` 有自己的地板：1080 短边的 12%，即 130 px。数字可以到 300 px。
- `lh`（行高倍数）PPT 侧用 `spcPts`、HTML 侧用 `line-height`，都读同一个值。
- 正文行高不要小于 1.14。中文的上下伸部比拉丁字母高，1.0 会切字。纯数字的章节号
  （`chapter.id`）例外，它只有一个数字，用 1.0 让数字贴齐。

## 收缩算法

```
在 [min, base] 里二分：
  按宽度贪心断行（逐字符测 advance width，不按字符数估算）
  块高 = 行数 × 字号 × lh / SAFETY
  若最长行 ≤ 框宽 且 块高 ≤ 框高 -> 可行，继续试更大
返回最大的可行字号；若 min 仍不可行，返回 min 并标 overflow=True
```

`SAFETY = 1.04` 是 PowerPoint 与 PIL 的度量漂移补偿。没有它，PPT 侧会稳定溢出 2–4%。

`fit_text.py` 的 `--face mixed` 会按字符在 Arial 与雅黑之间切换。纯中文页面用 `cjk`，
纯数字页（章节号、大数字）用 `num`，中英混排的标题用 `mixed`。

## PPTX 侧的三条实测坑

1. **生成成功 ≠ 版面正确**。必须用 PowerPoint COM 打开，读每个 shape 的
   `Left/Top/Width/Height`，和 `layout.json` 对照。只看 XML 看不到 PowerPoint 的自动调整。
2. **字体缺失会静默替换**。`Microsoft YaHei` 不在目标机器上时，PPT 会换成宋体，
   行宽变窄、行数变多，然后溢出。交付前在目标机器上打开一页确认字体名。
3. **行距是磅值不是倍数**。`pt = px × 0.5 × lh`，四舍五入到 0.5 磅。写 1.14 倍会在
   PowerPoint 里变成 1.2，最后一行被压出框。

## 图形元素

右侧的节点-连线装饰是为了让「人脉/网络」有视觉落点，不是必需品。规则：

- 装饰不得进入内容列（x < 1426 px），不得压在任何文字上。
- 节点圆直径 18–46 px，连线 1 px，颜色只用主题里的两个中性色加一个强调色。
- 每页同一套节点坐标，只换亮暗配色。跨页跳动会让整集显得廉价。
