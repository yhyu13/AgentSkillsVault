# 画布渲染

2026-11-14，这台机器的 Playwright 页面截图重复返回同一张浅色图，但画布像素是正确的。因此本技能使用画布导出。换机器时先比较三张不同时间的页面截图；如果截图正常，仍可使用同一套 `renderAt(t)`，只替换导出方式。

`renderAt(t)` 仍是唯一画面函数。它每次清空画布，不能保存上一帧状态，也不能用随机数。字体和页面准备完成后设置 `window.__ready = true`，渲染脚本才会开始。预览和导出调用同一个函数。

每个语音段至少有一个由 `t` 驱动的变化：长度、位置、透明度或依次出现。只有标题和段落文字不算变化。

渲染后运行 `check_frames.py <frames-dir>`。它抽五帧，拒绝墨迹过少的空白帧，也拒绝首尾几乎相同的静止成片。

确认 MP4 可播放后删除 `reel/frames`。1920×1080 PNG 每帧约 100–160KB，全片约 1GB。
