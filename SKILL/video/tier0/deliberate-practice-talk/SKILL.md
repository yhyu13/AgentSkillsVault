# 把变强方法讲成可核对的结论

这份 Skill 把一次讲解变成三件东西：中文总结、不超过 16 页的课件、1920×1080 口播 MP4。它保留的是方法，不是某一场讲座的结论。

## 为什么做

变强建议最容易在转写时被改顺。年份、人数、研究结论和讲者经历混在一起后，听起来像事实，实际上可能只是转写错误。这份 Skill 要让每句口播都能回到原片时间。

## 先选来源

英文原片用 faster-whisper small.en，一次只转写一段不超过 115 秒的音频。中文原片没有可靠逐字稿时停止。公开接口返回多个分集时，先读分集标题，不默认第一集就是原声。

没有 DASH 视频流或音频流时停止。下载后记录实际宽高，不把公开接口的 480p 写成原片清晰度。

## 口径先于口播

写总结前先做口径表。每条结论只标一种：

- 讲者自述：第一人称经历。
- 讲者观察：他看到的群体现象。
- 讲者转述：他引用的研究或别人的说法。
- 讲者估计：他说“大约”“多数人”但没有给出测量。
- 转写不确定：句子断裂、专名不像原词，或语义和上下文冲突。

转写不确定的句子不改写成确定事实。研究没有作者时，只说“讲者转述一项研究”，不补作者。

## 口播只压缩，不新增

保留主张、例子、限制和步骤，删掉重复。每段 40 到 90 个汉字。数字必须能在逐字稿里找到；敏感说法必须在同一句标出口径。

语音用 edge-tts 的 zh-CN-YunyangNeural，不改速度。实测字速要落在 4.7 到 6.0 字/秒。超出就改句子，不加速。

## 画面和课件

画面由当前时间决定。每个语音段要有长度、位移、透明度或依次出现中的一种变化。标点不能出现在新行行首。

课件不超过 16 页。每页备注写原片时间和口径。页图要能读出标题、正文和页脚，不能靠缩小字号掩盖溢出。

## 验收

`scripts/check_talk.py` 检查四项：逐字稿存在，口径表有五类口径，口播数字能回到逐字稿，成片音视频参数与时间轴一致。

```bash
python scripts/check_talk.py <project>
```

退出码 0 只表示这四项在。退出码 1 会指出缺的文件、没有口径的句子，或成片参数不符。它不算完成，也不能证明总结忠实。

## 失败后怎么查

下载到的语言不对，先看分集，不换模型反复听。转写像拼音，确认模型是 small.en。口播数字检查失败，删掉该数字或改回原词。字速超出范围，删句子，不改语速。成片只有几 MB 且画面几乎不动，先查帧像素，再重新合成。

## 一次只补一个缺口

试跑失败时先分类。语言下错，改分集选择。数字无来源，改口播。字速超出，改句子。帧空白或静止，改画面函数。不要同时改口径和画面，否则看不出是哪一处生效。

人工复盘提出的修改先由人核对，再写入文件。不要把一次讲座的数字写进通用规则。

## 一个会失败的例子

把口播里的“约 20 支队伍”改成“约 21 支队伍”，再运行检查器。21 不在逐字稿里，检查器必须返回 1，并指出段落和数字。把空目录交给它，也必须返回 1。两次都返回 0，说明检查器没有真正读取项目。

正确项目返回 0 后，再抽三帧。开场应能读出讲者身份，中段应能看到进度条变长，结尾不应有行首标点。三帧里只要有一帧做不到，就不进入安装。

```bash
python scripts/check_talk.py <project>
```

```bash
python scripts/check_talk.py <empty-dir>
```

## 停止条件

遇到这些情况就停止扩展：

- 中文原片没有可靠逐字稿。
- 分集语言无法判断。
- 研究作者、样本和结果不能在逐字稿中同时找到。
- 检查通过，但抽看的帧仍有溢出、空白或行首标点。

退出码 0 不算完成。最后要抽看开场、中段和结尾三帧，并核对页图。

## 交付时写清楚限制

交付说明要分开写四件事：原片实际分辨率、口播实测字速、哪些句子是讲者自述或转述、哪些专名因为转写不确定而没有采用。不能用成片的 1920×1080 代替原片清晰度，也不能用检查器通过代替人工抽看。

如果一页课件或一帧口播在正常观看尺寸下读不清，就回到对应句子删短，不降低字号。若时间只够完成总结而没有成片，交付必须标明成片未完成，不能把口播稿说成 MP4。

## 相邻选择

只想下载原片或只要逐字稿时，不进入口播和课件。整门多集课程不放进这一份 Skill，因为它要先决定集数、字数和总时长。页面截图被证明重复时，改用画布像素导出，不继续相信截图文件的时间顺序。

中文原片没有可靠逐字稿时，不使用英文模型猜测。把拼音输出整理成中文，会把听错的句子变成看起来完整的事实。
