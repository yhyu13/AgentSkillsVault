# 课件版式

## 画幅与栅格

- 13.333 × 7.5 英寸（16:9）。PptxGenJS 里**必须** `defineLayout` 再 `layout = name`：只设 `p.width/p.height` 不会改幻灯片尺寸，页内坐标会按 10 英寸算，右边三分之一直接跑到画面外。
- 页边距 0.83 英寸。正文区左边界 0.83，右边界 12.5。
- 标题基线：kicker 0.5、标题 0.95、内容 2.2 起、页脚 7.0。标题最多两行，字号 34。
- 三栏用 3.85 英寸步长、3.55 英寸宽；两栏用 6.2 / 5.4。

## 字体与字号

| 用途 | 字体 | 字号 |
|---|---|---|
| 标题 | Microsoft YaHei Bold | 34（封面 60） |
| 正文 | Microsoft YaHei | 12–14 |
| 数字与命令 | Consolas | 10–22 |
| kicker / 页脚 | Consolas + 字距 | 9–10 |

中文正文小于 11pt 在投影上就吃力；英文命令可以到 9pt，因为它是对照用的。

## 配色

纸色 `F5EFE3`、次级纸色 `FBF7ED`、墨色 `14191C`、正文 `33393C`、灰 `6E6A61`、朱红 `C2402A`、松绿 `2C6B5A`、赭 `A87520`、分隔线 `C9BFAE`、终端底 `10161A`。

- 一个强调色贯穿全册。红色只给「问题 / 风险 / 值得试」，绿色只给「恢复 / 可用」，不要同一页里两种强调并存。
- 深色块只用于终端和「主角」卡，一页最多两块。
- 纸色系里不要用纯白 `FFFFFF` 做卡片，会显脏；用 `FBF7ED`。

## 每页只有一件事

标题就是结论（「服务端是唯一真身」），不是目录词（「架构介绍」）。一页一个判断，最多三行支撑。

常用页型：

1. **对照页**：三栏并列，中间那条用墨色，表示「这片子在讲这个」。
2. **嵌套页**：对象模型由外向内，每层左上角一个 mono 小标签。层与层之间留 0.5 英寸，否则标签会被下一层盖住。
3. **行表页**：三到五行，左侧色条表示结局（红 = 丢，绿 = 留），右侧 mono 状态词。
4. **命令页**：一个深色终端块，右侧三条注解，注解用 11–12pt。
5. **判据页**：三行「情况 → 结论」，选中的那行下面划一道强调色。

## 溢出

`render_pptx.py` 是近似渲染，字体度量比真 PowerPoint 宽约三成，所以它报溢出你要看，它不报也不能全信。两条经验：

- 标题宁可拆成两行用 `String.fromCharCode(10)`，也不要把 34pt 的中文塞满一行。
- 卡片里两行正文 + 一行 mono 注解是最稳的组合；四行以上就换页。

## 备注

每页备注写三样：原片时间区间、这条结论的证据、口径提醒。`check_deck.py --min-notes 0.8` 要求至少八成页面有备注。

## 验收顺序

```bash
python scripts/check_deck.py decks/x.pptx
python scripts/render_pptx.py decks/x.pptx --out decks/qa --sheet decks/qa/sheet.png
```

先看退出码，再看 sheet 缩略图找失衡的页，最后抽 3 页全尺寸看字号和对比。三者都过才算完成。
