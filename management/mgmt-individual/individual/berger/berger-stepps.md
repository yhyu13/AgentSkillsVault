# 乔纳·伯杰 · 疯传六原则STEPPS

> 不是运气，而是科学——产品/想法/行为之所以传播，是因为它们触发了社交货币、诱因、情绪、公共性、实用价值、故事这六个心理机制。

## 核心理念

伯杰要解决的根本问题是：**为什么有些产品、想法和行为会疯传，而另一些同样好的却默默无闻？**

传统观点认为疯传靠运气、靠网红、靠病毒视频，但伯杰通过十年研究发现：**疯传不是随机的，而是有规律的**。他分析了数千个病毒式传播案例，提炼出六个共同原则STEPPS——社交货币（Social Currency）、诱因（Triggers）、情绪（Emotion）、公共性（Public）、实用价值（Practical Value）、故事（Stories）。这六个原则的核心逻辑是：**人们分享不是因为内容好，而是因为分享让自己看起来好/让自己被想到/让自己感受强烈/让自己被看见/让自己有帮助/让自己会讲故事**。传播的动力不是内容质量，而是社交心理。

伯杰特别强调一个反直觉发现：**口碑传播的影响力是广告的10倍以上，但60%的口碑传播发生在线下而非线上**。社交媒体放大了传播的可见性，但并没有改变传播的底层心理机制。STEPPS既适用于线上也适用于线下，既适用于营销也适用于公共政策和社会运动。

## 关键模块

### 模块1：STEPPS全景

- 定义：STEPPS是六个驱动口碑传播的心理原则——社交货币、诱因、情绪、公共性、实用价值、故事；任何产品/想法/行为只要触发其中一个或多个原则，就更有可能被传播
- 输入：产品特性 + 传播目标 + 目标受众心理特征
- 输出：传播策略——选择激活哪些STEPPS原则以及如何激活
- 关键动作：
  - 社交货币（Social Currency）——人们分享让自己看起来聪明/有趣/酷的内容；如同社交货币，分享是"支付"自我形象的方式
  - 诱因（Triggers）——环境中的刺激触发对产品/想法的联想；诱因决定了产品是否在"顶部意识"（Top of Mind）
  - 情绪（Emotion）——高唤醒情绪（愤怒/敬畏/兴奋/焦虑）驱动分享，低唤醒情绪（悲伤/满足/抑郁）抑制分享
  - 公共性（Public）——可观察的行为更容易被模仿；如果别人看不到你在做什么，他们就无法模仿
  - 实用价值（Practical Value）——有用的信息被分享，因为分享有用信息让人感觉自己在帮助他人
  - 故事（Stories）——信息嵌入叙事更容易被传播和记忆；故事是信息的特洛伊木马
  - STEPPS不是全有或全无——触发1-2个原则就足以产生显著传播效果，触发越多传播力越强；但不需要六个都触发
- 常见误区：认为STEPPS是传播的充分条件——STEPPS增加传播概率但不保证疯传；只关注线上传播——60%的口碑传播发生在线下；把STEPPS当作营销工具——STEPPS是心理机制，适用于任何需要传播的场景

### 模块2：社交货币

- 定义：社交货币是人们通过分享来提升自我形象的心理机制——人们分享让自己看起来聪明/有趣/酷/内行的内容，就像用社交货币"购买"社交地位
- 输入：产品/品牌的内在社交属性 + 目标受众的自我呈现需求
- 输出：提升产品社交货币的策略
- 关键动作：
  - 内在诱因——找到产品中自然存在的"让人想炫耀"的特性；如秘密酒吧Please Don't Tell的隐藏入口、Google早期邀请制的稀缺性、航空公司精英会员的特权
  - 稀缺与专属性——稀缺和专属让拥有者感到特别，从而更愿意分享；限量版/邀请制/会员专属都是制造稀缺的方式；但稀缺必须是真实的而非人为制造的，虚假稀缺会被识破并产生反效果
  - 游戏化——将产品体验游戏化（积分/徽章/排行榜/进度条），让用户有"成就"可炫耀；Foursquare的市长徽章就是经典案例——用户签到不仅为了记录位置，更为了在朋友面前展示"我是这里的市长"
  - 为什么人们分享让自己看起来好的内容——社交分享的本质是自我呈现（Self-Presentation），人们通过分享来管理他人对自己的印象；分享有趣的内容让自己看起来有趣，分享有用的内容让自己看起来聪明，分享稀缺的内容让自己看起来有特权；理解这一点就能设计出"让人忍不住分享"的产品特性
- 常见误区：把社交货币等同于"炫富"——社交货币不只是炫耀物质，更是展示品味/知识/幽默感/独特性；过度设计社交货币——如果分享动机太明显，用户会觉得被操纵而非自愿分享；忽视产品本身的社交属性——不是所有产品都有天然社交货币，强行制造可能适得其反

### 模块3：诱因+情绪

- 定义：诱因是环境中触发产品联想的刺激（外在驱动），情绪是驱动分享的生理激活状态（内在驱动）；两者共同决定产品是否在"顶部意识"以及分享的冲动强度
- 输入：产品使用场景 + 目标受众日常环境 + 情绪唤醒点
- 输出：设计诱因策略 + 情绪触发策略
- 关键动作：
  - 高频vs低频诱因——诱因的效力取决于频率：高频诱因（每天遇到的刺激）比低频诱因（偶尔遇到的刺激）更有效；伯杰的经典案例：Wassup啤酒广告关联了"打招呼"这个高频诱因，而GEICO保险关联了"壁虎"这个低频诱因——啤酒广告更成功因为"打招呼"比"看到壁虎"更频繁
  - 诱因与场景绑定——将产品与特定场景/时间/活动绑定，让目标受众在特定场景中自然想到产品；如Kit Kat与"咖啡休息"绑定、M&M与"万圣节"绑定
  - 高唤醒vs低唤醒情绪——情绪按唤醒度（Arousal）分为高唤醒和低唤醒：高唤醒情绪（愤怒/敬畏/兴奋/焦虑/幽默）驱动行动（分享），低唤醒情绪（悲伤/满足/抑郁）抑制行动（让人想蜷缩而非分享）；这个发现解释了为什么愤怒的文章比悲伤的文章更容易被分享
  - 为什么愤怒比悲伤更易传播——愤怒是高唤醒情绪，激活"战斗"反应，驱动人们采取行动（分享/评论/转发）；悲伤是低唤醒情绪，激活"退缩"反应，让人想独处而非分享；同理，敬畏（看到壮丽风景/感人故事）是高唤醒情绪，所以也容易被分享
- 常见误区：只关注情绪效价（正面/负面）而忽视唤醒度——正面低唤醒情绪（满足/放松）不如负面高唤醒情绪（愤怒/焦虑）驱动分享；设计低频诱因——低频诱因虽然独特但效力不足，高频诱因虽然普通但更有效；忽视诱因的竞争——同一个诱因可能触发多个品牌联想，如果你的品牌不是第一联想，诱因效果会打折扣

### 模块4：公共性+实用价值

- 定义：公共性是行为的可观察性——可观察的行为更容易被模仿；实用价值是信息的有用性——有用的信息更容易被分享；两者共同驱动"因为别人在做/因为对别人有用"的传播
- 输入：产品使用行为的可见性 + 产品的实用信息含量
- 输出：提升行为可观察性的策略 + 突出实用价值的策略
- 关键动作：
  - 可观察性——如果别人能看到你在做什么，他们就更可能模仿；苹果的白色耳机让iPod用户在人群中一眼可辨，每个白色耳机都是一次免费广告；反例：很多SaaS产品是"看不见的使用"，用户在使用但别人看不到，这就失去了公共性的传播力
  - 行为残留——行为残留是行为结束后留下的可见痕迹；运动手环的步数排名、阅读App的年度书单、Spotify的年度歌单都是行为残留——使用行为结束了，但痕迹还在传播
  - 实用价值规则——人们按"折扣比例"而非"绝对金额"判断价值：同一件衣服从100降到75（25%折扣）比从1000降到975（2.5%折扣）更有吸引力，尽管后者省了更多钱；实用价值有阈值——折扣必须超过某个比例才有感知价值（通常>20%）
  - 为什么可见=可模仿——人类是社会性动物，行为学习主要靠观察模仿；如果看不到别人在做什么，就无法模仿；公共性将每个用户变成产品的活广告，这是最经济也最可信的传播方式
- 常见误区：认为线上分享就是公共性——线上分享是公共性的一种，但线下可见行为同样重要甚至更重要；忽视行为残留——一次性的可见行为传播力有限，行为残留才能持续传播；用绝对金额而非折扣比例设计促销——消费者心理按比例而非绝对值判断折扣

### 模块5：故事

- 定义：故事是信息的特洛伊木马——将产品/品牌信息嵌入叙事中，让信息在传播过程中不被丢弃；故事是最古老也最有效的信息传播方式
- 输入：核心传播信息 + 叙事框架 + 目标受众的文化背景
- 输出：嵌入核心信息的叙事
- 关键动作：
  - 特洛伊木马效应——好的故事像特洛伊木马：表面是引人入胜的叙事，内部是品牌/产品信息；听众在享受故事的同时不知不觉接收了信息；关键测试：如果把品牌/产品从故事中拿掉，故事是否还能讲？如果不能，说明信息与故事是融合的；如果能，说明信息只是故事的附属品，传播过程中会被丢弃
  - 故事承载信息——故事之所以比事实更易传播，是因为故事有叙事结构（开头/冲突/解决）、有情感共鸣、有记忆锚点；纯事实信息在传播中容易被简化/扭曲/丢失，但嵌入故事的信息在传播中更完整
  - 为什么故事比事实更易传播——认知心理学研究表明，叙事传输（Narrative Transportation）让人暂时放下批判性思维，沉浸在故事中；在沉浸状态下，信息绕过了"心理防线"直接进入记忆；相反，直接陈述事实会触发批判性评估——"这是真的吗？""这是广告吗？"
  - 故事设计原则——故事必须有内在价值（即使没有品牌信息也值得听）；品牌/产品必须是故事的关键元素而非可替换的赞助商；故事必须激发情感共鸣而非只是信息传递
- 常见误区：把品牌硬塞进故事——如果品牌在故事中只是"赞助商"角色，传播过程中品牌信息会被丢弃；只关注故事而忽视信息——好的营销故事不是"好故事+品牌露出"，而是"品牌信息与故事不可分割"；认为任何故事都能传播——故事必须有内在传播价值（社交货币/情绪/实用价值等），无聊的故事即使嵌入了品牌信息也不会被传播

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 传播力评估 | 如果产品/内容没有触发任何STEPPS原则→传播力弱，需要至少激活1-2个 | STEPPS全景 |
| 社交货币设计 | 如果产品没有天然稀缺性→考虑游戏化或邀请制制造社交货币 | 社交货币模块 |
| 诱因选择 | 如果诱因是低频的（偶尔遇到）→换高频诱因（每天遇到的刺激） | 高频vs低频诱因 |
| 情绪触发 | 如果想驱动分享→用高唤醒情绪（愤怒/敬畏/兴奋），避免低唤醒情绪（悲伤/满足） | 高唤醒vs低唤醒 |
| 行为可见性 | 如果产品使用行为不可见→设计行为残留（分享/排名/年度报告） | 公共性模块 |
| 促销设计 | 如果折扣比例<20%→消费者感知不到实用价值，提高折扣比例或降低原价 | 实用价值规则 |
| 故事设计 | 如果把品牌从故事中拿掉后故事还能讲→品牌信息会在传播中丢失，重新设计 | 特洛伊木马效应 |
| 线上vs线下 | 如果只关注线上传播→记住60%口碑传播在线下，线下传播同样重要 | STEPPS全景 |
| 传播渠道选择 | 如果产品使用场景在线下→线下行为可见性比线上分享更重要 | 公共性模块 |
| 情绪效价 | 如果认为正面情绪一定比负面情绪更易传播→错误，高唤醒负面情绪（愤怒）比低唤醒正面情绪（满足）更易传播 | 情绪模块 |

## 适用场景

### 最适合

- 消费品口碑营销——STEPPS直接指导如何设计产品的社交传播属性
- 内容营销——用STEPPS原则设计更容易传播的内容
- 社交媒体运营——理解传播心理机制，优化内容策略
- 新产品上市——在产品设计阶段就嵌入STEPPS原则，让产品自带传播力
- 公共政策传播——用故事和情绪让政策信息更易被理解和接受

### 不适合

- B2B复杂采购决策——B2B决策靠理性分析而非口碑传播，STEPPS的心理机制影响有限
- 高度专业化的技术产品——目标受众太小，口碑传播的乘数效应不足
- 需要精确信息传递的场景——故事传播可能导致信息简化/扭曲，不适合需要精确性的场景
- 强监管行业的广告——某些STEPPS策略（如利用情绪/制造稀缺）可能违反广告法规

## 实施检查清单

- [ ] 产品/内容是否触发了至少1-2个STEPPS原则
- [ ] 是否有社交货币——用户分享时是否让自己看起来好
- [ ] 是否绑定了高频诱因——目标受众在什么场景下会自然想到产品
- [ ] 是否触发了高唤醒情绪——内容是否让人愤怒/敬畏/兴奋而非悲伤/满足
- [ ] 产品使用行为是否可见——如果不可见，是否设计了行为残留
- [ ] 实用价值是否超过感知阈值——折扣比例是否>20%
- [ ] 故事中的品牌信息是否不可分割——拿掉品牌后故事是否还能讲
- [ ] 是否同时关注线上和线下传播——60%口碑传播在线下
- [ ] 是否测试了传播效果——用A/B测试验证STEPPS策略
- [ ] 传播内容是否真实——虚假的社交货币/情绪/故事会产生反效果

## 诚实边界

1. **STEPPS的因果强度不确定**：伯杰的研究主要是相关性研究——疯传的内容确实包含STEPPS元素，但包含STEPPS元素的内容不一定疯传。STEPPS是必要条件还是充分条件？是增加概率还是决定结果？目前的研究无法精确回答。STEPPS更像"增加传播概率的因素"而非"保证疯传的公式"。

2. **实验室vs真实世界的差距**：伯杰的很多实验在受控环境中进行，真实世界的传播受到算法推荐、社交网络结构、信息过载等多重因素影响。实验室中"愤怒比悲伤更易传播"的结论，在真实社交媒体中可能被平台算法、信息茧房、注意力稀缺等因素调制。

3. **文化差异的忽视**：STEPPS基于美国文化背景的研究，不同文化中社交货币、情绪表达、公共性行为的规范不同。在集体主义文化中，"让自己看起来好"的动机可能弱于"与群体保持一致"的动机。STEPPS的跨文化适用性需要更多验证。

4. **传播的伦理边界**：利用愤怒和焦虑驱动传播（高唤醒情绪策略）可能产生负面社会影响——愤怒驱动的传播可能加剧社会极化，焦虑驱动的传播可能制造不必要的恐慌。STEPPS是描述性理论，但应用时涉及价值判断。

5. **短期传播vs长期品牌**：STEPPS擅长设计"容易被传播"的内容，但"容易被传播"不等于"对品牌有益"。病毒式传播可能带来关注但损害品牌形象（如争议性内容），短期传播力与长期品牌建设之间存在张力。

6. **平台算法的影响**：STEPPS研究的是"人们为什么分享"，但在算法驱动的平台上，"平台推荐什么"可能比"人们想分享什么"更影响传播效果。伯杰的理论没有充分考虑算法推荐对传播的塑造作用。

7. **公开资料与原始研究的差异**：《疯传》是面向大众的畅销书，为了可读性简化了研究方法和统计细节。本文件基于该书整理，可能无法完全还原伯杰学术论文中的精确发现和限定条件。
