# 艾·里斯+杰克·特劳特 · 定位理论

> 定位不是你对产品做什么，而是你对潜在客户的心智做什么——在信息过载时代，只有占据心智位置的品牌才能被选择。

## 核心理念

里斯和特劳特要解决的根本问题是：**在信息过载的时代，品牌如何进入并占据消费者的心智？**

1972年里斯和特劳特在《Advertising Age》发表系列文章提出"定位"概念时，美国社会正经历信息爆炸——广告数量激增、媒体渠道多元化、产品同质化严重。他们发现一个根本矛盾：**信息供给无限增长，但消费者心智容量有限**。每个品类消费者只能记住7个以内的品牌，而实际存在的品牌可能有数百个。在这个矛盾下，品牌竞争的本质不是产品竞争，而是心智竞争——**谁先占据心智中的位置，谁就赢得竞争**。

里斯和特劳特特别强调一个反直觉发现：**第一>更好**。第一个进入消费者心智的品牌（如可口可乐/柯达/赫兹）比"更好的"后来者有巨大优势——消费者心智先入为主，第一个占据位置的品牌成为品类的代名词，后来者必须与"第一"建立关联才能被记住。如果不能第一，就开创新品类成为新品类的第一。

## 关键模块

### 模块1：定位定义

- 定义：定位是在潜在客户心智中占据一个位置——不是对产品做什么，而是对心智做什么；定位是信息过载时代的生存法则
- 输入：品类心智地图 + 竞品心智位置 + 品牌资源与能力
- 输出：品牌在心智中要占据的位置定义
- 关键动作：
  - 在潜在客户心智中占据一个位置——消费者心智是一个"位置有限"的空间，每个品类只有少数几个位置被占据；定位的目标是找到心智中的空位并占据它；如沃尔沃占据"安全"位置、宝马占据"驾驶乐趣"位置、奔驰占据"声望"位置
  - 为什么定位不是产品而是心智——产品差异可以模仿，心智位置难以替代；可口可乐的配方可以被模仿，但"可乐=可口可乐"的心智位置无法被替代；定位的战场不在工厂而在心智
  - 信息过载时代的生存法则——里斯和特劳特指出：信息供给每10年翻一番，但消费者心智容量不变；在信息过载的环境中，消费者用"简化"应对——每个品类只记住少数品牌；品牌如果不能进入消费者的简化清单，就不存在
  - 定位的前提——定位假设消费者心智已经拥挤，新品牌不能"添加"信息，只能"关联"或"重新排列"已有信息；因此定位不是"告诉消费者我是谁"，而是"让消费者在已有认知框架中找到我的位置"
- 常见误区：把定位等同于产品定位——产品定位是"产品有什么特点"，心智定位是"消费者心智中占据什么位置"；认为定位是"说出来的"——定位是消费者心智中的位置，不是品牌自己声明的；忽视心智的先入为主——心智已经被占据的位置极难被取代

### 模块2：心智阶梯

- 定义：消费者心智中每个品类都有一个阶梯——第一级是最先想到的品牌，第二级是其次想到的，以此类推；第一法则和品类开创是占据心智阶梯的核心策略
- 输入：品类心智份额数据 + 品牌排名 + 竞品心智位置
- 输出：品牌在心智阶梯中的目标位置
- 关键动作：
  - 第一法则——第一个进入消费者心智的品牌拥有巨大优势：它成为品类的代名词（Kleenex=纸巾/Xerox=复印/Google=搜索）；第一品牌的心智份额通常是第二品牌的2倍，第二品牌是第三品牌的2倍；第一品牌的营销效率远高于后来者——同样的广告投入，第一品牌获得更多心智份额
  - 品类开创——如果不能在现有品类中成为第一，就开创新品类成为新品类的第一；如红牛开创"能量饮料"品类、星巴克开创"第三空间咖啡"品类、特斯拉开创"电动豪华车"品类；新品类的开创者自动成为该品类的第一
  - 为什么第一>更好——消费者心智先入为主：第一个占据位置的品牌定义了品类标准，后来者被按这个标准评估；"更好"需要消费者改变已有认知，而改变认知比建立新认知难得多；如七喜用"非可乐"定位关联可乐品类，比试图证明"七喜比可乐更好喝"有效得多
  - 如果不能第一就开创新品类——这是里斯最重要的战略建议：与其在已有品类中与第一竞争，不如开创新品类成为第一；开创新品类不是发明新产品，而是给消费者一个新的分类框架——如"白色洗衣机"不是新发明，但"白色家电"是新品类
- 常见误区：认为"更好"可以打败"第一"——在消费者心智中，"更好"不如"第一"有说服力；忽视品类开创——大多数品牌试图在已有品类中竞争，而非开创新品类；把品类开创等同于产品创新——品类开创是心智层面的创新，不是技术层面的创新

### 模块3：四种商战

- 定义：根据品牌在市场中的地位，选择不同的竞争战略——防御战（领导者）、进攻战（第二名）、侧翼战（小品牌）、游击战（本地/细分品牌）；市场地位决定战略
- 输入：品牌市场份额 + 市场排名 + 竞争格局
- 输出：适合品牌地位的商战策略
- 关键动作：
  - 防御战（市场领导者）——防御战的原则：1.只有市场领导者才能打防御战（自己不是领导者就不能打防御战）；2.最好的防御是攻击自己（主动推出新产品替代自己的老产品，不让对手有攻击机会）；3.强大的攻势必须被封锁（对手发起重大进攻时必须立即回应）；如吉列不断推出新刀片替代自己的旧刀片，让竞争者永远追不上
  - 进攻战（第二名）——进攻战的原则：1.领导者定位中的强势是主要考量（不是看自己有多强，而是看领导者的强势中有没有弱点）；2.在领导者强势中找到弱点并攻击（这个弱点必须是领导者强势的必然结果——如可口可乐的强势是"经典"，弱点是"老派"）；3.在尽可能狭窄的战线上发动进攻（集中兵力于一点，不要分散）；如百事可乐攻击可口可乐"老派"的弱点，定位"新一代的选择"
  - 侧翼战（小品牌）——侧翼战的原则：1.在无人竞争的区域展开（找到领导者没有覆盖的细分市场）；2.战术奇袭（不要提前宣布你的战略，出其不意）；3.追击与防守同样重要（侧翼战成功后必须迅速巩固阵地）；如大众甲壳虫在美国市场用"小"定位侧翼攻击底特律的"大"
  - 游击战（本地/细分品牌）——游击战的原则：1.找到一块足够小但足以守得住的阵地；2.无论多么成功都不要学领导者（小品牌的优势是灵活，学领导者就失去了灵活）；3.随时准备撤退（如果阵地守不住就立即转移，不要恋战）；如本地啤酒品牌在区域市场对抗全国品牌
  - 为什么市场地位决定战略——领导者打防御战是因为有阵地要守，第二名打进攻战是因为有明确目标要攻，小品牌打侧翼战是因为正面进攻必败，本地品牌打游击战是因为资源有限只能打小仗；用错战略等于自杀——第二名打防御战等于放弃进攻，小品牌打进攻战等于以卵击石
- 常见误区：所有品牌都想打进攻战——进攻战只适合第二名，小品牌打进攻战必败；领导者不攻击自己——领导者如果不主动攻击自己，对手就会攻击你的弱点；侧翼战成功后不巩固——侧翼战成功后必须迅速转为防御，否则会被对手反攻

### 模块4：定位方法

- 定义：定位方法是品牌在心智中占据位置的具体战术——关联定位、对立定位、重新定位竞争对手；定位是减法不是加法
- 输入：品类心智地图 + 竞品心智位置 + 品牌自身资源
- 输出：具体的定位策略
- 关键动作：
  - 关联定位——将自己的品牌与心智中已有的强势品牌建立关联，借势进入心智；如七喜的"非可乐"关联可乐品类、安飞士的"我们更努力"关联赫兹、百事的"新一代的选择"对立可口可乐的"经典"；关联定位的逻辑：消费者心智中已有位置很难被取代，但可以通过关联已有位置来建立自己的位置
  - 对立定位——找到领导者的强势中的弱点，站在领导者的对立面；对立定位的逻辑：领导者的强势必然伴随弱点——可口可乐的强势是"经典"，弱点是"老派"；宝马的强势是"终极驾驶机器"，奔驰的弱点是"不是为驾驶而造"；对立不是否定领导者，而是提供领导者的反面选择
  - 重新定位竞争对手——改变消费者心智中竞争对手的位置，为自己的品牌腾出空间；重新定位不是攻击竞争对手的产品，而是改变消费者对竞争对手的认知；如泰诺重新定位阿司匹林为"伤胃的止痛药"，为"不伤胃的泰诺"腾出空间；重新定位必须基于事实——虚假的重新定位会遭到法律诉讼和消费者反弹
  - 为什么定位是减法不是加法——消费者心智容量有限，品牌信息越少越容易被记住；定位不是"告诉消费者我什么都好"，而是"让消费者记住我一个特点"；如沃尔沃只说"安全"，不说"安全+豪华+性能+空间"；减法比加法难——企业总想多说，但多说等于没说
- 常见误区：定位贪多——同时占据多个位置等于没有位置；对立定位变成攻击——对立是提供不同选择，攻击是贬低对手，前者有效后者可能反噬；重新定位没有事实依据——虚假的重新定位可能面临法律风险

### 模块5：定位的局限

- 定义：定位理论在数字化时代面临挑战——过度简化、品类分化vs融合的矛盾、数字化时代需要升级
- 输入：定位理论的假设 + 数字化时代的现实
- 输出：对定位理论的适用性评估
- 关键动作：
  - 过度简化——定位将品牌简化为一个词/一个概念，但很多品牌的价值无法用一个词概括；苹果=什么？"创新"？"设计"？"生态系统"？苹果的成功恰恰在于它不是单一维度的品牌；定位的"一个词"法则可能限制品牌的扩展空间
  - 品类分化vs融合——里斯后期强调"品类分化"（品类不断细分，每个细分品类产生新的第一品牌），但数字化时代的趋势是"品类融合"（手机=相机+音乐+导航+支付+...）；品类融合打破了定位的"一个品类一个位置"假设——iPhone占据的不是"手机"位置，而是"生活方式"位置
  - 为什么定位在数字化时代需要升级——数字化时代有三个变化挑战定位理论：1.消费者获取信息的渠道从"广告"变成"搜索+社交+算法推荐"，心智位置的建立方式不同了；2.平台经济模糊了品类边界（美团=外卖+酒店+电影+买菜），一个品类一个位置的假设不成立；3.消费者决策从"品牌选择"变成"场景选择"（在不同场景选择不同品牌），心智位置不再是固定的
  - 定位理论的持久价值——尽管面临挑战，定位的核心洞察仍然有效：消费者心智容量有限、先入为主优势巨大、简化比复杂更有效；需要升级的不是"占据心智位置"这个核心思想，而是"如何占据"和"占据什么"的方法
- 常见误区：认为定位理论已经过时——定位的核心洞察（心智有限/先入为主/简化有效）仍然成立，过时的是部分方法；在数字化时代机械套用定位——需要根据数字化环境调整定位方法；用定位的局限否定定位——任何理论都有局限，关键是理解适用边界

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 品牌定位 | 如果品牌没有在心智中占据明确位置→品牌不存在，必须找到心智空位 | 定位定义 |
| 竞争策略 | 如果品牌是品类第一→打防御战，主动攻击自己 | 四种商战 |
| 第二名策略 | 如果品牌是品类第二→打进攻战，攻击领导者强势中的弱点 | 四种商战 |
| 品类选择 | 如果不能在现有品类中成为第一→开创新品类成为第一 | 品类开创 |
| 定位表达 | 如果品牌定位需要超过一个词来概括→定位不清晰，做减法 | 定位是减法 |
| 关联策略 | 如果品牌无法独立建立心智位置→与已有强势品牌建立关联 | 关联定位 |
| 对立策略 | 如果领导者强势中找不到弱点→换一个角度找，强势必然伴随弱点 | 对立定位 |
| 信息简化 | 如果品牌信息超过3个要点→消费者记不住，简化到1个 | 定位是减法 |
| 小品牌策略 | 如果品牌市场份额很小→打游击战，找小而可守的阵地 | 游击战 |
| 数字化定位 | 如果在数字化时代做定位→升级方法但保留核心洞察（心智有限/先入为主） | 定位的局限 |

## 与其他方法论的关系

| 关联方法论 | 关系 | 接口 |
|-----------|------|------|
| 科特勒STP | 互补-STP+定位 | 科特勒STP中的P（Positioning）是"在目标市场中建立独特位置"，里斯+特劳特将其发展为"在消费者心智中占据一个词"；科特勒定位是市场战略（在哪个市场定位），里斯定位是心智战略（在心智中占什么位置）；两者互补：科特勒解决"在哪竞争"，里斯解决"如何被记住" |
| 夏普品牌增长 | 对比-心智可用性vs心智定位 | 里斯追求"在心智中占据一个词"（窄而深），夏普追求"在购买场景中被想到"（广而浅）；里斯认为品牌应该有一个清晰的定位词，夏普认为品牌应该与尽可能多的购买场景关联；里斯是"聚焦"逻辑，夏普是"扩散"逻辑；两者对"心智"的理解根本不同 |
| 波特竞争战略 | 互补-战略+定位 | 波特解决"如何竞争"（成本领先/差异化/聚焦），里斯解决"如何被记住"（在心智中占据位置）；波特是竞争战略的"做什么"，里斯是竞争战略的"怎么说"；两者互补：波特定义竞争方式，里斯定义心智位置 |
| 克里斯坦森颠覆式创新 | 互补-颠覆+品类开创 | 克里斯坦森的颠覆式创新从技术/商业模式层面创造新品类，里斯的品类开创从心智层面定义新品类；克里斯坦森解决"如何创造新品类"，里斯解决"如何让新品类被记住"；颠覆式创新提供品类开创的技术基础，定位理论提供品类开创的心智策略 |
| 华为MTL | 下游-定位在B2B的应用 | 里斯+特劳特的定位理论主要面向B2C，华为MTL将定位思想应用于B2B场景；MTL中的"市场洞察→市场管理→线索管理"流程中，市场管理包含"确定目标市场和价值定位"，这是定位理论在B2B的具体化；B2B定位不是"占据一个词"而是"成为特定场景的首选供应商" |
| 字节增长 | 对比-增长黑客vs心智占领 | 字节增长黑客用数据驱动用户增长（AARRR+实验循环），里斯定位用心智占领驱动品牌选择（占据心智位置）；增长黑客是"行为驱动"（让用户做更多），定位是"认知驱动"（让用户想到你）；增长黑客适合短期行为优化，定位适合长期心智建设 |

## 适用场景

### 最适合

- 新品牌上市——用定位理论找到心智空位并占据
- 品牌重新定位——当原有定位失效时重新找到心智位置
- 第二名挑战领导者——用进攻战策略攻击领导者弱点
- 品类开创——开创新品类成为第一
- 品牌命名和传播——用"一个词"原则简化品牌信息

### 不适合

- 品类融合型产品——如智能手机/平台型产品，无法用"一个词"定位
- 高度个性化的品牌——如奢侈品牌/艺术品牌，定位简化会损失品牌深度
- B2B复杂解决方案——决策链长，"一个词"定位不足以支撑购买决策
- 快速迭代的互联网产品——产品频繁变化，心智位置难以固定
- 垄断市场——没有竞争就不需要定位

## 实施检查清单

- [ ] 品牌是否在心智中占据了明确的位置——消费者用什么词描述你的品牌
- [ ] 定位是否可以用一个词概括——如果需要多个词，定位不清晰
- [ ] 是否分析了品类心智阶梯——品牌在心智阶梯的哪一级
- [ ] 是否根据市场地位选择了正确的商战策略——防御/进攻/侧翼/游击
- [ ] 定位是否做了减法——去掉不必要的信息，只保留核心
- [ ] 如果是第二名，是否找到了领导者强势中的弱点——而非自己的优势
- [ ] 如果不能第一，是否考虑了开创新品类——而非在已有品类中竞争
- [ ] 定位是否基于消费者心智而非产品特性——定位不是产品定位而是心智定位
- [ ] 是否考虑了数字化时代对定位的挑战——品类融合/算法推荐/场景选择
- [ ] 重新定位竞争对手是否有事实依据——虚假重新定位有法律风险

## 诚实边界

1. **过度简化的风险**：定位理论的核心是"一个词占据心智"，但很多成功的品牌无法用一个词概括——苹果不只是"创新"，亚马逊不只是"快"。过度简化可能限制品牌扩展空间，让品牌在进入新领域时面临"定位冲突"。定位的减法有时是必要的牺牲，有时是过度简化。

2. **品类融合的挑战**：里斯后期坚持"品类分化"（品类不断细分），但数字化时代的趋势是"品类融合"（手机融合了相机/音乐/导航/支付）。当品类边界模糊时，"一个品类一个位置"的假设不成立。定位理论对品类融合的解释力不足。

3. **心智位置的动态性**：定位理论假设心智位置一旦占据就相对稳定，但数字时代的心智位置变化更快——算法推荐可以快速改变消费者对品牌的认知，社交媒体可以快速建立或摧毁心智位置。定位理论对心智动态性的指导不足。

4. **第一法则的例外**：第一法则说"第一>更好"，但有很多"第一"失败的案例——Mosaic是第一个图形浏览器但被Netscape取代，Friendster是第一个社交网络但被Facebook取代。第一是优势但不是保证，执行力和迭代能力同样重要。

5. **商战隐喻的局限**：四种商战用军事隐喻描述商业竞争，但商业竞争和军事战争有本质区别——商业竞争不是零和博弈（市场可以扩大），军事战争是零和博弈（领土有限）。商战隐喻可能导致过度对抗思维，忽视合作和共创的可能性。

6. **B2C偏向性**：定位理论主要面向B2C消费市场——消费者决策快、品类清晰、心智位置明确。B2B采购决策链长、品类模糊、决策标准复杂，"一个词"定位在B2B中往往不够用。

7. **公开资料与原始思想的差异**：里斯和特劳特后来分道扬镳，各自发展了定位理论的不同方向——里斯更强调"品类开创"和"视觉锤"，特劳特更强调"战略定位"和"一致执行"。本文件基于两人合著时期的著作整理，可能无法完全反映两人后期的思想分化。
