# 迈克·温伯格 · 新型销售管理

> 大多数销售管理失败不是因为方法不对，而是因为管理者要么微观管理要么放任——销售管理的核心是计划、会议、招聘和文化

## 核心理念

温伯格要解决的核心问题是：**为什么大多数销售管理者失败？销售管理到底应该管什么？**

温伯格在30年销售管理和咨询生涯中发现一个惊人的规律：大多数销售管理者要么微观管理（盯住每个销售的每通电话、每封邮件），要么放任自流（"你们都是成年人了，自己搞去吧"），两者都导致团队业绩低下。温伯格说："销售管理不是管人，而是管计划、管会议、管招聘、管文化。"（Sales management is not about managing people. It's about managing the plan, the meetings, the hiring, and the culture.）

温伯格的核心洞察：销售管理者最大的失败不是"不会管"，而是"管错了事"。大多数销售管理者把时间花在——看CRM报表、催销售更新数据、参加内部会议、写报告——这些事不创造业绩。真正创造业绩的四件事：①一号计划——明确销售方向和优先级；②销售会议——通过高质量会议驱动行动；③招聘+培养——找到对的人并让他们快速产出；④销售文化——创造高绩效的文化环境。

核心公式：**销售管理成功 = 一号计划 × 高效会议 × 对的人 × 高绩效文化**

## 关键模块

### 模块1：销售管理的失败

- 定义：大多数销售管理失败不是因为方法不对，而是因为管理者在微观管理和放任自流之间摇摆——两者都不创造业绩
- 输入：销售管理者的行为模式 + 团队业绩数据
- 输出：对销售管理失败根因的诊断
- 关键动作：
  - **为什么大多数销售管理失败**：温伯格总结了销售管理失败的5个原因：①从顶级销售提拔为管理者——顶级销售擅长自己卖东西，不擅长让别人卖东西，两者的技能完全不同；②没有计划——管理者没有明确的销售计划，团队不知道方向；③会议浪费时间——每周的销售会议变成汇报会而非行动会；④招错人——招聘时看"感觉"而非标准，招来的人不适合销售；⑤忽视文化——管理者以为流程和激励就够了，忽略了文化对行为的塑造
  - **微观管理vs放任**：两种极端都不行——微观管理者盯住每个销售的每个动作（"你今天打了多少电话？""你为什么没更新CRM？"），销售感觉不被信任，创造力和主动性被扼杀；放任者完全不管（"你们自己看着办"），销售没有方向和纪律，业绩随个人能力波动。温伯格说："好的销售管理者像教练——不上场踢球，但制定战术、训练球员、在关键时刻做调整。"
  - **销售经理的3个核心职责**：温伯格定义了销售经理的三个核心职责：①制定和执行一号计划——明确方向和优先级，让团队知道"往哪走"和"怎么走"；②驱动关键行为——通过会议和一对一辅导，确保团队在做对的事；③建立和维持高绩效文化——创造一个让优秀销售愿意留下、让平庸销售无法混日子的环境。温伯格的警告：如果你不做这三件事，你就是在做"假管理"——看起来很忙但不创造业绩
- 常见误区：认为销售管理就是"管人"——销售管理是管计划、管行为、管文化，不是管人；认为从顶级销售提拔管理者是自然选择——顶级销售和管理者是两种完全不同的角色；认为CRM数据=管理——CRM数据是结果不是原因，管理应该关注行为而非数据

### 模块2：一号计划

- 定义：一号计划是销售团队的年度/季度作战计划——明确方向、目标、策略和行动，没有计划=没有方向
- 输入：公司战略 + 市场分析 + 团队能力评估
- 输出：清晰的销售计划 + 团队共识 + 行动优先级
- 关键动作：
  - **销售计划**：温伯格的"一号计划"不是厚重的战略文档，而是一份简洁的、可执行的行动计划。核心内容：①我们的目标客户是谁——不是"所有企业"，而是具体的行业、规模、职位；②我们的价值主张是什么——不是"全方位解决方案"，而是针对目标客户的具体痛点；③我们的竞争策略是什么——不是"我们更好"，而是"我们在哪个维度上赢"；④我们的行动优先级是什么——不是"什么都做"，而是"先做什么后做什么"
  - **为什么没有计划=没有方向**：温伯格的观察：大多数销售团队没有计划——他们有目标（"今年做1000万"），但没有计划（"怎么做到1000万"）。目标和计划的区别：目标是结果（"我们要去哪里"），计划是路径（"我们怎么去"）。没有计划的团队：①每个销售各自为战——方向不一致，资源分散；②管理者无法评估进度——没有基准就没有偏差分析；③遇到困难时没有预案——只能临时应对，而非按计划调整
  - **计划5要素**：温伯格的一号计划5要素：①目标客户画像——具体到行业、规模、职位、痛点；②价值主张——针对目标客户的具体价值，而非泛泛的"我们很好"；③领地划分——每个销售负责哪些客户/区域，避免内耗；④活动指标——每周/每月需要完成的关键行为（外呼量/会议量/提案量）；⑤里程碑——季度/月度的关键节点和检查点。温伯格强调：计划不需要完美，但必须存在——一个不完美的计划比没有计划强100倍
- 常见误区：计划太复杂——计划应该是1-2页纸的行动指南，不是50页的PPT；计划只有目标没有路径——"今年做1000万"是目标不是计划，计划是"怎么做到1000万"；计划做完就束之高阁——计划应该被每周回顾和调整，不是做完了就忘

### 模块3：销售会议

- 定义：销售会议是销售管理者最重要的管理工具——但大多数销售会议浪费时间而非驱动行动
- 输入：一号计划 + 团队当前状态
- 输出：团队对齐 + 行动承诺 + 问题解决
- 关键动作：
  - **为什么大多数销售会议浪费时间**：温伯格观察了上千场销售会议，发现最常见的三种浪费：①汇报会——每个人轮流汇报自己的pipeline，其他人玩手机，没有讨论没有行动；②数据会——管理者盯着CRM报表质问销售为什么数据没更新，销售被动应付；③鸡汤会——管理者放励志视频、喊口号，销售表面兴奋实际无感。这三种会议的共同问题：没有驱动行动
  - **高效会议3规则**：温伯格的高效销售会议3规则：①会议必须有明确的议程和产出——每次会议开始前，每个参与者知道"今天要讨论什么"和"会议结束时我们要达成什么"；②会议必须驱动行动——每个讨论项结束时必须有明确的下一步行动（谁在什么时候做什么）；③会议必须解决真实问题——不是汇报进度，而是解决阻碍业绩的真实问题。温伯格建议：每周1小时的团队会议 + 每人每月1次30分钟的一对一辅导
  - **一对一辅导**：温伯格最重视的管理动作是一对一辅导——每周或每两周与每个销售做30分钟的深度对话。一对一辅导的核心：①不是审讯——不是"你为什么没完成目标"，而是"你在哪里卡住了，我能怎么帮你"；②关注行为而非结果——结果已经发生了无法改变，但行为可以调整；③角色扮演——在安全环境中练习关键对话（如开场白/异议处理/成交话术），比任何培训都有效
- 常见误区：会议太频繁——每天站会+每周团队会+每月复盘会，销售花太多时间在会议上而非卖东西；会议没有议程——"大家聊聊"不是会议，是浪费时间；一对一变成汇报——一对一辅导应该是帮助销售提升，不是让销售向你汇报

### 模块4：招聘+培养

- 定义：招聘比培训重要——招到对的人是销售管理最重要的决策，新人90天决定成败
- 输入：岗位要求 + 候选人池
- 输出：高绩效销售团队
- 关键动作：
  - **为什么招聘比培训重要**：温伯格的核心观点：你不能把一个不适合销售的人培训成顶级销售——销售需要特定的天赋和动机（韧性/好奇心/竞争心/自驱力），这些很难通过培训获得。培训可以提升技能，但无法创造天赋。温伯格说："给我一个有销售天赋的新人，我可以在6个月内让他产出；给我一个没有销售天赋的老手，我花6年也改变不了他。"
  - **3个招聘错误**：温伯格总结了3个最常见的招聘错误：①用"感觉"招聘——"我觉得他不错""她很有激情"——感觉不是标准，应该用结构化面试和客观评估；②招"便宜"的人——为了省钱招经验不足的人，结果产出更低、流失率更高；③招"像自己"的人——管理者倾向于招和自己相似的人，导致团队同质化，缺乏多样性
  - **新人90天**：温伯格的新人90天框架——前90天决定一个销售是否能在公司成功：①第1-30天——学习产品/市场/流程，不做销售——让新人充分理解他要卖什么和卖给谁；②第31-60天——开始外联和对话，管理者密切辅导——每天检查关键行为，及时纠偏；③第61-90天——独立销售，管理者从辅导转向监督——如果90天后新人还不能独立产出，可能招错了人。温伯格的警告：90天是试错期，不要过早放弃也不要过晚淘汰
- 常见误区：招人看简历而非行为——简历告诉你他做过什么，面试中的行为告诉你他怎么做；新人来了就让他卖——没有充分的入职培训，新人会养成坏习惯；淘汰太慢——明知道一个人不适合销售却迟迟不淘汰，对团队士气伤害最大

### 模块5：销售文化

- 定义：文化>流程——高绩效销售文化是销售团队长期成功的根基，流程和激励只能在文化框架内发挥作用
- 输入：管理者的行为 + 团队规范 + 奖惩机制
- 输出：高绩效销售文化
- 关键动作：
  - **为什么文化>流程**：温伯格的核心论点：流程告诉你"应该做什么"，文化决定你"实际做什么"。当一个销售面临压力时——客户拒绝、季度末冲刺、竞争对手降价——流程会被遗忘，但文化会驱动行为。好的文化让销售在压力下做对的事（坚持价值主张、不随意降价、维护客户关系），坏的文化让销售在压力下做错的事（虚报pipeline、过度承诺、内部抢客户）
  - **高绩效销售文化的5个特征**：温伯格定义了5个高绩效销售文化特征：①结果导向——团队关注结果而非活动，"你做了多少"不如"你达成了什么"；②透明诚实——pipeline真实、承诺可信、问题不藏，没有人虚报数据；③持续学习——团队愿意分享最佳实践、接受反馈、尝试新方法，没有人觉得自己已经够了；④团队优先——销售之间互相帮助而非内部竞争，"我们赢"比"我赢"更重要；⑤高标准——团队对平庸零容忍，每个人都在追求更好，没有人觉得"差不多就行"
  - **管理者如何塑造文化**：温伯格的文化塑造方法：①以身作则——管理者自己的行为是文化的最强信号，你说什么不重要，你做什么才重要；②奖励对的行为——你奖励什么就得到什么，如果你奖励pipeline数量，你就得到虚报的pipeline；如果你奖励真实的机会，你就得到真实的机会；③处理违规者——对违反文化的人零容忍，一个有毒的销售比一个平庸的销售危害更大；④讲述故事——用真实的成功和失败故事传递文化价值观，故事比规则更有说服力
- 常见误区：认为文化就是"团建"——团建是活动不是文化，文化是团队在压力下的行为模式；认为文化可以速成——文化需要时间积累，不能通过一次off-site或一个口号建立；认为文化不需要管理——文化如果不被主动塑造，就会被默认行为塑造——而默认行为通常不是你想要的

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 判断销售管理是否有效 | 如果团队没有一号计划→管理无效，方向不明 | 一号计划 |
| 判断销售会议是否有效 | 如果会议结束时没有明确的行动承诺→会议无效 | 销售会议 |
| 判断是否招对了人 | 如果新人90天后仍不能独立产出→可能招错了人 | 新人90天 |
| 判断销售文化是否健康 | 如果pipeline数据不可信→文化不健康 | 销售文化 |
| 判断管理者是否微观管理 | 如果管理者在告诉销售"怎么说话"→微观管理，应该通过辅导让销售自己找到方式 | 微观管理vs放任 |
| 判断管理者是否放任 | 如果管理者不知道每个销售在做什么→放任，应该通过一对一辅导了解 | 微观管理vs放任 |
| 判断招聘标准 | 如果用"感觉"招聘→标准不清晰，应该用结构化面试 | 3个招聘错误 |
| 判断团队是否结果导向 | 如果团队关注活动量而非结果→不是结果导向 | 高绩效文化 |
| 判断是否需要淘汰某人 | 如果一个人违反文化且辅导无效→必须淘汰，拖延伤害更大 | 销售文化 |
| 判断计划是否有效 | 如果计划只有目标没有路径→不是计划，只是愿望 | 一号计划 |

## 与其他方法论的关系

| 关联方法论 | 关系 | 接口 |
|-----------|------|------|
| 拉克姆SPIN | 互补-方法论+管理 | SPIN定义了"销售怎么对话"，温伯格定义了"怎么管理销售团队"；SPIN是销售的微观技巧，温伯格是管理的宏观框架——SPIN告诉销售"怎么做"，温伯格告诉管理者"怎么管" |
| 韦尔奇区分制 | 互补-区分制+销售管理 | 韦尔奇区分制（20-70-10）提供了人才分类的框架，温伯格提供了销售团队中如何应用区分制的具体方法；韦尔奇说"淘汰底部10%"，温伯格说"90天试错期后淘汰不适合的人"——区分制是原则，温伯格是销售场景的实践 |
| 华为干部管理 | 对比-干部管理vs销售管理 | 华为干部管理是全方位的干部选拔/培养/流动体系，温伯格是聚焦销售团队的管理方法；华为面向所有管理者，温伯格专门面向销售经理——前者是"通用管理"，后者是"专业管理" |
| 罗斯SDR | 互补-SDR模式+销售管理 | 罗斯定义了SDR/AE/CSM的角色分离，温伯格定义了如何管理这些角色；罗斯是"组织设计"，温伯格是"管理执行"——罗斯告诉你"应该有什么角色"，温伯格告诉你"怎么管这些角色" |
| 科特领导vs管理 | 互补-领导+管理在销售中的应用 | 科特区分了领导（设定方向/激励人）和管理（计划/预算/控制），温伯格在销售场景中同时需要两者——一号计划是管理（设定方向），销售文化是领导（激励人）；科特是理论，温伯格是销售场景的实践 |
| 稻盛经营十二条 | 对比-经营哲学vs销售管理 | 稻盛经营十二条是全面的经营哲学（从"明确事业的目的"到"始终保持乐观"），温伯格是聚焦的销售管理实践；稻盛从哲学高度看经营，温伯格从实践角度看销售——前者是"道"，后者是"术" |

## 适用场景

### 最适合

- 新任销售经理——需要明确"该管什么"和"怎么管"
- 销售团队业绩低迷——需要诊断问题并制定改进计划
- 销售团队快速扩张——需要建立管理框架和文化基础
- 销售管理者"太忙但不出结果"——需要重新聚焦核心职责
- 销售招聘和培养体系缺失——需要建立系统化的人才管理

### 不适合

- 一人销售团队——没有团队就不需要销售管理
- 纯产品驱动增长（PLG）公司——没有销售团队就不需要销售管理
- 非常成熟的销售组织——已经有成熟的管理体系，温伯格的方法可能过于基础
- 创始人销售阶段——创始人自己卖东西，不需要管理框架

## 实施检查清单

- [ ] 是否制定了一号计划——明确目标客户、价值主张、领地划分、活动指标、里程碑
- [ ] 销售会议是否有明确的议程和产出——而非变成汇报会或数据会
- [ ] 是否建立了每周团队会议+每月一对一辅导的节奏
- [ ] 一对一辅导是否关注行为而非结果——帮助销售提升而非审讯
- [ ] 招聘是否使用结构化面试——而非凭"感觉"
- [ ] 新人是否有90天框架——前30天学习、中30天实践、后30天独立
- [ ] 是否在90天后果断淘汰不适合的人——而非拖延
- [ ] 是否在塑造高绩效销售文化——结果导向、透明诚实、持续学习、团队优先、高标准
- [ ] 管理者是否以身作则——自己的行为与文化要求一致
- [ ] 是否对违反文化的人零容忍——一个有毒的销售比一个平庸的销售危害更大

## 诚实边界

1. **温伯格的经验偏传统B2B**：温伯格的咨询客户主要是传统B2B公司——制造业、服务业、分销业。他的方法论在SaaS/科技行业的适用性需要调整——SaaS销售周期更短、产品更标准化、数据更丰富，温伯格的"一号计划"和"销售会议"框架需要适配。

2. **"招聘比培训重要"可能过于绝对**：温伯格说"你不能把一个不适合销售的人培训成顶级销售"，这在方向上是对的，但低估了系统性培训的价值。Salesforce的SDR培训体系证明，即使是没有销售经验的人，通过系统化培训也能成为高效的销售开发代表。天赋和培训不是二选一，而是乘法关系。

3. **对CRM和数据的态度可能过于轻视**：温伯格对CRM数据和报表的态度偏负面——他认为管理者不应该花太多时间看数据。但在数据驱动的SaaS销售中，CRM数据是诊断问题和优化流程的基础。温伯格的警告（不要只看数据）是对的，但完全不看数据也是危险的。

4. **"90天淘汰"的文化风险**：温伯格建议90天后果断淘汰不适合的人，这在方向上是对的，但过于刚性的90天期限可能造成"先招再扔"的循环——招聘成本和团队士气都会受损。更合理的做法是：在招聘环节更严格（减少招错人的概率），在入职环节更系统（提高新人成功的概率），而非依赖90天淘汰来纠错。

5. **文化塑造的"慢变量"特性**：温伯格说"文化>流程"，但文化是慢变量——需要数月甚至数年才能建立，而流程是快变量——几周就能落地。在急需业绩提升的场景中，先落地流程（快速见效）再逐步塑造文化（长期有效）可能更实际。

6. **缺乏对远程/混合销售团队的管理指导**：温伯格的方法论基于面对面管理的假设——办公室里的销售团队、面对面的会议和辅导。2020年后，越来越多的销售团队是远程或混合办公，温伯格的管理方法需要适配远程场景。

7. **公开资料与原始经验的差异**：《New Sales. Simplified.》是面向销售管理者的实用指南，风格直白、案例丰富但缺乏学术严谨性。温伯格的很多结论来自个人经验而非系统性研究。本文件基于公开资料整理，无法验证温伯格所有案例的真实性。
