# torchcookpackopt 项目周报

> 目的：把「从仓库状态提炼周报」固化成可复用流程。每周内容不同，但**模板、数据来源、事项映射、写作口径**是固定的。

---

## 固定模板（三段 + 可选个人建议）

```
本周进展：

1. 事项名
  1. 子项：做了什么 + 完成度（已完成 / 待落地 / 待拆 / 尚未开始）
  2. 子项：……

下周计划：

1. 事项：要做什么
2. 事项：要做什么

风险提示：

最大的风险是 XXX，导致 XXX。其次 XXX；XXX。

个人建议（可选）：

赞赏：……
吐槽：……
```

要点：
- **本周进展按「事项」分节**，子项写「做了什么事 + 做到哪一步」，完成度用自然词，不硬写百分比。
- **风险提示**最大的风险放最前，一句话点明「导致什么后果」，再逐条其次。

---

## 数据来源（按顺序读）

| 来源 | 拿什么 |
|---|---|
| `git log --since=7.days` + `git status --short` | 本周实际改了什么（commit 消息 + 新增/删除文件） |
| `OKR.md` | KR 定义、负责人、各 KR 的子项名 |
| `KR1/最小化打包_诊断分析.md` | KR1 优化项 + 收益数字 + 60 分钟测算 |
| `KR2/recook加速.md` | KR2 指标（K1–K10）+ 排查结论 |
| `JOURNEY.md` | 方法论进展（看最后更新的表格行 / 最新章节） |

> 优先看文件修改时间（`LastWriteTime`）和 git log，判断本周到底新做了哪些事；旧结论不重复写。

## 事项映射（OKR → 周报「事项」，固定）

本周进展的顶层「事项」按 KR 拆，每项下再按 OKR 子项分条：

**KR1 最小化打包**：
- 快速热更 = 合并 cmdlet（7 次引擎启动 → 1 次，省 ~3m）
- 非Cook资产 = Lua/配表路径（无需 cook；纯 Lua/配表 CL 可跳过构建引擎 ~5m）
- Cook资产 = 图集/模型/烘焙（增量校验 / 去冗余 / 按条件跳过）

**KR2 Recook 加速**：
- 降低Recook = INI 白名单盘点 / -iterate 命中率 / cook 确定性治理
- 耗时优化 = Shader 编译 / Texture 压缩（ASTC）

## 写作口径（本次打磨结论，逐条固守）

1. **说人话**：写成老板能直接读懂的完整句子，禁止密集缩写堆叠（反例：`cook 四步跳过 13m24s + 合并 cmdlet 2-3m，平均墙钟压到 45m26s`）。领域词（Cook / Shader / Recook / CL / cmdlet）可保留，但必须放进完整句子里。
2. **打薄**：每个子项一句话，删过程性修饰（「完成诊断分析、量化了耗时基线」这类不写）。
3. **行动 + 原因，不是总结**：写清「做了什么 / 要做什么」和「为什么」，落到收益或结论；不写流水账。
4. **数字说话**：结论带具体数字（179 条、62 分钟、省 3 分钟、8 倍去重），但每处只留一个关键数字，不堆。
5. **风险最大放最前**：一句话「风险 → 后果」，其次逐条带缓解方向。

## 示例（2026-08-21 最终版，作风格参照）

```
本周进展：

1. 最小化打包诊断分析（KR1）
  1. 数据摸查：拉了 179 条打包记录，把两条打包路径（只改 Lua/配表、改美术资源）按步骤拆开看耗时，找出最慢的环节，已完成。
  2. 优化测算：改美术资源的打包平均要 62 分钟，超了 60 分钟红线；算出来有 5 个地方值得优化，做完能压到 45 分钟左右，已完成。

2. 热更命令合并（KR1-快速热更）
  1. 打包热更时要反复启动 7 次引擎，每次光启动就要 20 多秒。已经写好「7 次合成 1 次」的方案和代码，能省 3 分钟，等编译落地。

3. 跳过无关步骤（KR1-非Cook资产）
  1. 整理出一套判断规则：这次改动没碰到代码或贴图，对应的打包步骤就不跑。比如只改 Lua 时，能省掉 5 分钟的引擎构建，已完成。

4. Recook 加速排查（KR2）
  1. 指标：定了 10 个衡量指标，完成。
  2. Shader 排查：查了着色器重复编译的问题，结论是重复其实已经去得很干净（8 倍），真正能省的是减少材质变体数量，完成；贴图压缩还没查。

下周计划：
1. 落地热更合并方案，跑一遍验证。
2. 催 CL 改动列表，解锁几个可以跳过的步骤。
3. 量一遍 recook 各环节耗时，拿到基线。
4. 拆解贴图压缩的耗时。

风险提示：
最大的风险是 CL 改动列表还没拿到，所有「按改动跳过步骤」的优化都启动不了，KR1 会往后拖。另外 recook 还没测基线，没法量化；mumu 那台打包机配置偏老，比别的机器慢 15 分钟，得协调换机器。
```
