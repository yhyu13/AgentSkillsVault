# 丰田 · 5S现场管理

> 环境塑造行为——有序的现场是一切改善的起点

## 核心理念

5S解决的问题是：为什么改善总是无法维持？答案往往不在改善方法本身，而在工作环境——如果现场混乱无序，任何改善都会被杂乱淹没。5S不是大扫除，而是一套从物理环境到行为习惯的系统性改造：先清理不需要的（整理），再给需要的安家（整顿），保持设备健康（清扫），把前三步制度化（清洁），最终让正确行为成为本能（素养）。5S是TPS的地基——没有5S，看板找不到位置，安灯被杂物遮挡，标准化无从谈起。

## 框架结构


## 关键模块

### 模块1：整理（Seiri）

- 定义：区分需要的和不需要的物品，清除不需要的
- 输入：现场所有物品
- 输出：只保留必要物品的空间
- 关键动作：红牌作战（给不需要的物品贴红牌）；分类标准：过去一年没用过的→移走，一个月没用过的→存远处，每天用的→放在手边
- 常见误区：什么都觉得"以后可能用得上"，导致什么都不敢扔

### 模块2：整顿（Seiton）

- 定义：对保留的物品定位、定量、标识，做到30秒内找到任何东西
- 输入：整理后保留的物品
- 输出：每件物品有固定位置和标识
- 关键动作：定置管理（画线标识位置）；可视化标识（标签、颜色编码）；先进先出设计；使用频率决定放置距离
- 常见误区：只画线不维护，时间一长又回到混乱

### 模块3：清扫（Seiso）

- 定义：彻底清扫工作场所和设备，清扫即点检
- 输入：工作场所和设备
- 输出：干净的环境+设备异常的早期发现
- 关键动作：清扫不是保洁的工作，是操作者的责任；清扫时检查设备有无松动、泄漏、异常；建立清扫责任区和检查表
- 常见误区：把清扫外包给保洁，操作者与设备脱节

### 模块4：清洁（Seiketsu）

- 定义：将前3S的做法制度化、标准化，维持成果
- 输入：前3S的实践成果
- 输出：可重复执行的5S标准和检查机制
- 关键动作：制定5S标准；建立定期检查和评分机制；目视化管理（让异常一眼可见）；管理者定期巡检
- 常见误区：没有检查机制，5S变成一阵风运动

### 模块5：素养（Shitsuke）

- 定义：让遵守5S标准成为习惯，内化为行为方式
- 输入：制度化的5S标准
- 输出：全员自觉维持有序环境的习惯
- 关键动作：每日5S晨会；领导以身作则；新员工5S培训；持续改善5S标准本身
- 常见误区：用惩罚维持5S，而非培养自觉习惯

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 物品是否该保留 | 过去一年没用过→移走 | 整理原则 |
| 物品该放哪里 | 使用频率越高，放得越近 | 整顿原则 |
| 清扫时发现设备异常 | 清扫即点检，立即报告 | 清扫原则 |
| 5S成果回退 | 检查4S（制度化）是否到位 | 清洁原则 |
| 员工不遵守5S | 检查领导是否以身作则 | 素养原则 |
| 想跳过1S直接做2S | 没整理就整顿=给垃圾安家 | 5S递进逻辑 |

## 适用场景

### 最适合

- 制造业车间、仓库、实验室
- 任何有物理工作环境的场景
- 作为精益转型的第一步（门槛低、见效快）
- 改善总是无法维持的组织

### 不适合

- 纯数字化的工作环境（需要适配为数字5S）
- 临时性、一次性工作场景
- 创意工作室（过度整顿可能抑制创造力）

## 实施检查清单

- [ ] 是否清除了所有不需要的物品（1S整理）
- [ ] 每件保留物品是否有固定位置和标识（2S整顿）
- [ ] 操作者是否负责清扫自己的设备和区域（3S清扫）
- [ ] 是否有5S标准和定期检查机制（4S清洁）
- [ ] 领导是否以身作则参与5S（5S素养）
- [ ] 5S是否每日执行而非一阵风运动
- [ ] 是否有可视化看板展示5S状态

## 诚实边界

1. 5S是必要条件而非充分条件——环境有序不等于流程高效
2. 5S容易变成形式主义（为了检查而5S，而非为了工作而5S）
3. 从4S到5S（素养）是最难的跨越，需要数年文化沉淀
4. 知识工作场景需要重新定义5S（信息整理、文件整顿、数字清扫）
5. 过度整顿可能降低灵活性——快速变化的环境中，固定位置可能需要频繁调整
