# 美团 · 科学运营

> 战略不是核心竞争力，运营才是——做同样的事比别人做得更好。

## 核心理念

科学运营解决的核心问题：为什么很多企业有战略却执行不了？干嘉伟从阿里中供铁军到美团COO的实践总结出一个判断——大多数企业不是输在战略方向，而是输在运营能力。战略决定做什么，运营决定做到什么程度。科学运营的本质是用数据和体系替代经验和直觉，把"拍脑袋"变成"看数据"，把"靠能人"变成"靠机制"。三步法是骨架：科学理解生意→组织架构匹配→运营数据化。六大病是诊断：先知道自己哪里病了，再对症下药。五步法是手术刀：解构→观测→对标→学习→重构，用科学手段理解生意。借假修真是人才观：通过过程管理培养出不逊于自己的团队。

## 关键模块

### 模块1：科学运营三步法
- 定义：干嘉伟总结的运营体系化路径，三步顺序不可颠倒——先理解生意再调组织，最后数据化
- 输入：企业战略方向+业务现状
- 输出：可量化、可追踪、可复制的运营体系
- 关键动作：
  - 第一步：科学理解自己的生意，科学设定阶段目标。不理解生意就定目标等于盲人骑瞎马
  - 第二步：组织架构要匹配，用硬件解决硬件问题。组织架构是硬件，管理制度是软件，硬件不匹配靠软件补是徒劳
  - 第三步：运营数据化，建立数据驱动的决策机制。没有数据就没有科学运营，经验决策在复杂业务中必然失灵
  - 三步顺序不可跳：不理解生意就调组织是乱调，不调组织就上数据是空转
- 常见误区：以为三步法可以并行推进，实际每一步都是下一步的前提

### 模块2：企业运营6大病
- 定义：干嘉伟总结的企业运营常见病理，6大病分别对应三步法的3个环节缺失
- 输入：企业运营现状
- 输出：诊断结果+对症治疗方案
- 关键动作：
  - 病1+病2对应第一步缺失：没有科学理解生意，目标靠拍脑袋，路径靠经验
  - 病3对应第二步缺失：组织架构不合理，用软件（管理制度）解决硬件（组织架构）问题
  - 病4+病5+病6对应第三步缺失：不关注效率、不关注供给侧、不掌握科学方法，本质是缺乏数据驱动的运营体系
  - 病3的核心洞察：整天开会说要协同的企业，首先要检讨组织结构——协同需求旺盛本身就是组织设计有问题的信号
- 常见误区：以为6大病要同时治，实际应按三步法顺序从第一步开始治

### 模块3：解构→观测→对标→学习→重构
- 定义：科学理解生意的五步法，是三步法第一步的具体操作工具
- 输入：一个需要理解的生意/业务
- 输出：对该生意的科学认知+可量化的运营模型
- 关键动作：
  - 解构：把生意拆到最小单元，理解每个环节的输入输出和效率
  - 观测：对每个最小单元建立量化指标，用数据而非感觉描述现状
  - 对标：找到行业最优实践，量化差距，知道天花板在哪里
  - 学习：研究标杆为什么做得好，提取可迁移的方法而非照搬结果
  - 重构：基于科学认知重新设计运营体系，用数据替代经验
  - 五步是闭环：重构后再次解构，持续迭代
- 常见误区：以为对标=照搬，实际对标是找差距，学习是找方法，重构是适配自己的场景

### 模块4：借假修真——通过过程管理培养团队
- 定义：干嘉伟的人才观——管理者的核心任务不是自己做得好，而是通过过程管理培养出不逊于自己的团队
- 输入：管理者+团队成员+业务过程
- 输出：不逊于管理者的团队+可持续的组织能力
- 关键动作：
  - "假"是业务过程和结果，"真"是团队能力和组织沉淀
  - 通过Review（复盘）机制：不是追责而是培养，每次复盘都是一次教学
  - 过程管理>结果管理：只看结果等于放弃了培养的机会，过程才是培养的载体
  - 管理者的成功标准不是自己做了多少业绩，而是离开后团队是否还能运转
  - 借假修真与蕊维欧模式一脉相承：陪访+复盘循环就是借假修真的具体实践
- 常见误区：以为培养=上课培训，实际培养=在真实业务过程中通过复盘提炼能力

### 模块5：比对手快7倍的进化速度
- 定义：美团通过每日25项数据追踪+日清日结闭环，实现运营迭代速度远超竞争对手
- 输入：25项核心运营数据+每日运营节奏
- 输出：24小时内问题闭环解决+持续进化的运营体系
- 关键动作：
  - 25项数据追踪：覆盖商户覆盖/签约率/续约率/配送时效/用户满意度等全链路指标
  - 日清日结：晨会目标分解→午间进度追踪→夕会复盘改进，问题不过夜
  - 比对手快7倍的进化速度：对手按月复盘，美团按日迭代，同样一年美团迭代365次对手迭代52次
  - 数据驱动决策：不是看数据做报告，而是看数据做决策——数据异常立即行动
  - 进化速度公式：迭代频率 × 每次迭代的信息量 = 进化速度
- 常见误区：以为数据驱动=做数据看板，实际数据驱动=数据异常立即行动，看板只是工具不是目的

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 企业运营效率低下 | 先诊断6大病，按三步法顺序治，不跳步 | 干嘉伟 |
| 组织协同成本高 | 先检讨组织结构，不要用管理制度补组织设计的坑 | 干嘉伟 |
| 定目标靠拍脑袋 | 先用五步法理解生意，再定目标 | 解构→观测→对标→学习→重构 |
| 管理者忙于救火 | 借假修真，通过过程管理培养团队，让自己可替代 | 干嘉伟 |
| 运营迭代速度慢 | 缩短复盘周期，从月复盘改为日复盘 | 日清日结 |
| 对标学习无效 | 对标是找差距不是照搬，学习是找方法不是抄结果 | 五步法 |
| 数据看板没人看 | 数据异常必须触发行动，看板不是装饰是决策工具 | 25项数据追踪 |
| 新业务理解不清 | 解构到最小单元，每个环节建立量化指标 | 解构→观测 |

## 适用场景

### 最适合
- 规模化运营型企业，需要体系化提升运营效率
- O2O/本地生活/电商等运营密集型业务
- 团队规模扩张快，需要从靠能人转向靠机制
- 竞争对手运营粗糙，靠数据驱动可以拉开差距

### 不适合
- 早期探索型业务（模式未验证，数据指标体系尚未建立）
- 创意驱动型业务（数据驱动可能扼杀直觉和灵感）
- 高度定制化的B2B业务（每个客户差异大，标准化数据指标难建立）
- 垄断型企业（没有竞争压力，科学运营的紧迫感不足）

## 诚实边界

1. 科学运营的前提是业务模式已经验证，模式未验证时过度数据化会锁死探索空间
2. 三步法是事后总结的框架，干嘉伟在美团实际推进中有大量试错和调整，不是一步到位
3. "比对手快7倍"的进化速度是特定竞争环境（千团大战对手运营粗糙）下的结果，对手运营能力提升后差距会缩小
4. 数据驱动有滞后性——数据只能告诉你已发生的事，对未发生的事（战略转折点）仍需判断力
5. 借假修真对管理者要求极高：管理者自身必须具备可传授的方法论，否则"修真"无从谈起
6. "用硬件解决硬件问题"的组织调整有成本和阵痛，短期业绩压力下可能被迫用软件补硬件
