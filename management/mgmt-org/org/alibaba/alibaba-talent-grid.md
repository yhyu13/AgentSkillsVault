# 阿里巴巴 · 人才盘点九宫格

> 用业绩×潜力二维矩阵把人才分九格，让"谁该上谁该下"不再是拍脑袋——人才盘点不是年终仪式，而是持续性诊断动作

## 核心理念

阿里巴巴人才盘点九宫格解决的核心问题是：**如何在规模化组织中系统性地识别人、分类人、发展人？**

很多企业的人才决策依赖主管直觉——谁该提拔、谁该淘汰、谁该培养，全凭"感觉"。阿里的解法是把这种直觉判断变成结构化工具：用业绩（当前产出）和潜力（未来空间）两个维度交叉，把所有人落入3×3的九宫格。每个格子对应不同的人才处置策略——明星重用、小白兔给机会、野狗不提拔、狗淘汰。九宫格不是给员工贴标签，而是让组织对人才状态保持清醒认知。

三个关键设计选择：
1. **业绩×潜力双维**：业绩衡量"做到了什么"，潜力衡量"还能做到什么"——前者是事实判断，后者是预判判断，两者缺一不可
2. **九格而非五类**：与业绩×价值观的五分类不同，九宫格用三档×三档产生九种组合，颗粒度更细，处置更精准
3. **持续性诊断**：人才盘点不是一年一次的仪式，而是持续运转的诊断动作——组织的人才地图必须实时更新

核心公式：**业绩（当前产出）× 潜力（未来空间）= 人才定位与处置策略**

## 关键模块

### 模块1：业绩×潜力二维评估

- 定义：用业绩（当前产出水平）和潜力（未来成长空间）两个独立维度交叉评估人才
- 输入：绩效评分（361体系产出）+ 潜力评估（学习速度/适应力/领导力倾向）
- 输出：二维坐标定位，落入九宫格某一格
- 关键动作：
  - 业绩评估相对客观——361绩效评分、OKR完成度、战功记录均可量化
  - 潜力评估相对主观——需要综合判断学习敏锐度、跨界适应力、领导力萌芽、价值观内化深度
  - 两个维度独立评分，不允许"业绩好就给潜力打高分"的晕轮效应
  - 潜力评估的关键信号：是否主动承担超出职责的挑战、是否在陌生领域快速上手、是否培养出比自己更强的人
- 常见误区：把潜力等同于"聪明"——潜力不是智商，而是学习速度+适应力+成长意愿的综合体；业绩好≠潜力高，很多高业绩者是执行力强但发展空间有限

### 模块2：九宫格分类与处置策略

- 定义：业绩三档×潜力三档交叉产生九种人才类型，每种类型对应不同的处置策略
- 输入：业绩评分+潜力评分的交叉定位
- 输出：分类结果+对应的培养/使用/淘汰决策
- 关键动作：
  - **明星**（高业绩+高潜力）：重奖重用，给舞台给资源，是晋升第一梯队——但需持续验证，明星也可能坠落
  - **中坚**（高业绩+中潜力）：稳定使用，给挑战性任务维持状态，是组织的中流砥柱——不急于提拔，但不可忽视
  - **野狗/老油条**（高业绩+低潜力）：用其产出但不提拔——业绩是硬通货但潜力见顶，提拔到更高岗位可能塌方
  - **老黄牛**（中业绩+高潜力）：重点培养，给机会给指导——当前产出不够但成长空间大，是最值得投资的类型
  - **待发展**（中业绩+中潜力）：关注观察，给明确改进方向——既不紧急也不放弃，需要时间验证
  - **边缘**（中业绩+低潜力）：淘汰预警——产出不突出且空间有限，组织资源应投向更有回报的人
  - **小白兔**（低业绩+高潜力）：给机会给时间，不改则淘汰——"心要仁慈，刀要快"，潜力不能无限期兑现
  - **问题员工**（低业绩+中潜力）：警告+限期改进——潜力不足以抵消当前低产出
  - **狗**（低业绩+低潜力）：直接淘汰，无需犹豫——既无当前产出也无未来空间
- 常见误区：以为九宫格是给员工"定终身"——实际是动态工具，每次盘点重新定位，明星可能变老油条，小白兔可能变明星

### 模块3：持续性诊断机制

- 定义：人才盘点不是一年一次的定期仪式，而是嵌入日常管理的持续性诊断动作
- 输入：日常观察+绩效数据+关键事件记录
- 输出：实时更新的人才地图和处置建议
- 关键动作：
  - 定期盘点（年度/半年度）是正式节点，但人才状态判断是持续进行的
  - 政委在人才盘点中扮演关键角色——独立于业务线，用价值观视角校准业务主管的判断
  - 盘点结果与361绩效联动——九宫格定位影响361分布中的位置，361分布反过来验证九宫格判断
  - 盘点不是填表交差——核心产出是"谁该上谁该下谁该培养"的决策，不是九宫格本身
  - "人才盘点是组织健康的体检报告"——不做盘点等于拒绝体检，问题积累到爆发时已无法挽回
- 常见误区：把人才盘点做成"年终填表"——如果盘点结果不影响任何人的去留升降，那就是走过场

### 模块4：晋升四条件与流程

- 定义：晋升不是对过去业绩的奖励，而是对未来担当的授权——必须同时满足四个条件
- 输入：候选人业绩记录+潜力评估+价值观评分+战功证明
- 输出：晋升决策（通过/不通过）
- 关键动作：
  - **价值观吻合**：晋升者的价值观必须是六脉神剑的践行者——价值观不吻合的人被提拔，会向组织传递"价值观不重要"的信号
  - **战功突出**：必须有可量化的业务贡献——没有战功的晋升是"论资排辈"，阿里不认资历只认战功
  - **能力达标**：当前岗位能力必须已经达标——"能力还没到就提拔"等于设置失败陷阱
  - **潜力充足**：必须有承担更高职责的成长空间——潜力不足的人被提拔，到新岗位塌方，对个人和组织双输
  - 四个条件缺一不可——有战功无价值观=野狗提拔，有价值观无战功=小白兔提拔，都是错误晋升
- 常见误区：以为晋升是"业绩好就该升"——晋升不是奖励而是担当，业绩好但潜力见顶的人不应该被提拔到无法胜任的岗位

### 模块5：晋升流程——四步审核与2/3通过制

- 定义：晋升决策不由一人独裁，而是经过四步审核、面试评估需2/3评委通过
- 输入：主管提名材料+政委审核意见+BU复核结论+面试评估结果
- 输出：最终晋升决定
- 关键动作：
  - **主管提名**：直属主管基于日常观察和九宫格定位发起提名，需提供业绩证据和潜力判断
  - **政委审核**：政委从价值观角度审核——价值观不吻合一票否决，这是政委的核心权力之一
  - **BU复核**：BU层面跨部门校准——防止"一个部门标准松一个部门标准严"，确保晋升标准的一致性
  - **面试评估（2/3通过）**：由多位评委面试评估，需2/3以上通过才可晋升——集体决策降低个人偏见
  - 2/3通过制的设计逻辑：不是100%一致同意（那会导致"一人否决"的僵局），也不是简单多数（那会降低标准），2/3是共识与效率的平衡点
- 常见误区：以为主管提名就等于晋升——主管只是发起者，政委、BU、面试评委各有否决权，四步审核是层层校验

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 高业绩但潜力见顶 | 如果潜力评估为低，则不提拔——用其产出但不给更高岗位，野狗/老油条类必须控制 | 九宫格处置策略 |
| 低业绩但潜力很高 | 如果潜力为高且价值观吻合，则给1-2次机会——小白兔类"心要仁慈刀要快" | 九宫格处置策略 |
| 业绩和潜力都低 | 如果双低则直接淘汰——狗类没有犹豫空间 | 九宫格处置策略 |
| 晋升决策 | 如果四个条件（价值观/战功/能力/潜力）有任一不满足，则不晋升——晋升不是奖励而是担当 | 晋升四条件 |
| 主管提名被政委否决 | 如果价值观不吻合则一票否决——政委的否决权是制度设计不是权力博弈 | 晋升流程 |
| 人才盘点流于形式 | 如果盘点结果不影响任何人的去留升降，则盘点无效——持续性诊断必须产生行动 | 持续性诊断机制 |
| 九宫格定位与361冲突 | 如果九宫格定位为明星但361落入末位，则需校准——两个体系必须互验 | 盘点机制层 |
| 中业绩+高潜力的投资 | 如果老黄牛类持续2次盘点仍为中业绩，则需重新评估潜力——潜力不能无限期等待兑现 | 九宫格处置策略 |
