# 阿里巴巴 · 合伙人制度

> 不靠股权多数、不靠AB股，靠一纸治理契约把"谁定董事会"的权力锁定在使命传承者手中——互联网时代用治理结构替代股权控制的公司控制权方案

## 核心理念

合伙人制度解决的核心问题是：**当"人才"取代"资本"成为企业最核心的生产要素时，如何设计一套治理机制，确保掌握核心能力的人而非掌握最多股权的人主导公司方向？**

传统公司治理的逻辑是"谁出钱多谁说了算"——股权比例决定投票权，大股东控制董事会。这套逻辑在工业时代运转良好，因为资本是最稀缺的生产要素。但互联网公司不同：代码、算法、运营体系、用户洞察——这些核心能力长在人身上，不在钱身上。创始团队和管理层才是公司真正的"核心资产"，但他们往往不是最大的股东。

阿里巴巴面临的就是这个问题的极端版本。2005年与雅虎的融资协议让雅虎拿到39%的股权、软银持有29.3%，马云和管理层的持股被稀释到个位数。按传统治理逻辑，阿里应该由雅虎和软银说了算。但马云认为：资本可以买到股权，买不到对使命愿景价值观的理解和坚守。如果让不懂互联网、不认同阿里文化的财务投资者控制董事会，阿里的长期价值会被短期利润诉求侵蚀。

解决方案不是回购股权（太贵），不是AB股（港交所当时不允许），而是创造一种全新的治理结构：**合伙人制度**。核心设计是：合伙人拥有董事会多数席位的提名权。不是股权控制，不是投票权控制，而是"谁坐上董事会"这件事的控制权。只要合伙人能提名多数董事，即使只持有5%的股权，也能主导公司治理方向。

这套制度的灵感来源多元：咨询公司的合伙人制（能力而非资本决定话语权）、投行的合伙人制（专业共同体自治）、甚至罗马元老院制度（精英共治而非独裁）。但阿里的创新在于：把这些理念从"内部管理"层面提升到"公司治理"层面——不只是内部谁说了算，而是法律意义上谁控制这家公众公司。

核心公式：**治理结构控制 > 股权控制**（用提名权锁定董事会，用董事会锁定公司方向，用文化传承锁定合伙人准入）

## 框架结构

```
阿里巴巴合伙人制度 = 治理结构层面的控制权方案
│
├── 制度起源
│   └── 2005年雅虎融资 → 股权稀释 → 创始团队控制权危机 → 制度创新
│
├── 核心机制：董事会提名权
│   ├── 合伙人提名董事会多数席位
│   ├── 股东大会否决 → 合伙人可重新提名
│   └── 提名权不随股权变动而丧失
│
├── 合伙人准入与退出
│   ├── 准入：在阿里工作≥5年 + 现有合伙人投票（≥75%同意）
│   ├── 退出：离职/退休/被合伙人会议除名
│   └── 人数动态调整（从27人增长到30+人）
│
├── 文化传承功能
│   ├── 合伙人是使命/愿景/价值观的传承者
│   ├── 合伙人委员会负责文化守护和重大决策
│   └── 新合伙人由老合伙人选拔 → 文化基因代际传递
│
└── 治理哲学
    └── "人才"取代"资本"成为核心要素 → 治理权应归属人才共同体
```

## 关键模块

### 模块1：董事会提名权

- 定义：合伙人拥有提名董事会简单多数席位的排他性权利，是整个制度的核心权力来源
- 输入：合伙人会议的提名决议
- 输出：董事会成员候选人名单 → 提交股东大会表决
- 关键动作：
  - 合伙人提名董事会过半数席位，股东只能对提名投赞成或反对，不能另提候选人
  - 若股东大会否决某提名人，合伙人可另行提名，直至通过——实质上否决权无法阻止合伙人最终控制董事会
  - 提名权写入公司章程（Articles of Association），修改需极高门槛，不因股权变动而失效
  - 这不是"股权控制"，而是"治理结构控制"——用制度设计绕开了股权比例的限制
- 常见误区：以为合伙人制度等于AB股——AB股是"一股多票"（同股不同权），合伙人制度是"提名权锁定"（同股同权但提名权独立于股权），两者机制完全不同

### 模块2：合伙人准入与退出机制

- 定义：决定谁能成为合伙人的选拔和退出规则，是文化传承的"入口"和"出口"
- 输入：候选人资历 + 现有合伙人投票
- 输出：新合伙人加入 / 现有合伙人退出
- 关键动作：
  - 准入门槛：在阿里工作满5年以上，品行端正，认同使命愿景价值观
  - 选拔流程：现有合伙人投票，需获≥75%赞成票方可加入——高门槛确保文化一致性
  - 合伙人委员会：由部分合伙人组成，负责管理合伙人事务、提名新合伙人、审核候选人资格
  - 退出机制：主动离职自动退出；退休可保留荣誉合伙人身份但不参与提名权；严重违反价值观可被除名
  - 人数不固定，随组织发展动态扩容——从最初的27人逐步增长
- 常见误区：以为合伙人是终身制——合伙人身份与在职状态绑定，离职即退出；以为合伙人是股权激励——合伙人没有特殊股权，权力来自制度而非股份

### 模块3：文化传承功能

- 定义：合伙人制度不仅是控制权工具，更是使命愿景价值观的代际传承机制
- 输入：创始团队的文化基因 + 每一代合伙人的实践沉淀
- 输出：跨越创始人个人影响力的文化延续能力
- 关键动作：
  - 合伙人的本质定义不是"权力持有者"，而是"使命/愿景/价值观的传承者"——这是制度设计的价值锚点
  - 新合伙人由老合伙人选拔，选拔标准中文化认同权重极高——确保每一代合伙人都经过文化"认证"
  - 合伙人委员会在重大战略决策中扮演"文化守门人"角色——不是业务决策者，而是方向校准者
  - 制度设计的目标：即使马云退出日常管理，阿里的文化和方向也不会被资本力量改变
- 常见误区：以为合伙人制度纯粹是控制权工具——控制权是手段，文化传承才是目的；没有文化传承的合伙人制度只是一个权力俱乐部

### 模块4：制度起源与历史语境

- 定义：合伙人制度诞生的具体历史条件——2005年雅虎融资引发的控制权危机
- 输入：资本运作的现实压力 + 创始团队对长期控制权的战略需求
- 输出：一套绕开传统股权控制路径的治理创新方案
- 关键动作：
  - 2005年：阿里与雅虎达成融资协议，雅虎以10亿美元+雅虎中国业务换取39%股权，软银持有29.3%——马云团队持股被稀释至个位数
  - 融资协议中包含保护条款（如马云不被解职），但远不足以保障长期控制权
  - 15年前的这次资本运作成为合伙人制度的直接催化剂——不是理论推演，而是现实倒逼
  - 2009年左右开始酝酿合伙人制度，2013年在IPO招股书中正式披露
  - 2014年纽交所上市时，合伙人制度作为核心治理结构写入公司章程
- 常见误区：以为合伙人制度是IPO时才设计的——实际酝酿了4-5年，是长期战略而非临时应对

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 创始团队股权被稀释但需保持控制权 | 如果行业核心要素是人才而非资本，用治理结构控制（提名权）替代股权控制 | 合伙人制度核心逻辑 |
| 大股东与创始团队利益冲突 | 如果冲突涉及长期方向，合伙人制度锁定董事会多数提名权，确保长期主义不被短期利润诉求压倒 | 雅虎融资教训 |
| 选择AB股还是合伙人制度 | 如果所在市场不允许AB股（如当时的港交所），合伙人制度是替代方案；如果允许AB股，AB股更简单直接 | Google vs 阿里路径选择 |
| 合伙人选拔标准 | 如果候选人在阿里工作<5年或文化认同存疑，不应纳入——低门槛会稀释文化基因 | 准入机制 |
| 合伙人人数扩张 | 如果新合伙人只是为了"分权"而非"传承"，制度会蜕变为权力俱乐部 | 文化传承功能 |
| 创始人退出后的治理稳定性 | 如果合伙人制度的文化传承功能运行良好，创始人退出不会导致方向偏移；如果文化传承失效，合伙人制度只剩空壳 | 制度设计目标 |

## 与其他方法论的关系

| 关联方法论 | 关系 | 接口 |
|-----------|------|------|
| Google AB股制度 | 对立参照 | Google用AB股（一股十票）确保创始人控制——同股不同权，简单粗暴但依赖股权结构；阿里用合伙人制度——同股同权但提名权独立于股权，机制更复杂但更灵活。Google方案的前提是创始团队持续持有B股，阿里方案的前提是合伙人文化传承不失效 |
| Amazon治理结构 | 对立参照 | Amazon贝佐斯通过持股比例+CEO身份保持控制权——传统路径，靠股权+职位双保险；阿里马云持股比例极低，只能靠治理结构创新。Amazon的控制权绑定在个人，阿里的控制权绑定在制度共同体 |
| 华为员工持股+轮值CEO | 对立参照 | 华为100%员工持股（任正非仅约1%）+轮值CEO制度——资本民主化+权力轮换；阿里合伙人制度+软银雅虎大股东——资本集中在外部+权力集中在内部共同体。华为解决"资本归属"问题（谁拥有），阿里解决"治理权归属"问题（谁说了算）。华为是"全员所有+精英轮值"，阿里是"外部所有+内部精英共治" |
| 阿里六脉神剑价值观体系 | 上游-文化基础 | 合伙人制度是价值观的制度护城河——六脉神剑定义"信什么"，合伙人制度确保"不会被资本力量改变"。没有价值观体系的合伙人制度是权力俱乐部，没有合伙人制度的价值观体系是墙上标语 |
| 阿里政委体系 | 下游-文化执行 | 合伙人制度在治理层面守护文化，政委体系在执行层面守护文化——一个在董事会，一个在业务线，形成文化守护的双层防线 |
| 咨询公司/投行合伙人制 | 灵感来源 | 咨询公司和投行的合伙人制是"内部管理"层面的能力共同体——谁能力强谁就是合伙人；阿里把这套逻辑提升到"公司治理"层面——不只是内部谁说了算，而是法律意义上谁控制这家公众公司。从管理创新到治理创新 |
| 罗马元老院制度 | 灵感来源 | 元老院是精英共治而非独裁——权力不属于某个人而属于一个经过筛选的精英群体；阿里合伙人制度同理——控制权不属于马云个人而属于合伙人共同体。元老院的问题（寡头化、脱离民众）也是合伙人制度的潜在风险 |

## 适用场景

### 最适合

- 互联网/科技企业，核心生产要素是人才而非资本设备
- 创始团队股权被融资稀释但仍需保持战略方向控制权
- 所在资本市场不允许AB股（如2018年前的港交所）
- 组织有强烈的使命愿景价值观，且需要制度保障其不被短期资本力量侵蚀
- 创始人希望将控制权从个人转移到制度共同体，降低对个人魅力的依赖

### 不适合

- 传统资本密集型行业（制造/能源/地产）——资本仍是核心要素，股权控制逻辑合理
- 创始团队持股比例高、不存在控制权危机——AB股或直接控股更简单
- 缺乏强文化认同的组织——没有文化传承功能的合伙人制度只是权力俱乐部
- 上市公司治理要求严格的市场——合伙人制度可能面临监管质疑（如港交所2013年的拒绝）
- 创始人希望个人独裁而非精英共治——合伙人制度是集体决策机制，不适合一人说了算

## 实施检查清单

- [ ] 董事会提名权是否写入公司章程且修改门槛极高？
- [ ] 合伙人准入是否要求≥5年司龄+≥75%现有合伙人同意？
- [ ] 合伙人退出机制是否明确（离职/退休/除名）？
- [ ] 合伙人委员会是否有效运作（管理合伙人事务、提名新合伙人）？
- [ ] 合伙人选拔标准中文化认同权重是否足够高？
- [ ] 合伙人人数是否动态调整而非固定不变？
- [ ] 是否有防止合伙人制度蜕变为权力俱乐部的机制（如定期文化审计）？
- [ ] 股东大会否决提名人后，合伙人是否有权重新提名？
- [ ] 制度设计是否覆盖"创始人退出后"的场景——控制权绑定在制度而非个人？

## 诚实边界

1. **制度依赖文化传承**：合伙人制度的有效性取决于合伙人共同体是否真正坚守使命愿景价值观。如果文化传承失效——新合伙人只是"权力持有者"而非"价值观传承者"——制度就会蜕变为既得利益者的权力俱乐部。这是制度最大的内生风险。

2. **与AB股的效率差异**：AB股制度简单直接——一股多票，规则清晰，市场理解成本低。合伙人制度机制复杂，需要向投资者、监管机构大量解释，2013年港交所因此拒绝阿里上市。复杂性的代价是市场接受度和流动性折价。

3. **"精英共治"的寡头风险**：合伙人制度本质上是精英共治，与罗马元老院面临同样的问题——精英群体可能脱离普通员工和股东的利益，形成封闭的权力圈层。75%的准入门槛既保证了文化一致性，也制造了"自己人选自己人"的封闭性。

4. **与华为对比的语境差异**：说"华为全员所有+精英轮值，阿里外部所有+内部精英共治"是简化。华为的员工持股并非真正意义上的"全员所有"——任正非虽仅持1%但有一票否决权，轮值CEO也不是真正的民主选举。阿里的软银雅虎虽是大股东但签署了投票权协议，不干预日常经营。两者的实际控制权结构都比表面更复杂。

5. **港交所博弈的代价**：2013年阿里因合伙人制度被港交所拒绝上市，转赴纽交所。2018年港交所修改规则允许同股不同权，小米成为首家受益者。阿里的制度创新推动了港交所制度变革，但自身也承担了上市路径变更的成本。

6. **蚂蚁集团事件后的制度韧性考验**：2020年蚂蚁集团上市被叫停后，马云逐步退出阿里日常管理。合伙人制度是否能在创始人淡出后保持韧性，这是正在进行的"压力测试"——结论尚未完全揭晓。

7. **公开资料局限**：合伙人制度的运作细节（如合伙人委员会的具体决策流程、新合伙人选拔的实际操作标准、合伙人之间的分歧解决机制等）未完全公开，本文基于光大证券研报和公开资料重构，部分推断可能与阿里内部实际存在偏差。
