# OPPO/vivo · 段永平哲学

> 不做的事情比做的事情更重要——Stop Doing List是战略的终极过滤器，慢就是快，少就是多

## 核心理念

段永平哲学的核心是"不做"而非"做"。大多数人思考战略时问"我们应该做什么"，段永平问的是"我们不应该做什么"。Stop Doing List不是消极的约束，而是最积极的战略选择——每增加一条"不做"，就为"做"释放了更多资源和专注力。这个哲学有三个递进的层次：第一层是Stop Doing——不做不对的事情，这是底线；第二层是慢就是快——不追求短期速度，追求长期正确，方向对了慢也是快；第三层是少就是多——不做太多事情，把少数事情做到极致，少做才能做好。段永平用这个哲学打造了步步高、OPPO、vivo三家百亿级企业，用同样的哲学在投资领域获得了远超市场的回报——他重仓苹果和茅台，持有不动十余年，用"不做"赚到了最多的钱。

核心命题：**战略的本质不是选择做什么，而是选择不做什么——不做的事情定义了你是什么，做的事情只定义了你做什么。**

## 关键模块

### 模块1：Stop Doing List——不做的事情比做的事情更重要

- 定义：用"不做什么"来定义战略边界，每一条Stop Doing都是对错误方向的提前拦截
- 输入：所有可选的行动方向和商业机会
- 输出：经过"不做"过滤器筛选后的极少数正确方向
- 关键动作：
  - 列出Stop Doing List——明确哪些事情坚决不做
  - 定期审视Stop Doing List——随着认知深化，不断补充新的"不做"
  - 用Stop Doing指导决策——每个决策先过"不做"过滤器
  - Stop Doing的优先级高于To Do——先确定不做，再确定做
- 常见误区：以为Stop Doing是消极避世——Stop Doing是最积极的战略选择，不做错事才能做对事

### 模块2：慢就是快——方向对了慢也是快，方向错了快是灾难

- 定义：不追求短期速度，追求长期正确。方向对了慢也是快，方向错了快是灾难
- 输入：市场对速度的焦虑和短期竞争压力
- 输出：在正确方向上的持续积累和长期复利
- 关键动作：
  - 先确认方向正确——方向比速度重要一百倍
  - 方向正确后坚持——不因短期波动改变长期方向
  - 不追求短期排名——短期第一不如长期唯一
  - 用时间换空间——长期正确的事需要时间积累，急不得
- 常见误区：以为"慢就是快"是鼓励拖延——慢的前提是方向正确，方向错误时慢是慢性自杀

### 模块3：少就是多——不做太多事情，把少数事情做到极致

- 定义：资源和注意力是有限的，做太多事情意味着每件事都做不好，少做才能做好
- 输入：所有想做的业务方向和产品线
- 输出：极少数但做到极致的业务和产品
- 关键动作：
  - 砍掉不重要的业务——不重要的业务占用了重要业务的资源
  - 聚焦核心——把有限的资源集中在最重要的事情上
  - 做到极致——既然做了就要做到行业最好，不做第二
  - 抵制诱惑——新机会不断出现，但大多数新机会是陷阱
- 常见误区：以为"少就是多"是保守——少做不是不做，是把有限的精力集中在最有价值的事情上

### 模块4：能力圈——不做超出能力范围的事

- 定义：每个人都有能力边界，超出能力边界的事情不做，在能力圈内做到极致
- 输入：个人的知识、经验和能力的边界
- 输出：在能力圈内的最优决策和持续的能力圈扩展
- 关键动作：
  - 认清能力圈边界——知道自己不知道什么比知道自己知道什么更重要
  - 在能力圈内决策——超出能力圈的不碰
  - 慢慢扩展能力圈——能力圈可以扩展，但必须慢慢来
  - 不羡慕别人的能力圈——每个人的能力圈不同，在自己的圈里做到最好
- 常见误区：以为能力圈是固定不变的——能力圈可以扩展，但扩展速度不能超过认知深化的速度

### 模块5：买股票就是买公司——投资哲学与经营哲学的统一

- 定义：段永平的投资哲学和经营哲学是统一的——买股票就是买公司，经营公司就是做对的事情
- 输入：投资决策和经营决策
- 输出：长期视角的投资和经营决策
- 关键动作：
  - 买股票就是买公司——不炒股票，买公司
  - 看懂了才买——看不懂的不碰
  - 买了就不卖——好公司不需要卖
  - 用经营思维做投资——投资决策和经营决策用同一套逻辑
- 常见误区：以为段永平的投资哲学只适用于投资——投资哲学和经营哲学是统一的，Stop Doing在投资和经营中同样适用

## 适用场景

### 最适合

- 面临太多选择、需要做减法的组织
- 创始人驱动的企业，需要将个人哲学转化为组织战略
- 资源有限、无法四面出击的中小企业
- 追求长期主义、愿意为长期正确放弃短期利益的组织
- 需要在复杂环境中保持战略定力的企业

### 不适合

- 生存期企业（没有资格做减法，先活下去再说）
- 需要快速试错迭代的早期项目（Stop Doing可能过于保守）
- 资源充裕、可以多线并行的巨头企业（少就是多在资源充裕时未必最优）
- 需要快速抢占市场的竞争环境（慢就是快在速度竞争中可能失效）
- 能力圈尚未建立的个人或组织（没有能力圈就无法判断什么该做什么不该做）

## 实施检查清单

- [ ] 是否有明确的Stop Doing List（书面化、定期审视）？
- [ ] Stop Doing List的优先级是否高于To Do List？
- [ ] 每个重大决策是否先过"不做"过滤器？
- [ ] 是否有方向比速度更重要的共识（慢就是快）？
- [ ] 是否在做减法（砍掉不重要的业务和产品线）？
- [ ] 是否在能力圈内决策（超出能力圈的不碰）？
- [ ] 是否抵制了短期诱惑（问"三年后这事还重要吗"）？
- [ ] 是否用长期视角做投资和经营决策？
- [ ] 是否选本分的人而非只看能力？
- [ ] Stop Doing List是否随认知深化不断补充？

## 诚实边界

1. Stop Doing List的有效性高度依赖判断力——什么该做什么不该做，判断错了Stop Doing就是自我束缚
2. "慢就是快"在速度敏感的竞争环境中可能失效——互联网行业的窗口期很短，慢可能意味着出局
3. "少就是多"的前提是"少"的事情确实能做到极致，如果做不到极致，少就是少
4. 段永平哲学的成功有时代背景——步步高/OPPO/vivo成长于中国消费电子的黄金年代，同样的哲学在不同时代可能效果不同
5. 能力圈的边界是模糊的，实践中很难精确判断什么是能力圈内、什么是能力圈外
6. 段永平的投资成功（苹果、茅台）可能存在幸存者偏差——同样的哲学用于其他标的不一定获得同样回报
