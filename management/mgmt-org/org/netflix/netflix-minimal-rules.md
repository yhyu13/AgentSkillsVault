# Netflix · 极简规则

> 用五个字的政策替代厚厚的员工手册，前提是人才密度和坦诚度已到位

## 核心理念

极简规则解决的核心问题是：**流程审批越多，组织越慢；但取消流程后，如何防止混乱？**

传统组织的逻辑是"出问题→加流程→再出问题→再加流程"，员工手册越来越厚，审批链条越来越长，最终组织被自己的流程压垮。Netflix的逻辑反过来：如果人才密度够高、坦诚度够强，大部分流程就是多余的——聪明人不需要被规则管住，他们需要的是清晰的期望和充分的信息。

但极简规则不是"没有规则"。Reed Hastings反复强调：取消流程时，必须同时补上信息共享、期望清晰度和公平评估。不是"取消"，是"替换"——用透明替换审批，用信任替换管控，用示范替换制度。如果只取消不替换，结果不是自由，而是真空。

核心命题：**极简规则的底层逻辑是"用更少但更精准的规则，替代更多但更模糊的流程"，前提是人才密度和坦诚度已经到位。**

## 框架结构

```
极简规则 = 最小化流程系统
│
├── 三大极简政策
│   ├── 假期政策："Take Vacation"（无上限、无审批）
│   ├── 费用政策："Act in Netflix's Best Interest"（五个字、无审批）
│   └── 决策政策：Informed Captain直接决定（无审批链）
│
├── 替换机制（取消流程时必须同步建立）
│   ├── 信息共享 → 替代审批的信息把关
│   ├── 期望清晰度 → 替代制度的行动锚定
│   └── 公平评估 → 替代流程的结果校准
│
├── 硬性边界（极简≠没有）
│   ├── 道德红线
│   ├── 信息安全
│   └── 法律合规
│
└── 示范行为（领导层必须做的）
    ├── 带头休假（给假期政策锚定）
    ├── 公开决策（给决策政策锚定）
    └── 透明花费（给费用政策锚定）
```

## 关键模块

### 模块1：无假期政策——"Take Vacation"

- 定义：员工自行决定休假时长和时机，无需事先批准，没有年假上限
- 输入：员工个人判断 + 团队工作节奏
- 输出：员工自主安排的休假计划
- 关键动作：
  - 告知团队休假计划（信息共享替代审批）
  - 确保工作交接到位（责任不因休假消失）
  - 管理者带头休假（示范行为，给团队锚定）
- 常见误区：
  - 取消假期制度但没有领导带头休假 → 员工不敢休 → 实际休假反而更少
  - 没有团队讨论休假规范 → 每个人都不确定"多少算正常" → 锚定缺失
  - 把"无限假期"当成福利宣传 → 忽略了它需要配套的示范和讨论机制

### 模块2：无费用审批——"Act in Netflix's Best Interest"

- 定义：员工花费无需审批，唯一准则就是五个字——"为Netflix最佳利益行事"
- 输入：员工判断 + 商业场景
- 输出：自主决策的花费行为
- 关键动作：
  - 花费后如实记录（信息透明替代事前审批）
  - 个人消费与公司消费严格区分（诚信底线）
  - 异常花费由财务事后审查而非事前审批（事后校准替代事前把关）
- 常见误区：
  - 以为取消审批=花钱无限制 → 实际上"最佳利益"是比审批更严格的道德准则
  - 担心员工滥用 → 数据显示员工花费可能略高，但省下的审批流程成本远超差价
  - 忽略诚信前提 → 无费用审批需要高人才密度支撑，低信任环境必翻车

### 模块3：无决策审批——Informed Captain

- 定义：任何员工都可以做决策，前提是充分告知利益相关方（Informed），然后由最接近信息的人直接拍板（Captain）
- 输入：业务场景 + 相关方信息
- 输出：快速决策 + 利益相关方知情
- 关键动作：
  - 决策前主动咨询受影响的人（Informed的含义）
  - 决策后通知相关人员（信息闭环）
  - 决策者对结果负责（Captain的含义——权力与责任绑定）
- 常见误区：
  - 把Informed Captain理解为"谁都可以随便决定" → 缺少Informed环节的Captain是独断
  - 跳过咨询直接拍板 → 失去信息共享的保护
  - 事事请示上级 → 退回审批模式，Informed Captain失效

### 模块4：替换机制——不是取消，是替换

- 定义：每取消一个流程，必须同时建立对应的替代机制
- 输入：被取消的流程 + 其原有功能
- 输出：信息共享 + 期望清晰度 + 公平评估

  -
