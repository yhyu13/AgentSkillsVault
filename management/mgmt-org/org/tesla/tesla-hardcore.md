# Tesla · 硬核文化+极致紧迫

> 用极限压力筛选出改变世界的人——代价是燃烧，回报是突破

## 核心理念

Tesla硬核文化解决的核心问题是：**当组织的使命是"不可能完成的任务"时，需要什么样的文化才能把不可能变成可能？**

马斯克的回答是：极限紧迫感。不是"努力工作"，是"用命工作"。不是"鼓励加班"，是"不加班的人不配留"。这不是管理技巧，而是一种信念——改变世界的人不可能朝九晚五、周末双休。舒适是敌人，紧迫是燃料。

这套文化的底层逻辑是：当目标远超行业常规（电动车取代燃油车、火箭回收复用、脑机接口），常规节奏根本不可能追上。只有把组织推到极限，才能在极限处找到突破口。马斯克自己先做到——睡工厂地板三年、每周工作80-100小时、Model 3产能地狱期亲自驻厂——然后用同样的标准要求所有人。

核心公式：**极限使命 → 极限紧迫 → 极限筛选 → 极限产出 → 极限代价**

## 关键模块

### 模块1：极限紧迫信念——舒适是敌人

- 定义：将"改变世界"的使命与"极限工作强度"绑定，形成不容质疑的信念体系
- 输入：超越行业常规的使命目标
- 输出：全员对极限工作强度的合理化认同
- 关键动作：
  - 使命绑定：不是"公司要求你加班"，是"改变世界需要你加班"——把工作强度从管理要求升维为使命召唤
  - "没有人能靠朝九晚五、周末双休改变世界"——不是建议，是判断标准
  - "创业是嚼玻璃+凝视深渊"——提前告知痛苦，筛选愿意承受痛苦的人
  - 紧迫感制度化：不是阶段性冲刺，是常态化的极限节奏
- 常见误区：以为极限紧迫只是"加班文化"——加班文化是压榨，极限紧迫是信念驱动的自我燃烧；以为信念可以替代制度——信念让人愿意燃烧，但不能解决燃烧后的灰烬

### 模块2：CEO以身作则——先燃烧自己

- 定义：马斯克用自身行为设定组织节奏的上限，所有人看到的不是"老板要求我拼命"，是"老板比我还拼命"
- 输入：危机/瓶颈/产能地狱
- 输出：CEO行为成为组织节奏的锚点
- 关键动作：
  - 睡工厂地板三年：不是偶尔加班到深夜，是长期把床搬进工厂——物理距离归零，管理响应时间归零
  - 每周80-100小时工作：是常人工作量的2-2.5倍，用数字定义"极限"
  - Model 3产能危机期亲自驻厂：2018年Fremont工厂，马斯克睡在办公桌下，亲自排查产线问题——CEO变成一线工程师
  - 技术管理者须20%时间参与一线编码：管理者不能脱离技术，必须保持对一线的真实感知——用代码说话，不用PPT说话
- 常见误区：以为以身作则只是"做样子"——马斯克是真的睡地板、真的写代码，不是拍照打卡；以为CEO做到就能要求所有人做到——CEO有股权激励和使命感，普通工程师没有对等回报

### 模块3：残酷筛选——不合格立即开除

- 定义：用持续高压环境做筛选器，扛不住的、不够好的、不够快的，立即清除
- 输入：员工在高压下的表现
- 输出：即时淘汰决策
- 关键动作：
  - "不合格者立即开除"：不需要PIP，不需要改进计划，不需要警告——不合格就是不合格
  - 持续筛选而非一次性筛选：不是入职时筛选一次就完，而是每天都在筛选——高压环境本身就是筛选器
  - 筛选标准不是"做错了什么"，是"够不够硬核"——能力够但抗压不够，同样被淘汰
  - 马斯克亲自参与关键岗位的淘汰决策——不是HR流程，是CEO直接判断
- 常见误区：以为残酷筛选=随意开除——Tesla的筛选有明确标准（硬核、抗压、产出），不是随机淘汰；以为残酷筛选只针对底层——高管同样被筛选，多名高管因"不够硬核"离职
