# 销售 · 转化与渠道

> 销售的终极命题：让潜在客户变成付费客户——从线索到合同，从谈判到渠道，从个人技巧到组织体系

## 核心理念

销售学科解决的核心问题是：**如何系统化地将潜在需求转化为付费合同？**

横跨组织实践与个人理论，销售方法论呈现四条主线：第一条是**大客户流程线**——华为LTC用端到端流程管理B2B复杂销售，从线索到回款全链路可追踪；第二条是**渠道体系线**——OPPO/vivo用三级分销+利益共同体构建20万+门店的渠道壁垒，美团用标准化地推铁军实现线下商户的快速覆盖；第三条是**对话技巧线**——拉克姆SPIN用提问引导客户发现隐性需求，沃斯用谈判策略在对抗中创造价值；第四条是**组织管理线**——罗斯SDR模式用角色分离和漏斗数学实现可预测收入，温伯格用一号计划+销售文化管理销售团队。

四条主线的根本张力在于：大客户流程线追求"可控可预测"，渠道体系线追求"广覆盖深绑定"，对话技巧线追求"以客户为中心的说服力"，组织管理线追求"从艺术到工程的系统化"。大客户销售是"狙击手"模式——精准但慢，渠道销售是"机枪手"模式——覆盖广但浅，对话技巧是"单兵作战"模式——依赖个人能力，组织管理是"系统作战"模式——依赖流程和分工。

## 关键模块

### 模块1：大客户销售流程

- 定义：B2B复杂销售的端到端流程管理，从线索到回款全链路可追踪
- 输入：营销线索(MTL产出) + 客户需求 + 解决方案
- 输出：签约合同 + 回款 + 客户关系
- 关键动作：
  - LTC全流程：线索管理→机会点验证→标前引导→制定策略→投标/谈判→签单→交付→回款——华为的B2B销售流程
  - 铁三角协同：AR(客户经理)+SR(解决方案专家)+FR(交付专家)——客户、方案、交付三维协同
  - 机会点分级：A/B/C/D四级——资源投入与机会质量匹配
  - 销售项目制：每个大客户机会作为一个项目运作——有PM、有计划、有评审
- 常见误区：流程过重变形式主义——LTC在简单销售场景过重；铁三角变三不管——角色不清导致互相推诿；只考核签单不考核回款——坏账侵蚀利润

### 模块2：渠道体系与下沉

- 定义：通过代理商网络和利益绑定实现广域市场覆盖
- 输入：品牌产品 + 渠道政策 + 代理商网络
- 输出：广域市场覆盖 + 渠道壁垒
- 关键动作：
  - 三级分销：省代→市代→县代——OPPO/vivo的渠道骨架，利益共享而非层层加价
  - 利益共同体：品牌方承担更多风险（不压货/价格保护/滞销退换）——换取代理商深度绑定
  - 渠道下沉：从一线城市到乡镇六级覆盖——20万+门店的触达网络
  - 地推铁军：标准化执行+强管控——美团的线下商户拓展模式，铁军执行而非伙伴共生
  - 渠道选择：利益共同体(伙伴共生) vs 标准化铁军(强管控) vs 直营(品牌控制)——根据品类和阶段选择
- 常见误区：认为三级分销=层层加价——OPPO/vivo的利润来自品牌让利而非终端加价；认为地推可以无限扩张——地推成本随覆盖密度递增；忽视渠道成本——渠道壁垒的代价是利润空间被挤压

### 模块3：销售对话与谈判

- 定义：通过提问和谈判技巧引导客户决策
- 输入：客户需求（显性+隐性）+ 竞争态势 + 谈判筹码
- 输出：客户承诺 + 合同条款
- 关键动作：
  - SPIN四类提问：Situation(现状)→Problem(问题)→Implication(影响)→Need-payoff(需求-回报)——拉克姆的顾问式销售方法；核心是让客户自己说出需求而非销售推销
  - 沃斯谈判策略：镜像模仿+标注情绪+校准型问题+让对方说"不"——用战术性共情在对抗中创造价值
  - 价值主张设计：从产品特性到客户价值的翻译——客户买的不是功能，是结果
  - 异议处理：理解异议背后的真实关切——价格异议往往不是价格问题
- 常见误区：SPIN机械套用——四类提问是框架不是脚本，机械套用让客户感觉被审讯；认为谈判=对抗——沃斯的核心是"战术性共情"，理解对方才能影响对方；过早报价——在建立价值之前报价，价格永远太高

### 模块4：销售组织与预测

- 定义：通过角色分离、漏斗数学和系统管理实现可预测的销售产出
- 输入：销售流程 + 团队规模 + 历史数据
- 输出：可预测的收入 + 高效的销售组织
- 关键动作：
  - SDR/AE/CSM角色分离：SDR找线索→AE成交→CSM留存——罗斯的专业化分工；月新增线索>200且客户池>500时建立SDR
  - 漏斗数学：可预测收入=线索量×转化率1×转化率2×客单价——从目标收入倒推需要的线索量
  - 一号计划：目标客户+价值主张+领地划分+活动指标+里程碑——温伯格的销售管理核心
  - 销售文化：结果导向+透明诚实+持续学习+团队优先+高标准——文化>流程
- 常见误区：过早分离SDR——规模不够时协作成本>效率提升；只考核线索量不考核质量——1000个低质量线索不如100个高质量；微观管理或放任——两种极端都不创造业绩

### 模块5：销售范式选择

- 定义：根据客户类型、产品复杂度和组织规模选择合适的销售范式
- 输入：客户类型 + 产品复杂度 + 组织规模 + 销售周期
- 输出：销售范式组合策略
- 关键动作：
  - B2B大客户 vs B2C大众：大客户用LTC+SPIN（流程+深度对话），大众用渠道+地推（广覆盖+标准化）
  - 顾问式 vs 交易型：高价值解决方案用SPIN（让客户自己发现需求），标准化产品用SDR（批量触达快速筛选）
  - 流程驱动 vs 关系驱动：华为LTC是流程驱动（可控可复制），OPPO/vivo渠道是关系驱动（深度绑定不可复制）
  - 伙伴共生 vs 铁军执行：OPPO/vivo代理商是伙伴共生（利益共同体），美团地推是铁军执行（标准化管控）
- 常见误区：在B2C场景生搬硬套LTC——流程过重且不必要；在复杂大客户销售用SDR——SDR无法处理长决策链；认为一种范式走天下——不同客户类型需要不同范式

## 决策启发式

| 场景 | 判断规则 | 来源 |
|------|---------|------|
| 销售流程选择 | 如果客户决策链>3人且周期>3月→LTC大客户流程 | 华为LTC |
| 渠道模式选择 | 如果下沉市场是核心→利益共同体渠道；如果标准化覆盖→地推铁军 | OPPO/vivo vs 美团 |
| 是否建立SDR | 如果月新增线索>200且客户池>500→建立SDR | 罗斯SDR |
| 销售对话方法 | 如果客户有隐性需求→SPIN；如果客户需求明确→直接价值主张 | 拉克姆SPIN |
| 谈判策略 | 如果对方有对抗性立场→战术性共情；如果合作氛围→直接共创 | 沃斯谈判 |
| 销售管理重心 | 如果团队没有一号计划→先做计划；如果计划有了但执行差→管会议和辅导 | 温伯格管理 |
| 代理商选择 | 选本分的人，不选能力最强但不本分的人 | 段永平 |
| 收入预测 | 如果有3个月以上转化率数据→预测可靠；否则→不可靠 | 罗斯漏斗数学 |
| 新人评估 | 如果90天后仍不能独立产出→可能招错了人 | 温伯格90天 |
| 渠道冲突 | 线上线下同价同利，不让线上侵蚀代理商利益 | OPPO全渠道策略 |

## 适用场景

### 最适合

- B2B复杂解决方案销售——LTC+SPIN+铁三角组合
- C端下沉市场覆盖——三级分销+利益共同体
- B2B SaaS标准化销售——SDR+AE+CSM角色分离
- O2O本地生活商户拓展——地推铁军+标准化执行
- 新任销售经理团队管理——一号计划+销售文化

### 不适合

- 纯线上自助购买——不需要销售流程
- 垄断市场——没有竞争就不需要销售技巧
- 产品驱动增长(PLG)——用户自己来，不需要销售外联
- 强合规行业——授权和灵活决策可能违反监管

- [ ] 大客户销售是否有端到端流程——从线索到回款全链路可追踪
- [ ] 渠道政策是否以利益共享为核心——而非压价博弈
- [ ] 销售对话是否以客户需求为中心——SPIN式提问而非推销
- [ ] 是否评估了SDR模式的适用性——线索量和客户池是否足够

- [ ] 销售会议是否驱动行动——而非变成汇报会
- [ ] 新人是否有90天框架——学习→实践→独立
- [ ] 是否建立了高绩效销售文化——结果导向+透明诚实
- [ ] 收入预测是否基于漏斗数学——而非拍脑袋

## 诚实边界

1. **B2B偏向性**：LTC、SPIN、SDR等方法论天然偏向B2B场景。C端消费品的销售逻辑完全不同——决策链短、情感驱动、品牌影响大，B2B方法难以直接应用。
2. **渠道模式的不可复制性**：OPPO/vivo的20万+门店耗时十余年建立，渠道壁垒的"时间成本"被严重低估。新品牌试图复制这个模式时，往往发现时间窗口已关闭。
3. **SDR模式的衰退趋势**：罗斯的冷邮件2.0在2011年高效，但2020年代后冷邮件回复率持续下降。AI生成邮件进一步稀释差异化效果。SDR模式需要适配新的触达方式。
4. **SPIN的隐性前提**：SPIN假设客户有隐性需求且愿意被引导。但在很多交易型销售中，客户需求明确、决策快速，SPIN的深度对话反而浪费时间。
5. **地推模式的成本陷阱**：美团地推铁军在扩张期高效，但地推成本随覆盖密度递增。当低线城市的商户密度不足以支撑地推成本时，模式不可持续。
6. **销售文化的慢变量特性**：温伯格说"文化>流程"，但文化需要数月甚至数年建立。急需业绩提升时，先落地流程再逐步塑造文化可能更实际。
7. **谈判策略的情境依赖**：沃斯的谈判策略来自FBI人质谈判场景，在商业谈判中需要大幅适配。商业谈判的"对抗性"远低于人质谈判，"战术性共情"的力度需要调整。
