# 真人口播改成线稿动画讲解

- **作者**：Axton (@AxtonLiu)
- **原帖 / 来源**：https://x.com/AxtonLiu/status/2102827887732932956
- **分组**：2.2 带结构的讲解与营销片模板

## 说明

条件：干净的 Claude Code、safe mode、effort high，不加载任何 Skill，也不给外部素材。按字幕切了约 30 个镜头，用时 28 分 53 秒，全程没有人工介入。

## 提示词（提示词原文）

```text
把 short-1.mp4 做成一条新的竖屏短片 short-1-v5.mp4：

1. 我的人像缩小成右下角的圆形画中画，能看清我在讲话，不遮字幕。
2. 主画面换成一段动画 B-roll，跟着我讲的内容走：我说到哪个概念，画面就画哪个概念。风格轻松有趣，线稿动画就可以，不要写实。
3. 原声、原字幕、时长都不变。
```

## 怎么测

1. 在 Claude Code 里新建一个空目录，模型选 Opus 5.5，effort 建议 high 或更高。
2. 粘贴上面的提示词，替换方括号或 `<inputs>` 里要你填的内容。
3. 本机准备好 Node、Chrome 和 FFmpeg，让它自己渲染成 MP4。只在网页对话里跑的话，可以预览 HTML 后录屏。
