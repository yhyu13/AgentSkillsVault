## Distilly でできること

Distilly は素材（メッセージ、ドキュメント、インタビュー、公開情報）とあなたの説明から、出典に基づく Person Profile を作り、Agent Skill としてパッケージします。

- 3 種類の人物: **colleague**（同僚、メンター）、**relationship**（パートナー、家族、友人）、**celebrity**（著名人、架空のキャラクター）。
- 8 つのエージェントホストで動作します: Claude Code、Hermes Agent、OpenClaw、Codex、DeepSeek Harness、Pi coding agent、Grok Build、OpenCode。
- データソース: Lark、DingTalk、Slack、WeChat、X の公開投稿、PDF、メール、Markdown。

## インストール

対応するエージェントホストで次のように送信します:

> `https://github.com/titanwings/distilly` から Distilly をインストールし、このホストで認識されるか確認して。

または、ホストの Skills ディレクトリに直接クローンします:

```bash
git clone https://github.com/titanwings/distilly <DISTILLY_SKILL_DIR>
```

## 使い方

エージェントに *「Distilly で `<人物>` の Person Profile を作って」* と伝えます。自分のプロフィールなら *「Distilly で私のプロフィールを設定して」*。
