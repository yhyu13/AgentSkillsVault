原始需求信息如下

## 风格要点速查

- 标题：`主题 + 进度（MM/DD更新）`
- 开篇：OKR 简述表 + 完整版链接
- 章节：中文序号（一、二、附）+ 加粗目标陈述句
- 表格七列：对应KR / 行动 / 状态 / 优先级 / 时间 / 交付物 / 备注
- 状态三符号：✔ 已完成 / 🔄 进行中 / ⬜ 未开始
- 里程碑分隔行：加粗"以上完成后…… 下面都是改进项"
- 备注：一句话，记阻塞 / 决策 / 风险 / 方法论调整
