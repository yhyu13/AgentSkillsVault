# 三个标杆案例拆解

> 基于 2026 年原文的案例 + 提示词工程原理,逆向拆解三个标杆场景,展示"万能公式 + 质感技巧"如何在真实场景中落地。

---

## 案例 1:情感文案可视化

### 场景
- **触发**:"我想你了" — 四个字,想做一段 5-10 秒的情感视频,投放到抖音/朋友圈

### 原文启示
- 文生视频(T2V)的典型适用场景:情感文案可视化

### 反向工程出的提示词

```
主体:一位 25 岁亚洲女性,穿着米白色棉麻长裙,黑色长发
动作:站在窗边,抬头望向远方,手指轻触窗玻璃,眼眶微红
环境:秋日黄昏,柔和逆光,窗外银杏叶金黄,室内木质家具
情绪:思念、克制、温柔的忧伤
镜头:固定机位 + 中景 + 慢推,浅景深
特殊效果:丁达尔效应光柱,光斑散景
风格:宫崎骏的梦境风
规格:1080p,24fps,无水印
```

### 七要素逐一对应

| 要素 | 词条 | 不写会怎样 |
|------|------|-----------|
| 主体 | "25 岁亚洲女性,米白色棉麻长裙,黑色长发" | 模型随机出欧式面孔,失情感代入 |
| 动作 | "站在窗边,抬头,手指轻触窗玻璃,眼眶微红" | 动作不清,观众感受不到"情绪动作" |
| 环境 | "秋日黄昏,逆光,银杏叶,木质家具" | 失秋日思念的"视觉锚" |
| 情绪 | "思念、克制、温柔的忧伤" | **关键 — 没这句就是空壳动作片** |
| 镜头 | "固定机位 + 中景 + 慢推,浅景深" | 镜头乱晃,失细腻感 |
| 风格 | "宫崎骏的梦境风" | 风格漂移 |
| 规格 | "1080p,24fps" | 输出尺寸不可控 |

### 进阶优化(加 3 个气质词):
- 声音:"远处风铃轻响,风吹过银杏叶的沙沙声"(触发观众听觉想象)
- 节奏:"镜头慢推,女主角动作缓慢,如时间凝固"
- 情感升华:"画面里有一封未寄出的信,压在窗台上"

### 失败预防
- 动作过大 → 加"静态姿态,缓慢呼吸"约束
- 人物变形 → 用 I2V 模式(先 MJ 出图,再图生视频)

## 案例 2:产品开箱动效

### 场景
- **触发**:某品牌新品上市,需要 1 段 5-10 秒的开箱动效视频,投放到电商详情页

### 原文启示
- 图生视频(I2V)的典型适用场景:产品宣传片(手机开箱动效)

### 推荐工作流
```
Step 1  Midjourney/DALL·E 3 出产品静帧(纯色背景,产品占画面 60%)
Step 2  把静帧导入 TapNow / Runway 图生视频
Step 3  配提示词描述动作
Step 4  后期叠加音效 + 字幕
```

### 提示词(图+文混合模式)
```
(图像输入):一张高端手机产品图,纯白背景,产品占画面中央

(文字输入):
主体:同一款高端手机,纯白机身,金属反光
动作:缓慢 360 度旋转悬浮,周围有金色光斑散景
环境:纯白背景,渐变至浅灰
情绪:高端、轻奢、礼物感
镜头:微距 + 360 度环绕运镜
特殊效果:金属反光,丝绸光泽,光斑散景,极浅景深
风格:苹果广告风
规格:4K,1080p,无水印
```

### 关键决策
- 用 I2V 而非 T2V:产品外观必须精准,不能随机生成
- 用"一画布"工作台:出图→出片→加字幕在同页面完成
- 用 4K 输出:电商详情页需要高分辨率适配大屏

### 失败预防
- 产品占比过小 → 提示词强调"产品占 60%"
- 背景杂乱 → 提示词强调"纯白背景"
- 镜头太快 → 提示词强调"缓慢 360 度旋转"

## 案例 3:末日史诗感短剧分镜

### 场景
- **触发**:15 秒的"末日女战士"主题短片,投放到 B 站/YouTube,作为系列片头

### 原文启示(直接取自原文)
> 用户输入:"一名戴墨镜的女战士站在废墟城市中央,远处爆炸火光映照她的脸,风吹动披风"
>
> 结果:生成一段长达 15 秒的"末日史诗感"视频,镜头缓慢推进,披风飘动自然,眼神坚定有力,极具电影张力。

### 反向工程出的完整提示词
```
主体:一名 28 岁亚洲女战士,戴着战术墨镜,身穿黑色紧身战斗服,披风长及脚踝,手持长刀
动作:站在废墟中央,身体微微前倾,披风被风吹起飘动,墨镜反射远处火光
环境:废墟城市,远处有爆炸火光,烟尘弥漫,天色暗沉
情绪:坚定、孤独、史诗感、不屈
镜头:慢速推进,中景→中近景,低角度仰拍
特殊效果:丁达尔效应光柱,爆炸火光反射,风沙飞溅,胶片颗粒
风格:扎克·施奈德式油画质感,扎导 DC 电影风
规格:4K 21:9 电影画幅,24fps
```

### 七要素逐一对应

| 要素 | 词条 | 不写会怎样 |
|------|------|-----------|
| 主体 | "28 岁亚洲女战士,墨镜,黑色战斗服,长刀" | 主体不立体,失"战士"辨识度 |
| 动作 | "身体前倾,披风飘动,墨镜反射火光" | 失动态感 |
| 环境 | "废墟城市,爆炸火光,烟尘,天色暗沉" | 失末世氛围 |
| 情绪 | "坚定、孤独、史诗感、不屈" | **关键 — 没这段就是普通动作片** |
| 镜头 | "慢推,中景→中近景,低角度仰拍" | 失影视感 |
| 风格 | "扎克·施奈德式油画质感" | 失史诗电影辨识度 |
| 规格 | "4K 21:9,24fps" | 失电影画幅 |

### 进阶优化(加 3 个气质词):
- 时间锚点:"黄昏时刻最后一缕阳光"
- 声音暗示:"远处爆炸声回荡在废墟中"
- 情绪升华:"战斗服的破损显示她经历过无数战斗"

### 失败预防(原文口径)
- **镜头缓慢推进** + **披风飘动自然** = 影视感关键
- 镜头关键词必须加,否则就是"动图"不是"短片"

### 适用平台
- Sora(时空一致性最好,适合 15 秒长片)
- Kling 2(角色一致性 + 长动作链)
- TapNow 一画布(分段生成 + 拼接)

## 三个案例的对比

| 维度 | 情感文案 | 产品开箱 | 末日短剧 |
|------|---------|---------|---------|
| **模式** | T2V | I2V / TI2V | TI2V |
| **出片时长** | 5-10 秒 | 5-10 秒 | 15 秒 |
| **核心要素** | 情绪词 + 镜头词 | 外观精准 + 材质词 | 输入优先级 + 风格词 |
| **失败预防重点** | 主体动作过大 | 产品占比过小 | 时空一致性 |
| **平台推荐** | TapNow 文生视频 | TapNow 图生视频 | Sora / Kling |
| **质感词数** | 5-7 | 5-7 | 7-10(更多 = 更史诗) |

> 📌 **规律**:**质感词数量 × 平台能力 × 模式选择 = 输出质量**。情感文案可少(观众要求低),史诗级必须多(观众要求高)。
