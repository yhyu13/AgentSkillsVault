# AIGC 视频生成创作手册 (aigc-video-creation)

一份**领域知识 + 操作框架**型 skill。封装 AIGC 视频从原理认知、平台选型、提示词工程、流程管理到审美进阶的全链路,让一个完全没碰过 AI 视频的创作者按这套手册能稳定出片。知识源是 2026 年一篇以 TapNow 为载体、覆盖原理→工具→提示词→审美→结语的中文 AI 视频深度长文。

继承 `content-craft` 的"准确 / 有用 / 易读"基线 — 本 skill 负责**AIGC 视频这条具体手艺**,不负责通用写作风格(用 `style-cn-platform-tutorial`)也不负责发布(用 `blog-to-*`)。

## 适用场景 vs 不适用

| 适用 | 不适用 |
|------|--------|
| 想从零开始用 AI 生成视频 | 真人拍摄、传统镜头过渡 |
| 选 AI 视频平台 / 工具 | 选直播/推流/编码工具 |
| 写 AIGC 视频提示词 | 写摄影分镜脚本 |
| AI 视频翻车了(变形/闪烁/风格漂移) | 真人短片剪辑翻车 |
| 提升 AI 视频"电影感" / 审美 | 写剧本/写分镜 |
| 用 TapNow 类"一画布"工作台产出 | 简单的 GIF/动图生成 |

## 三大认知锚点(在动手前先想清楚)

1. **AI 视频 = 内容理解 + 图像生成 + 动态渲染 三步走**(扩散模型生成图像,LLM 解析语义,CV/动态建模生成连贯帧)。它不是"按帧渲染",而是"理解意图→生成关键帧→动态插值"。
2. **"高质量" = 模型能力 × 参数控制 × 流程管理**。模型再强,提示词不到位 + 流程不拆分,出来的也是废片。
3. **真正的护城河是审美,不是技术**。技术决定你能做什么,审美决定你做成什么样。

## 一、三种生成模式:选对入口决定 80% 出片质量

| 模式 | 一句话 | 优势 | 劣势 | 推荐场景 |
|------|--------|------|------|----------|
| **文生视频 (T2V)** | 纯文字 → 视频 | 零素材,灵感秒验证 | 构图自由度低,易畸形/逻辑乱 | 情感文案可视化、科普短片、微剧情、氛围感短视频 |
| **图生视频 (I2V)** | 一张图 → 视频 | 首帧 100% 可控,风格统一,质感强 | 需先有高质量静帧(建议 MJ / DALL·E 3 + I2V 模块) | 产品开箱、品牌片、短剧分镜、艺术短片 |
| **图+文混合 (TI2V)** | 一图 + 一段描述 → 视频 | 既保构图又给动态,**2026 年最推荐** | 需协调图与文的权重 | 剧情类、品牌视觉、影视概念设计、自媒体剧情号 |

**默认决策树**:

```
需要精确构图?            是 → I2V(图生视频)
                        否 → 进入下一问
需要强叙事/剧情张力?     是 → TI2V(图+文混合)
                        否 → T2V(文生视频,简单快)
有现成的高质量首帧?      是 → I2V 或 TI2V
                        否 → 先用 MJ/DALL·E 出图 → I2V
```

## 二、平台选型框架:六维评估,不见工具先卡标准

不要"看哪个图最炫"先选谁 — 先按下面六维评分:

| 维度 | 评估问题 | 加分项 |
|------|---------|--------|
| **界面设计** | 一张画布搞定全流程 vs 需要跳转? | 一画布 + 无跳转 |
| **生成速度** | 1080P 出片时间 | 30 秒 ~ 2 分钟 |
| **模型多样性** | 内置多少主流模型,能否切换 | 5+ 模型且可一键对比 |
| **提示词辅助** | 是否给关键词建议/补全 | 自动补动作/环境/镜头 |
| **导出选项** | 分辨率/帧率/水印/音频 | 4K/60fps/无水印/带音频 |
| **协作能力** | 是否支持多人编辑/版本管理 | 团队项目级 |

**判据**:综合效率 × 可控性 × 用户体验 三个维度,"既要快又要好"的创作者优先选"一画布"工作台(类 TapNow)而非点状工具。

> ⚠️ 平台中立声明:本 skill 以 TapNow 为案例载体讲解,因其文档结构完整且覆盖三种生成模式。具体平台选型请按上表自评,本 skill 不替任何具体工具站台。

## 三、万能提示词公式

```cobol
【主体】 + 【动作】 + 【环境】 + 【情绪/氛围】 + 【镜头语言】 + 【风格参考】 + 【输出规格】
```

### 低效 vs 高效对比

```
❌ 低效:"一个女孩在公园里走路。"

✅ 高效:"一位身穿白色连衣裙的亚洲女孩,在春日午后的小径上缓步前行,
        微风轻拂她的长发,花瓣随风飘落,背景是盛开的樱花树,
        柔和逆光,慢速推进镜头,电影感,日本动画风格,4K 超清"
```

七要素逐项拆解:

| 要素 | 作用 | 不写会怎样 |
|------|------|-----------|
| **主体** | 锚定画面焦点(谁/什么) | 模型随机填,容易出畸形 |
| **动作** | 决定动态节奏 | 画面死板或乱动 |
| **环境** | 决定光线/空间/场景 | 主体悬空、无背景感 |
| **情绪/氛围** | 给作品灵魂 | 看起来"假"但不感人 |
| **镜头语言** | 决定影视感 | 看起来像"动图"而不是"短片" |
| **风格参考** | 锁定美学方向 | 风格漂移 |
| **输出规格** | 锁定画质/比例 | 输出尺寸不可控 |

## 四、9 个质感提升提示词技巧

按场景挑用,不必全上(全文命中 5-7 个即足够):

| # | 技巧 | 触发词例 | 适用场景 |
|---|------|---------|----------|
| 1 | **镜头语言** | "中景跟拍"/"广角俯拍"/"手持晃动感" | 任何视频 |
| **2** | **材质描述** | "丝绸般光泽"/"金属反光"/"毛绒质感" | 产品片、质感大片 |
| **3** | **运动节奏** | "缓慢呼吸般移动"/"突然停顿"/"急速旋转" | 剧情片、情绪片 |
| **4** | **光影特征** | "侧逆光剪影"/"丁达尔效应"/"霓虹灯晕染" | 氛围片、品牌片 |
| **5** | **时间状态** | "黄昏时刻"/"暴雨前的寂静"/"午夜三点" | 叙事类 |
| **6** | **声音暗示** | "脚步声回响空旷走廊"/"风铃轻响" | 故事片(用于触发观众联想) |
| **7** | **艺术家风格** | "宫崎骏笔下的梦境"/"大卫·林奇式迷幻" | 风格化短片 |
| **8** | **缺陷感** | "轻微胶片颗粒"/"老电影划痕" | 复古/纪实风 |
| **9** | **情绪基调** | "孤独感"/"希望之光"/"压抑中的挣扎" | 一切有灵魂的作品 |

> 📌 进阶:建立自己的"提示词库",按类型分类(爱情/悬疑/科幻/古风/赛博朋克),每次创作微调复用。

## 五、6 类常见翻车与避坑

| 问题 | 根因 | 解决方案 |
|------|------|----------|
| 人物变形/手部错位 | 提示词模糊 + 动作幅度过大 | 限制动作幅度,加"稳定姿态"关键词 |
| 画面闪烁/跳帧 | 时空一致性差 | 用"分镜生成"模式,避免长视频一次性生成 |
| 物体忽大忽小 | 缺乏空间锚点 | 加"固定位置"/"前景遮挡"描述 |
| 风格不统一 | 模型混用或参数冲突 | 固定单一模型,统一风格设定 |
| 生成速度慢 | 画面复杂度高 | 先生成低分辨率草稿,再升级到 4K |
| 无法商用 | 忽视版权协议 | 查看官方授权范围,优先"可商用模型" |

### 终极心法:**不要追求一步到位**

```
策略:分段生成 + 后期合成
1. 先做分镜(每段 3-5 秒)
2. 每段单独提示词精调
3. 后期拼接 + 调色 + 加字幕/音乐
```

## 六、5 步审美进阶法(从"会生成"到"懂创作")

"有灵魂的 AI 视频"四要素:

- **情绪共鸣**:观众感受到悲伤/希望/震撼
- **叙事逻辑**:有开头 / 发展 / 高潮 / 结尾
- **视觉节奏**:镜头快慢、色温冷暖匹配情绪
- **文化深度**:融入时代 / 地域 / 精神内核

### 五步培养法

1. **多看经典影视**:研究镜头语言、剪辑节奏、光影运用。参考片单:《银翼杀手 2049》《寄生虫》《花样年华》《2001 太空漫游》。
2. **拆解优秀 AI 视频**:在 YouTube/B 站搜 "AI 短片"/"AI 电影",拆解其结构 + 镜头选择 + 风格来源。
3. **建立视觉语料库**:按风格收集图集(国风 / 赛博朋克 / 极简主义 / 胶片复古),做自己的 mood board。
4. **练习分镜脚本写作**:哪怕只是文字描述,也要训练"画面思维" — 一个镜头=一个时间段的视觉选择。
5. **定期反思作品**:问自己三个问题 — "这个视频让我感动吗?它想表达什么?哪一帧是最有张力的?"

### 审美口诀

> **技术决定你能做什么,审美决定你做成什么样。**

## 七、推荐工作流(TapNow 类"一画布"平台示例)

```
Step 1  选生成模式    T2V / I2V / TI2V 三选一(按决策树)
Step 2  写提示词      套用万能公式 + 挑 5-7 个质感技巧
Step 3  选模型        按风格选(Sora-style / Kling / Seedance / 自研)
Step 4  试生成        先生成低分辨率草稿,确认构图
Step  5  精调 + 重生   锁定参数 + 微调提示词
Step  6  分段拼接      长片按 3-5 秒分段,后期合成
Step  7  后期          防抖 + 调色 + 字幕 + 音乐 + 音效
Step  8  导出          按发布平台选分辨率/比例/水印策略
```

## 八、平台无关的"五条死线"(选型 checklist)

写 AI 视频选题/做平台对比时,按这五条卡:

| # | 死线 | 含义 |
|---|------|------|
| 1 | **是否一画布** | 流程是否需要跳转?跳转=摩擦 |
| 2 | **模型可切换** | 是否能一键试不同模型?否则被单一模型绑架 |
| 3 | **提示词辅助** | 是否给关键词补全?否则新手出片效率差 |
| 4 | **商用授权** | 输出能否商用?水印/分辨率/授权范围 |
| 5 | **协作版本管理** | 是否支持多人/版本?否则团队项目难做 |

## 已知局限

- **不替代摄影/导演**:AI 视频擅长"短片级"内容,长片(> 5 分钟)、复杂剧情、多角色交互仍是传统制作的地盘。
- **平台绑定风险**:本 skill 以 TapNow 为案例,但平台能力日新月异;遇到具体问题请优先看官方文档。
- **审美判断有主观性**:本 skill 提供的审美口诀是普适指引,不替代个人风格的形成。
- **提示词上限**:AI 视频对"超现实物理"(流体、超长动作链)的还原仍不稳定;超出能力时降级为 I2V + 后期。
