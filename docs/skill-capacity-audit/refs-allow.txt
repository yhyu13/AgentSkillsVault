# refs-allow.txt — 允许的"包外引用"，check_refs.py 的唯一豁免来源。
#
# 为什么需要：SKILL.md 里的 `docs/...`、`assets/...` 有两类完全不同的语义——
#   1) 包内载荷（必须存在，缺了就是打包错误）
#   2) 项目侧路径 / 正文里的示范或措辞（本机不该有，也不该算缺陷）
# 这个文件只登记第 2 类，每条必须写理由。新增一行前先确认：删掉它以后
# 使用者会不会真的读不到文件？会，就不要加。
#
# 格式：<skill>|<fnmatch 模式>|<理由>
#       skill 写 * 表示对所有 skill 生效
#
# 用法：py -3 docs\skill-capacity-audit\check_refs.py --root SKILL --jobs 12 --self-check --fail-on-broken
